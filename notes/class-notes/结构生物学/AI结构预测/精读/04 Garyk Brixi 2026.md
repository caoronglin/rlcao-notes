## 一句话结论

在 **9.3 万亿** token、**88 亿亿个核苷酸**上预训练的 **400 亿参数**基因组语言模型 Evo 2，把「序列建模」的尺度从蛋白推到了**全生命域基因组**——它能零样本预测变异效应、生成约 58 万碱基的细菌基因组、并用「莫尔斯码」在实验上写出了可控的染色质开放模式。

## 研究问题

作者的出发点是一个雄心陈述：

> 创建一台能够**跨生命的多样性**设计功能的机器，需要它学习生物复杂性的深层、通才式（generalist）表征。

而要获得这种能力，**训练数据必须覆盖生物多样性的全谱系**——这是本文与此前蛋白语言模型最根本的差别。作者也明确指出，**这类复杂性超出了人类直觉的范畴**，而 AI 提供了一个通用框架，可以利用规模化的数据与算力去发现高阶模式。

**此前 Evo 系列的能力边界**：Evo 1 证明在**原核生物基因组序列**上训练的模型可以建模 DNA、RNA、蛋白质的功能及其互作。Evo 2 要做的，是把这个范式**扩展到真核基因组的尺度与复杂度**——作者列出了五项需要推进的方面：数据策展、模型架构、大规模预训练、**先进的可解释性方法**、以及推理时的预测与生成方法。

## 方法与数据

### 模型与训练数据

| 项 | Evo 2 7B | Evo 2 40B |
| --- | --- | --- |
| 参数 | **70 亿** | **400 亿** |
| 训练 token | **2.4 万亿** | **9.3 万亿** |

**训练数据集 OpenGenome2**：由策展的、非冗余的核苷酸序列数据汇编而成，来自**细菌、古菌、真核生物与噬菌体**，总计**超过 88 亿亿个核苷酸（8.8 trillion nucleotides）**。

### 两阶段训练策略（Fig.1c–e）

**第一阶段（预训练）**：上下文长度 **8 192 token**，数据加权聚焦于**基因窗口（genic windows）**，以学习功能性遗传元件。

**第二阶段（中期训练，midtraining）**：多阶段地把上下文长度**扩展到 100 万 token**，以学习跨长基因组距离的元件间关系。

作者指出这与自然语言的最佳实践一致——**先在较短上下文下预训练能同时提升效率与整体模型质量**。

### 架构：StripedHyena 2

一种卷积多混合（multi-hybrid）架构，结合**三种不同变体的输入依赖卷积算子**与注意力机制（Fig.1f）。它按序列长度组织为：

| 层级 | 算子 |
| --- | --- |
| 短程 | 显式（explicit, **SE**）hyena 算子 |
| 中程 | 正则化（regularized, **MR**）hyena 算子 |
| 长程 | 隐式（implicit, **LI**）hyena 算子 |

**关键性能指标**：
- 相对高度优化的 Transformer 基线与前代混合模型，StripedHyena 2 吞吐显著更高——**在 400 亿参数规模、100 万上下文长度下最高达 3 倍加速**（Fig.1g）；
- 相对 StripedHyena 1 与 Transformers，**改善了 DNA 上的损失缩放**，从而在同等训练数据下获得更低的预测误差，并更高效地使用算力。

### 上下文能力的验证

- **长上下文长度扩展**在模型规模与上下文长度上都带来了损失改善（Fig.1h）；
- **"大海捞针"（needle-in-a-haystack）合成任务**（Fig.1i）：Evo 2 能在 **100 万碱基**的随机 DNA 中定位并预测一段特定 **100 碱基**序列（针）的值。作者明确称这是一个**合成的质量检查**，用于验证模型能按预期从完整上下文窗口中检索信息。

### 生物安全：数据排除

> 与 Evo 1 一样，**我们出于生物安全目的，将感染真核宿主病毒的基因组序列排除在训练数据之外。**

作者**验证了这一排除的效果**：在真核病毒的基因组序列上困惑度很高，表明模型在该领域的语言建模能力很差。

## 主要结果与关键数字

### （一）模型「学到了进化约束」——零样本预测能力

**（1）起始密码子与翻译起始信号（Fig.2b）**

在蛋白编码基因起始密码子周围的基因组序列中逐位置引入突变，发现：

- 原核与真核生物中**起始密码子内的突变都引起强烈的似然变化**；
- 随后出现**三碱基周期性模式，反映三联体密码子**，其中**摆动位置（wobble position）**的突变对似然影响较低；
- 在编码区（CDS）**上游观察到与已知翻译起始共识序列位置一致的模式**——原核的 **Shine–Dalgarno 序列**、真核的 **Kozak 序列**；
- 终止密码子周围的 SNV 呈现类似模式。

**（2）不同元件中突变类型的影响（Fig.2c,d）**

跨 **20 个原核物种与 16 个真核物种**：

- **非同义突变、提前终止密码子、移码突变**引起的似然变化**远大于同义突变**；
- 非编码区中，**tRNA 与 rRNA 中的缺失**影响**远大于**基因间区及其他非编码位点的缺失——反映这些 RNA 的已知必需角色；
- **40B 模型对 miRNA 与 snoRNA 序列缺失的敏感性高于 7B 模型**；
- Evo 2 还预测**翻译效率较低的密码子似然低于翻译效率较高的密码子**。

**（3）遗传密码的识别（Fig.2e）**

这是一个非常精巧的测试。训练数据中包含使用不同遗传密码的基因组，作者测试了**不同提前终止密码子如何影响那些终止密码子使用方式不同的物种**：

> 模型学会了**标准密码**（终止密码子 TAA、TAG、TGA）、**支原体密码（Code 4，终止密码子 TAA 与 TAG）**与**纤毛虫密码（Code 6，终止密码子 TGA）**之间的区别。当纤毛虫基因组被**人工重编码为标准遗传密码**时，Evo 2 预测来自标准终止密码子的突变有害——**这证明模型依靠序列上下文来确定适用的遗传密码**。

### （二）DMS 相关的性能——一个需要诚实陈述的结果

| 数据类型 | Evo 2 的表现 |
| --- | --- |
| **9 个原核蛋白数据集**、**6 个真核蛋白数据集**、**7 个 rRNA/tRNA/核酶数据集** | 序列似然与多样化的适合度定义相关 |
| 与 **ProGen**（蛋白语言模型）比蛋白 DMS | **有竞争力** |
| 与 RNA 语言模型比 ncRNA DMS | **有竞争力** |
| 与蛋白 DMS 的**最先进方法**比 | **表现不及** |

⚠️ 作者自己指出两点，都必须传达：

> **与观察到的蛋白语言模型趋势一致，Evo 2 在这些适合度预测基准上的性能开始饱和，并且可能在最大的模型规模下反而下降。**

### （三）一个被主动排除的领域

- **感染人类宿主的病毒蛋白**：**Evo 2 似然与病毒蛋白适合度无相关性**（Extended Data Fig. 2b）——与数据排除的预期效果一致；
- **生成人类病毒蛋白**：**即使直接试图引诱一个病毒蛋白，Evo 2 的序列恢复也基本是随机的**（Extended Data Fig. 2c），作者说这**阻止了 Evo 2 无约束地或意外地生成人类病毒蛋白**；
- **人类 mRNA 降解速率**：零样本关联**有限（modest）**。

### （四）外显子分类器（Fig.2g–i）

在 Evo 2 7B 基础嵌入上训练轻量模型，做**单核苷酸分辨率**的外显子标签分类：

- 在**八个留出物种**上，最佳分类器 AUROC 达 **0.91 至 0.99**；
- **优于**在 Nucleotide Transformer 与 Evo 1 嵌入上训练的模型，以及**保守性指标**（局部 GC 含量、PhyloP）分类；
- **优于从头预测的 AUGUSTUS，在所有测试物种上**；
- **优于 SegmentNT，在 SegmentNT 训练集之外的所有物种上**，以及其训练集中三个物种里的一个。

作者由此提出：Evo 2 序列嵌入**结合监督方法可帮助跨多样物种（含非模式生物）的功能注释**。

### （五）基因必需性

- **原核生物与噬菌体**：用提前终止密码子插入的零样本似然打分，Evo 2 **与 Evo 1 表现相似，并优于其他零样本方法**；
- **人类基因必需性（零样本）**：Evo 2 40B **AUROC = 0.66，AUPRC = 0.15**；优于其他基因组语言模型（AUROC 范围 **0.50–0.59**，AUPRC **0.09–0.12**）；处于四个 PhyloP 保守性分数的范围内（AUROC **0.65–0.71**，AUPRC **0.13–0.21**）。**但作者明确说「整体预测性能仍然有限（modest）」。**

### （六）人类变异效应预测——非 SNV 是最大的差异化优势

**（1）ClinVar（Fig.3b,c）**

| 变异类型 | 样本量 | Evo 2 的表现 |
| --- | --- | --- |
| 编码区 SNV | n = 14 319 | 40B 与 7B **有竞争力**，领先包括 ESM-2 在内的零样本方法，但**落后于 ESM-1b、GPN-MSA 与部分 PhyloP 变体** |
| **编码区非 SNV**（插入/缺失） | n = 1 236 | **两个 Evo 2 模型都优于所有其他方法** |
| 非编码区 SNV | n = 34 761 | **Evo 2 40B 在无监督模型中排名第一**，仅落后于监督模型 |
| **非编码区非 SNV** | n = 3 894 | **Evo 2 40B 优于所有测试模型** |

**作者特别指出**：**这些非 SNV 变异根本无法被 AlphaMissense 与 GPN-MSA 等领先模型打分**——因为它们不是单核苷酸变异。这是一个结构性的、AlphaFold 类工具覆盖不到的缺口。

**（2）剪接变异（Fig.3d，SpliceVarDB）**

外显子（n = 1 181）与内含子（n = 3 769）上，**Evo 2 40B 与 7B 均在无监督模型中排名第一**。

- 内含子变异：零样本预测**与监督模型有竞争力**，略落后 SpliceAI 与 CADD，但领先 Pangolin；
- 外显子变异：**落后于专门的监督模型，但优于所有零样本模型**。

**（3）BRCA1 / BRCA2（Fig.3e,i）**

- BRCA1：零样本在编码区 SNV 上表现强，**在非编码区 SNV 上优于所有其他模型**；编码+非编码合并时 7B 与 40B 均优于其他模型——作者认为这提示**跨变异类型的预测是良好校准的**；
- BRCA1 非编码变异（无论靠近还是远离剪接位点）：**Evo 2 40B 优于所有测试模型，包括监督型剪接预测器**；
- BRCA2（近期发布的数据集）：编码+非编码合并时 Evo 2 超过 GPN-MSA 等专门模型，**仅次于监督模型 CADD**。

**（4）监督学习可再大幅提升**

只用 BRCA1 变体训练的**岭回归**模型（输入为 Evo 2 嵌入）：测试集 **AUROC = 0.95，AUPRC = 0.88**，**显著优于 Evo 2 40B 的零样本预测**。

作者系统性地提取了 Evo 2 40B **每个模块**的序列嵌入，以确定哪一层给出最具信息量的特征（Extended Data Fig. 5d）。

**（5）远端调控区：明确的失败（Fig.6 相关，DART-eval）**

| 模型 | caQTL AUROC | dsQTL AUROC |
| --- | --- | --- |
| **Evo 2 40B** | **0.58** | **0.66** |
| Nucleotide Transformer | 0.52 | 0.61 |
| **ChromBPNet**（在可及性数据上训练的序列-功能模型） | **0.77** | **0.89** |

作者的解读很克制：

> 这表明**仅在序列上训练的多物种语言模型能捕获部分调控信息，但在此情形下带有任务专门训练的序列-功能模型性能更高**。

根因也写明了：**临床变异数据集高度富集于编码、剪接或 UTR 变异**，而**远端调控序列（尤其基因远端）保守性显著更低**。

作者还特别说明：**Evo 2 没有在任何人类遗传变异或功能基因组学数据上训练过。**

### （七）机制可解释性（Fig.4）

**方法**：在 Evo 2 **第 26 层**的表示上训练 **Batch-TopK SAE**，训练数据为**10 亿 token**，均匀取自若干完整的真核与原核基因组。**完全没有任何先验生物学注释或标签。**

匹配特征与已知生物学概念的方法称为**对比特征搜索（contrastive feature search）**——寻找在含特定注释的序列段中富集的特征。

**几个具体发现**：

| 特征 | 发现 |
| --- | --- |
| **f/19746** | 与原核生物的前噬菌体区域紧密关联；在 *E. coli* 基因组中激活于已注释前噬菌体，**包括隐匿前噬菌体 CPZ-55**；还在 **CRISPR 阵列的间隔序列**上激活（这些序列在 CRISPR 适应过程中整合自噬菌体 DNA 等外来遗传物质）、在最后一个 CRISPR 直接重复之后、以及在**合成/打乱的间隔序列**上激活——作者据此认为 **Evo 2 是把 CRISPR 间隔序列与噬菌体序列联系起来，而非直接记忆噬菌体基因组**；也在 geNomad 尚未注释为噬菌体、但含有前噬菌体相关基因（如整合酶、倒位酶）的区域激活 |
| ORF / 基因间区 / tRNA / rRNA 特征 | 在 *E. coli* 基因组中识别到对应特征（Fig.4c） |
| **α 螺旋、β 折叠** | 识别到与蛋白二级结构相关的特征；叠有 **AF3 对 EF-Tu 与 tRNA 复合物、以及 RpoB–RpoC 复合物的结构预测**（Fig.4d）——**这些特征跨越了从 DNA 到蛋白结构的层次** |
| **f/24278** | 突变敏感特征，**优先在移码突变与提前终止突变后激活** |
| 转录因子结合基序 | 在人基因启动子区观察到与已知人类转录因子结合位点高度相似的 DNA 基序激活。跨随机采样的人启动子序列，Evo 2 无监督 SAE 特征对 **HOCOMOCO v.12 CORE 数据库**中 **70%** 的启动子富集基序有显著命中（**q < 0.01，Sandelin–Wasserman 相似性**，用 TOMMOT 比较工具）；**作为对照，专门基序发现算法 HOMER 只召回同样基序的 35%** |
| 外显子/内含子边界 | **f/15680**（编码区）、**f/28339**（内含子）、**f/1050**（内含子后外显子的最初碱基）、**f/25666**（内含子前外显子的最后碱基）。**编码区特征也在细菌 ORF 上激活**，提示模型学到了**编码序列的普适表示** |
| **跨物种迁移** | 上述特征是在**只用模式生物（包括灵长类、小鼠、非洲爪蟾、果蝇）训练的 SAE** 上识别的，但**进一步观察到这些特征迁移到了猛犸基因组的一部分基因区** |

作者指出高阶依赖的一个例子：**外显子边界特征（f/1050 与 f/25666）整合了跨多个核苷酸的剪接位点信号**，而前噬菌体特征（f/19746）识别的是**需要千碱基尺度上下文的移动遗传元件**。

### （八）基因组尺度生成

**（1）基因补全（Fig.5b）**

跨**六个多样物种**（古菌、原核生物，以及四条真核谱系：真菌、原生生物、植物、动物），每物种选取高度保守的代表基因，以**1 000 bp 上游序列 + 目标基因前 500–1 000 bp** 作为提示。Evo 2 实现了**高氨基酸序列恢复率的基因补全，且随规模提升而改善**；40B 与 7B 均优于 Evo 1。

**（2）人线粒体基因组（Fig.5c–f）**

以人线粒体 DNA 片段提示，生成**超过 250 条独特的 16 kb 序列**。用 MitoZ 注释发现：

- 生成序列具有**人线粒体中预期的正确数量的 CDS、tRNA 基因与 rRNA 基因**；
- 与天然基因的序列相似性程度不一，但**保持正确的共线性（synteny）**；
- 生成序列编码的蛋白，其**预测多聚体复合物与人线粒体蛋白的复合物匹配**；
- **密码子使用**也与人线粒体基因组高度接近；平均而言**成功生成了每种预期类型的 tRNA 各一个，且未重复提示中已包含的那两个**。

**（3）*M. genitalium* 最小基因组（Fig.5g–k）**

利用 100 万 bp 上下文窗口生成小原核基因组尺度的 DNA。以参考序列的 **10.5 kb** 片段为提示，生成**十条 580 kb 序列**，用 **Prodigal** 注释：

- **近 70% 的生成基因含有显著的 Pfam 命中**——相比 Evo 1 的 131k 模型（**18%**）是实质性改进；
- 生成蛋白的**长度与二级结构分布**与天然 *M. genitalium* 相似；
- 生成蛋白与天然蛋白有结构比对，**但生成蛋白的结构预测置信度相对天然基因较低**。

**（4）*S. cerevisiae* 染色体 III（Fig.5l）**

以 **10.5 kb** 序列提示，生成 **20 条 330 kb** DNA 序列。这些序列**包含 tRNA、启动子与带内含子结构的基因**；**tRNA 与基因特征的密度低于天然酵母基因组**，但生成基因的长度分布与天然蛋白相似。四核苷酸使用偏差（TUD）——系统发生关系的一个常用度量——与天然 *S. cerevisiae* 相关，**且 40B 的一致性高于 7B**。

**⚠️ 作者对基因组生成给出的告诫（必须传达）**：

> 这些评估指标**不保证功能正常或可复制的基因组**；我们的基因组尺度生成**缺少重要元件，例如一些必需基因**。对基因组尺度设计的实验检验还将需要大规模、迭代的工作。

### （九）哺乳动物染色质模式设计——实验验证部分

**方法**：Evo 2 本身**不显式学习染色质可及性**。作者把 **Enformer 与 Borzoi 的集成**定义为一个评分函数，接受或拒绝生成的序列（依据其预测的染色质可及性与期望模式的匹配程度）。**束搜索**在每采样 **128 bp** 后重新评估 Enformer 与 Borzoi，只从最有希望的样本继续自回归生成。使用 **129 ES-E14 细胞**中来自两个模型的 DNase 超敏预测，并用天然小鼠基因组上下文作为预测信息。

**计算-质量关系（Fig.6c,d）**：作者观察到**对数-线性关系**——增加束搜索宽度（即增加推理时算力）产生更好的设计。**采样 30 个以上的 128 bp 块、每步选出最好的两个**，即可达到**最终设计 AUROC 高于 0.9**。

**实验验证一：摩尔斯码（Fig.6e–h）**

- 设计的信息："EVO2"、"LO"、"ARC"；
- 实验流程：**合成与组装设计 DNA → 位点特异性整合到小鼠胚胎干细胞（mESC）基因组 → 用 ATAC-seq 测量染色质可及性**；
- 生成序列**替换小鼠基因组 chrX: 52,051,929–52,123,468 处的天然序列**；使用**每碱基 30–84 个 token** 采样；在 **Bl6xcast mESC** 中验证；
- **三个摩尔斯码模式的实验 AUROC 为 0.92–0.95**；
- 更简单的峰模式也获得实验成功（**AUROC > 0.89**）。

**关键的消融对照（Extended Data Fig.10b–e）**：把流程中的 Evo 2 换成**均匀（uniform）或双字母（bigram）提案**，观察到**更差的 token 匹配的推理时缩放**与**更差的集成预测共识**。作者据此假设：**这类简单提案容易生成对抗样本**，正如在蛋白设计中观察到的那样。

**一个有趣的涌现性质（Extended Data Fig.10f–i）**：**设计峰区包含显著更高的预测转录因子基序密度**（双侧 Welch t 检验，**P = 3.6 × 10⁻⁷**）；且 Evo 2 设计**显著富集了在 mESC 中表达的转录因子**（单侧超几何 **P = 2.0 × 10⁻⁴**），其 GC 与 CpG 密度与染色质峰的相关水平**与天然序列相似**。

⚠️ 作者强调：**Evo 2 并没有被显式条件化去生成富含基序的序列**——这些性质是**涌现**的。

**实验验证二：人类细胞系（Fig.6i–k）**

在 **HEK293T 与 K562** 两种人类细胞系中，设计并实验检验 **1–4 kb** 序列的染色质可及性谱：

| 任务 | 结果 |
| --- | --- |
| 在设计序列内**改变可及性水平** | **36 个设计中 33 个（92%）AUROC > 0.8**（HEK293T 测试 5 个设计，K562 测试 31 个） |
| 在两种细胞系间设计**差异可及性**（困难得多） | **24 个中 4 个（17%）**有**超过两倍**的差异可及性；**24 个中 1 个（4%）**有**超过三倍**的差异 |
| 上述 4 个 >2 倍差异设计 | 设计峰中预测的转录因子基序**显著富集 K562 表达的转录因子**（单侧超几何 **P = 0.0017**），但**不富集 HEK293T 表达的转录因子**（**P = 0.25**） |

## 对照与消融

这篇的对照密度很高，且方法学上很有借鉴价值：

1. **遗传密码对照（Fig.2e）**——用**人工重编码的纤毛虫基因组**测试模型是否真的在读序列上下文，而不是死记密码表。这是全文最巧妙的一个测试。

2. **跨物种的对照**——**20 个原核 + 16 个真核物种**，检验似然变化是否符合已知生物约束，而不是拟合某几个物种。

3. **保守性基线的对照**——外显子分类器不仅与 NT、Evo 1 比较，还与**保守性指标（局部 GC 含量、PhyloP）**和**从头预测的 AUGUSTUS** 比较——后者是领域外基线。

4. **数据排除的自我验证**——作者**主动验证了排除措施的效果**（真核病毒困惑度高、病毒蛋白适合度无相关、生成随机），并做了**红队测试**。这是罕见的、把安全措施当作**可证伪假设**来检验的做法。

5. **生成提案的消融（Extended Data Fig.10）**——用**均匀/双字母提案替换 Evo 2**，证明生成模型带来的不只是「序列像自然」，而是**集成预测的一致性**。

6. **蛋白 DMS 的饱和现象**——作者报告了在最大模型规模下性能**可能下降**，与文献中蛋白语言模型的普遍趋势一致。

7. **SAE 特征的对照**——与专门基序发现算法 **HOMER（35%）** 对比，Evo 2 无监督特征命中 **70%** 的启动子富集基序。

## 作者自述的局限

作者的自我评价相当完整，且**罕见地坦诚列出了负面结果**：

1. **蛋白 DMS 上不及最先进方法**——「在蛋白 DMS 上表现不及最先进模型」，且「性能开始饱和，并可能在最大的模型规模下**下降**」。

2. **人类基因必需性性能有限**——「尽管整体预测性能**仍然有限（modest）**」。

3. **远端调控区的失败**——DART-eval 上 caQTL **0.58**、dsQTL **0.66**，**远低于**在可及性数据上训练的 ChromBPNet（0.77、0.89）。作者明确归因于训练数据的偏倚（临床变异数据集偏向编码/剪接/UTR）。

4. **人类 mRNA 降解速率的关联有限**。

5. **生成基因组不保证功能**——「这些评估指标**不保证功能正常或可复制的基因组**」；「基因组尺度生成**缺少重要元件，例如一些必需基因**」；「对基因组尺度设计的实验检验还将需要大规模、迭代的工作」。

6. **细胞类型差异可及性的难度**——两细胞系间 >2 倍差异只有 **17%**，>3 倍只有 **4%**。作者没有为这个数字提供乐观的解释。

7. **安全缓解可能被绕过**——「**任务专门的后训练可能绕过这一风险缓解措施，应谨慎对待**」。作者同时指出「我们展示了 Evo 2 的**无群体偏向设计缓解了模型预测中的祖源偏倚**」。

8. **SAE 分析的覆盖面有限**——「当前机制可解释性分析主要聚焦于**注释良好的特征**」；「**系统的基准测试仍是必要的**」。

9. **推理时引导的计算成本**——「用推理时引导改进生成**可能需要计算密集的采样**」。

10. **实验设计的闭环尚未建立**——「用生物实验反馈进行监督微调与强化学习，很可能提升 Evo 2 在复杂应用中生成序列的效率与质量」。

11. **可解释性作为基因组挖掘工具尚未验证**——「未来的工作可以利用这些方法进行基因组挖掘与发现更复杂的生物元件组合」。

## 我的评价

**这篇的核心贡献，是把「基础模型」这个概念在生物学中推到了一个此前没有人认真做过的尺度——基因组。**

蛋白语言模型的语料是数亿条序列；Evo 2 的语料是**88 亿亿个核苷酸、跨越全部生命域**。这个跨度不只是「更大」，而是**改变了问题的性质**——从「预测一个蛋白做什么」变成「预测一段 DNA 在什么细胞里、什么位置、什么时候会被读取」。Fig.2b 那张按 k-mer 频率嵌入整个训练集基因组（包括古菌、纤毛虫、HIV 邻近物种等）的 UMAP 图，是全文最有视觉冲击力的一张。

**第二个技术亮点是 StripedHyena 2 的架构决策。** 「短程用显式卷积、中程用正则化卷积、长程用隐式卷积」这个分层设计，直指长序列建模的核心矛盾：**显式算力精确但无法扩展，隐式算力可扩展但损失精度**。分层的混合架构在 400 亿参数、100 万上下文下取得 3 倍加速，同时改善了损失缩放——**这是本文中最工程、也最容易被忽略的部分**。

**第三个亮点，也是我认为最值得学习的方法学示范，是「把安全措施当作可证伪的假设」。** 绝大多数论文提到安全措施时是声明式的（"我们出于安全排除了 X"）；本文则是**实验式的**：

1. 排除真核病毒序列 → **验证困惑度确实升高**；
2. → **验证病毒蛋白适合度确实无相关**；
3. → **验证生成确实基本随机**；
4. → **做了红队测试**（直接试图引诱致病病毒蛋白）；
5. → **还验证了祖源偏倚的缓解效果**。

更值得称道的是，作者同时指出了这个措施的**局限**：「任务专门的后训练可能绕过这一风险缓解措施」——**在展示安全措施有效的同时承认它可能被绕过**，这比单纯宣称安全要可信得多。

**第四点，作者在负面结果上的诚实度。** 三处「不及」被直接写进摘要级结论里：蛋白 DMS 不及 SOTA、人类基因必需性「modest」、远端调控区大幅落后 ChromBPNet。作为一篇被广泛宣传的 Nature 论文，这种自我暴露值得肯定。

**汇报时必须传达的边界（这篇最容易被过度宣传）**：

- **「生成基因组」≠「可用的基因组」**。作者自己说了：不保证功能、不保证可复制、**缺少一些必需基因**。*M. genitalium* 的「近 70% 基因有 Pfam 命中」听起来不错，但**结构预测置信度低于天然基因**，而且这只是一条**随机基因组**——能不能在细胞里活，本文没回答也不打算回答。
- **染色质设计的两个数字必须并列**：「36 个设计中 33 个（92%）AUROC > 0.8」是**改变可及性水平**；而「两细胞系间 >2 倍差异只有 **17%**（4/24）」是**难度高得多的任务**。只讲 92% 会严重误导。
- **细胞类型特异的调控设计还没解决**。四个成功设计的基序富集分析（P = 0.0017 / 0.25）说明方向对，但**4/24 这个数字说明方法远未成熟**。
- **蛋白 DMS 上不及 SOTA，且可能随规模下降**——这一条对「基础模型越大越好」的叙事是一个直接反例，值得在汇报时单独点出。

**第五点，最容易被忽略但很有意思的发现**：Evo 2 的设计峰区**自发富集了在 mESC 中表达的转录因子基序**（P = 2.0 × 10⁻⁴），而模型**并未被显式条件化去生成富含基序的序列**。作者把它归入「涌现」。这提示一个更一般的结论：**一个足够好的序列提案模型，本身就携带了关于「什么序列在该上下文中功能重要」的先验知识**，这正是他们替换成均匀/双字母提案后集成一致性崩溃的原因。

**与本专题其他篇的连接**：本专题的主线是「结构」，Evo 2 是唯一一篇**从基因组尺度绕开结构**的工作。但它与 ProteinMPNN / RFdiffusion 共享同一种方法论——**在给定条件下生成序列，然后用实验验证**；而 RFdiffusion 2023 论文也引用了 Vázquez Torres 等关于**「对抗样本」**的观察，Evo 2 在染色质设计中独立地重述了这一现象（简单提案容易产生对抗样本）。**这个跨领域的呼应是本专题中一个未被明确点破的共性。**

## 可复现要点

**模型**
- **Evo 2 7B**：70 亿参数，2.4 万亿 token
- **Evo 2 40B**：400 亿参数，9.3 万亿 token
- 上下文长度：**8 192（预训练）→ 100 万（中期训练，多阶段扩展）**
- 架构：**StripedHyena 2**（SE / MR / LI 三类 hyena 算子混合）
- 另发布一个**实验性的 10 亿参数短上下文模型**——作者明确说「**应当避免使用，因整体性能较弱**」

**数据**
- **OpenGenome2**：超过 **88 亿亿个核苷酸**，来自细菌、古菌、真核生物、噬菌体
- **完整训练数据集开源**
- 预训练加权聚焦基因窗口；中期训练聚焦长序列组成
- **排除感染真核宿主的病毒基因组序列**（生物安全）

**可解释性**
- **Batch-TopK SAE**，训练于 **Evo 2 第 26 层**表示
- 训练数据 **10 亿 token**，均匀取自若干完整真核与原核基因组
- 特征匹配方法：**对比特征搜索（contrastive feature search）**
- 基序比对：**TOMTOM**；基序库 **HOCOMOCO v.12 CORE**；对照 **HOMER**
- 前噬菌体注释参照：**geNomad**

**染色质设计**
- 评分函数：**Enformer + Borzoi 集成**
- 细胞系：**129 ES-E14**（预测）、**Bl6xcast mESC**（实验验证）、**HEK293T** 与 **K562**（人类细胞系）
- 束搜索：每 **128 bp** 重新评估；采样 **30+** 块、每步选 top **2**；使用**每碱基 30–84 token**
- 小鼠基因组替换位点：**chrX: 52,051,929–52,123,468**
- 实验读出：**ATAC-seq**（转座酶可及性染色质测序）；**位点特异性整合**

**基因组生成**
- **MitoZ**（线粒体基因组注释）、**Prodigal**（原核基因预测）、**Pfam**（结构域）、**hmmscan**（E 值 < 0.001）
- *M. genitalium*：提示 **10.5 kb**，生成 **10 条 580 kb** 序列
- *S. cerevisiae* 染色体 III（约 **316 kb**）：提示 **10.5 kb**，生成 **20 条 330 kb** 序列
- 人线粒体：生成**超过 250 条独特 16 kb 序列**
- **TUD**（四核苷酸使用偏差）作为系统发生相关性的度量

**基线工具**：Nucleotide Transformer、Evo 1、GenSLM、ProGen、ESM-1b、ESM-2、GPN-MSA、AlphaMissense、CADD、Pangolin、SpliceAI、SegmentNT、AUGUSTUS、ChromBPNet、PhyloP

**在线工具**：`https://arcinstitute.org/tools/evo/evo-designer`（生成与打分序列）、`https://arcinstitute.org/tools/evo/evo-mech-interp`（探索 SAE 特征）

## 术语

| 术语 | 含义 |
| --- | --- |
| StripedHyena 2 | 短程显式 / 中程正则化 / 长程隐式 hyena 卷积算子组成的多混合架构 |
| OpenGenome2 | Evo 2 的训练数据集，跨全生命域的策展非冗余核苷酸序列 |
| 中期训练（midtraining） | 预训练之后、专门用于扩展上下文长度的训练阶段 |
| 似然（likelihood） | 模型赋予给定序列的概率；降低该概率的突变被预测为有害 |
| 零样本预测（zero-shot） | 未经任务特定微调或监督的直接预测 |
| DMS | 深度诱变扫描，实验测量蛋白/非编码 RNA 的功能效应 |
| SAE | 稀疏自编码器，用于把网络表示分解为可解释的潜在维度 |
| Batch-TopK SAE | 一种 SAE 变体，激活值取 Top-K 以获得稀疏性 |
| 对比特征搜索 | 找出在含特定注释序列段中富集的特征的方法 |
| CRISPR 间隔序列（spacer） | CRISPR 阵列中整合自外源遗传材料（如噬菌体 DNA）的序列 |
| 推理时引导（inference-time guidance） | 用独立的评分/奖励函数引导生成模型生成过程 |
| 束搜索（beam search） | 每步保留最优若干候选并继续扩展的搜索策略 |
| ATAC-seq | 测量染色质可及性的测序方法 |
| TUD | 四核苷酸使用偏差，系统发生关系度量 |
| caQTL / dsQTL | 染色质可及性 / DNase I 敏感性定量性状位点 |
