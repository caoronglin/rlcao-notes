# 实验记录

从工作台“新建实验”创建记录。标题会带日期和时间，避免重复实验覆盖旧记录。

- `date`：实验日期，可在属性中修改。
- `status`：计划、进行中、待分析、完成、暂停。
- `project`：填写关联项目的完整笔记链接。
- `sample_ids`：样品编号列表。
- `protocol`、`raw_data`：协议链接与原始数据位置。

原始数据保留在实际分析目录，在此记录位置和关键参数；不要将科学数据批量搬入笔记库。

项目、实验总览表可直接编辑属性；实验正文按时间顺序保留观察和偏离方案的情况。
