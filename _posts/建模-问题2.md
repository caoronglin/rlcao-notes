## 一、代码概述

该工具是一个针对NIPT（无创产前胎儿染色体检测）的最佳检测时间点分析系统，主要解决**不同BMI孕妇的Y染色体浓度随孕周变化规律**问题，通过数据建模确定各BMI分组的最佳检测孕周。系统采用中文拼音重命名函数和变量，便于中文用户理解，同时包含详细的中文注释。

## 二、核心功能流程

1. **数据清洗与预处理**：处理原始NIPT检测数据
2. **BMI分组**：按临床标准将孕妇分为不同BMI组
3. **模型训练**：建立Y染色体浓度预测模型
4. **风险评估**：通过蒙特卡洛仿真计算各孕周风险
5. **结果可视化**：生成临床决策图表和报告

## 三、关键字段说明

| 字段名称 | 类型 | 说明 | 处理方式 |
| --- | --- | --- | --- |
| **检测孕周** | 数值 | 孕妇接受NIPT检测时的孕周 | 特殊处理"11w+6"等格式，转换为小数(11.857周) |
| **孕妇BMI** | 数值 | 孕妇体重指数(BMI=体重/身高²) | 范围校验(10-60)，缺失值用中位数填补 |
| **Y染色体浓度** | 数值 | 男胎NIPT检测的关键指标 | 取对数变换(log1p)作为目标变量 |
| **孕妇代码** | 字符串 | 唯一标识孕妇的ID | 用于去重，仅保留首次检测数据 |
| **bmi_zu** | 分类 | BMI分组标签 | 按临床标准分为7个组别 |
| **最佳孕周** | 数值 | 综合风险最低的检测时间点 | 通过风险评估计算得出 |
| **成功率** | 百分比 | 预测Y染色体浓度≥阈值的概率 | 蒙特卡洛仿真计算 |
| **阈值** | 数值 | Y染色体浓度检测下限 | 动态确定(通常为30%分位数) |

## 四、模型使用与评估

### 1. 使用的模型：LightGBM回归模型

**模型特点**：

- 高效的梯度提升决策树(GBDT)实现
- 适合中小型数据集
- 天然支持特征重要性评估
- 能处理特征交互关系

**特征工程**：

```python
# 基础特征
- 孕妇BMI
- 检测孕周

# 高级特征
- bmi_yunzhou_jiao_hu = BMI × 检测孕周 (交互项)
- bmi_ping_fang = BMI² (非线性关系)
- yunzhou_ping_fang = 检测孕周² (非线性关系)
```

**目标变量**：

- `log_y = np.log1p(Y染色体浓度)`

- 采用对数变换解决右偏分布问题
- 预测后通过`np.expm1()`转换回原始尺度

### 2. 模型参数配置

```python
can_shu = {
    'num_leaves': 31,       # 控制树复杂度
    'learning_rate': 0.05,  # 学习率
    'max_depth': 6,         # 最大深度
    'min_child_samples': 20,# 叶子节点最小样本数
    'subsample': 0.8,       # 训练样本采样率
    'colsample_bytree': 0.8,# 特征采样率
    'n_estimators': 500,    # 树的数量
    'early_stopping': 50    # 早停机制
}
```

### 3. 模型评估指标

- **RMSE (均方根误差)**：预测Y染色体浓度与实际值的差异

- 值越小表示预测精度越高
- 公式：`√(Σ(实际值 - 预测值)²/n)`

- **R² (决定系数)**：模型解释的方差比例

- 值越接近1表示模型拟合越好
- 公式：`1 - (残差平方和/总平方和)`

**典型输出**：

```plain
模型训练完成: RMSE=0.0421, R²=0.8735
```

表示模型能解释约87%的Y染色体浓度变化，预测精度较高。

## 五、风险评估核心逻辑

### 1. 蒙特卡洛仿真流程

1. **生成虚拟样本**：

- 对每个BMI组，通过KDE或均匀分布生成1000个虚拟BMI值
- 遍历孕周区间(10-26周，步长0.25)

2. **预测Y染色体浓度**：

```python
log_yu_ce = mo_xing.predict(X_yu_ce)
yu_ce_zhi = np.expm1(log_yu_ce)  # 转换回原始尺度
```

3. **模拟检测误差**：

```python
xiang_dui_cha = np.random.normal(1.0, 0.10, size=len(yu_ce_zhi))
dai_cha_yu_ce = yu_ce_zhi * xiang_dui_cha  # 添加10%随机误差
```

4. **计算成功率**：

```python
cheng_gong_lv[i] = np.mean(dai_cha_yu_ce >= cheng_gong_yu_zhi)
```

- `cheng_gong_yu_zhi` = max(0.04, 实际值30%分位数)

5. **计算综合风险**：

```python
# 孕周风险权重（BMI调整）
if yunzhou < 10: quan_zhong = 100.0 * bmi_yin_zi
elif 10 <= yunzhou < 12: quan_zhong = (20.0 - (yunzhou - 10) * 8.0) * bmi_yin_zi
elif 12 <= yunzhou < 14: quan_zhong = (4.0 - (yunzhou - 12) * 2.0) * bmi_yin_zi
elif 14 <= yunzhou < 18: quan_zhong = 1.0 * bmi_yin_zi
elif 18 <= yunzhou < 22: quan_zhong = (1.0 + (yunzhou - 18) * 0.3) * bmi_yin_zi
else: quan_zhong = (2.2 + (yunzhou - 22) * 0.5) * bmi_yin_zi

# 综合风险 = (1 - 成功率) × 风险权重
feng_xian_zhi[i] = (1 - cheng_gong_lv[i]) * quan_zhong
```

### 2. BMI风险调整因子

| BMI范围 | 风险调整因子 | 临床意义 |
| --- | --- | --- |
| <24 | 1.0 | 标准风险 |
| 24-28 | 1.05 | 轻度增加 |
| 28-32 | 1.15 | 中度增加 |
| ≥32 | 1.3 | 显著增加 |

### 3. 最佳孕周选择策略

1. 首先找到风险值最低的孕周
2. 根据BMI设定优先窗口：

- 极重度肥胖(BMI≥36)：优先11.5-16周
- 重度肥胖(BMI≥32)：优先12.0-16.5周
- 轻度肥胖(BMI≥28)：优先12.5-17周
- 正常体重：优先13.0-18周

3. 在优先窗口内选择风险最低的孕周

- 肥胖孕妇的**检测阈值更高**（中度肥胖0.06 vs 正常0.04），表明需要更高Y染色体浓度才能可靠检测

## 八、技术亮点

1. **深度数据清洗**：

- 智能处理"11w+6"等特殊孕周格式
- 严格的逻辑校验(孕周8-40周，BMI10-60)
- 保留首次检测数据避免重复

2. **临床导向特征工程**：

- BMI与孕周的交互项捕捉复杂关系
- 多项式特征捕获非线性趋势
- 对数变换处理偏态分布

3. **创新风险评估模型**：

- 蒙特卡洛仿真考虑检测误差
- 动态阈值设定(30%分位数)
- BMI与孕周联合风险权重

4. **个性化临床建议**：

- 按BMI分组提供定制化建议
- 明确区分"早期/标准/延迟"检测窗口
- 量化成功率与风险值

## 九、应用场景

1. **临床决策支持**：帮助医生为不同BMI孕妇推荐最佳检测时间
2. **实验室质控**：识别低成功率孕周，优化检测流程
3. **患者咨询**：向肥胖孕妇解释为何需要更早检测
4. **研究分析**：探索BMI与胎儿DNA浓度的定量关系

此工具通过数据驱动的方法，解决了NIPT检测中的关键临床问题，特别针对肥胖孕妇这一高风险群体提供了科学的检测时间建议，可显著提高检测成功率，减少假阴性风险。
