## 5.1 指针和指针变量

### 变量与地址

- **内存**：存放运行中的程序和数据，基本单元是字节(Byte)
- **地址**：CPU为每个内存单元分配的编号
- **变量**：程序中的可变值，声明时系统分配内存单元

```c
int a = 0;  // &a表示a的地址
```

### 指针与指针变量

- **指针**：变量的地址（如`&a`）
- **指针变量**：专门存储地址的变量（如`p = &a`）

```plain
变量a <--[指向]-- 指针变量p（存储&a）
```

### &与*运算符

| 运算符 | 含义 | 优先级 | 结合性 |
| --- | --- | --- | --- |
| `&` | 取变量地址 | 2 | 自右向左 |
| `*` | 间接寻址（解引用） | 2 | 自右向左 |

**关系**：互为逆运算

```c
int i = 10;
int *i_pointer = &i;
// 等价关系：
i_pointer == &i == &(*i_pointer)
i == *i_pointer == *(&i)
```

### 直接访问与间接访问

```c
i = 3;          // 直接访问
*i_pointer = 20; // 间接访问
```

### 指针变量定义

```c
数据类型 *指针名;  // 如 int *p1, *p2;
```

**注意事项**：

1. `int *p1, p2;` 中p1是指针，p2是整型变量
2. 指针名是`p1`而非`*p1`
3. 只能指向定义时规定类型的变量
4. 必须先赋值后使用

### 指针变量初始化

```c
int i;
int *p = &i;       // 正确
int *q = p;        // 用已初始化指针赋值

// 错误示例（未初始化）：
int *p; *p = i;    // 危险操作！
```

### 指针交换示例

```c
int a = 20, b = 15, c;
int *p1 = &a, *p2 = &b;
int *p3;
// 交换指针指向
p3 = p2; p2 = p1; p1 = p3;
// 交换值
c = *p2; *p2 = *p1; *p1 = c;
```

## 5.2 指针与一维数组

### 指向数组元素的指针

```c
int array[10];
int *p = &array[0]; // 等价于 p = array;
```

- **数组名**：表示数组首地址的常量（`array == &array[0]`）

### 指针运算

**合法赋值**：

```c
p = &a;          // 变量地址
p = array;       // 数组首地址
p = &array[i];   // 元素地址
p1 = p2;         // 指针间赋值
```

**非法赋值**：

```c
p = 1000;        // ✗ 不能赋整数值
int i = p;       // ✗ 不能赋给整型变量
```

**算术运算**：

```c
p ± i  // 移动i个元素（实际位移=i*元素字节数）
p++, p--, p += i
p1 - p2 = (地址差)/元素大小  // 同数组内有效
```

### 数组元素表示

```c
a[i] 等价于 *(a+i) 等价于 p[i] 等价于 *(p+i)
```

### 应用示例

**1. 求数组平均值**

```c
#include <stdio.h>
int main() {
    int a[10];
    float sum = 0;
    for(int i=0; i<10; i++) {
        scanf("%d", a+i);    // &a[i]的等价写法
        sum += *(a+i);       // a[i]的等价写法
    }
    printf("Average: %f", sum/10);
}
```

**2. 查找最大值及位置**

```c
#include <stdio.h>
int main() {
    int a[10], *p, *pMax = a;
    for(p=a; p<a+10; p++) scanf("%d", p);
    
    for(p=a+1; p<a+10; p++)
        if(*p > *pMax) pMax = p;
    
    printf("Max: %d, Position: %ld", *pMax, pMax-a);
}
```

## 5.3 指针与二维数组

### 二维数组地址

```c
int a[3][4];
```

- `a`：第0行首地址
- `a+i`：第i行首地址
- `a[i]`：第i行第0列元素地址
- `a[i][j]` 等价于 `*(*(a+i)+j)`

### 访问方式

**1. 元素指针**

```c
int a[3][4] = {...};
int *p = a[0];  // 指向首元素
for(; p < a[0]+12; p++)
    printf("%d ", *p);
```

**2. 行指针**

```c
int (*p)[4] = a;  // 定义行指针
for(int i=0; i<3; i++) {
    for(int j=0; j<4; j++)
        printf("%d ", *(*(p+i)+j)); // p[i][j]等价形式
}
```

### 对称矩阵判断

```c
#include <stdio.h>
int main() {
    int a[4][4], (*p)[4] = a, flag=1;
    // 输入省略
    for(int i=0; i<4; i++)
        for(int j=0; j<i; j++)
            if(p[i][j] != p[j][i]) flag=0;
    printf(flag ? "Yes!" : "No!");
}
```

## 5.4 指针与字符串

### 两种表示方式

**字符数组**

```c
char str[] = "Hello";
str[0] = 'h'; // ✓ 可修改
```

**字符指针**

> [!info]
> 此语句看似将字符串常亮赋值给了指针变量，而事实上是将存放该字符串常量的首地址赋予了指针变量，要访问该字符串，只能通过指针变量进行

```c
char *p = "World";
// p[0] = 'w'; ✗ 不可修改常量字符串
```

### 注意事项

1. 数组名为常量，指针为变量

```c
char str[10]; str = "New"; // ✗ 非法
char *p; p = "New";       // ✓ 合法
```

2. 指针输入需先分配空间

```c
char *p, str[10];
p = str; scanf("%s", p); // ✓ 正确
```

### 统计字符类型

```c
#include <stdio.h>
int main() {
    char str[100], *p = str;
    int digit=0, letter=0, other=0;
    gets(str);
    while(*p) {
        if(*p>='0' && *p<='9') digit++;
        else if((*p>='a'&&*p<='z') || (*p>='A'&&*p<='Z')) letter++;
        else other++;
        p++;
    }
    printf("Digit:%d Letter:%d Other:%d", digit, letter, other);
}
```

## 5.5 指针数组

### 定义与应用

```c
数据类型 *数组名[长度];  // 如 int *p[3];
```

**1. 处理二维数组**

```c
int a[3][4], *p[3] = {a[0], a[1], a[2]};
for(int i=0; i<3; i++)
    for(int j=0; j<4; j++)
        printf("%d ", *(p[i]+j));
```

**2. 处理字符串**

```c
char *str[] = {"Sunday", "Monday", "Tuesday"};
printf("%s", str[0]); // 输出: Sunday
```

**3. 字符串排序**

```c
#include <stdio.h>
#include <string.h>
int main() {
    char *str[5], temp[20];
    // 输入省略
    for(int i=0; i<4; i++)
        for(int j=i+1; j<5; j++)
            if(strcmp(str[i], str[j]) > 0) {
                strcpy(temp, str[i]);
                strcpy(str[i], str[j]);
                strcpy(str[j], temp);
            }
}
```

## 5.6 函数指针与多级指针

### 函数指针

```c
返回值类型 (*指针名)(参数列表);  // 如 int (*p)(int, int);
```

**使用示例**：

```c
int max(int x, int y) { return x>y?x:y; }
int main() {
    int (*p)(int, int) = max;
    printf("%d", (*p)(3,5)); // 输出5
}
```

### 多级指针

```c
int i = 10;
int *p1 = &i;   // 一级指针
int **p2 = &p1; // 二级指针
printf("%d", **p2); // 输出10
```

### 空指针

```c
int *p = NULL;  // 安全初始化
if(p != NULL) { // 安全检查
    // 操作指针
}
```

## 5.7 动态内存分配（自学）

### 核心函数

| 函数 | 功能 |
| --- | --- |
| `void* malloc(size_t size)` | 分配size字节内存 |
| `void* calloc(size_t n, size_t size)` | 分配n*size字节并初始化为0 |
| `void* realloc(void *ptr, size_t size)` | 调整已分配内存大小 |
| `void free(void *ptr)` | 释放内存 |

### 应用示例

**1. 一维动态数组**

```c
int *p, n;
scanf("%d", &n);
p = (int*)malloc(n * sizeof(int));
// 使用p[i]...
free(p);
```

**2. 二维动态数组**

```c
int **a, row, col;
scanf("%d%d", &row, &col);
a = (int**)malloc(row * sizeof(int*));
for(int i=0; i<row; i++)
    a[i] = (int*)malloc(col * sizeof(int));
// 使用a[i][j]...
for(int i=0; i<row; i++) free(a[i]);
free(a);
```

> 注意：动态分配内存后必须检查是否成功，使用完毕后及时释放防止内存泄漏。
