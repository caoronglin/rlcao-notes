# 总结与前言

## 专有名词

## 稀疏计数信息

### **稀疏数据（Sparse data）**

"Refers to data that mostly measures zeros and rarely other values (sparse data vs. missing data). This is common in gene expression data, where many genes are not expressed in most cells."（稀疏数据指绝大部分度量值为零、极少为其他值的数据，常见于基因表达数据，因多数基因在多数细胞中不表达）。

### **稀疏矩阵（Sparse matrix）**

"A way to store sparse data. Instead of keeping all the zeros, it only saves the non-zero values and their positions, saving space and making calculations faster."（一种存储稀疏数据的方式，仅保存非零值及其位置，节省空间并加速计算）。

## 初始化简单对象

## 导入所需包

此处我们创建了一个简单的包含稀疏计数信息的矩阵`AnnData`对象

>**稀疏计数信息**：即指**以计数矩阵形式存在的、绝大多数元素为零的测序/表达数据**（如基因×细胞的 UMI 计数矩阵），以及其背后的生物学与技术含义。包含：[[#稀疏数据（Sparse data）]][[#稀疏矩阵（Sparse matrix）**]]

```python
import anndata as ad
import lamindb as ln
import numpy as np
import pandas as pd
from scipy.sparse import csr_matrix
ln.track()
```

## 使用泊松分布初始化数据

```python
counts = csr_matrix(
	np.random.default_rng().poisson(1,size=(100,2000)),dtype=np.float32
)
adata=ad.AnnData(counts)
adata
```

>AnnData object with n_obs × n_vars = 100 × 2000
>得到的对象100个观测值和2000个变量

我们创建好的随机变量可以通过以下方式进行访问

```python
#访问数据
adata.X
```

```python
adata.obs_names = [f"Cell_{i:d}" for i in range(adata.n_obs)] 
adata.var_names = [f"Gene_{i:d}" for i in range(adata.n_vars)] 
print(adata.obs_names[:10])
```

## 添加数据修饰

```python
ct = np.random.default_rng().choice(['B','T','Monocyte'],size=(adata.n_obs,))

adata.obs

```
