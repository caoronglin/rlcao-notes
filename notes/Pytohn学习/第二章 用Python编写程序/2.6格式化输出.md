# 2.6格式化输出

# Python格式化输出详细总结

## 1. 百分号(%)格式化（旧式格式化）

### 基本语法

```python
"格式化字符串" % (值1, 值2, ...)
```

### 常用格式化符号

| 符号 | 描述 | 示例 |
| --- | --- | --- |
| `%s` | 字符串 | `"Name: %s" % "Alice"` |
| `%d` | 整数 | `"Age: %d" % 25` |
| `%f` | 浮点数 | `"Price: %f" % 3.14` |
| `%.2f` | 保留2位小数 | `"Price: %.2f" % 3.14159` |
| `%x` | 十六进制整数 | `"Hex: %x" % 255` |
| `%o` | 八进制整数 | `"Octal: %o" % 255` |
| `%e` | 科学计数法 | `"Scientific: %e" % 1234567` |
| `%%` | 百分号本身 | `"Progress: 50%%"` |

### 详细示例

```python
# 基本用法
name = "Alice"
age = 25
height = 1.68
print("Name: %s, Age: %d, Height: %.2f" % (name, age, height))
# 输出: Name: Alice, Age: 25, Height: 1.68

# 字典格式化
person = {"name": "Bob", "age": 30}
print("Name: %(name)s, Age: %(age)d" % person)
# 输出: Name: Bob, Age: 30

# 宽度和对齐
print("|%10s|" % "Hello")    # 右对齐，宽度10: |     Hello|
print("|%-10s|" % "Hello")   # 左对齐，宽度10: |Hello     |
print("|%010d|" % 42)       # 数字前补零: |0000000042|

# 多个值
print("%s has %d apples and %.1f kg of oranges" % ("Tom", 5, 2.5))
# 输出: Tom has 5 apples and 2.5 kg of oranges
```

### 优缺点

- **优点**：简单直观，兼容性好
- **缺点**：功能有限，复杂格式时代码可读性差

## 2. str.format() 方法（Python 2.6+）

### 基本语法

```python
"格式化字符串".format(值1, 值2, ...)
```

### 占位符类型

| 占位符 | 描述 | 示例 |
| --- | --- | --- |
| `{}` | 自动编号 | `"{} {}".format("Hello", "World")` |
| `{0}` `{1}` | 位置参数 | `"{0} {1}".format("Hello", "World")` |
| `{name}` | 关键字参数 | `"{name} is {age}".format(name="Alice", age=25)` |
| `{0[0]}` | 列表索引 | `"{0[0]} {0[1]}".format(["Hello", "World"])` |
| `{obj.attr}` | 对象属性 | `"{0.name}".format(person_obj)` |

### 格式说明符

```python
"{:格式说明}".format(值)
```

### 详细示例

```python
# 基本用法
print("Hello, {}!".format("World"))  # Hello, World!
print("{0}, {1}!".format("Hello", "World"))  # Hello, World!
print("{1}, {0}!".format("Hello", "World"))  # World, Hello!

# 关键字参数
print("Name: {name}, Age: {age}".format(name="Alice", age=25))
# 输出: Name: Alice, Age: 25

# 混合使用
print("{0} is {age} years old".format("Alice", age=25))
# 输出: Alice is 25 years old

# 数字格式化
print("{:d}".format(42))           # 42 (整数)
print("{:f}".format(3.14159))       # 3.141590 (浮点数)
print("{:.2f}".format(3.14159))     # 3.14 (保留2位小数)
print("{:.0f}".format(3.14159))     # 3 (四舍五入到整数)
print("{:e}".format(1234567))       # 1.234567e+06 (科学计数法)
print("{:%}".format(0.75))          # 75.000000% (百分比)

# 对齐和填充
print("|{:10}|".format("Hello"))    # |Hello     | (左对齐)
print("|{:>10}|".format("Hello"))   # |     Hello| (右对齐)
print("|{:^10}|".format("Hello"))   # |  Hello   | (居中对齐)
print("|{:*<10}|".format("Hello"))  # |Hello*****| (填充字符)
print("|{:0>10}|".format("42"))     # |0000000042| (数字填充)

# 千位分隔符
print("{:,}".format(1234567))       # 1,234,567
print("{:_}".format(1234567))       # 1_234_567

# 二进制、八进制、十六进制
print("{:b}".format(42))            # 101010 (二进制)
print("{:o}".format(42))            # 52 (八进制)
print("{:x}".format(42))            # 2a (十六进制小写)
print("{:X}".format(42))            # 2A (十六进制大写)

# 复杂格式化
data = {"name": "Alice", "age": 25, "score": 95.5}
print("Student: {name}, Age: {age}, Score: {score:.1f}".format(**data))
# 输出: Student: Alice, Age: 25, Score: 95.5

# 嵌套格式化
width = 10
precision = 2
value = 3.14159
print("{0:{1}.{2}f}".format(value, width, precision))  # 3.14
```

### 优缺点

- **优点**：功能强大，支持复杂格式化，代码可读性好
- **缺点**：语法相对复杂，性能略低于f-strings

## 3. f-strings（格式化字符串字面量，Python 3.6+）

### 基本语法

```python
f"格式化字符串 {变量} {表达式}"
```

### 详细示例

```python
# 基本用法
name = "Alice"
age = 25
print(f"Name: {name}, Age: {age}")
# 输出: Name: Alice, Age: 25

# 表达式计算
x, y = 10, 20
print(f"Sum: {x + y}, Product: {x * y}")
# 输出: Sum: 30, Product: 200

# 函数调用
def greet(name):
    return f"Hello, {name}!"

print(f"{greet('Bob')}")
# 输出: Hello, Bob!

# 格式说明符
pi = 3.14159
print(f"Pi: {pi:.2f}")           # Pi: 3.14
print(f"Pi: {pi:.0f}")           # Pi: 3
print(f"Pi: {pi:.4f}")           # Pi: 3.1416

# 对齐和填充
name = "Alice"
print(f"|{name:10}|")            # |Alice     |
print(f"|{name:>10}|")           # |     Alice|
print(f"|{name:^10}|")           # |  Alice   |
print(f"|{name:*<10}|")          # |Alice*****|

# 数字格式化
number = 1234567
print(f"{number:,}")             # 1,234,567
print(f"{number:_}")             # 1_234_567
print(f"{number:e}")             # 1.234567e+06

# 进制转换
num = 42
print(f"{num:b}")                # 101010 (二进制)
print(f"{num:o}")                # 52 (八进制)
print(f"{num:x}")                # 2a (十六进制)
print(f"{num:X}")                # 2A (十六进制大写)

# 百分比
percentage = 0.75
print(f"{percentage:%}")         # 75.000000%
print(f"{percentage:.1%}")       # 75.0%

# 日期时间格式化
from datetime import datetime
now = datetime.now()
print(f"Current time: {now:%Y-%m-%d %H:%M:%S}")
# 输出: Current time: 2023-12-25 14:30:45

# 多行f-string
name = "Bob"
age = 30
message = f"""
Hello, {name}!
You are {age} years old.
Next year you'll be {age + 1}.
"""
print(message)

# 调试功能（Python 3.8+）
x = 10
y = 20
print(f"{x=}, {y=}")             # x=10, y=20
print(f"{x + y=}")               # x + y=30

# 自定义格式化
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age
    
    def __format__(self, format_spec):
        if format_spec == "age":
            return f"{self.name} is {self.age} years old"
        elif format_spec == "name":
            return f"Name: {self.name}"
        else:
            return str(self)

person = Person("Alice", 25)
print(f"{person:age}")           # Alice is 25 years old
print(f"{person:name}")          # Name: Alice
```

### 优缺点

- **优点**：语法简洁，性能最好，支持表达式，可读性极佳
- **缺点**：仅Python 3.6+支持

## 4. Template Strings（模板字符串）

### 基本语法

```python
from string import Template
template = Template("格式化字符串 $变量")
result = template.substitute(变量=值)
```

### 详细示例

```python
from string import Template

# 基本用法
template = Template("Hello, $name!")
result = template.substitute(name="Alice")
print(result)  # Hello, Alice!

# 多个变量
template = Template("$name is $age years old.")
result = template.substitute(name="Bob", age=30)
print(result)  # Bob is 30 years old.

# 使用字典
data = {"name": "Charlie", "age": 35}
template = Template("$name is $age years old.")
result = template.substitute(data)
print(result)  # Charlie is 35 years old.

# ${}标识符边界
template = Template("${name}ist")  # 避免与后续字符混淆
result = template.substitute(name="Art")
print(result)  # Artist

# safe_substitute（不会因缺失变量而报错）
template = Template("Hello, $name!")
try:
    result = template.substitute()  # 缺失name变量
except KeyError as e:
    print(f"Error: {e}")

result = template.safe_substitute()  # 不会报错
print(result)  # Hello, $name!

# 复杂模板
template = Template("""
Dear $name,

Thank you for your purchase of $item.
Amount: $$${amount:.2f}
Date: $date

Best regards,
$company
""")

data = {
    "name": "Alice",
    "item": "Python Book",
    "amount": 29.99,
    "date": "2023-12-25",
    "company": "Python Store"
}

result = template.substitute(data)
print(result)
```

### 优缺点

- **优点**：安全性高，适合用户输入的模板，语法简单
- **缺点**：功能有限，不支持复杂格式化

## 5. 其他格式化相关方法

### str() 和 repr()

```python
# str()：面向用户的字符串表示
# repr()：面向开发者的字符串表示（可用于eval）

value = 42
print(str(value))      # 42
print(repr(value))     # 42

text = "Hello\nWorld"
print(str(text))       # Hello (换行) World
print(repr(text))      # 'Hello\nWorld'

class Person:
    def __init__(self, name):
        self.name = name
    
    def __str__(self):
        return f"Person: {self.name}"
    
    def __repr__(self):
        return f"Person('{self.name}')"

person = Person("Alice")
print(str(person))     # Person: Alice
print(repr(person))    # Person('Alice')
```

### join() 方法

```python
# 字符串连接
words = ["Hello", "World", "Python"]
print(" ".join(words))           # Hello World Python
print(", ".join(words))          # Hello, World, Python
print("-".join(words))           # Hello-World-Python

# 数字列表需要先转换为字符串
numbers = [1, 2, 3, 4, 5]
print(", ".join(map(str, numbers)))  # 1, 2, 3, 4, 5
```

### 文本换行和对齐

```python
text = "Hello, World!"

# 居中对齐
print(text.center(20))      # "    Hello, World!    "
print(text.center(20, '*')) # "****Hello, World!****"

# 左对齐
print(text.ljust(20))       # "Hello, World!       "
print(text.ljust(20, '-'))  # "Hello, World!-------"

# 右对齐
print(text.rjust(20))       # "       Hello, World!"
print(text.rjust(20, '='))  # "=======Hello, World!"
```

### 字符串填充和截断

```python
# 填充
text = "42"
print(text.zfill(5))        # 00042
print(text.zfill(10))       # 0000000042

# 截断
long_text = "This is a very long text that needs to be truncated"
print(long_text[:20])       # This is a very long
print(long_text[:20] + "...")  # This is a very long...
```

## 6. 格式化输出到文件

### 基本文件写入

```python
# 使用不同格式化方法写入文件
data = {"name": "Alice", "age": 25, "score": 95.5}

# 使用f-string
with open("output.txt", "w") as f:
    f.write(f"Name: {data['name']}\n")
    f.write(f"Age: {data['age']}\n")
    f.write(f"Score: {data['score']:.1f}\n")

# 使用format()
with open("output.txt", "w") as f:
    f.write("Name: {}\n".format(data["name"]))
    f.write("Age: {}\n".format(data["age"]))
    f.write("Score: {:.1f}\n".format(data["score"]))

# 使用%
with open("output.txt", "w") as f:
    f.write("Name: %s\n" % data["name"])
    f.write("Age: %d\n" % data["age"])
    f.write("Score: %.1f\n" % data["score"])
```

### 表格格式化输出

```python
# 创建表格数据
data = [
    ["Name", "Age", "Score"],
    ["Alice", 25, 95.5],
    ["Bob", 30, 87.2],
    ["Charlie", 28, 92.8]
]

# 计算每列最大宽度
col_widths = [max(len(str(row[i])) for row in data) for i in range(len(data[0]))]

# 生成表格
with open("table.txt", "w") as f:
    for row in data:
        formatted_row = " | ".join(f"{str(item):<{col_widths[i]}}" for i, item in enumerate(row))
        f.write(formatted_row + "\n")
        if row == data[0]:  # 在标题后添加分隔线
            separator = "-+-".join("-" * width for width in col_widths)
            f.write(separator + "\n")

# 输出内容：
# Name   | Age | Score 
# ------+----+-------
# Alice  | 25  | 95.5  
# Bob    | 30  | 87.2  
# Charlie| 28  | 92.8  
```

## 7. 性能对比

### 性能测试代码

```python
import timeit

name = "Alice"
age = 25
score = 95.5

# 测试不同方法的性能
def test_percent():
    return "Name: %s, Age: %d, Score: %.1f" % (name, age, score)

def test_format():
    return "Name: {}, Age: {}, Score: {:.1f}".format(name, age, score)

def test_fstring():
    return f"Name: {name}, Age: {age}, Score: {score:.1f}"

# 执行性能测试
n = 1000000
time_percent = timeit.timeit(test_percent, number=n)
time_format = timeit.timeit(test_format, number=n)
time_fstring = timeit.timeit(test_fstring, number=n)

print(f"% formatting: {time_percent:.4f} seconds")
print(f"str.format(): {time_format:.4f} seconds")
print(f"f-string: {time_fstring:.4f} seconds")
```

### 性能结果（示例）

```plain
% formatting: 0.3456 seconds
str.format(): 0.4567 seconds
f-string: 0.2345 seconds
```

**性能排序**：f-string > % 格式化 > str.format()

## 8. 最佳实践和建议

### 选择合适的格式化方法

| 场景 | 推荐方法 | 原因 |
| --- | --- | --- |
| Python 3.6+ | f-string | 性能最好，语法简洁，可读性最佳 |
| Python 2.6-3.5 | str.format() | 功能强大，兼容性好 |
| 简单格式化 | % 格式化 | 简单直接，历史代码兼容 |
| 用户输入模板 | Template | 安全性高，防止注入攻击 |

### 代码风格建议

```python
# 好的实践
name = "Alice"
age = 25

# 1. 使用f-string（Python 3.6+）
message = f"Hello, {name}! You are {age} years old."

# 2. 复杂表达式使用括号
result = f"The sum of {x} and {y} is {(x + y) * 2}."

# 3. 长字符串拆分
long_message = (
    f"Hello, {name}!\n"
    f"You are {age} years old.\n"
    f"Next year you'll be {age + 1}."
)

# 4. 格式化数字时指定精度
pi = 3.14159265359
print(f"Pi: {pi:.2f}")  # Pi: 3.14

# 5. 使用千位分隔符提高可读性
large_number = 1234567
print(f"Number: {large_number:,}")  # Number: 1,234,567

# 避免的实践
# 1. 不要在同一个项目中混用多种格式化方法
# 2. 避免过度复杂的格式化表达式
# 3. 不要在性能关键代码中使用str.format()
```

### 调试技巧

```python
# Python 3.8+ 的调试功能
x = 10
y = 20
print(f"{x=}, {y=}")           # x=10, y=20
print(f"{x + y=}")             # x + y=30

# 使用!r和!s
name = "Alice"
print(f"{name!r}")             # 'Alice' (repr)
print(f"{name!s}")             # Alice (str)

# 自定义对象的调试输出
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y
    
    def __repr__(self):
        return f"Point(x={self.x}, y={self.y})"

p = Point(3, 4)
print(f"{p!r}")                # Point(x=3, y=4)
```

## 9. 常见错误和解决方案

### 常见错误1：类型不匹配

```python
# 错误示例
age = 25
print("Age: %s" % age)  # 虽然能工作，但不规范

# 正确做法
print("Age: %d" % age)  # 使用正确的格式化符号
print(f"Age: {age}")    # f-string自动处理类型
```

### 常见错误2：索引越界

```python
# 错误示例
print("{0} {1} {2}".format("A", "B"))  # IndexError

# 正确做法
print("{0} {1}".format("A", "B"))     # 匹配参数数量
print("{} {}".format("A", "B"))        # 使用自动编号
```

### 常见错误3：键错误

```python
# 错误示例
data = {"name": "Alice"}
print("Age: {age}".format(**data))  # KeyError

# 正确做法
print("Name: {name}".format(**data))  # 使用存在的键
print("Name: {name}, Age: {age}".format(name="Alice", age=25))  # 提供所有参数
```

### 常见错误4：模板注入

```python
# 危险的做法（用户输入可能包含恶意代码）
user_input = "{name.__class__.__bases__[0].__subclasses__()}"
print(user_input.format(name="test"))  # 可能泄露系统信息

# 安全的做法
from string import Template
user_input = "$name"
template = Template(user_input)
print(template.safe_substitute(name="test"))  # 安全
```

## 10. 总结

### 格式化方法对比

| 方法 | 语法 | 性能 | 功能 | 安全性 | Python版本 |
| --- | --- | --- | --- | --- | --- |
| f-string | `f"{var}"` | 最高 | 最强 | 一般 | 3.6+ |
| str.format() | `"{0}".format(var)` | 中等 | 强 | 一般 | 2.6+ |
| % 格式化 | `"%s" % var` | 较高 | 有限 | 一般 | 所有版本 |
| Template | `Template("$var")` | 最低 | 基础 | 最高 | 所有版本 |

### 推荐使用场景

1. **现代Python开发（3.6+）**：

- 优先使用f-string
- 复杂逻辑时考虑代码可读性
- 调试时使用`{var=}`语法

2. **遗留代码维护**：

- 保持现有格式化方法的一致性
- 逐步迁移到f-string

3. **用户输入处理**：

- 使用Template确保安全性
- 避免直接使用format()或f-string

4. **性能敏感场景**：

- 使用f-string获得最佳性能
- 避免在循环中使用str.format()

### 未来趋势

- f-string已成为Python格式化的主流方法
- 每个新Python版本都在增强f-string功能
- 旧式格式化方法逐渐被淘汰
- 格式化性能持续优化

掌握Python格式化输出是编写高质量代码的基础技能，建议开发者重点学习f-string的使用，同时了解其他方法以便维护遗留代码。
