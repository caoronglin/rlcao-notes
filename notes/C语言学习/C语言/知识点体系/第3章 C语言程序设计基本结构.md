# 第3章 C语言程序设计基本结构

📎 [第3章 程序设计基本结构.pptx](https://www.yuque.com/attachments/yuque/0/2025/pptx/25845402/1749278719135-69cae6ac-42bc-4953-a455-15408c236fcd.pptx)

## 一、三种基本程序结构

### 1. 顺序结构

- **特点**：语句按顺序依次执行
- **易错点**：忽略输入数据的合法性检查（如三角形三边值检查）

### 2. 选择结构

- **二分支**：if-else语句
- **多分支**：switch语句或if-else if-else结构
- **特点**：根据条件选择执行路径

### 3. 循环结构

- **当型循环**：while, for
- **直到型循环**：do-while
- **特点**：重复执行代码块直到条件不满足

## 二、选择结构程序设计（重难点）

### 1. if语句

#### 形式：

```c
// 单分支
if(表达式) 语句;

// 双分支
if(表达式) 语句1;
else 语句2;

// 多分支
if(表达式1) 语句1;
else if(表达式2) 语句2;
...
else 语句n;
```

#### 易错点：

- **else配对问题**：else总是与最近的未匹配if配对

```c
// 错误示例
if(a==b)
  if(b==c)
    printf("a==b==c");
else // 实际与内层if配对
  printf("a!=b");

// 正确写法
if(a==b) {
  if(b==c)
    printf("a==b==c");
}
else
  printf("a!=b");
```

- **浮点数比较**：避免直接使用==比较浮点数

```c
// 错误示例
if(x == 1.0) 

// 正确做法
if(fabs(x - 1.0) < 1e-6)
```

### 2. switch语句

#### 基本结构：

```c
switch(表达式) {
  case 常量1: 语句1; break;
  case 常量2: 语句2; break;
  ...
  default: 语句n;
}
```

#### 重难点：

- **break作用**：防止case穿透

```c
// 无break将执行所有后续case
switch(grade) {
  case 'A': printf("优秀"); break; // 必须加break
  case 'B': printf("良好"); break;
  ...
}
```

- **case值要求**：

- 必须是整型常量表达式
- 值必须唯一
- 允许多个case共用代码块

```c
switch(score/10) {
  case 10: 
  case 9: printf("A"); break; // 90-100分
  case 8: printf("B"); break; // 80-89分
  ...
}
```

## 三、循环结构程序设计（重难点）

### 1. 循环语句比较

| 循环类型 | 特点 | 适用场景 |
| --- | --- | --- |
| for | 明确循环次数 | 计数循环 |
| while | 先判断后执行 | 条件循环 |
| do-while | 先执行后判断，至少一次 | 输入验证 |

### 2. 循环控制语句

- **break**：立即终止当前循环
- **continue**：跳过本次循环剩余语句

### 3. 循环嵌套

#### 易错点：

- **内外层循环变量**：避免混用

```c
for(int i=0; i<5; i++) {
  for(int j=0; j<5; j++) {
    // 正确：使用不同变量i和j
  }
}
```

- **死循环**：忘记修改循环变量

```c
// 错误示例：死循环
int i=0;
while(i<10) {
  printf("%d", i);
  // 忘记 i++ 
}
```

### 4. 典型算法

#### (1) 穷举法

```c
// 水仙花数求解
for(int n=100; n<=999; n++) {
  int a=n/100, b=n/10%10, c=n%10;
  if(a*a*a + b*b*b + c*c*c == n)
    printf("%d\n", n);
}
```

#### (2) 迭代法

```c
// 平方根迭代计算
float x0, x1 = a/2;
do {
  x0 = x1;
  x1 = (x0 + a/x0)/2;
} while(fabs(x1-x0) > 1e-5);
```

#### (3) 递推法

```c
// Fibonacci数列
long f1=1, f2=1;
for(int i=1; i<=20; i++) {
  printf("%12ld%12ld", f1, f2);
  f1 = f1 + f2;
  f2 = f2 + f1;
}
```

## 四、典型例题

### 1. 选择结构示例

#### 闰年判断

```c
#include <stdio.h>
int main() {
  int year;
  scanf("%d", &year);
  if((year%4==0 && year%100!=0) || (year%400==0))
    printf("%d是闰年\n", year);
  else
    printf("%d不是闰年\n", year);
  return 0;
}
```

#### 成绩等级转换

```c
#include <stdio.h>
int main() {
  int score;
  scanf("%d", &score);
  switch(score/10) {
    case 10: case 9: printf("A"); break;
    case 8: printf("B"); break;
    case 7: case 6: printf("C"); break;
    default: printf("D");
  }
  return 0;
}
```

### 2. 循环结构示例

#### 素数判断

```c
#include <stdio.h>
#include <math.h>
int main() {
  int m, k, i;
  scanf("%d", &m);
  k = sqrt(m);
  for(i=2; i<=k; i++)
    if(m%i == 0) break;
  if(i>k) printf("%d是素数\n", m);
  else printf("%d不是素数\n", m);
  return 0;
}
```

#### 九九乘法表

```c
#include <stdio.h>
int main() {
  for(int i=1; i<=9; i++) {
    for(int j=1; j<=i; j++)
      printf("%d*%d=%-4d", j, i, i*j);
    printf("\n");
  }
  return 0;
}
```

## 五、易错点总结

1. **选择结构**：

- if条件后误加分号：`if(x>0); { ... }`
- 混淆=和==：`if(x=0)` 总是假
- switch中忘记break导致case穿透

2. **循环结构**：

- 死循环：循环条件永远成立
- 循环变量未初始化
- 循环嵌套时内外层变量混淆
- 在for循环中修改循环变量

3. **通用问题**：

- 忘记包含必要头文件（如math.h）
- 浮点数比较使用==
- 复合语句忘记加花括号

1. 输入三角形三边，判断能否构成三角形，并计算面积

```c
#include<stdio.h>
#include<math.h>
int main(){
    int a,b,c;
    double area;
    printf("请输入三角形三边长度：");
    scanf("%d%d%d",&a,&b,&c);
    if((a+b)>c&&c>fabs(a-b)){
        double p=(a+b+c)/2;
        area=sqrt(p*(p-a)*(p-c)*(p-b));
    }
    printf("%.2lf",area);
}
```
