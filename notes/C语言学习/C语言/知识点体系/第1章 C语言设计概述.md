# 计算机如何解决问题

1. 程序是用计算机语言描述的、为了解决某一问题、满足一定语法规则的语句序列。
2. 计算机是可以按照人们事先编写的高速、精确地进行数据加工、处理的电子装置
3. 程序设计是把要求分解的任务或设计好的算法准换为计算机程序的全过程

1. 编译连接后，可产生执行文件，可以脱离编译环境独立运行
2. 发布编译后的程序，有助于保护软件版权
3. 相对于解释方式，程序执行效率更高
