# 2.3布尔类型、空值和列表运算

# 布尔类型

Python 中布尔类型用作逻辑运算

## 关系运算符

Python 中的关系运算符可以一起使用，与人们的认知并无二意

| 运算符 | 含义 |
| --- | --- |
| == | 判断相等 |
| ！= | 判断不等于 |
| > | 判断大于 |
| >= | 判断大于等于 |
| < | 判断小于 |
| <= | 判断小于等于 |

> [!success]
> 基本基表法则：
>
>   1. 关系运算符优先级相等
>   2. 两个数字比较，按照数字大小进行比较
>   3. 两个字符串比较，关系运算符按照字符串中字符的 Unicode 码值比较，从左到右比较
>
>   1. 若第一个字符相等，则比较第二个字符
>   2. 以此类推，直到比较出大小

## 逻辑运算符

and、not、or 常用来连接条件表达式构成更加复杂的条件表达式。

> [!note]
> and 和 or 具有惰性求值或者短路的特点，连接多个表达式是只计算必须要计算的值
>
> 运算符 and 和 or 并不一定会返回布尔值，而是最后一个被计算的表达式的值，但是 not 一定返回 true 或者 false

> [!success]
>   1. and 是与运算，所有值为真才为真
>   2. or 是或运算
>   3. not 是非运算

### 空值

空值是 Python 中的 一个特殊类型，用 none 表示，不能理解为 0，0 是有意义的

### 运算符的优先级和结合性

| 优先级 | 运算符 | 描述 | 结合性 |
| --- | --- | --- | --- |
| 1 | `(expressions...)`<br>`[expressions...]`<br>`{key: value...}`<br>`{expressions...}` | 圆括号、列表、字典、集合表达式 | 从左到右 |
| 2 | `x[index]`<br>`x[index:index]`<br>`x(arguments...)`<br>`x.attribute` | 下标、切片、调用、属性引用 | 从左到右 |
| 3 | `await x` | 等待表达式 | 无 |
| 4 | `**` | 幂运算 | 从右到左 |
| 5 | `+x`<br>`-x`<br>`~x` | 正号、负号、按位取反 | 无 |
| 6 | `*`<br>`@`<br>`/`<br>`//`<br>`%` | 乘、矩阵乘、除、整除、取模 | 从左到右 |
| 7 | `+`<br>`-` | 加、减 | 从左到右 |
| 8 | `<<`<br>`>>` | 左移、右移 | 从左到右 |
| 9 | `&` | 按位与 | 从左到右 |
| 10 | `^` | 按位异或 | 从左到右 |
| 11 | `\|` | 按位或 | 从左到右 |
| 12 | `in`<br>`not in`<br>`is`<br>`is not`<br>`<`<br>`<=`<br>`>`<br>`>=`<br>`!=`<br>`==` | 成员测试、身份测试、比较 | 从左到右 |
| 13 | `not x` | 逻辑非 | 无 |
| 14 | `and` | 逻辑与 | 从左到右 |
| 15 | `or` | 逻辑或 | 从左到右 |
| 16 | `if-else` | 条件表达式（三元运算符） | 从右到左 |
| 17 | `lambda` | Lambda 表达式 | 无 |
| 18 | `:=` | 海象运算符（赋值表达式） | 从右到左 |

# 列表类型

列表可由零个或多个元素组成，元素之间用逗号分开

```python
a=[2,3,4,5,6,]
```
