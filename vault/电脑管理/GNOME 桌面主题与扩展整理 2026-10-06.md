## Problems（**重要：本次操作造成破坏**）

### 事故：9 个扩展卡死在 ERROR 状态，必须注销重登恢复

**根因**：我把 `enabled-extensions` 和 `disabled-extensions` 用两次 `gsettings set`
**无间隔连续写入**。GNOME Shell 的扩展系统是异步状态机，读到源码
`ui/extensionSystem.js` 的「rebase」逻辑后确认问题：

```js
// "Rebase" the extension order by disabling and then enabling extensions
// in order to help prevent conflicts.
// Example:
//   order = [A, B, C, D, E]
//   user disables C
//   this should: disable E, disable D, disable C, enable D, enable E
```

**禁用一个扩展会连带 disable + re-enable 它后面所有扩展**。两次快速写入 →
多轮 disable/enable 交错 → 多个扩展的 `disable()` 在未完成状态下重复执行并抛异常
→ 旧的状态指示器（status indicator）残留在 `Main.panel.statusArea` 未销毁
→ 之后每次 `enable()` 都撞 `throw new Error("Extension point conflict: there is
already a status indicator for role X")`（`ui/panel.js:714`）。

**为什么无法自愈**——ERROR 是状态机死胡同：

```js
async _callExtensionDisable(uuid) {
    if (extension.state !== ExtensionState.ACTIVE) return;    // ERROR 直接返回
}
async _callExtensionEnable(uuid) {
    if (extension.state !== ExtensionState.INACTIVE) return;  // ERROR 直接返回
}
```

**受影响的 9 个扩展**：Vitals、blur-my-shell、chinese-calendar、clipboard-indicator、
drive-menu、media-controller、quick-settings-avatar、tiling-assistant、user-theme。
（`ubuntu-dock` 变为 INACTIVE，`lockscreen-extension` 为 INITIALIZED。）

### 已验证无效的所有补救手段（不要重复尝试）

| 手段 | 结果 |
|---|---|
| `gnome-extensions disable/enable <uuid>` | 无效，ERROR 状态下两个操作都早退 |
| `gnome-extensions reset` | 只重置扩展设置，不动运行态 |
| D-Bus `ReloadExtension` | `Method ReloadExtension is not implemented` |
| D-Bus `Eval` | 返回 `(false, '')`，`unsafe_mode` 未开 |
| 切换 `disable-extension-version-validation` | **反而扩大损害**（触发全量 reload） |
| Wayland `Alt+F2` → `r` | GNOME 49+ 已移除，`runDialog.js` 内部命令只剩 lg/debugexit/rt |
| `systemctl --user restart org.gnome.Shell@ubuntu.service` | `RefuseManualStart=on` + `Restart=no` |
| 等待 | 不收敛，错误停止但状态不复位 |

### 唯一恢复方式

**注销重登**（或重启）。`panel.statusArea` 随 shell 进程销毁而清空，
重登后按新的 gsettings 列表重建，9 个扩展会正常加载。

```bash
# 确认恢复后状态
gnome-extensions list --enabled | wc -l   # 应为 16
for u in Vitals@CoreCoding.com blur-my-shell@aunetx; do
  gnome-extensions info "$u" | grep 状态
done
```

## Reproduction（错误做法，禁止再犯）

```bash
# ✗ 错误：两次写入无间隔
gsettings set org.gnome.shell enabled-extensions "[...]"
gsettings set org.gnome.shell disabled-extensions "[...]"

# ✓ 正确：逐个操作 + 间隔验证
gnome-extensions disable <uuid>
sleep 2
gnome-extensions info <uuid>   # 确认状态已稳定
```
或直接用 GUI（gnome-extensions-app / 扩展管理器）——它内部逐项提交。
