# 生信前言

## 什么是生信

生信（**生物信息学，Bioinformatics**）可以先理解为：**用计算机、统计学和算法，处理并解释生物学数据的学科**。🧬

1. **数据质控**：测序质量是否可靠？接头、低质量 reads 要不要去除。  
2. **比对/组装**：这些序列来自基因组的哪个位置？或者在没有参考基因组时拼出序列。  
3. **定量与统计**：不同样本之间，哪些基因表达显著不同？是否有突变、微生物组成变化或细胞亚群差异？  
4. **生物学解释**：这些基因是否集中在某条通路？能否支持某个疾病机制或实验假说？
