事件管理过程 教材 8.4.3

案例题高频：给运维场景要求补流程。原文顺序如下——

1事件接收和记录
2分类和初步支持
3调查和诊断
4解决与恢复
5事件关闭

目标是「在成本允许的范围内尽快恢复正常服务」——答题时先写目标，再写步骤。

易混对照：三个"生命周期" 跨章节

信息系统生命周期规划（立项）→ 开发 → 运维 → 消亡
IT 服务生命周期战略规划 → 设计实现 → 运营提升 → 退役终止
项目生命周期启动 → 计划 → 执行 → 收尾
开发阶段细分总体规划 → 系统分析 → 系统设计 → 系统实施 → 系统验收

三个都叫"生命周期"但阶段不同，是选择题的经典干扰点。
