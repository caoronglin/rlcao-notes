## 3. 可信度分析

### 3.1 什么是"可信度"

进化树中每个**内部分支**（分叉点）的可信度由两种独立方法评估：

| 指标 | 全称 | 范围 | 含义 |
|------|------|------|------|
| **SH-aLRT** | Shimodaira-Hasegawa Approximate Likelihood Ratio Test | 0–100% | 该分支被数据支持的概率 |
| **UFbootstrap** | Ultrafast Bootstrap | 0–100% | 重抽样 2000 次中该分支出现的频率 |
| **aBayes** | Approximate Bayes | 0–1 | 该分支的后验概率 |

### 3.4 年龄可信度

年龄计算基于 lLTR-rLTR 序列的 K2P 距离，受以下因素影响：

| 因素 | 影响 |
|------|------|
| lLTR/rLTR 序列长度 | 短序列 (<200 bp) 年龄估计方差大 |
| K2P 距离过大 (>0.5) | 饱和效应，年龄被低估 |
| 极端异常值 (>100 MYA) | 4个，建议剔除 (比对错误) |
| identity=100% | 3,990 个，年龄=0，可能为极近期插入或注释问题 |

## 4. 如何使用可信度指标

### 4.1 在 iTOL 中可视化

1. 打开 <https://itol.embl.de/>
2. 上传 `top800_tree_v2_superfamily.tree`
3. 支持率自动显示在分支上
4. 建议设置：
   - SH-aLRT < 50% → 灰/红色分支
   - UFbootstrap < 50% → 虚线分支
   - 仅展示支持率 ≥ 75% 的数值

### 4.2 分支可信度解读标准

| 同时满足 | 结论 |
|----------|------|
| SH-aLRT ≥ 90% **且** UFbootstrap ≥ 95% | ⭐ 发表级别，几乎确定 |
| SH-aLRT ≥ 75% **且** UFbootstrap ≥ 75% | ✅ 高可信，可做结论 |
| SH-aLRT ≥ 50% **或** UFbootstrap ≥ 50% | ⚠️ 参考级别，需更多证据 |
| 两者 < 50% | ❌ 不可靠，不做结论 |

### 4.3 年龄值使用建议

- 中位数 (0.31 MYA) 和分布比单个值更有意义
- 极端值 (>100 MYA) 应排除或标记
- 年龄=0 的 LTR 可能是近期插入 (<1万年) 或测序/注释错误
- 同一超家族内的年龄差异反映不同插入时间

### 4.4 超家族进化关系

Gypsy 和 Copia 是 LTR 逆转录转座子的两大超家族，在树中应形成明显的两大支。如果某分支同时包含 Gypsy 和 Copia，检查其支持率 — 低支持率的分支可能是聚类噪声。

## 6. 方法

### 6.1 年龄: K2P from 原始序列

```
1. 从参考基因组提取 lLTR + rLTR 序列 (52,648 对)
2. 全局成对比对 (Biopython pairwise2.globalms)
3. K2P: K = -½·ln[(1-2p-q)·√(1-2q)]
   其中 p=转换率, q=颠换率
4. 年龄: T(MYA) = K / (2 × 1.3×10⁻⁸) / 10⁶
```

### 6.2 Top800 进化树

```
LTRRT 核苷酸序列 (bedtools getfasta)
  → 6框翻译 → 最长 ORF ≥ 80 aa
  → MAFFT --auto 比对
  → trimAl -gt 0.3
  → IQ-TREE: -m MFP -B 2000 -alrt 1000 -bnni -nm 5000 -nt 80
```
