# 4.1条件语句

# 一、条件语句的基本概念

Python条件语句是通过一条或多条语句的执行结果（True或者False）来决定执行的代码块。Python中的条件语句主要包括`if`、`if-else`和`if-elif-else`三种形式。

在Python中，任何非0和非空（null）值为True，0或者null为False。

# 二、条件语句的基本语法

### 1. if语句

`if`语句是最基本的条件判断形式，当条件为True时执行相应的代码块。

**语法结构**：

```python
if 条件表达式:
    执行语句1
    执行语句2
    ...
```

**示例**：

```python
age = 18
if age >= 18:
    print("您已成年")
    print("可以进入")
```

### 2. if-else语句

`if-else`语句在条件为True时执行if后面的代码块，为False时执行else后面的代码块。

**语法结构**：

```python
if 条件表达式:
    执行语句1
    ...
else:
    执行语句2
    ...
```

**示例**：

```python
age = 16
if age >= 18:
    print("您已成年")
else:
    print("您未成年")
```

### 3. if-elif-else语句

当需要判断多个条件时，可以使用`if-elif-else`语句。elif是else if的缩写。

**语法结构**：

```python
if 条件表达式1:
    执行语句1
    ...
elif 条件表达式2:
    执行语句2
    ...
elif 条件表达式3:
    执行语句3
    ...
else:
    执行语句4
    ...
```

**示例**：

```python
score = 85
if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

### 4. 简单的语句组

对于简单的条件判断，可以在同一行上编写if语句：

```python
var = 100
if var == 100: print("变量 var 的值为100")
print("Good bye!")
```

# 三、条件表达式（三元运算符）

> [!note]
> Python中的条件表达式（也称为三元运算符）提供了一种简洁的方式来编写简单的条件判断。

### 1. 基本语法

**语法结构**：

```python
值1 if 条件表达式 else 值2
```

> [!error]
> **解释**：如果条件表达式为True，则返回值1；如果条件表达式为False，则返回值2。

### 2. 示例

```python
# 比较两个数的大小
x, y = 4, 3
smaller = x if x < y else y
print(smaller)  # 输出: 3

# 判断奇偶数
num = 10
result = "偶数" if num % 2 == 0 else "奇数"
print(result)  # 输出: 偶数
```

### 3. 与传统if-else的比较

**传统if-else写法**：

```python
if x < y:
    smaller = x
else:
    smaller = y
```

**三元运算符写法**：

```python
smaller = x if x < y else y
```

三元运算符使代码更加简洁，特别适合简单的条件判断。

## 四、条件语句中的逻辑运算符

在Python中，可以使用逻辑运算符来组合多个条件。

### 1. and运算符

当所有条件都为True时，整个表达式才为True。

```python
age = 25
score = 85
if age >= 18 and score >= 60:
    print("符合条件")
```

### 2. or运算符

当至少有一个条件为True时，整个表达式就为True。

```python
day = "Sunday"
if day == "Saturday" or day == "Sunday":
    print("周末")
```

### 3. not运算符

用于反转条件的布尔值。

```python
is_raining = False
if not is_raining:
    print("没有下雨")
```

### 4. 运算符优先级

- 比较运算符（>、<、==、>=、<=）的优先级高于逻辑运算符
- not的优先级高于and
- and的优先级高于or

可以使用括号来改变运算顺序：

```python
if (age > 18 and score > 80) or (age > 20 and score > 70):
    print("符合条件")
```

## 五、嵌套条件语句

条件语句可以嵌套使用，即在if语句内部再使用if语句。

### 1. 基本嵌套

```python
age = 20
gender = "female"

if age >= 18:
    if gender == "male":
        print("成年男性")
    else:
        print("成年女性")
else:
    if gender == "male":
        print("未成年男性")
    else:
        print("未成年女性")
```

### 2. 多层嵌套

```python
score = 85
age = 20

if score >= 90:
    if age >= 18:
        print("优秀成年人")
    else:
        print("优秀未成年人")
elif score >= 80:
    if age >= 18:
        print("良好成年人")
    else:
        print("良好未成年人")
else:
    print("一般")
```

**注意**：过度嵌套会降低代码的可读性，建议使用逻辑运算符或重构代码来减少嵌套层级。

## 六、条件语句的最佳实践

### 1. 使用all()函数替代多个and运算符

当需要检查多个条件是否都为True时，使用`all()`函数可以提高代码的可读性。

**传统写法**：

```python
condition1 = x > 0
condition2 = y < 10
condition3 = z == 5
if condition1 and condition2 and condition3:
    print("All conditions are met!")
```

**使用all()的写法**：

```python
if all([x > 0, y < 10, z == 5]):
    print("All conditions are met!")
```

**优点**：

- 可读性更好
- 更容易扩展（添加更多条件）
- 代码更简洁

### 2. 使用any()函数替代多个or运算符

当需要检查多个条件中是否至少有一个为True时，使用`any()`函数可以提高代码的可读性。

**传统写法**：

```python
condition1 = x > 0
condition2 = y < 10
condition3 = z == 5
if condition1 or condition2 or condition3:
    print("At least one condition is met!")
```

**使用any()的写法**：

```python
if any([x > 0, y < 10, z == 5]):
    print("At least one condition is met!")
```

### 3. 将all()和any()与生成器表达式结合使用

使用生成器表达式可以提高内存效率，特别是在处理大型数据集时。

**使用all()和生成器表达式**：

```python
numbers = [1, 2, 3, 4, 5]
if all(n > 0 for n in numbers):
    print("All numbers are positive.")
```

**使用any()和生成器表达式**：

```python
numbers = [1, 3, 5, 7, 8]
if any(n % 2 == 0 for n in numbers):
    print("There's at least one even number.")
```

**优点**：

- 内存效率高：不需要一次性存储所有值
- 延迟评估：找到满足条件的值后立即停止评估

### 4. 避免过度嵌套

过度嵌套的条件语句会降低代码的可读性，可以通过以下方式改进：

**使用逻辑运算符**：

```python
# 不推荐的嵌套写法
if age >= 18:
    if score >= 80:
        if has_experience:
            print("符合条件")

# 推荐的写法
if age >= 18 and score >= 80 and has_experience:
    print("符合条件")
```

**提前返回**：

```python
def check_eligibility(age, score, has_experience):
    if age < 18:
        return False
    if score < 80:
        return False
    if not has_experience:
        return False
    return True
```

### 5. 使用字典替代多重if-elif-else

Python没有switch语句，当需要处理多个条件分支时，可以使用字典来替代多重if-elif-else。

**传统写法**：

```python
def get_day_name(day_num):
    if day_num == 1:
        return "Monday"
    elif day_num == 2:
        return "Tuesday"
    elif day_num == 3:
        return "Wednesday"
    elif day_num == 4:
        return "Thursday"
    elif day_num == 5:
        return "Friday"
    elif day_num == 6:
        return "Saturday"
    elif day_num == 7:
        return "Sunday"
    else:
        return "Invalid day"
```

**使用字典的写法**：

```python
def get_day_name(day_num):
    day_map = {
        1: "Monday",
        2: "Tuesday",
        3: "Wednesday",
        4: "Thursday",
        5: "Friday",
        6: "Saturday",
        7: "Sunday"
    }
    return day_map.get(day_num, "Invalid day")
```

**优点**：

- 代码更简洁
- 更容易维护和扩展
- 查找效率更高

## 七、条件语句的注意事项

### 1. 缩进的重要性

Python使用缩进来表示代码块，同一代码块中的语句必须有相同的缩进量。

```python
# 正确的缩进
if age >= 18:
    print("成年人")
    print("可以进入")

# 错误的缩进
if age >= 18:
print("成年人")  # 缩进错误
  print("可以进入")  # 缩进不一致
```

### 2. 短路求值

Python中的逻辑运算符采用短路求值（Short-circuit Evaluation）：

- `and`运算符：如果第一个条件为False，则不会评估第二个条件
- `or`运算符：如果第一个条件为True，则不会评估第二个条件

**示例**：

```python
a = 0
b = 1

# 不会报错，因为a > 0为False，不会评估后面的条件
if (a > 0) and (b / a > 2):
    print("yes")
else:
    print("no")

# 会报错，因为a > 0为False，会评估后面的条件
if (a > 0) or (b / a > 2):
    print("yes")
else:
    print("no")
```

### 3. 真值测试

在Python中，以下值被视为False：

- None
- False
- 所有数值类型的零：0, 0.0, 0j
- 空的序列和集合：'', (), [], {}
- 用户定义的类的实例，如果类定义了`__bool__()`或`__len__()`方法，且该方法返回0或False

其他所有值都被视为True。

```python
# 真值测试示例
if []:
    print("空列表为True")
else:
    print("空列表为False")  # 这行会被执行

if [1, 2, 3]:
    print("非空列表为True")  # 这行会被执行
else:
    print("非空列表为False")
```

### 4. 条件表达式中的赋值

在Python 3.8之前，不能在条件表达式中直接进行赋值。Python 3.8引入了海象运算符（:=），允许在条件表达式中进行赋值。

```python
# Python 3.8+ 的海象运算符
if (n := len(some_list)) > 10:
    print(f"列表长度{n}大于10")

# 传统写法
n = len(some_list)
if n > 10:
    print(f"列表长度{n}大于10")
```

## 八、条件语句的常见应用场景

### 1. 输入验证

```python
def get_age():
    age = input("请输入您的年龄: ")
    if age.isdigit():
        age = int(age)
        if age >= 0 and age <= 120:
            return age
        else:
            print("年龄必须在0-120之间")
    else:
        print("请输入有效的数字")
    return get_age()
```

### 2. 状态检查

```python
def check_system_status():
    cpu_usage = get_cpu_usage()
    memory_usage = get_memory_usage()
    disk_usage = get_disk_usage()
    
    if cpu_usage > 90:
        alert("CPU使用率过高")
    if memory_usage > 90:
        alert("内存使用率过高")
    if disk_usage > 90:
        alert("磁盘使用率过高")
    
    if all([cpu_usage < 70, memory_usage < 70, disk_usage < 70]):
        alert("系统状态良好")
```

### 3. 权限控制

```python
def check_permission(user_role, action):
    permission_map = {
        'admin': ['read', 'write', 'delete'],
        'editor': ['read', 'write'],
        'viewer': ['read']
    }
    
    if user_role in permission_map:
        if action in permission_map[user_role]:
            return True
    return False
```

### 4. 数据处理

```python
def process_data(data):
    if not isinstance(data, (list, tuple)):
        raise TypeError("数据必须是列表或元组")
    
    if not data:
        return []
    
    processed = []
    for item in data:
        if isinstance(item, int) and item > 0:
            processed.append(item * 2)
        elif isinstance(item, str) and len(item) > 0:
            processed.append(item.upper())
    
    return processed
```
