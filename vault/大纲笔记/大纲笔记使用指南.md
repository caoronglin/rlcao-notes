# 大纲笔记与思维导图

## 写作方式
- 用标题组织主题，用缩进列表拆分想法。
- Tab 缩进，Shift+Tab 提升层级。
- Outliner 支持列表折叠、拖动与层级操作；可在命令面板搜索 Outliner。

## 一篇笔记，两种视图
- 打开任意大纲笔记后按 **Ctrl+Alt+M**，右侧面板出导图（XL Toolbox，本库自研）。
- 导图直接读当前 Markdown 的标题与缩进列表：标题是分支，缩进是层级，没写标题也能用纯列表。
- 改完大纲，导图会自动跟着重画；也可点工具栏「重新生成」。
- 点节点跳到原文对应行；`+N` 圆点折叠子树，「折到 2 层」一键收拢全部内容。
- 要给别人看或放进报告，点「导出 SVG」（矢量，改字不用重画）或「导出 PNG」，文件写在笔记同目录。
- 需要自由布局的关系图时，使用内置 Canvas；它与自动生成的大纲导图用途不同。

## 常用入口
- 工作台“新建大纲”。
- 命令面板 QuickAdd：新建大纲笔记。
