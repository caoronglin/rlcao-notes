# 7.2异常操作

#### 以下是对Python异常处理（异常处理机制）的全面总结，综合了核心概念、语法结构、常见异常类型及最佳实践，便于你快速掌握和查阅。

---

## 一、异常基础

### 1. 什么是异常？

异常是程序在执行过程中发生的事件，会打断正常的指令流。若未妥善处理，程序将终止并报错。Python通过异常对象表示错误，并提供了强大的异常处理机制。

### 2. 异常的类层次结构

所有内置异常类都继承自`BaseException`，常见的直接或间接继承自`Exception`。部分主要异常如下：

- `Exception`：所有非系统退出类异常的基类。

- `ArithmeticError`：算术错误（如`ZeroDivisionError`、`OverflowError`）。
- `LookupError`：索引、键错误（如`IndexError`、`KeyError`）。
- `OSError`：操作系统相关错误（如`FileNotFoundError`、`PermissionError`）。
- `ValueError`：传入无效参数。
- `TypeError`：类型不匹配。
- 等等……

完整异常列表参考：[Python官方文档](https://docs.python.org/3/library/exceptions.html)

## 二、异常处理语法

### 1. 基本结构：try...except

```python
try:
    # 可能产生异常的代码
    f = open("file.txt", "r")
except IOError as e:
    # 捕获特定异常，并获取异常对象
    print("文件打开失败:", e)
except Exception as e:
    # 捕获所有其它Exception子类异常
    print("发生异常:", e)
```

- 可以指定多个`except`，按顺序匹配。
- `as e`用于获取异常实例，便于输出或记录。

### 2. 捕获所有异常（慎用）

```python
try:
    # 可能出错的代码
except:
    print("捕获所有异常，包括键盘中断和系统退出，慎用！")
```

> 注意：这样会捕获`KeyboardInterrupt`和`SystemExit`，可能导致程序无法正常退出。

### 3. 使用else

当try块没有异常时执行`else`：

```python
try:
    print("尝试执行")
except:
    print("出错了")
else:
    print("没有异常时执行")
```

### 4. 使用finally

无论是否发生异常，`finally`块都会执行（通常用于资源清理）：

```python
try:
    f = open("file.txt", "r")
except IOError:
    print("打开失败")
finally:
    f.close()  # 确保文件关闭
```

## 三、主动抛出异常（raise）

使用`raise`可以主动抛出异常：

```python
def check_positive(num):
    if num < 0:
        raise ValueError("数值必须为正")
    return num

try:
    check_positive(-1)
except ValueError as e:
    print(e)  # 输出：数值必须为正
```

## 四、自定义异常

可通过继承`Exception`类创建自定义异常：

```python
class MyError(Exception):
    def __init__(self, msg):
        self.msg = msg

    def __str__(self):
        return self.msg

try:
    raise MyError("这是一个自定义异常")
except MyError as e:
    print(e)  # 输出：这是一个自定义异常
```

## 五、使用traceback模块获取详细信息

`traceback`模块用于获取和打印异常的堆栈跟踪信息，便于调试：

```python
import traceback

try:
    1 / 0
except Exception:
    traceback.print_exc()
```

输出类似：

```plain
Traceback (most recent call last):
  File "test.py", line 4, in <module>
    1 / 0
ZeroDivisionError: division by zero
```

- `traceback.format_exc()`：返回字符串，便于日志记录。
- `traceback.print_exc(file=open('tb.txt', 'w+'))`：可将异常信息写入文件。

## 六、最佳实践

1. **捕获具体异常**：避免裸露的`except:`，尽量捕获明确异常类型。
2. **合理使用else和finally**：`else`用于无异常时的逻辑，`finally`用于资源释放。
3. **慎用异常覆盖控制流**：异常用于异常，不要用其代替常规条件判断。
4. **记录异常信息**：生产环境中建议记录异常日志（如`logging`模块），而非直接打印。
5. **自定义异常要有意义**：明确区分业务异常与系统异常。
