# 质控与过滤

## 质控

```shell
fastp -i DM01_KN1_1.fq -I DM01_KN1_2.fq -o ../fastp/DM01_KN1_1.fq.gz -O ../fastp/DM01_KN1_2.fq.gz
```

## 过滤

```shell
trim_galore -q 20 --phred33 --stringency 3 --length 20 -e 0.1 \
    --paired DM01_KN1_1.fq DM01_KN1_2.fq\
    --gzip -o ./output --fastqc
```
