# Highly accurate protein structure prediction with AlphaFold.

## 一句话结论

作者开发了完全重新设计的神经网络 AlphaFold（CASP14 参赛名为 AlphaFold2），在 CASP14 盲测中以中位主链精度 0.96 Å r.m.s.d.95 大幅超越其他方法（次优方法 2.8 Å），在多数情形下达到接近实验结构的原子级精度，并能给出可靠的逐残基置信度（pLDDT）。

## 研究问题

蛋白质结构预测（protein structure prediction）是从氨基酸序列推断三维结构的问题，是"蛋白质折叠问题"中的结构预测部分，50 余年来未解决；实验测定一条结构需数月至数年，已测定约 10 万个独特蛋白结构，与数十亿已知序列之间存在巨大缺口（来自 dataset.json 中的摘要）。论文指出现有两类路线——基于物理相互作用的模拟路线（受限于计算不可解性、稳定性对环境的依赖、物理模型精度不足）与基于进化历史的生物信息学路线（利用同源模板与进化耦联）——在"无近同源实验结构"的多数情形下都远达不到实验精度。本文要回答的是：能否构建一个计算方法，在大多数情形下以接近实验的精度预测蛋白质结构，并且让预测自带可信度。

## 方法与数据

- **总体设计**：AlphaFold 直接预测给定蛋白所有重原子的三维坐标，输入为氨基酸一级序列 + 同源序列比对（MSA）+ 少量同源模板结构（templates）。全文方法细节依赖 Supplementary Methods 1.1–1.16、Algorithms 1–32、Supplementary Figs. 1–8、Supplementary Tables 1–6。
- **两阶段网络**（Fig. 1e）：第一阶段为躯干（trunk），由 48 个 Evoformer 模块重复堆叠，输出 Nseq × Nres 的 MSA 表示（processed MSA）与 Nres × Nres 的残基对表示（pair representation）；第二阶段为结构模块（structure module），输出原子坐标。
- **Evoformer 的关键机制**：MSA 表示通过对序列维求和的逐元素外积更新对表示，且在每个模块中都执行（而非只在网络开头一次）；对表示上有两种更新——带"三角形第三边"logit 偏置的轴向注意力（triangle self-attention）与三角乘法更新（triangle multiplicative update），二者单独用都能得到高精度，组合更优；MSA 的行注意力（per-sequence attention）由对表示投影出的额外 logits 偏置，形成"对表示→MSA 表示"的信息回流闭环。
- **结构模块与 IPA**：每个残基用一个全局刚性框架（旋转 + 平移，"residue gas"，对应 N-Cα-C 几何）表示，初始化为恒等旋转与原点位置；先用不变点注意力（invariant point attention, IPA）更新单残基表示（不变 3D 位置），再等变地更新残基框架。IPA 在注意力中加入了局部框架下产生的 3D 查询点/键点/值点，对全局旋转平移不变，并引入空间局部性偏置。骨架的肽键几何在结构模块运行中完全不受约束（网络会频繁违反链约束，以换取各部分同时局部精化），最终靠 Amber 力场梯度下降松弛（OpenMM v.7.3.1 + Amber99sb）消除立体化学违规。
- **输出与损失**：侧链 χ 角与逐残基精度 pLDDT 由网络末端的小型逐残基网络输出；pTM 由最终对表示的线性投影（预测两两误差）得到。核心损失 FAPE（frame-aligned point error）：对所有"预测框架 (Rk, tk) 与真实框架对齐"的 Nframes × Natoms 距离做截断 L1 惩罚，是 AlphaFold 手性（chirality）的主要来源（Supplementary Methods 1.9.3、Supplementary Fig. 9）。辅助损失包括：对表示线性投影到分箱距离分布（distogram）的交叉熵、随机掩蔽 MSA 的 BERT 式重建损失、结构模块输出预测分箱 lDDT-Cα、训练期的侧链损失、微调期的结构违规损失。
- **循环精化（recycling）**：整个网络重复运行并把输出递归回喂，本文配置为 4 次循环 × 48 个 Evoformer 模块，共提供 192 个中间结构轨迹。
- **自蒸馏**：先用初训模型对 Uniclust30 中约 350,000 条（Methods 精确写为 355,993 条）多样序列预测结构并筛出高置信子集，再用 PDB 与预测结构混合数据从头训练同架构（75% 采自 Uniclust 预测集、25% 采自聚类后的 PDB 集），显著提升精度。
- **训练配置**：训练用 PDB 拷贝（2019-08-28 下载），结构发布日期上限 2018-04-30；按 40% 序列一致性聚类的簇大小反比例采样，随机裁剪至 256 残基、批大小 128，每 TPU v3 核 1 个样本即 128 个 TPU v3 核；训练约 1000 万样本至收敛，再以 384 残基长裁剪、更大 MSA 栈、降低学习率微调；初训约 1 周、微调约 4 天。共训练 5 个随机种子不同的模型（部分用模板、部分不用），CASP14 后再微调加入 pTM 目标（用于 Fig. 2d）。
- **序列与模板数据库**：自建 BFD（65,983,866 个蛋白家族 / 2,204,359,010 条序列，覆盖 UniProt、土壤参考蛋白目录、海洋真核参考目录及宏基因组/宏转录组）；MSA 检索用 Uniref90 v.2020_01、BFD、Uniclust30 v.2018_08、MGnify v.2018_12；模板检索用 2020-05-14 的 PDB 与 2020-05-13 的 PDB70。工具：HHBlits / HHSearch（hh-suite v.3.0-beta.3）、jackhmmer（HMMER3）、TensorFlow + Sonnet。
- **评估数据**：近期 PDB 测试集使用 2021-02-15 下载的 PDB，筛除发布日期 ≤2018-04-30、单氨基酸链、含模糊化学组分、重复、解析残基 <16、含未知残基、NMR 结构、>1400 残基链等，最终 10,795 条链；模板身份用 hmmsearch 对 PDB SEQRES fasta 判定。指标：lDDT（全重原子）、lDDT-Cα（主链）、GDT（CASP 结构域）、TM-score（全链叠加）、r.m.s.d.95（5 次最小二乘对齐后取误差最低 95% Cα 的 r.m.s.d.）。

## 主要结果与关键数字

- **CASP14（2020 年 5–7 月，以"AlphaFold2"队名参赛）**：主链中位精度 0.96 Å r.m.s.d.95（95% CI 0.85–1.16 Å），次优方法 2.8 Å（95% CI 2.7–4.0 Å）；全原子精度 1.5 Å r.m.s.d.95（95% CI 1.2–1.6 Å）对次优 3.5 Å（95% CI 3.1–4.2 Å）。作为参照，碳原子宽度约 1.4 Å。强模板存在时也明显优于基于模板的方法。
- **近期 PDB 泛化**：3,144 条全链中位主链 r.m.s.d. 1.46 Å；pLDDT 与真实 lDDT-Cα 的 Pearson r = 0.76，pTM 与 TM-score 的 Pearson r = 0.85。
- **计算开销**：单模型 V100 计时——ensemble 配置 256 残基 4.8 min、384 残基 9.2 min、2500 残基 18 h；关闭 ensemble 快 8 倍（0.6 min / 1.1 min / 2.1 h）；开源代码因启用 XLA 编译器比 CASP14 版本更快。16 GB V100 无 ensemble 可推约 1300 残基；内存随残基数近似平方增长，16 GB V100 无 ensemble 可推约 1300 残基，2500 残基需统一内存并申请 4 块 GPU 的内存（计算用单块 V100）。
- **MSA 来源贡献**（同一模型、不同 MSA 构造重跑 CASP14 蛋白）：去掉 BFD 平均精度 −0.4 GDT，去掉 MGnify −0.7 GDT，两者都去掉 −6.1 GDT；多数目标变化很小，少数离群目标差异达 20+ GDT。
- **消融结论**（Fig. 4a，具体数值图像未获取）：多种机制共同贡献精度；三角乘法更新与三角注意力二者任选其一都能达到高精度，组合更优；循环精化以极小的额外训练时间显著提升精度；自蒸馏显著提升精度；Amber 松弛不改善 GDT 或 lDDT-Cα，但消除立体化学违规。
- **网络行为解读**：48 个 Evoformer 模块各挂一个额外训练的结构模块（主网络冻结），共 192 个中间结构；前几层之后轨迹异常平滑，呈持续增量改进；SARS-CoV-2 ORF8（T1064）需大量层数反复重排二级结构元件。

## 对照与消融

- **外部对照**：CASP14 为双年盲测金标准；与 146 个参赛条目中的前 15 名及次优方法对比（Fig. 1a）；近期 PDB 集进一步排除训练截止后的时间泄漏（Figs. 2、4a、5a）。
- **架构消融**（Fig. 4a，双数据集、三种子均值差异）：覆盖 Evoformer 组件、三角更新组合、循环、蒸馏等（具体消融模型的说明在 Supplementary Methods 1.13 与 Supplementary Fig. 10）。
- **数据消融**：BFD / MGnify 单独与联合移除（−0.4 / −0.7 / −6.1 GDT），结论是两个宏基因组库至少保留其一对 UniRef 覆盖差的目标类至关重要，两者兼得才能达到完整 CASP 精度。
- **推断配置对照**：ensemble（不同 MSA 聚类中心）vs 无 ensemble——CASP14 后作者发现无 ensemble 精度"非常接近或等于"有 ensemble，故多数推断关闭 ensemble。

## 作者自述的局限

- 精度依赖 MSA：中位比对深度低于约 30 条序列时精度大幅下降（Fig. 5a）；作者假设 MSA 信息主要用于网络早期粗定位，之后的精化不太依赖 MSA。
- 对链内 / 同型（homotypic）接触远少于异型（heterotypic）接触的蛋白明显偏弱——典型如大复合物中的桥接结构域，其形状几乎完全由其他链的相互作用塑造；作者预期未来系统可预测完整异源复合物以解决此问题。
- 训练目标本质是"最可能出现在 PDB 结构中的结构"：对化学计量、配体、离子仅能隐式满足约束；结构模块运行中违反肽键几何，需靠 Amber 松弛事后修正。
- 推断内存随残基数近似平方增长，大蛋白超出单 GPU 内存（2500 残基需 4 GPU 内存/统一内存）。
- r.m.s.d.95 指标剔除的 5% 残基有时包含真实建模错误（方法学说明）。

## 我的评价

- **方法论的干净性令人印象深刻**：用物理/几何归纳偏置（三角形约束、刚体框架、FAPE）替代手工特征与手工评分函数，配合进化信息（MSA），是"数据驱动 + 领域先验"结合的范例。论文明确承认这是两类历史路线的融合。
- **可追问之处**：(1) 核心结论的中位统计掩盖了尾部表现——论文自己用 Fig. 5a 和 MSA 消融承认存在大量离群目标（20+ GDT 差距），"多数情形达到实验精度"的措辞应结合分布解读；(2) 近期 PDB 测试集虽在时间上晚于训练截止，但存在与训练集的同源冗余，论文通过模板身份过滤部分缓解，而 10,795 条链的总集（Figs. 2c/d）未按模板过滤，其 r = 0.76 / 0.85 的相关性可能高估；(3) 消融图（Fig. 4a）的具体数值在本提取稿中不可得，只能确认其存在与实验设计，无法核对幅度；(4) 论文没有给出与实验结构测定精度本身的系统对照（如多晶体结构之间的差异），"接近实验精度"的上限在哪里仍值得追问。
- **结构生物学教学价值**：residue gas 的"每残基一个刚体框架、肽键无约束"设计，与物理化学中残基自由度的处理形成有趣对照；pLDDT 的校准（r = 0.76 且有系统偏移拟合式）说明置信度不等于精度，仍是下游使用者的必修课。

## 可复现要点

- 训练：PDB 拷贝（2019-08-28）发布日期 ≤2018-04-30；40% 一致性聚类反比例采样；256 残基随机裁剪、批 128、128 TPU v3 核；约 1000 万样本 + 384 残基/大 MSA 栈/低学习率微调；FAPE + distogram 交叉熵 + BERT 式掩蔽 MSA + 分箱 lDDT-Cα + 侧链损失（训练）/ 违规损失（微调）；5 模型多种子（部分无模板）。
- 数据流水线：Uniref90 v.2020_01 + BFD + Uniclust30 v.2018_08 + MGnify v.2018_12（MSA，HHBlits/jackhmmer）；PDB（2020-05-14）+ PDB70（2020-05-13）模板（HHSearch）；自蒸馏集 355,993 条 Uniclust30 序列；松弛用 OpenMM v.7.3.1 + Amber99sb。
- 推断：5 模型取置信度最优；默认无 ensemble；V100 单模型 0.6 min（256 残基）/1.1 min（384 残基）/2.1 h（2500 残基，统一内存）；16 GB 上限约 1300 残基。
- 评估集重建：2021-02-15 的 PDB，发布日期 >2018-04-30，经单氨基酸链、模糊组分、重复、<16 解析残基、未知残基、NMR、>1400 残基、40% 聚类取最高分辨率链等过滤后 10,795 条；模板判定用 hmmsearch + 2018-04-30 前的模板身份；Neff 按 80% 一致性阈值计算。
- 关键超参与参数、伪代码（Algorithms 1–32）、网络图（Supplementary Figs. 1–8）、特征表（Supplementary Table 1）在本提取稿中不可得，需查 Supplementary Information 原文。

## 术语

- **r.m.s.d.95**：与真实结构最小二乘对齐后，取误差最低 95% Cα 原子计算的 r.m.s.d.，共 5 轮迭代。
- **GDT（global distance test）**：CASP 报告结构域精度用的全局距离测试指标。
- **lDDT / lDDT-Cα**：local-distance difference test，分别基于全重原子 / 仅 Cα 的局域距离差，无需先做结构域切分。
- **TM-score**：全链全局叠加指标；**pTM** 为其预测值。
- **pLDDT**：逐残基预测的 lDDT-Cα，模型的置信度输出。
- **MSA（multiple sequence alignment）**：同源序列的多序列比对；**Neff** 为归一化有效序列数（80% 一致性阈值的加权计数）。
- **Evoformer**：躯干网络模块，在 MSA 表示与残基对表示间交替更新并互相馈送信息。
- **IPA（invariant point attention）**：不变点注意力，在注意力中加入局部框架下定义的 3D 点，对全局旋转平移不变。
- **FAPE（frame-aligned point error）**：帧对齐点误差，核心结构损失。
- **residue gas**：将每残基表示为自由漂浮刚体框架（骨架 N-Cα-C）加侧链 χ 角的表示。
- **recycling（循环精化）**：网络输出反复回喂同一模块的迭代精化机制。
- **self-distillation（自蒸馏）**：用模型自身预测的高置信结构作为额外训练数据的训练策略。
- **distogram**：分箱的距离分布预测。**BERT 式目标**：随机掩蔽 MSA 并重建。
- **CASP14**：第 14 届蛋白质结构预测关键评估（2020 年 5–7 月，双年盲测）。
- **BFD（Big Fantastic Database）**：本文自建公开蛋白家族数据库；**Uniclust30 / UniRef90 / MGnify / PDB70**：序列聚类或宏基因组数据库。
- **Amber99sb / OpenMM**：力场与分子力学引擎，用于预测后松弛。
- **TPU v3 / V100 / XLA**：训练与推断所用硬件及 TensorFlow 编译加速器。
