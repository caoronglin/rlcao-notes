# 引入方式

## 下载文件内引入

访问[仓库](https://github.com/Fgaoxing/pandown-js)，将pandown-js文件下载到本地，在主题`inject`引

入js文件

```yaml
inject:
head:
     - <script src="/xxxxx/pandown.js" /></script>
```

## 通过raw引入

```yaml
inject:
head:
     - <script src="https://raw.githubusercontent.com/Fgaoxing/pandown-js/main/pandown.js" /></script>
```

## 通过jsd引入

```yaml
inject:
head:
     - <script src="https://cdn.jsdelivr.net/gh/Fgaoxing/pandown-js@main/pandown.js" /></script>
```

## 通过本站CDN引入

```yaml
inject:
head:
     - <script src="https://cdn.cnortles.top/gh/Fgaoxing/pandown-js@main/pandown.js" /></script>
```
