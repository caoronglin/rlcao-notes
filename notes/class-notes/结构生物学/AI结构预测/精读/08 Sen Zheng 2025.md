## 一句话结论

把 PDB 里的「缺坐标」当作无序的操作性定义，就能问出一个被回避的问题：**AlphaFold 的 pLDDT 到底能不能告诉你哪些区域没被实验解析出来？** 答案��「大体能，但有一个所有人都没测过的中间地带——软缺失残基，三个模型全军覆没。」

## 研究问题

论文的问题意识来自一个观察：AlphaFold2 在无序区与环区的预测精度有限，**但这种「低精度」如果分析得当，反而可以用于识别无序**。已有工作探索过 pLDDT 在定位无序区域上的用途。

作者要做的事情往前推了一步：**不是问「pLDDT 能不能预测无序」，而是问「pLDDT 能不能预测实验结构里哪些残基根本没被建出来」**——这需要一套以实验结构为「真值」的数据集，而这样的数据集此前没有人系统构建过。

论文自己给出了一个极聪明的操作化定义（见下），这也是全文最大的方法论价值。

## 方法与数据

### 数据集构建

**无序的操作性定义：missing coordinates（缺坐标）**

作者采用「无序 = 最长结构表示中缺失的坐标」这一定义。理由写得很清楚：

> 缺失坐标是实验确定蛋白结构中**直接且可观察**的特征，为进一步分析提供了一个直接的依据。

这样做的好处是——**「无序」这个模糊的生物学概念，被替换成了一个可以逐残基判定的、客观的二值标签**。

**结构筛选**

- 从 PDB 中选取**序列同一性 100%** 的条目中**最完整**的结构（截至 **2024 年 3 月**）。作者说明理由：优先选这些条目是因为其完整性高，可减少「模型不完整」带来的不确定性。
- 按 UniProt 登录号与序列进一步分组，分为三个实验方法组：**X-ray、SPA（单颗粒分析）、Tomo（断层扫描，含断层成像与亚断层平均）**。把 Tomography 与 sub-tomogram averaging 放在一起，是因为它们在数据采集、三维重建与深度学习结构解释上原理相近。

**最终数据集规模**

| 方法 | 唯一蛋白条目数 |
| --- | --- |
| X-ray | **34 568** |
| SPA | **11 072** |
| Tomo | **416** |

### 残基三分类（本文最关键的设计）

作者分析了**同一蛋白的多个 PDB 条目**，检查每个残基位置是否存在 Cα 坐标，据此分三类：

| 类别 | 定义 |
| --- | --- |
| **Modeled（已建模）** | 同一残基位置在**所有**相关 PDB 条目中都存在 Cα |
| **Hard Missing（硬缺失）** | 在**所有**相关条目中都**缺失** Cα |
| **Soft Missing（软缺失）** | 在相关条目中**有时缺失、有时存在** |

**「软缺失」这一类的引入是本文最重要的贡献。** 此前讨论「预测残基 vs 未解析残基」时，默认只有二分；而「同一个蛋白的多个结构里，这个残基有时建出来、有时没建出来」这一状态被完全忽略了。

### 区域划分

在「硬缺失」的连续区段上按长度划分：

- **≤ 30 残基** → **短**（short）无序区
- **> 30 残基** → **长**（long）无序区

30 残基的阈值来自**先前的长度依赖性无序分析**（文献 [47]），目的是检验短段与长段在可预测性上是否有差异。

### 特征与阈值

| 特征 | 来源 | 说明 |
| --- | --- | --- |
| **pLDDT** | AlphaFoldDB 结构文件 | 逐 Cα 置信度 |
| **IUPred 分数** | 本地安装 **IUPred3**，采用 **"long" 方法**、默认设置 | < 16 残基的序列（IUPred3 无法处理）**赋 0 分** |
| 氨基酸组成 | PDB 文件 | |
| 二级结构信息 | UniProt | |

**象限分析**（Fig.2）阈值：**pLDDT 70**（AlphaFold2 中常用于识别高度可靠区域）、**IUPred 0.5**（区分有序/无序的默认阈值）：

| 象限 | pLDDT | IUPred |
| --- | --- | --- |
| **Q1** | ≥ 70（高置信） | < 0.5（有序） |
| **Q2** | ≥ 70 | ≥ 0.5（无序） |
| **Q3** | < 70（低置信） | < 0.5 |
| **Q4** | < 70 | ≥ 0.5 |

### 预测模型

**训练/验证划分**：**PDB 发布于 2022 年之前的条目为训练集，之后为验证集**——作者说明这是为了「理解近期预测工具开发中不同实验类型数据的差异」。

**三个被比较的模型**

1. **基础 pLDDT 模型**：pLDDT < 70 记为「硬缺失」，其余为「已建模」——完全按 AlphaFold2 的既定用法；
2. **基础 IUPred 模型**：IUPred > 0.5 记为「硬缺失」；
3. **LSTM 模型**：序列转为 **21 维 token 编码**，再加 **2 维**（pLDDT 与 IUPred 分数）→ LSTM 层 → dense 层 + softmax；分类目标为**三分类**（已建模/硬缺失/软缺失）。优化器 Adam，损失 categorical_cross-entropy。

**LSTM 的具体配置**

| 数据集 | 序列长度标准化 | 神经元数 |
| --- | --- | --- |
| X-ray | **1 500** | **256** |
| SPA | **2 500** | **300** |

作者说明这是「提供了最优结果」的设置。**只训练了 X-ray 与 SPA 两个 LSTM 模型**；因数据有限**未开发 Tomo 的 LSTM 模型**，而是用 **SPA 的 LSTM 模型去验证 Tomo 数据集**。

**关键的防偏处理**：**丢弃「硬缺失」残基少于 5 个的条目**，以防止模型偏向「已建模」类别。作者说明这同时解决了「短无序区在预测模型训练中常被代表不足」的问题。

**注**：在基础 pLDDT 与基础 IUPred 模型中，**「软缺失」类别未被使用**——因为在数据中检测相关性困难。

## 主要结果与关键数字

### （一）残基计数的中位数（每蛋白）

| 方法 | 已建模 | 硬缺失 |
| --- | --- | --- |
| X-ray | **242** | **5** |
| SPA | **190** | **25** |
| Tomo | **179** | **11** |

> **这组数字本身就很有信息量**：X-ray 结构的硬缺失残基**中位数只有 5 个**，而 SPA 是 **25 个**。

### （二）Pearson 相关性（Fig.1）

**「已建模」残基**

| 特征 | X-ray | SPA | Tomo |
| --- | --- | --- | --- |
| 高 pLDDT（≥ 70） | **0.99** | **0.92** | **0.90** |
| 有序 IUPred（< 0.5） | **0.98** | **0.92** | **0.90** |

**「硬缺失」残基**

| 特征 | X-ray | SPA | Tomo |
| --- | --- | --- | --- |
| 低 pLDDT（< 70） | **0.75** | **0.80** | **0.78** |
| 无序 IUPred（≥ 0.5） | **0.55** | **0.73** | **0.69** |

**「软缺失」残基：所有特征的相关性都在 0.1–0.3**，无明显线性关系。

排序上：**氨基酸残基类型次之，再次是二级结构类型的残基数**。而**二级结构元素（螺旋、折叠、转角）的残基数量没有表现出可比的相关性**——作者据此指出「单独测量二级结构类型的数量不足以预测结构存在性」，并呼应先前发现（用二级结构做无序预测常失败，因为检测方法缺乏残基层级分辨率）。

| 方法 | 已建模 pLDDT 中位数 | 软缺失 | 硬缺失 |

**注意软缺失的 pLDDT 中位数（84–89）远高于硬缺失（52–56）**——这正是「软缺失难预测」的量化体现：它的置信度看起来像「已建模」。

### （四）氨基酸组成

- **硬缺失残基**富集于**极性或带电残基（K、E、S、P）**，而**缺失疏水残基（W、Y、F、L、I、V）**——**与 IDR 的已知特征一致**；
- **软缺失残基的组成介于两者之间**——呼应其「不确定」的本质；
- 组成分析显示本文的 **X-ray 数据集与先前报告的 PDB-25 数据集相似**，而 **SPA 与 Tomo 数据集在多数残基类型上更接近 PDB-25 与另一套无偏 Swiss-Prot 数据集**。

### （五）象限分布（Fig.2）

**「已建模」残基集中在 Q1**：X-ray **93.6%**、SPA **86.6%**、Tomo **84.2%**。作者指出各方法分布模式的相似性说明这些技术**相应地反映了预测置信度与无序分数**。

**「硬缺失」残基**：分布在 Q1、Q3、Q4，**Q3 占比高于 Q2**——作者指出这提示两种预测因子之间可能存在潜在关系，值得进一步研究。

**「软缺失」残基**：主要在 Q1（X-ray **63.7%**、SPA **73.2%**、Tomo **65.3%**），部分在 Q3（X-ray **20.1%**）。**Tomo 数据中 Q4 的占比明显增加**。

**X-ray vs 冷冻电镜的一个结构性差异**：X-ray 结构的**短硬缺失多于长硬缺失**（结晶难以处理长无序段），而 **SPA 与 Tomo 的长硬缺失多于短硬缺失**。作者的解读是：**冷冻电镜比 X 射线更能容纳延展的无序段**。

### （六）预测性能（Table 2 与 Table 3）

**残基级 F1 分数**

| 类别 | 模型 | X-ray | SPA | Tomo |
| --- | --- | --- | --- | --- |
| **已建模** | **LSTM** | **0.98** | **0.91** | **0.91** |
| | pLDDT | 紧随其后 | | |
| | IUPred | 表现最差 | | |
| **硬缺失** | **LSTM** | **0.58** | **0.66** | **0.65**（略高于 pLDDT 的 0.64） |
| **软缺失** | LSTM | **0** | **0** | **0** |

> ⚠️ **「软缺失」上 LSTM 在验证集上一个都没有分类出来**——作者归因于「低相关性效率与该类数据点稀少」。

**区域级 F1 分数（区分短/长）**

| 区域 | 模型 | X-ray | SPA | Tomo |
| --- | --- | --- | --- | --- |
| **短**（≤ 30） | **LSTM** | **0.52** | **0.43** | **0.36** |
| | pLDDT | 0.51 | 0.40 | 0.34 |
| **长**（> 30） | **pLDDT** | **0.49** | **0.62** | **0.65** |
| | LSTM | 0.44 | 0.61 | 0.65 |

**这张表的信息量很大**：

1. **短区域 LSTM 全面略胜 pLDDT，长区域 pLDDT 反超**；
2. 两种模型的区域级 F1 **都低于残基级**（0.58→0.52/0.49 等）——作者归因于「把长度作为额外因素纳入度量后假阳性（FP）增加」；
3. 作者引用先前研究指出：**预测器对「短无序区」的准确率普遍更低**，可能与其不同的组成和位置有关。

作者还指出：**来自「短」区域的残基表现出更强的结构化特征**（更高 pLDDT、更有序的 IUPred 分数），而「长」区域相反——**这可能解释不同模型在长短区域间预测差异的来源**。

**一个补充的进展说明**：作者提到 LSTM 的持续更新已把 F1 提升到 **0.60**（X-ray，硬缺失）与 **0.67**（SPA，硬缺失），**略微超过 pLDDT 基线的 0.58 与 0.66**（数据未展示）。

### （七）实际应用：筛出值得做实验的候选蛋白

把人类蛋白按 UniProt 的 PDB 覆盖情况分为两组（截至 **2024 年 3 月**）：

| 类别 | 定义 | 条目数 |
| --- | --- | --- |
| **Unsolved Sequence（部分已解）** | UniProt 标注为部分已解析。示例：蛋白 A6NED2 长 376 残基，UniProt 报告残基 **139–143** 有 PDB 覆盖（6F4R、6F4S、6FST），则 139–143 为「solved」，**1–138 与 144–376 为「unsolved」** | **8 099** |
| **Undetermined Sequence（完全未解）** | 无任何关联 PDB 结构数据，**整条序列归为无结构** | **11 665** |

用两个指标评估「可能已建模」的概率：序列中 **pLDDT ≥ 70** 的残基占比，以及 **SPA-LSTM 预测为「已建模」**的残基占比。

**筛选结果**：

- **3 179** 个「未确定序列」条目**有较高概率含有已建模残基**（两个模型均给出 **≥ 80%** 预测比例，且长度**超过 200 残基**）；
- **322** 个「未解序列」条目同样富含潜在「已建模」残基。

**SLC9A3 示例的细节**：结构 7X2U 覆盖残基 40–665，**两个模型都把 616–665 标为潜在无结构**。作者指出这与 UniProt 注释吻合——该区段在功能上很关键（**残基 590–667 与 NHERF4 相互作用；591–695 与 AHCYL1 相互作用**）。因此，用本方法结合 UniProt 这类资源库，**可以更容易也更精确地识别「结构上无序但功能显著」的区段**。

## 对照与消融

1. **三个实验方法组的平行对比（X-ray / SPA / Tomo）**——这是本文最核心的对照设计。它揭示了**方法学差异**：

| 方法 | 短 vs 长硬缺失 | 每蛋白硬缺失中位数 | Q4 中软缺失占比 |
| --- | --- | --- | --- |
| X-ray | 短 **>** 长 | **5** | 最低 |
| SPA | 长 **>** 短 | **25** | 中 |
| Tomo | 长 **>** 短 | 11 | **最高** |

这一对照把「哪些残基缺失」从一个技术问题变成了一个**关于实验方法本身的信息**。

2. **三个模型的对照**（基础 pLDDT / 基础 IUPred / LSTM）——且是**分层对照**：

| 目标 | 推荐模型 | 依据 |
| --- | --- | --- |
| 识别**短**无序区、精度与 F1 更好 | **LSTM** | Table 3 |
| 分析**较长**序列 | **pLDDT** | Table 3 |
| 大规模蛋白质组筛选、无序预筛 | **IUPred** | 分钟级、方法根本不同、结论中明确推荐 |
| **软缺失** | **都不行** | F1 = 0 |

3. **补充材料 S4–S6 表**给出各模型在 X-ray/SPA/Tomo 中「硬缺失」残基的 TP/TN/FP/FN 分布。作者指出：**真阳性残基在各模型间保持一致，而 IUPred 的假阳性与假阴性方差更大**。

4. **训练/验证的时间划分**（2022 前 vs 后）——避免用同一时期的数据既训练又验证。

## 作者自述的局限

作者在 Discussion 与 Conclusions 中交代得相当完整：

1. **三个模型都无法有效分类「软缺失」残基**——「这突显了该任务的固有复杂性」。作者分析原因：「软缺失」残基正处于**有序与无序的交界处**，其不稳定性使可预测性复杂；其无序相关分数的分布把这些残基**放在接近有序/无序阈值的边界上**。

2. **IUPred 表现下降的原因可能是多方面的**——作者列出两点：(i) **在整个数据集上一律使用 "long" 方法**，没有考虑短/长无序区的具体语境；(ii) 无序预测的默认阈值选择**可能不是最优的**。

3. **Tomo 数据的「软缺失」在 Q4 中占比更高，但应谨慎解读**——因为**数据集规模较小（仅 416 条）**，且断层成像密度图分辨率为**低到中等**。

4. **短/长区域的类别不平衡**——长区域在 X-ray 组相对稀少，因为**它们比短区域更严重地妨碍结晶**。这与 LSTM 难以区分软缺失残基面临类似挑战。作者建议用**类权重（class weighting）**改善。

5. **长区域上 pLDDT 略优的可能原因**——作者推测是**网络架构更深，纳入了更全面的序列与结构上下文**。

6. **未发现二级结构与缺失残基计数的直接关联**——虽然 AlphaFold2 能有效预测 α 螺旋与 β 折叠，作者观察到**预测二级结构的残基数量与无序残基之间也无显著相关**（数据未展示）。

7. **单靠计算预测有固有风险**——某些情况可能需要补充的实验验证。作者建议结合 **NMR、质谱、电子顺磁共振（EPR）、小角 X 射线散射（SAXS）、Förster 共振能量转移（FRET）** 等方法。

8. **「软缺失」未来可通过**增加类权重、纳入**溶剂可及性**等细粒度特征来改善。

## 我的评价

**这篇最值得学习的是那个操作化定义：用「缺坐标」替代「无序」。**

「内在无序」（intrinsic disorder）是一个生物学概念，边界模糊、判定依赖方法；而「PDB 条目里有没有这个残基的 Cα 坐标」是一个**客观、可枚举、可复现**的二值标签。把前者换成后者，等于把一个解释性问题转成了可统计的问题——而且真值是实验数据本身。这是一次非常干净的「可操作化」。

**第二个关键设计是「软缺失」这一类。** 它的定义只用了「同一蛋白的多个 PDB 条目」这一条信息，逻辑上毫无额外假设，却抓住了一个此前被二分法完全掩盖的状态。而且数据立刻给出了它的刻画：软缺失的 pLDDT 中位数是 **84–89**，远高于硬缺失的 **52–56**——**也就是说，AlphaFold 对软缺失区域给出的置信度看起来像「已建模」，但实验从来没建出过它们。** 这解释了为什么 LSTM 在这一类上 F1 = 0。

**第三个值得讲的是 X-ray 与冷冻电镜的定量差异。** 每蛋白硬缺失残基中位数 **5（X-ray）vs 25（SPA）**，且 X-ray 短缺失多于长缺失而冷冻电镜相反。这组数字把「冷冻电镜不需要结晶」这个定性优势量化成了具体数字——**但同时暴露了一个反直觉的代价：冷冻电镜的模型里，残基缺失更多。** 汇报时这一点值得点出，因为它与「冷冻电镜结构更完整」的直觉相反。

**第四点，一个必须诚实呈现的结论**：**三个模型在软缺失上都失败了**。这不是某个模型的缺陷，而是「软缺失」本身处在两个判定阈值的边界上。论文没有粉饰这一点，反而在 Discussion 中专门讨论了「软缺失是研究与无序相关的动态性质」的未来方向。

**第五点，LSTM 相对基础 pLDDT 的增益其实很小。** 硬缺失 F1：0.58 vs（pLDDT 隐含接近）0.58、0.66 vs 0.66。**唯一确定的增益在短区域**（0.52 vs 0.51、0.43 vs 0.40、0.36 vs 0.34）。作者自己也说 LSTM「显示出潜力」。汇报时不应把它讲成「深度学习大幅超越简单阈值」——更准确的表述是：**在残基级判定上，一个 pLDDT < 70 的阈值规则已经相当有效，LSTM 的增量主要体现在短区段与上下文利用上。**

**第六点，实际应用的设计很有实用价值。** 「8 099 个部分已解 + 11 665 个完全未解」的人蛋白中筛出 **3 179 + 322** 个高概率可建模型的候选——这是一个可以直接用于后续实验规划的清单。SLC9A3 的例子尤其说明问题：**pLDDT 与 LSTM 都把 616–665 标为无结构，而 UniProt 显示这段正是 NHERF4 与 AHCYL1 的结合区**。这提醒我们：**高置信度不等于有功能意义，而低置信度区域恰恰是功能热点**——这一点与 Bonin 2024 中 pro-IL-18 的案例形成呼应（那里的 N 端前结构域在 AF 预测中无序，却正是与 caspase 互作的功能核心）。

**汇报时需要交代的边界**：

- **数据截止 2024 年 3 月**，AlphaFold 预测取自 AlphaFoldDB（`alphafold.com`），未使用更新版本模型；
- **Tomo 组仅 416 条**，其结论的稳健性明显弱于 X-ray（34 568）与 SPA（11 072）；
- **16 残基以下的序列被赋予 IUPred 分数 0**，这是作者的显式假设（认为此类 IDR 可能比长 IDR 更少无序），不是实测；
- **「软缺失」没有任何预测模型有效**，这是结论而非缺陷。

**与本模块其他篇的关系**：本文与 Bonin 2024 恰好构成一组对照——Bonin 讲「AF 高置信却预测错了拓扑」，本文讲「AF 低置信却准确标出了实验未建出的区域」。两者合看说明：**pLDDT 在「这个区域是否有稳定折叠结构」这一判定上是可靠的；在「这个具体折叠是否正确」这一判定上不可靠。**

## 可复现要点

**数据来源与版本**
- PDB：**序列同一性 100%** 的条目中最完整者，截至 **2024 年 3 月**
- AlphaFold 预测：**AlphaFoldDB**（`https://alphafold.com/`）
- 序列、二级结构、功能注释：**UniProt**（`https://www.uniprot.org/`）

**数据规模**：X-ray **34 568** / SPA **11 072** / Tomo **416** 条唯一蛋白

**工具与版本**
- **IUPred3**（本地安装，**"long" 方法**，默认设置；< 16 残基的序列赋 0）
- **Python 3.10.14**、**pandas 2.2.1**（Pearson 相关）、**TensorFlow 2.16.1**、**Keras 3.3.3**、**scikit-learn 1.5.0**、**NumPy 1.26.4**
- 可视化：**Matplotlib 3.8.4**、**seaborn 0.12.2**

**代码与模型**：`https://github.com/thsformygod/Nav-pLDDT-IUPred/`

**关键超参数**
- 区域长度阈值：**30 残基**（短 ≤ 30，长 > 30）
- 象限阈值：**pLDDT 70**、**IUPred 0.5**
- 「已建模」高置信阈值：**≥ 80%** 预测比例
- LSTM 输入：序列 **21 维 token** + **2 维**（pLDDT、IUPred）
- LSTM 配置：X-ray **长度 1 500 / 256 神经元**；SPA **长度 2 500 / 300 神经元**
- 训练集 = **2022 年前**发布的 PDB 条目；验证集 = 2022 年后
- **丢弃硬缺失残基 < 5 的条目**
- 优化器 Adam，损失 categorical_cross-entropy
- **仅训练 X-ray 与 SPA 两个 LSTM**；Tomo 用 SPA 模型验证

**示例蛋白**：**SLC9A3**（UniProt **P48764**），结构 PDB **7X2U**（SPA，发布 2022-04-20），覆盖残基 **40–665**；硬缺失段 **466–473**（短）与 **539–616**（长）

## 术语

| 术语 | 含义 |
| --- | --- |
| IDP / IDPR | 内在无序蛋白 / 内在无序区 |
| 硬缺失 / 软缺失 | 本文定义：Cα 在所有相关条目中均缺失 / 有时缺失 |
| 已建模（modeled） | Cα 在所有相关条目中均存在 |
| SPA | 单颗粒分析，冷冻电镜的主要模式 |
| Tomo / STA | 断层扫描 / 亚断层平均 |

| pLDDT | AlphaFold 逐残基置信度 |
| 象限分析（quadrant analysis） | 用两个指标各设阈值，把样本分成四组交叉比较 |
| 类权重（class weighting） | 训练中对少数类赋予更高权重以平衡数据 |
