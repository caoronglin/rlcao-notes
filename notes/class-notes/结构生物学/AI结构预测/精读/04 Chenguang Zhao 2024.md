## 一句话结论

专门用 AlphaFold 预测结构训练的功能注释工具 PANDA-3D，在三个 GO 本体的 Fmax 上全面超过以**实验结构**为输入的 DeepFRI——但特征消融显示，**贡献最大的三个特征是 ESM、序列 token 和二面角，全都不是三维结构特征**。

## 研究问题

论文的问题意识来自一个具体的障碍。此前的功能预测器基本都从**序列**出发（CAFA2/CAFA3 前十方法中，序列比对与机器学习是两个最常用手段），原因是**实验结构的数量不足以支撑训练**。

作者的分析很准确：

> 此前，功能预测器主要从氨基酸序列而非三级结构做预测，**因为实验解析结构数量有限，且预测结构的质量不令人满意**。

而 AlphaFold 出现后这一前提被推翻了。随之而来的是两个被忽视的问题：

1. **DeepFRI 在预测模型上的表现反而不如在实验结构上**（作者引用 DeepFRI 原文），而且 DeepFRI 把三级结构**先转成二维接触图**再送入 GCN，**没有充分利用三维信息**。GAT-GO 也有同样的降维问题。
2. 此前**没有任何方法用 AlphaFold 模型专门训练过**。

## 方法与数据

**架构（Fig.1）**

- **编码器**：由**逆折叠（inverse folding）**工作提出的 GVP-transformer 编码器块改造而来，利用 **GVP-GNN 层的几何推理能力**。
- **解码器**：受多标签分类工作启发的**改造版 transformer 解码层**。关键设计是——**把全部候选 GO 项都作为 query 喂进解码器**，让解码器学习所有可能 GO 项之间的关系与共现模式；自注意力更新后的 query 再与编码器输出做交叉注意力。
- 作者特别指出：**有些功能预测器只用编码器块，因为解码器块原本不是为多标签分类设计的**。PANDA-3D 改造了这一点——原 transformer 架构是为机器翻译的序列生成设计的（训练时带掩码），而本任务是无掩码的多标签分类。

**输入 GVP 层的结构特征**

| 特征 | 类型 | 说明 |
| --- | --- | --- |
| 欧氏距离 | 标量 | 每个残基最近 **k** 个邻居 |
| 边向量（edge vectors） | **向量** | 源残基 Cα → 目标残基 Cα |
| 取向向量（orientation vectors） | **向量** | 前向与后向相邻残基的同类原子间的向量 |
| 侧链向量 | **向量** | N→Cα 与 Cα→C 的单位向量 |
| pLDDT | 标量 | 每个 Cα 的预测局部距离差异测试准确度 |
| 二面角（dihedral） | 标量 | 相邻残基 N、Cα、C 原子构成的二面角 |
| ESM 嵌入 | — | 蛋白序列的进化尺度语言建模表示 |
| 序列 token | — | 每个氨基酸编码的数字 |

**旋转等变 vs 旋转不变的处理（本文最需要讲清的技术点）**

- **向量特征**（边向量、取向向量）是**旋转等变**的：旋转输入会改变特征值。
- **标量特征**（二面角、欧氏距离）是**旋转不变**的：旋转输入后输出不变。
- **问题**：GVP 层是旋转等变的，但**蛋白质的生物学功能并不受三维结构旋转的影响**。
- **解法**：对每个输入的三维结构**统一其在三维空间中的朝向**，或取其**局部参考系**——该参考系由每个氨基酸的 N、Cα、C 原子位置定义。

**pLDDT 阈值处理**

作者在 **0.5 到 1.0** 之间以 **0.1** 为步长测试阈值。**0.9 的阈值从训练与验证数据中移除了约 53.52% 的残基**；用 0.9 训练的深度学习模型在**验证损失**上表现最好。除掩蔽低置信残基的三维坐标外，**还把 pLDDT 的嵌入与结构特征一起送入 GVP 层**（即 pLDDT 既是过滤器也是特征）。

所有特征嵌入到 **128 维**空间。

**GVP 层的计算（Fig.1B）**

- 旋转不变的标量特征 $S_n \in \mathbb{R}^n$ 与旋转等变的向量特征 $V_v \in \mathbb{R}^{v\times 3}$ 分别输入；
- 向量特征经线性层更新为 $V_h \in \mathbb{R}^{h\times 3}$，其中 $h = \max(v, n)$；
- 对 $V_h$ 施加 **L2 范数**转成标量 $S_h$；
- $S_h$ 与 $S_n$ 拼接后经线性层得到 $S_m$；
- 一个输出 $V'$：对归一化的 $V_\mu$ 施加非线性尺度函数 $\sigma_+$，再与 $V_\mu$ 逐行相乘；
- 另一个输出 $S'$：对 $S_m$ 施加非线性尺度函数 $\sigma$。

**训练配置**

| 项 | 值 |
| --- | --- |
| 可训练参数 | **800 万** |
| 硬件 | **2 × NVIDIA A100（各 40 GB）** |
| 收敛时间 | 约 **18 小时** |
| 损失 | 二元交叉熵 + 对数函数 |
| **正类权重** | **3.0**（应对负样本远多于正样本） |
| 批大小 | 8 |
| 注意力头数 | 8 |
| 学习率 | **0.0001**（Adam） |

**计算效率**：对 **1 093 残基**的蛋白，在 Tesla V100 上推理 **36 秒**（不含生成 AlphaFold 模型的时间），**GPU 显存约 1 GB**。

**数据**

- 从 **Swiss-Prot** 下载人工审阅的蛋白序列与实验确定的蛋白功能（GO 证据代码：**EXP、IDA、IMP、IGI、IEP、TAS 或 IC**），版本为 **2022 年 5 月 25 日**发布；
- 使用**全部三个 GO 本体**：分子功能（MFO）、生物过程（BPO）、细胞组分（CCO）；
- GO 定义版本为 **2022 年 7 月 1 日**；
- **AlphaFold DB 模型截至 2022 年 5 月**；
- 训练时把 GO 节点**向上传播到根节点**，节点及其所有祖先都视为该蛋白的正标注 GO 项。

**样本量与划分**

- **68 523** 个蛋白同时具有实验确定的 GO 项与 AlphaFold 模型；
- 随机划分：**训练 80% / 验证 10% / 测试 10%**；
- **盲测设计**：测试集序列用 PSI-BLAST 检索训练集，**最大同一性超过阈值的被移除**。作者明确说明这是为了「确保盲测数据集与训练数据集无重叠，以便公平比较性能」。

**候选 GO 项的筛选**

- 只使用**在训练集中至少被 50 个蛋白标注**的 GO 项作为候选类别；
- 作者测试了 **45 与 50** 两个阈值，**50 略好**（数据未展示）；
- 代价是**可预测的 GO 项数量减少**——这是明确的取舍权衡。

**Table 5 — 特征置换重要性（消融）**

作者每次**在残基层级随机打乱一个特征的值**，观察性能变化。测试的特征为：ESM、序列 token、二面角、最近 k 邻居的欧氏距离、边向量、取向向量、pLDDT。

**结果：ESM、token、二面角是前三重要特征**——打乱它们会让 Fmax、Smin、AUPR 表现最差。

## 主要结果与关键数字

### （一）主基准（与 DeepFRI 同数据集，最大序列同一性截断 0.95）

**PANDA-3D 在全部三个 GO 类别上取得最佳 Fmax：**

| 本体 | Fmax |
| --- | --- |
| MFO（分子功能） | **0.642** |
| BPO（生物过程） | **0.471** |
| CCO（细胞组分） | **0.705** |

同时在 **Smin 与 AUPR 上也优于所有其他方法**。图注说明：粗体为最高 Fmax、斜体为最小 Smin 与最高 AUPR。

### （二）与序列方法（结构以外信息）的对比

| 对比 | 细节 |
| --- | --- |
| **vs DeepGO-SE** | 在 **9 项分数中的 8 项**占优；BPO/CCO 几乎始终优于，MFO 相当 |
| **vs SPROF-GO** | 在**第三个测试集上于 9 项中拿下 6 项**；BPO/CCO 优于，MFO 略差 |

**这些对照的意义**：DeepGO-SE 与 SPROF-GO 都是**基于蛋白语言模型（PLM）嵌入**的方法。PANDA-3D 胜出，说明**从预测结构中提取的 3D 特征确实携带了序列嵌入之外的信息**——尽管消融结果显示 ESM 特征仍是最重要的单一特征。

### （三）特征重要性（Table 5）

**前三：ESM、序列 token、二面角。** 打乱它们带来最差表现。

**这是一个必须诚实呈现的结论**：前三名中**没有一个是三维几何特征**（边向量、取向向量、欧氏距离都在其后）。唯一进入前三的结构相关特征是**二面角**——而它是一个旋转不变的标量。

### （四）术语中心（term-centric）评估（Table 6）

评估对象为：全部候选 GO 项，以及两个单项 GO——**biofilm formation（GO:0042710）** 与 **motility（GO:0001539）**。

- Naïve 的 AUROC 为 **0.5**，原因是其预测器设计导致**对测试集中所有蛋白的所有候选 GO 项给出相同置信度**；
- **PANDA-3D 在预测全部候选 GO 项、biofilm formation、motility 三者上都显著优于 BLAST 与其他方法**。

**为什么选这两个 GO 项？** 作者解释：在 CAFA3 与 CAFA-π 的评估中使用了三个 GO 项，但**这三个中只有两个是 PANDA-3D 的候选 GO 项**。作者还指出，这两个术语在 CAFA3/CAFA-π 中是**困难项**——预测 GO:0042710 时，**前五名团队的最佳 AUROC 仅略超 BLAST 基线**。

因此这部分结果的含金量在于：**在这两个公认困难的术语上，PANDA-3D 显著超过了所有对比方法**。

### （五）计算效率

1 093 残基蛋白、Tesla V100、**36 秒**、**约 1 GB 显存**。

## 对照与消融

1. **与 DeepFRI 的对照（同为结构+序列方法）**——这是最直接的对照，PANDA-3D 全面胜出。作者指出 DeepFRI 的两个结构性劣势：**训练于实验结构**，且**把三维结构降维成二维接触图**。PANDA-3D 直接在三维上工作（GVP 层保留标量/向量双通道），且训练于预测结构。

2. **与序列/PLM 基线的多层对照**——DeepGOCNN（DeepGOPlus 的 CNN 组件）、DeepGO-SE、SPROF-GO、Naïve、BLAST。**基线的设计刻意分层**（频率基线 → 序列拷贝基线 → 序列神经网络 → PLM 方法），使「结构信息」的边际贡献可以被隔离。

3. **同一性阈值的敏感性分析（Fig.5–7）**——在 40%–95% 六个阈值上重复评测。**BLAST 对阈值敏感而 PANDA-3D 不敏感**，这条证据比单点分数更能说明 PANDA-3D 不是靠序列相似性吃饭。

4. **特征置换消融（Table 5）**——残基层级随机打乱单特征。该方法**不重训练**，因此衡量的是该特征在既有模型中的信息贡献。

5. **无法与 GAT-GO 对比**——作者明确说明原因：**其训练数据与已训练模型均不可获得**。这是诚实交代对照缺口。

## 作者自述的局限

1. **唯一明确列出的局限**：**依赖 AlphaFold 模型作为输入**。若目标蛋白不在 AlphaFold DB 中，使用者必须先生成模型（可通过 DeepMind 的 Colab notebook 或开源代码）。

2. **候选 GO 项筛选的取舍**：只保留训练集中至少 50 个蛋白标注的 GO 项。作者明确写出这一取舍——「这样做的代价是**减少了 PANDA-3D 能预测的 GO 项数量**」。

3. **与 GAT-GO 的对照缺口**（见上）。

4. **一个容易被忽略的隐含限制**：**训练与测试都只用 AlphaFold DB 中截至 2022 年 5 月的模型**，而 MFO 的 Fmax（0.642）明显低于 CCO（0.705）。作者未展开讨论这一差异的原因。

## 我的评价

**这篇最重要的贡献，是它诚实地揭示了一个反直觉的结果：结构特征赢了比赛，但打乱损失最大的不是结构特征。**

作者没有回避这一点——Table 5 直接显示 **ESM、token、二面角是前三**。这一结果对本专题的意义相当大：它说明**预测结构带来的增益，与序列语言模型带来的增益，在很大程度上是互补而非替代的**。如果只用序列 PLM 就够了，PANDA-3D 的结构特征不会带来那些额外的 0.1 量级的 Fmax 提升。

**第二个值得讲的是旋转处理的处理方式。** 这是全篇技术含量最高的一段：区分**旋转等变的向量特征**与**旋转不变的标量特征**，然后指出 GVP 层虽是旋转等变的、**但蛋白功能不随三维结构旋转而改变**，因此必须先统一朝向或取局部参考系。没有这一步，模型会学到与全局坐标系绑定的、无生物学意义的模式。

**第三个方法学亮点是「pLDDT 既是过滤器也是特征」。** 作者用 0.9 的阈值掩蔽掉 **53.52%** 的低置信残基（三维坐标不用），**但同时把 pLDDT 的嵌入作为特征送进 GVP 层**。这个双重处理很有讲究——直接丢弃低置信坐标是对的，但把「模型自己对这个残基有多不确定」也作为信号喂进去，则保留了信息。

**第四点，盲测设计的严谨性值得学习。** 测试集序列用 PSI-BLAST 检索训练集，**同一性超阈值的全部剔除**，而不是只报告一个默认阈值下的结果。再叠加 40%–95% 的阈值扫描，让「BLAST 随阈值改善而 PANDA-3D 不变」这一对比浮现出来——这比单点分数有说服力得多。

**汇报时需要主动交代的边界**：

- **Fmax 的绝对值不宜过度解读**。BPO 的 0.471、CCO 的 0.705，跨研究不可直接比较（阈值、传播方式、数据集都不同）。
- **与 SPROF-GO 的比较在 MFO 上是输的**（Fig.4、Fig.7），要如实报告。
- **特征消融的结论容易被误读**：ESM 排第一**不代表结构信息没用**——消融是在**已含结构特征的模型内部**做的，它说明的是「在这个模型里序列特征仍最重要」，而不是「结构特征可以省」。这两者差别很大。
- **pLDDT 0.9 阈值移除 53.52% 残基**这个数字意味着：**对低置信区域，PANDA-3D 实际不做预测**。因此它在天然无序区的功能注释能力是受限的——而这恰恰是结构信息最有价值的地方。论文没有讨论这一点，是一个明显的盲区。

**与本模块其他篇的连接**：M2 模块其余三篇都在讲「数据基础设施」（AFDB、Foldseek），本文讲的是**预测结构被下游任务消费的第一个具体案例**。它同时也是 M6 模块的一个反例来源——消融结果显示序列特征的重要性，与 Chakravarty 2025「AF 依赖训练集记忆」的判断形成了有意思的呼应：PANDA-3D 在功能预测上的表现，可能有相当一部分来自 ESM，而不完全来自三维几何。

## 可复现要点

**代码框架**：PyTorch；基于 **ESM inverse folding**、**GVP**、**Transformer** 的代码实现

**模型配置**
- 可训练参数：**800 万**
- GVP 层数：2 层（特征消融实验过不同层数，结果见 Supplementary Table S2/S3）
- 嵌入维度：128（统一各特征维度后才能求和）
- 正类权重：**3.0**
- 批大小 8，注意力头 8，学习率 0.0001（Adam）
- 损失：二元交叉熵 + 对数
- 训练：**2 × A100 40GB，约 18 小时**收敛

**推理**
- 1 093 残基蛋白在 Tesla V100 上 **36 秒**，显存约 **1 GB**（不含 AF 模型生成时间）

**数据版本（复现必须对齐）**
- Swiss-Prot GO 标注：**2022 年 5 月 25 日**发布版
- GO 定义：**2022 年 7 月 1 日**版
- AlphaFold DB 模型：**截至 2022 年 5 月**
- GO 证据代码限定为 **EXP、IDA、IMP、IGI、IEP、TAS、IC**
- 68 523 个「同时有实验 GO 与 AF 模型」的蛋白；80/10/10 划分
- 候选 GO 项门槛：训练集中 **≥ 50** 个蛋白

**评估**
- 蛋白质中心：**Fmax、Smin、AUPR**（传播后的预测与真实值）
- 术语中心：**AUROC**
- 序列同一性截断扫描：**40%、50%、60%、70%、80%、95%**

**pLDDT 处理**：阈值 **0.9**（0.5–1.0 扫描得出），移除约 **53.52%** 残基的三维坐标；同时将 pLDDT 嵌入作为特征
