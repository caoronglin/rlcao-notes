## 8.1 文件概述

### 文件基本概念

- **文件定义**：存储在外存储器上的数据集合
- **文件分类**：

- **程序文件**：源代码文件（如 `.c`、`.h`）
- **数据文件**：程序输入/输出的原始数据及结果

- **文件标识**：`文件路径\主文件名.文件后缀`

- 示例：`d:\cc\temp\file1.dat`

### 文件存储形式

| 类型 | 说明 | 特点 | 示例 |
| --- | --- | --- | --- |
| **文本文件** | ASCII文件 | 每个字节存放字符的ASCII码 | `.txt`, `.c` |
| **二进制文件** | 原始二进制形式 | 与内存中数据格式一致 | `.dat`, `.exe` |

### 文件存取方式

| 方式 | 特点 | 适用场景 |
| --- | --- | --- |
| **顺序存取** | 必须按顺序访问数据 | 日志文件、流式数据 |
| **随机存取** | 可直接访问任意位置数据 | 数据库文件、索引文件 |

### 文件缓冲区

- **缓冲文件系统**：系统自动为文件开辟内存缓冲区
- **操作流程**：

1. 写操作：数据先到缓冲区 → 缓冲区满后写入外存
2. 读操作：从外存批量读入缓冲区 → 从缓冲区逐个处理数据

### 文件指针

```c
FILE *fp;  // 定义文件指针
```

- `FILE`类型：存放文件信息（文件名、状态、当前位置等）
- 文件操作均通过文件指针进行

## 8.2 文件的打开与关闭

### 文件打开（fopen）

```c
FILE *fopen(const char *filename, const char *mode);
```

**参数说明**：

- `filename`：带路径的文件名
- `mode`：文件打开模式

**文件打开模式**：

| 模式 | 说明 | 文本文件 | 二进制文件 |
| --- | --- | --- | --- |
| `"r"` | 只读 | ✓ | ✓ |
| `"w"` | 只写（覆盖创建） | ✓ | ✓ |
| `"a"` | 追加 | ✓ | ✓ |
| `"r+"` | 读写（文件必须存在） | ✓ | ✓ |
| `"w+"` | 读写（覆盖创建） | ✓ | ✓ |
| `"a+"` | 读写（追加） | ✓ | ✓ |
| `"t"` | 文本模式（默认） | ✓ | - |
| `"b"` | 二进制模式 | - | ✓ |

**路径处理**：

```c
// 正确写法（双斜杠）
FILE *fp = fopen("d:\\data\\test.txt", "r");

// 正确写法（正斜杠）
FILE *fp = fopen("d:/data/test.txt", "r");
```

**安全打开文件**：

```c
FILE *fopen_safe(const char *file, const char *mode) {
    FILE *fp = fopen(file, mode);
    if(fp == NULL) {
        printf("无法打开文件 %s\n", file);
        exit(0); // 终止程序
    }
    return fp;
}

// 使用示例
FILE *fp = fopen_safe("data.txt", "r");
```

### 文件关闭（fclose）

```c
int fclose(FILE *stream);
```

**重要说明**：

- 关闭文件将缓冲区数据写入外存
- 返回值：成功关闭返回0，失败返回EOF(-1)
- **必须关闭文件**：防止数据丢失和资源泄露

```c
fclose(fp);  // 关闭文件
```

## 8.3 文件的读写操作

### 文本文件读写

#### 1. 格式读写（fprintf/fscanf）

```c
// 写入格式数据
fprintf(fp, "格式字符串", 变量列表);

// 读取格式数据
fscanf(fp, "格式字符串", 变量地址列表);
```

**示例：学生档案管理**：

```c
typedef struct {
    char name[32];
    int age;
    char skill[32];
} Character;

int main() {
    FILE *fp = fopen_safe("swordsman.txt", "w");
    Character tmp;
    
    while(1) {
        printf("输入姓名(*结束): ");
        scanf("%s", tmp.name);
        if(strcmp(tmp.name, "*") == 0) break;
        
        printf("输入年龄和技能: ");
        scanf("%d %s", &tmp.age, tmp.skill);
        
        fprintf(fp, "%s %d %s\n", tmp.name, tmp.age, tmp.skill);
    }
    
    fclose(fp);
    return 0;
}
```

#### 2. 字符读写（fgetc/fputc）

```c
// 写入字符
int fputc(int char, FILE *stream);

// 读取字符
int fgetc(FILE *stream);
```

**示例：文件加密**：

```c
int main() {
    FILE *fp = fopen_safe("secret.txt", "w");
    char ch;
    
    printf("输入文本(@结束): ");
    while((ch = getchar()) != '@') {
        fputc(~ch, fp);  // 按位取反加密
    }
    
    fclose(fp);
    return 0;
}
```

#### 3. 字符串读写（fgets/fputs）

```c
// 写入字符串
int fputs(const char *str, FILE *stream);

// 读取字符串
char *fgets(char *str, int n, FILE *stream);
```

**示例：文件复制**：

```c
int main() {
    FILE *src = fopen_safe("source.txt", "r");
    FILE *dest = fopen_safe("copy.txt", "w");
    char buffer[256];
    
    while(fgets(buffer, sizeof(buffer), src) {
        fputs(buffer, dest);
    }
    
    fclose(src);
    fclose(dest);
    return 0;
}
```

### 二进制文件读写

#### 数据块读写（fread/fwrite）

```c
// 写入数据块
size_t fwrite(const void *ptr, size_t size, size_t count, FILE *stream);

// 读取数据块
size_t fread(void *ptr, size_t size, size_t count, FILE *stream);
```

**参数说明**：

- `ptr`：数据缓冲区指针
- `size`：单个数据项字节数
- `count`：数据项数量
- `stream`：文件指针

**示例：学生数据存储**：

```c
typedef struct {
    int num;
    char name[20];
    char sex;
    int age;
} Student;

int main() {
    Student stud[3] = {
        {10101, "Li Lin", 'M', 18},
        {10102, "Zhang Fun", 'M', 19},
        {10104, "Wang Min", 'F', 20}
    };
    
    // 写入二进制文件
    FILE *fp = fopen_safe("students.dat", "wb");
    fwrite(stud, sizeof(Student), 3, fp);
    fclose(fp);
    
    // 读取二进制文件
    fp = fopen_safe("students.dat", "rb");
    Student read_stud[3];
    fread(read_stud, sizeof(Student), 3, fp);
    
    for(int i=0; i<3; i++) {
        printf("%d %s %c %d\n", 
               read_stud[i].num, 
               read_stud[i].name, 
               read_stud[i].sex, 
               read_stud[i].age);
    }
    
    fclose(fp);
    return 0;
}
```

### 文件结束检测（feof）

```c
int feof(FILE *stream);
```

**使用注意**：

- 适用于文本文件和二进制文件
- 遇到文件结束符返回非0值，否则返回0

**正确使用方式**：

```c
while(!feof(fp)) {
    // 读取文件操作
}
```

## 8.4 文件的定位

### 1. fseek - 改变文件位置指针

```c
int fseek(FILE *stream, long offset, int whence);
```

**参数说明**：

- `offset`：偏移字节数（正数向文件尾，负数向文件头）
- `whence`：基准位置

- `SEEK_SET`(0)：文件开头
- `SEEK_CUR`(1)：当前位置
- `SEEK_END`(2)：文件末尾

**示例**：

```c
fseek(fp, 100L, SEEK_SET);  // 移动到文件头+100字节处
fseek(fp, -50L, SEEK_CUR);  // 从当前位置回退50字节
fseek(fp, -20L, SEEK_END);  // 移动到文件末尾前20字节
```

### 2. rewind - 重置文件位置指针

```c
void rewind(FILE *stream);
```

**功能**：将文件位置指针移动到文件开头

**示例**：

```c
rewind(fp);  // 等同于 fseek(fp, 0L, SEEK_SET);
```

### 3. ftell - 获取当前位置

```c
long ftell(FILE *stream);
```

**功能**：返回从文件开头到当前位置的字节数

**示例**：

```c
long size = ftell(fp);  // 获取当前位置
```

### 综合应用：文件连接

```c
int main() {
    FILE *fp1 = fopen_safe("file1.txt", "r");
    FILE *fp2 = fopen_safe("file2.txt", "a");
    
    // 获取文件1大小
    fseek(fp1, 0L, SEEK_END);
    long size = ftell(fp1);
    rewind(fp1);
    
    // 将文件1内容追加到文件2
    char ch;
    while((ch = fgetc(fp1)) != EOF) {
        fputc(ch, fp2);
    }
    
    fclose(fp1);
    fclose(fp2);
    
    printf("file1.txt大小: %ld字节\n", size);
    return 0;
}
```

## 文件操作总结

### 文件操作流程

1. **打开文件**：`fopen()`
2. **检查打开**：验证文件指针非NULL
3. **文件操作**：

- 读：`fscanf()`, `fgetc()`, `fgets()`, `fread()`
- 写：`fprintf()`, `fputc()`, `fputs()`, `fwrite()`
- 定位：`fseek()`, `rewind()`, `ftell()`

4. **关闭文件**：`fclose()`

### 最佳实践

1. 总是检查文件是否成功打开
2. 文本文件使用文本模式，二进制数据使用二进制模式
3. 操作完成后必须关闭文件
4. 随机访问文件时使用`fseek`精确定位
5. 处理大型文件时使用缓冲区提高效率

### 常见错误处理

```c
FILE *fp = fopen("data.txt", "r");
if(fp == NULL) {
    perror("文件打开失败");  // 输出系统错误信息
    exit(EXIT_FAILURE);
}

if(fclose(fp) != 0) {
    perror("文件关闭失败");
    exit(EXIT_FAILURE);
}
```
