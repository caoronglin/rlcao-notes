# 3.2字符串使用

# 一、什么是字符串

在Python中，字符串是基本数据类型，是一个**不可变的字符序列**，用于存储和表示基本的文本信息。也是一种基本的信息表示方式。

## 字符串的定义方式

Python中可以使用以下三种方式定义字符串：

1. **单引号**：`'hello'`
2. **双引号**：`"hello"`
3. **三引号**：`'''hello'''` 或 `"""hello"""`
4. 长字符串：用连续的三个引号连接，支持跨行
5. 原始字符串：在一个字符串前加 r`r'hello\worrd'`其中的 \ 不转义，直接输出

## 字符串的特点

1. **不可变性**：字符串一旦创建就不能更改
2. **序列性**：字符串是字符的有序序列
3. **驻留机制**：Python对相同的字符串只保留一份拷贝，节省内存空间

# 二、字符串的常用方法或函数

## 常用操作

### 1. 字符串的查询操作

| 方法 | 描述 |
| --- | --- |
| `index()` | 查找子串第一次出现的位置，不存在时抛出ValueError |
| `rindex()` | 查找子串最后一次出现的位置，不存在时抛出ValueError |
| `find()` | 查找子串第一次出现的位置，不存在时返回-1 |
| `rfind()` | 查找子串最后一次出现的位置，不存在时返回-1 |

### 2. 字符串的大小写转换操作

| 方法 | 描述 |
| --- | --- |
| `upper()` | 把字符串中所有字符都转成大写字母 |
| `lower()` | 把字符串中所有字符都转成小写字母 |
| `swapcase()` | 把字符串中所有大写字母转成小写字母，小写字母转成大写字母 |
| `capitalize()` | 把第一个字符转换为大写，其余字符转换为小写 |
| `title()` | 把每个单词的第一个字符转换为大写，其余字符转换为小写 |

### 3. 字符串的替换操作

| 方法 | 描述 |
| --- | --- |
| `replace()` | 替换字符串中的子串，可指定最大替换次数 |
| `join()` | 将列表或元组中的字符串合并成一个字符串 |

### 4. 字符串内容对齐操作

| 方法 | 描述 |
| --- | --- |
| `center()` | 居中对齐，可指定宽度和填充符 |
| `ljust()` | 左对齐，可指定宽度和填充符 |
| `rjust()` | 右对齐，可指定宽度和填充符 |
| `zfill()` | 右对齐，左边用0填充 |

### 5. 字符串劈分操作

| 方法 | 描述 |
| --- | --- |
| `split()` | 从字符串左边开始劈分，可指定劈分符和最大劈分次数 |
| `rsplit()` | 从字符串右边开始劈分，可指定劈分符和最大劈分次数 |

### 6. 判断字符串操作

| 方法 | 描述 |
| --- | --- |
| `isidentifier()` | 判断字符串是否是合法的标识符 |
| `isspace()` | 判断字符串是否全部由空白字符组成 |
| `isalpha()` | 判断字符串是否全部由字母组成 |
| `isdecimal()` | 判断字符串是否全部由十进制数字组成 |
| `isnumeric()` | 判断字符串是否全部由数字组成 |
| `isalnum()` | 判断字符串是否全部由字母和数字组成 |

### 7. 字符串的比较操作

使用运算符：`>`, `>=`, `<`, `<=`, `==`, `!=`

比较规则：首先比较两个字符串中的第一个字符，如果相等则继续比较下一个字符，直到两个字符串中的字符不相等时。

### 8. 字符串的切片操作

字符串是不可变序列，切片操作将产生新的对象：

```python
s = 'hello python'
s1 = s[2:]      # 从索引为2开始切片，默认到最后
s2 = s[:6]      # 从索引为0开始切片，到索引为6结束
s3 = s[1:5:1]   # 从索引为1开始到5（不包括5），步长为1
s4 = s[::2]     # 默认从0开始，默认到最后，步长为2
s5 = s[::-1]    # 默认从字符串最后开始，到字符串的第一个开始，步长为-1
```

## 三、将数字转换成字符串

在Python中，有几种常用的方法可以将数字（整数、浮点数等）转换为字符串：

### 1. 使用 `str()` 函数

这是最直接和常用的方法：

```python
num = 42
string_num = str(num)
print(string_num)  # 输出: '42'
print(type(string_num))  # 输出: <class 'str'>
```

对于浮点数也同样适用：

```python
float_num = 3.14159
string_float = str(float_num)
print(string_float)  # 输出: '3.14159'
```

### 2. 使用 f-strings（Python 3.6及更高版本）

F-strings提供了一种简便易读的方式将表达式嵌入到字符串字面量中：

```python
num = 42
string_num = f"{num}"
print(string_num)  # 输出: '42'
```

f-strings还支持格式化输出，如控制小数位数：

```python
pi = 3.14159
formatted_pi = f"{pi:.2f}"  # 保留两位小数
print(formatted_pi)  # 输出: '3.14'
```

### 3. 使用 `format()` 方法

`format()` 方法允许你使用占位符格式化字符串：

```python
num = 42
string_num = "{}".format(num)
print(string_num)  # 输出: '42'
```

`format()` 方法也支持格式化输出：

```python
pi = 3.14159
formatted_pi = "{:.2f}".format(pi)  # 保留两位小数
print(formatted_pi)  # 输出: '3.14'
```

### 4. 使用字符串格式说明符（%运算符）

这是较老但仍然有效的方法：

```python
num = 42
string_num = "%d" % num
print(string_num)  # 输出: '42'
```

对于浮点数：

```python
pi = 3.14159
formatted_pi = "%.2f" % pi  # 保留两位小数
print(formatted_pi)  # 输出: '3.14'
```

## 常见问题

### split()

在 Python 中，`split()` 和 `split(" ")` 的区别主要在于 **分隔符的处理方式**，尤其是对空白字符的处理逻辑。以下是详细对比：

---

#### 1. `split()`（不带参数）

- **默认行为**：  
  按 **任意数量的空白字符**（如空格、换行符、制表符 `\t` 等）作为分隔符。
- **特点**：

- 会自动忽略 **开头和结尾的空白**。
- 多个连续的空白字符（如 `"  "`, `"\t\t"`）会被视为一个分隔符。
- 如果字符串全由空白组成（如 `"   "`），`split()` 会返回一个空列表 `[]`。

- **示例**：

```python
s = "  Hello   world  this is   a test  "
print(s.split())  # 输出: ['Hello', 'world', 'this', 'is', 'a', 'test']
```

---

#### 2. `split(" ")`（带空格参数）

- **默认行为**：  
  仅以 **单个空格** 作为分隔符。
- **特点**：

- **不会自动忽略多个连续空格**，多个空格会被拆分为多个分隔符。
- 会导致结果中出现 **空字符串**（`""`）。
- 如果字符串全由空格组成（如 `"   "`），`split(" ")` 会返回 `['', '', '', '']`。

- **示例**：

```python
s = "  Hello   world  this is   a test  "
print(s.split(" "))  # 输出: ['', '', 'Hello', '', '', 'world', '', 'this', 'is', '', '', 'a', 'test', '']
```

---

#### 核心区别总结

| 特性 | `split()` | `split(" ")` |
| --- | --- | --- |
| 分隔符类型 | 任意空白字符（空格、换行、制表符等） | 仅单个空格 |
| 多个连续空格处理 | 合并为一个分隔符 | 拆分为多个分隔符 |
| 开头/结尾空白处理 | 自动忽略 | 保留为空字符串 |
| 全空白字符串处理 | 返回空列表 `[]` | 返回多个空字符串（如 `['', '', '']`） |
| 适用场景 | 通用字符串分割（如统计单词数量） | 严格按空格分割（如需要保留空格信息） |
