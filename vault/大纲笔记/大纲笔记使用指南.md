# 大纲笔记与思维导图

## 写作方式
- 用标题组织主题，用缩进列表拆分想法。
- Tab 缩进，Shift+Tab 提升层级。
- Outliner 支持列表折叠、拖动与层级操作；可在命令面板搜索 Outliner。

## 一篇笔记，两种视图
- 打开任意大纲笔记后按 **Ctrl+Alt+M**。
- Mindmap NextGen 会直接从当前 Markdown 的标题和列表生成导图。
- 修改大纲后更新导图视图即可，不需要再维护一份独立导图内容。
- 需要自由布局的关系图时，使用内置 Canvas；它与自动生成的大纲导图用途不同。

## 常用入口
- 工作台“新建大纲”。
- 命令面板 QuickAdd：新建大纲笔记。
