# 植物三代测序与多组学文献调研

> 同一题目由四个模型各跑一遍，综合评比后合并为一份交付：五年文献库 + 趋势报告 + 可视化站点。

## 目标与完成标准

- 检索窗口 2021-10-23 至 2026-10-30，按论文首次正式在线发表日期。
- 覆盖 PacBio CLR/HiFi、ONT DNA/cDNA/直接 RNA 在植物中的应用，以及三代 + 多组学融合。
- **区分「多技术联合」与「多组学融合」**：Hi-C 仅辅助组装、短读长纠错、全长转录本仅用于注释等，不计为多组学。
- 证据分级：VERIFIED / PARTIAL / UNVERIFIED / CONFLICT，未核实项一律标注，不作推断填充。
- 不宣称全网穷尽：频次是纳入口径下的计数，不代表领域真实占比。

## 合并策略

以 DOI 小写归一为主键匹配。yoke 对 gimlet / pestle 的覆盖分别为 79% / 77%，故以 yoke 的 1652 条为基座；
按 DOI 回灌 gimlet 的开放全文深核验结论与已核验 JIF、pestle 的实证邮箱；独有且在范围内的记录补录并延续编号。
ledger 只借鉴工程结构，数据不合入。每条记录带「数据来源」列，可逐条回溯。

## 已知覆盖缺口

OpenAlex 未纳入（429）、Crossref 全量核验受 429 阻断、JCR 订阅墙、非 OA 正文 403 不可达、
约四成记录摘要未写明测序品牌、未做 SRA/BioProject 反向补全与前向/后向引用追踪。
组学层次与登录号字段主要来自开放全文子集（1037/1123），不可外推全库。
