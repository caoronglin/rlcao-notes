| 环节             | 工具建议                                       |
| -------------- | ------------------------------------------ |
| 原始数据质控         | fastp`                                     |
| 比对             | `bwa-mem2` 或 `miniBWA`                     |
| BAM 操作         | `samtools`、`Picard`                        |
| 变异检测           | `GATK`、`bcftools`                          |
| VCF 过滤         | `bcftools`、`vcftools`、`PLINK`（视数据而定）       |
| BSA/QTL-seq 分析 | `QTLseqr`、自定义 Python/R 脚本                  |
| 变异注释           | `SnpEff`、VEP                               |
| 可视化            | `ggplot2`、`CMplot`、`R`、`Python matplotlib` |
| 候选区域人工检查       | `IGV`                                      |
| 精细定位标记         | KASP、CAPS、InDel PCR                        |
