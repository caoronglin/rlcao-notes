# 合并教材收尾：可视化站点、章节编号与 PDF 重建

## Goal

1. 给合并教材做 HTML 可视化站点（目录树、全文检索、公式、图片预览）。
2. 统一第三级标题编号，修掉站点锚点回退成 `s2` 的问题。
3. 用 antd CLI 体检站点工程。
4. 重建 PDF，使章文件改动进入成品。

## Findings

- 全书 898 个 `###` 中 99 个无编号，集中在第 18–21 章（此前为凑 4500 字扩写时新增的小节全部没编号）以及第 7、10 章的零星几个。其余无编号的是「关键概念 / 本节小结 / 公式与推导」三类辅助小节，共 53 个，是全书面统一的体例，PDF 也已如此，**不能给它们编号**。
- 第 29 章 `### 29.4 缺失值与重复值` 挂在 `## 29.3` 之下却自成 29.4 序列（后接 `## 29.5`），层级写错，改为 `##`。
- `antd` 在本机是 `@ant-design/cli`（mise 管理，v6.6.5），是知识/体检工具而非脚手架，所以站点用真实 Vite + React + antd 工程承载，`doctor` / `usage` / `lint` 才有适用对象。
- KaTeX 原生支持 `\tag{}`，数学公式无需预处理。

## Changes

**章节编号（43 处，仅 ch18–21）**：按所属 `##` 父节号补 `N.M.K`，序号取该父节下已有最大值 + 1。章首导语（ch19「引子」）与前言不编号。

**站点 `output/site/`**：

| 文件 | 改动 |
| --- | --- |
| `scripts/build-content.mjs` | 无编号小节锚点改为「父节号 + 语义后缀」（`19.8.key`、`19.5.sum`、`19.3.deriv`），章首/章末用 `x1`、`x2`；先按进入本节前的父节号定锚点再更新父节号；加 `usedIds` 全局唯一保护 |
| `src/components/ChapterView.jsx` | 新增 `isNumbered()`，只对纯数字编号显示编号徽标，`19.8.key` 这类只显示标题 |
| `src/components/Sidebar.jsx` | 页脚「20 部原著」改为「20 个来源」（15 部原著 + 5 个在线文档） |
| `README.md` | 新增：快速开始、目录结构、更新流程、路由表、锚点规则 |

**PDF**：`build_book.py` 全量重建。

## Problems

**一次脚本误写覆盖了 895 个标题。** 补编号脚本里正则写成 `^(###\s+)(.*)$`，却按 group(1) 取标题，结果 group(1) 恒为 `### `，原标题被替换成 `### 19.1.1 ###` 这种空壳，44 个章文件全部受损。

恢复办法：`output/生物信息学与数据科学_合并版.md` 是 `build_book.py` 的 `collect()` 对 44 个章文件的顺序拼接（只在部分标题前插入 `# 第X部分`），且生成于误写之前。按行扫描切块（必须跳过 ``` 代码块内的 `# 注释`，否则 99 个块会涨到 167 个），丢弃纯标题块，用各章文件**未受损的 H1 行**（误写只碰 `###`）配合并版正文重建。

校验：1215 节的 `md` 与站点 `src/data/content.json`（误写前快照）逐节比对，**0 处不匹配**；`###` 数回到 898；此前人工修改点（`US\$`、`I_{\mathcal{S}}`、闭合的 `$$`、闭合的粗体、`[PBM] 表 11-7`、37 处去 AI 腔编辑）全部在位。

教训：批量改写 markdown 必须 dry-run 并核对受影响行数是否等于预期。

- 站点可用：`output/site/dist/` 为静态产物，`npm run preview` 即可本地查看；支持目录树、全文检索、hash 路由（`#c19` 进章、`#19-19.2.1` 进节）、KaTeX 公式、antd 图片预览、明暗主题。
- 第 18–21 章 43 个小节编号补齐，与全书 `N.M.K` 体例一致；第 29.4 层级已修正。
- PDF 重建为 836 页 / 51.0 MB，与站点同源。
- antd CLI 三项检查全部通过。
