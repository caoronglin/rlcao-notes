### 名词解释

1. 交联酶晶体
	- 交联酶晶体是纯化的酶先制备成晶体，然后再用双功能试剂（如戊二醛）进行化学交联，从而得到的不溶性酶晶体催化剂。它是酶结晶技术和化学交联技术结合的产物，具有纯度高、活性高、稳定性好（耐极端pH、有机溶剂和蛋白酶等）以及易于回收等优点。
2. 酶的结合效率/固定化率/偶联率
	- 指酶与载体结合的百分率。其计算方法为：（固定化的总酶活力－未结合的酶活力）÷ 固定化的总酶活力 × 100%。其中，未结合的酶活力包括固定化后滤液及洗涤液中所含酶活力的总和。
3. 酶的化学修饰
	- 酶的化学修饰则是指在较温和的条件下，以可控制的方式使酶同某些化学试剂发生特异反应，从而引起单个氨基酸残基或其功能基团发生共价的化学改变。
4. 模拟酶
	- 又称人工酶或酶模型，是在分子水平上模拟酶活性部位的形状、大小及其微环境等结构特征，以及酶的作用机理和立体化学等特性。
5. 融合酶
	- 主要是指将两个或多个酶分子组合在一起所形成的融合蛋白，属于杂合酶。它把不同酶中的部件有机组合，会产生原酶没有的特性，使活性表现出协同效应。
6. 易错PCR
	- 一种在DNA序列中进行随机突变的快速、简便方法，主要特点是能够控制它的突变频率。用PCR扩增目的基因时，通过使用低保真度的Taq DNA聚合酶或改变常规反应条件，引起碱基以某一频率通过随机错配引入多点突变，构建突变库，再筛选出所需突变体。
7. 疏水参数lgP
	- 是表示溶剂疏水性的参数，其数学表示为 lgP=lg$\frac{有机溶剂在辛醇中的分配系数}{有机溶剂在水中的分配系数}$
8. 水活度
	- 水活度是指在一定的温度与压力下，反应体系中水的蒸气压与同样状态下纯水蒸气压的比值
9. 酶反应器
	- 利用酶蛋白作为催化剂催化酶促反应生产各种化学品的反应装置称为酶反应器，相比化学反应器具有耗能和产热均较低的特点
10. 生物传感器
	- 是一种由生物敏感元件（如酶、抗体、核酸、细胞等）与信号转换器紧密配合组成的分析检测装置。如酶传感器是以酶为分子识别元件的敏感材料，同信号转换器结合所构成的一类特殊的化学传感器，既具有酶的分子识别和选择催化功能，又具有电化学电极响应快、操作简便的特点。

### 简答（5×5=25）

1. 酶工程的概念和酶工程的研究内容
	- 概念：将酶、细胞器或细胞等置于特定的生物反应装置中，利用酶所具有的生物催化功能，借助工程手段将相应的原料转化为有用物质并应用于社会生活的一门科学技术。
	- 核心问题：如何廉价且有效生产出所需规格的酶，以及如何有效通过化学或生物手段改造酶，并使之有效发挥催化特性，最大限度服务于人类。
	- 研究内容：
		- 酶的生产（发酵和分离工程）
		- 酶的改造（化学酶工程和生物酶工程）
		- 酶的应用（非水相酶学，酶反应器，酶传感器，酶及酶抑制剂的应用）
2. 如何提高酶产量
	- 菌种选育：诱变育种；基因工程育种
	- 条件控制：
		- 添加诱导物
		- 降低阻遏物浓度
		- 添加表面活性剂
		- 添加产酶促进剂
3. 优良产酶微生物满足的条件
	- 酶产量高
	- 易培养（生长速率高、营养要求低）
	- 遗传性能稳定，不易退化
	- 易分离提纯
	- 安全可靠（不是致病菌）
4. 分离纯化常用方法及原理
	- 溶解度——盐析；等电点沉淀
	- 电荷极性——电泳；例子交换层析
	- 分子大小——离心；离子交换层析
	- 亲和专一性——染料亲和层析；免疫亲和层析
	- 稳定性——选择性变形法（热变性；酸碱变性）
5. 酶的固定化方法和特点
	- **吸附法**：通过氢键、疏水作用、离子键等非共价作用将酶固定于载体。
		- 操作简单，条件温和，但结合不牢固易脱落。
	- **包埋法**：将酶包裹在凝胶网格或半透膜内。
		- 酶未发生化学反应，活力高，但存在扩散限制，不适合大分子底物。
	- **共价结合法**：酶分子的活性基团与载体形成共价键。
		- 结合牢固不易脱落，但反应条件剧烈，易引起酶构象改变导致失活。
	- **交联法**：用双功能试剂使酶分子间或酶与载体间共价交联。
		- 结合牢固，但反应剧烈，机械强度较好但易引起酶失活。
	- **无载体固定化**：如交联酶晶体（CLEC）。
		- 纯度高，稳定性极佳，耐有机溶剂和极端环境，但制备成本较高。
6. 固定化对酶催化反应体系的影响
	- 构象效应：构象改变酶结合底物能力
	- 屏蔽效应：空间位阻
	- 微扰效应：载体直接影响酶的催化能力
	- 分配效应：底物、产物等在微管体系不等分配
	- 扩散限制效应：载体内外迁移扩散速率限制
7. 抗体酶的制备方法
	- 化学修饰法
	- 蛋白酶工程法
	- 相似分子诱导法
	- 拷贝法
	- 抗体库法
8. 化学酶工程和生物酶工程的研究内容
	- 化学酶工程
		- 化学修饰
		- 模拟酶
	- 生物酶工程
		- 酶基因的克隆和表达
		- 非理性设计和理性设计对酶进行遗传修饰
		- 融合酶，杂合酶
9. 非水体系中酶催化反应的优点
	- 有利于疏水性底物的反应。非极性底物溶解度提高。
	- 非水体系中，酶的热稳定性和储存稳定性增加。
	- 改变反应平衡，催化在水中不能进行的反应。
	- 有机溶剂凝固点远低于水，可保证温度敏感酶在最适温度下进行催化反应。
	- 可控制底物的特异性、区域选择性和立体选择性。
	- 可防止由水引起的副反应。抑制某些依赖于水的不利反应的副产物。
	- 有机溶剂中，产物易于分离纯化，游离酶可回收再利用。
10. 常见酶促反应有机介质体系
	- 与水互溶的有机溶剂-水单相体系
	- 非极性有机溶剂-水两相体系
	- 非极性有机溶剂-酶悬浮体系
	- 非极性有机溶剂-PEG修饰酶单相体系
	- 反胶束体系
11. 常见酶反应器名字+特点
	- （连续/间歇）搅拌罐式反应器（CSTR/BSTR）：混合均匀，传质传热好，易于控制温度和pH，但搅拌剪切力易磨损固定化酶。
	- 填充床反应器/固定床反应器（PBR）：单位体积酶量大，催化效率高，返混小，产物抑制作用小，但不适用不溶性或黏度大的底物。
	- 流化床反应器（FBR）：混合均匀，传质传热好，不易堵塞，能处理黏度较高反应液，但需保持流速，运转成本高。
	- 鼓泡反应器（BCR）：借助气体鼓泡实现混合并提供气体底物，结构简单，剪切力小，适合有气体参与的反应。
	- 膜式反应器（MR）：集反应与分离于一体，可实现小分子产物在线分离及酶的循环使用，但易发生膜孔阻塞。
12. 酶反应器的选择依据
	- 酶的应用形式
		- 游离酶：搅拌罐式反应器
		- 固定化酶：填充床反应器、流化床反应器
	- 酶反应动力学性质
	- 底物和产物的理化性质
	- 反应操作要求
	- 酶的稳定性

### 论述（10×2=20）

1. 发酵时工艺条件控制
	- 培养基：
		- 营养：碳源、氮源、无机盐、生长因子、水等五大营养要素
	- 培养条件：
		- 温度：根据菌种特性有最适生长温度与最适产酶温度
			- 控制温度方式：夹套，盘管
		- pH：
			- 初级调节控制（起始培养基）调整C/N，调整生理酸性物质与生理碱性物质之比。
			- 补料调节：流加酸/碱，初加碳、氮
		- 溶解氧：
			- 调节通气量
			- 调节氧的分压
			- 调节气液接触时间、面积
		- 泡沫：泡沫存在会阻碍二氧化碳排除，还会提高污染风险
			- 机械消泡或消泡剂消泡
			- 减少或缓加易起泡的原料
2. 定向进化的过程和主要方法
	- 过程：
		- 通过随机突变和（或）基因体外重组创造基因多样性
		- 导入适当载体构建突变文库
		- 通过灵敏的筛选方法，选择阳性突变子
	- 方法：
		- 易错PCR：在DNA序列中进行随机突变的方法。用PCR扩增目的基因时，通过使用低保真度的Taq DNA聚合酶或改变PCR常规反应条件，引起碱基以某一频率进行随机错配而引入多点突变，构建突变库，然后筛选出所需突变株。
		- DNA改组：基因在分子水平上进行有性重组。它利用DNA酶 I 将欲改造的基因或基因家族打断成一定的大小的片段，在PCR变性后的复性过程中，利用片段间具有的部分同源性发生错配。错配的片段互为模板进行延伸。而与此同时,不同来源的基因间也可发生重组，形成融合基因。经过反复的变性、复性(错配)和延伸(重组),直至扩出全长基因。这些基因在延伸中因为错配引入了突变，通过重组使基因融合，从而创造了新的基因。再通过人类的定向选择，最终可以得到一些符合人类需要的新基因。
		- 随机引物体外重组（RPR）：以DNA单链为模板，不需要DNA 酶 I ，用一套随机序列引物，产生大量合模板互补的引入少量点突变的短片段，去除模板后重新排布成全长突变基因。
		- 交错延伸法：在PCR反应中，将含有不同突变的模板混合，随之进行多轮变性、短暂的复性/延伸，反复重复指导形成全场基因片段。
3. 有机介质酶活力下降的原因和应对措施

| **原因**       | **解决方法**                        |
| :----------- | :------------------------------ |
| 扩散限制         | 增加搅拌速度；降低酶的颗粒大小                 |
| 封闭活性中心       | 用结晶酶替代                          |
| 构象改变         | 使用冻干保护剂；制备有机溶剂中可溶解的并可与两亲性物质络合的酶 |
| 底物脱离溶剂束缚的能力差 | 选择溶剂                            |
| 过渡态不稳定化      | 选择溶剂以获得与过渡态有利的相互作用              |
| 构象柔性降低       | 使 a_w 最适化；使用疏水溶剂                |
| 亚最适pH值       | pH记忆；使用有机相缓冲液                   |

4. 如何提高酶的稳定性

| 途径    |       | 方法    | 优点                    | 不足        |
| ----- | ----- | ----- | --------------------- | --------- |
| 酶分子改造 | 核酸水平  | 蛋白质工程 | 从根本上提高酶分子稳定性          | 操作复杂，周期长  |
|       | 蛋白质水平 | 化学修饰  | 适应所有酶，操作简单经济          | 修饰过程破坏酶分子 |

|       |       | 交联酶晶体 | 稳定性好，载量高，催化效率高        | 成本高       |
| 微环境改良 |       | 稳定剂   | 简单、经济                 | 工作量大      |
|       |       | 反应介质  | 适用于特殊反应体系和酶类          | 适合的酶类还不普遍 |

### 实验设计（10×1=10）

1. 胞内酶发酵液后处理
	- 发酵液预处理：由于胞内酶存在于细胞内部，首先需要对发酵液进行预处理。通过加热、凝聚（加电解质）、絮凝（加高分子絮凝剂）及添加助滤剂等方法，降低发酵液黏度，改变其物理性质，以提高后续固液分离的效率。
	- 液固分离收集菌体：采用离心或过滤分离技术，将预处理后的发酵液进行液固分离，收集含有目标胞内酶的菌体细胞沉淀，弃去含有大量杂质和胞外代谢产物的上清液。
	- 细胞破碎：将收集的菌体悬浮于适宜的缓冲液中，采用机械法（如超声波破碎、高压匀浆、珠磨法）或非机械法（如溶菌酶法、化学渗透法）破坏细胞壁和细胞膜，使胞内酶充分释放到溶液中，转化为悬浊液。
	- 破碎液分离与粗提取：将细胞破碎后的悬浊液再次进行离心或过滤，去除细胞碎片等固相杂质，收集含有目标酶的澄清上清液（粗酶液），此步骤实现了酶的粗分级分离。
	- 分离纯化与成品加工：根据酶的性质采用盐析、等电点沉淀等固相析出法进行粗分级，再利用离子交换层析、凝胶层析或亲和层析等方法进行细分级纯化。最后通过浓缩、干燥或结晶等成品加工步骤，获得满足使用需求的一定纯度的胞内酶制品。
2. 酶固定化的过程及其作用（果胶酶的固定化——原理（共价结合）+4步骤：载体制备，载体活化，偶联，活性检测）
	- 作用：克服游离酶不稳定、易流失、难回收等缺点；使酶保持催化活性且可重复利用，提高酶的利用率并节约生产成本；减少外源物质对果制品的污染；便于产物与酶分离，实现生产过程的连续化和自动化。
	- 原理：共价结合法固定化。壳聚糖为载体，戊二醛为交联剂，其两个醛基分别与壳聚糖氨基和酶氨基发生亲核加成，形成西佛碱共价键。
	- 载体制备：壳聚糖溶于3%乙酸，用注射器逐滴滴入NaOH溶液形成微珠，蒸馏水洗涤至中性。
	- 载体活化：加入4%戊二醛，室温活化5 h，蒸馏水洗涤除去游离戊二醛。
	- 偶联：果胶酶水溶液提取，离心取上清酶液；将酶液覆盖活化载体，4℃过夜偶联，洗涤除去游离酶，收集微珠。
	- 活性检测：设灭活对照管与反应管，各加果胶溶液50℃反应2 h；DNS显色后540 nm测定吸光度，按标准曲线计算固定化酶活力、酶结合效率及活力回收率。
