# 2.2字符串类型

用''或“”括以来的部分，用 str 表示，引号并不是字符串的一部分，也可以用''''''三引号分行

## 转义字符

| 转义字符 | 描述 |
| --- | --- |
| \\ | 反斜杠符号 |
| \' | 单引号 |
| \" | 双引号 |
| \a | 响铃 |
| \b | 退格 |
| \n | 换行 |
| \t | 横向制表符 |
| \r | 回车 |
| \f | 换页 |
| \000 | 最多三位八进制 |
| \xyz | 两位十六进制 |

> [!note]
> 在 Python 中可以用+号将多个字符或变量连接起来
>
> Python3 中使用 Unicode 编码，与 Python2 不同
