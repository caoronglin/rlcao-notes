# 5.1集合

## 一、集合的定义和特点

### 1. 集合的定义

集合（Set）是Python中的一种内置数据类型，它是一个无序的不重复元素序列。集合中的元素不会重复，并且可以进行交集、并集、差集等常见的集合操作。

> [!success]
> ### 2. 集合的特点
>
>   1. **无序性**：集合中的元素没有固定的顺序，不支持索引和切片操作
>   2. **唯一性**：集合中的元素不能重复，具有自动去重的功能
>   3. **可变性**：集合是可变的，可以添加或删除元素（但元素本身必须是不可变的）
>   4. **元素类型**：集合中的元素必须是不可变类型（如数字、字符串、元组等）

### 3. 集合的创建

```python
# 使用大括号创建集合
set1 = {1, 2, 3, 4}
print(set1)  # {1, 2, 3, 4}

# 使用set()函数创建集合
set2 = set([4, 5, 6, 7])
print(set2)  # {4, 5, 6, 7}

# 从字符串创建集合（会去重）
set3 = set('hello')
print(set3)  # {'h', 'e', 'l', 'o'}

# 注意：创建空集合必须用set()而不是{}
empty_set = set()  # 正确的空集合
empty_dict = {}   # 这是空字典，不是空集合
```

### 4. 不可变集合（frozenset）

Python还提供了不可变集合frozenset，一旦创建就不能修改。

```python
# 创建不可变集合
frozen_set = frozenset([1, 2, 3, 4])
print(frozen_set)  # frozenset({1, 2, 3, 4})

# 不可变集合不能添加或删除元素
# frozen_set.add(5)  # AttributeError: 'frozenset' object has no attribute 'add'
```

## 二、集合的基本操作

### 1. 添加元素

#### add()方法

添加单个元素到集合中，如果元素已存在，则不进行任何操作。

```python
s = set(('Google', 'Runoob', 'Taobao'))
s.add("Facebook")
print(s)  # {'Taobao', 'Facebook', 'Google', 'Runoob'}
```

#### update()方法

添加多个元素，参数可以是列表、元组、字典等。

```python
s = set(('Google', 'Runoob', 'Taobao'))
s.update({1, 3})
print(s)  # {1, 3, 'Google', 'Taobao', 'Runoob'}

s.update([1, 4], [5, 6])
print(s)  # {1, 3, 4, 5, 6, 'Google', 'Taobao', 'Runoob'}
```

### 2. 移除元素

#### remove()方法

移除指定元素，如果元素不存在，则会发生错误。

```python
s = set(('Google', 'Runoob', 'Taobao'))
s.remove("Taobao")
print(s)  # {'Google', 'Runoob'}

# s.remove("Facebook")  # 不存在会发生错误 KeyError: 'Facebook'
```

#### discard()方法

移除指定元素，如果元素不存在，不会发生错误。

```python
s = set(('Google', 'Runoob', 'Taobao'))
s.discard("Facebook")  # 不存在不会发生错误
print(s)  # {'Taobao', 'Google', 'Runoob'}
```

#### pop()方法

随机删除集合中的一个元素。

```python
s = set(("Google", "Runoob", "Taobao", "Facebook"))
x = s.pop()
print(x)  # 随机输出一个元素
```

### 3. 集合的其他基本操作

#### 计算集合元素个数

```python
s = set(('Google', 'Runoob', 'Taobao'))
print(len(s))  # 3
```

#### 清空集合

```python
s = set(('Google', 'Runoob', 'Taobao'))
s.clear()
print(s)  # set()
```

#### 判断元素是否在集合中

```python
s = set(('Google', 'Runoob', 'Taobao'))
print("Runoob" in s)  # True
print("Facebook" in s)  # False
```

## 三、集合的运算

### 1. 交集（Intersection）

返回两个集合中共同存在的元素。

```python
set1 = {1, 2, 3, 4, 5}
set2 = {3, 4, 5, 6, 7}

# 使用 & 运算符
intersection_set = set1 & set2
print(intersection_set)  # {3, 4, 5}

# 使用 intersection() 方法
intersection_set = set1.intersection(set2)
print(intersection_set)  # {3, 4, 5}
```

### 2. 并集（Union）

返回两个集合中所有元素（去重）。

```python
set1 = {1, 2, 3, 4, 5}
set2 = {3, 4, 5, 6, 7}

# 使用 | 运算符
union_set = set1 | set2
print(union_set)  # {1, 2, 3, 4, 5, 6, 7}

# 使用 union() 方法
union_set = set1.union(set2)
print(union_set)  # {1, 2, 3, 4, 5, 6, 7}
```

### 3. 差集（Difference）

返回在第一个集合中存在但不在第二个集合中的元素。

```python
set1 = {1, 2, 3, 4, 5}
set2 = {3, 4, 5, 6, 7}

# 使用 - 运算符
difference_set = set1 - set2
print(difference_set)  # {1, 2}

# 使用 difference() 方法
difference_set = set1.difference(set2)
print(difference_set)  # {1, 2}
```

### 4. 对称差集（Symmetric Difference）

返回只在其中一个集合中存在的元素。

```python
set1 = {1, 2, 3, 4, 5}
set2 = {3, 4, 5, 6, 7}

# 使用 ^ 运算符
symmetric_difference_set = set1 ^ set2
print(symmetric_difference_set)  # {1, 2, 6, 7}

# 使用 symmetric_difference() 方法
symmetric_difference_set = set1.symmetric_difference(set2)
print(symmetric_difference_set)  # {1, 2, 6, 7}
```

### 5. 子集和超集判断

#### issubset()方法

判断一个集合是否是另一个集合的子集。

```python
set1 = {1, 2, 3}
set2 = {1, 2, 3, 4, 5}

print(set1.issubset(set2))  # True
print(set2.issubset(set1))  # False
```

#### issuperset()方法

判断一个集合是否是另一个集合的超集。

```python
set1 = {1, 2, 3}
set2 = {1, 2, 3, 4, 5}

print(set1.issuperset(set2))  # False
print(set2.issuperset(set1))  # True
```

#### isdisjoint()方法

判断两个集合是否没有交集。

```python
set1 = {1, 2, 3}
set2 = {4, 5, 6}
set3 = {3, 4, 5}

print(set1.isdisjoint(set2))  # True
print(set1.isdisjoint(set3))  # False
```

## 四、集合推导式

集合推导式（Set Comprehension）是一种简洁的创建集合的方式，类似于列表推导式。

### 基本语法

```python
{expression for item in iterable if condition}
```

### 示例

```python
# 基本集合推导式
squares = {x**2 for x in range(10)}
print(squares)  # {0, 1, 4, 9, 16, 25, 36, 49, 64, 81}

# 带条件的集合推导式
even_squares = {x**2 for x in range(10) if x % 2 == 0}
print(even_squares)  # {0, 4, 16, 36, 64}

# 从字符串创建集合
unique_chars = {char for char in 'hello world' if char != ' '}
print(unique_chars)  # {'h', 'e', 'l', 'o', 'w', 'r', 'd'}
```

### 集合推导式的特点

- 自动去重：即使推导过程中产生重复元素，结果集合中也只会保留一个
- 无序性：集合中的元素没有固定顺序
- 元素必须是可哈希的：集合中的元素必须是不可变类型

## 六、集合的应用场景

### 1. 去重

集合最常见的用途是去除列表或其他可迭代对象中的重复元素。

```python
# 去除列表中的重复元素
my_list = [1, 2, 2, 3, 4, 4, 5]
unique_elements = set(my_list)
print(unique_elements)  # {1, 2, 3, 4, 5}

# 转换回列表
unique_list = list(set(my_list))
print(unique_list)  # [1, 2, 3, 4, 5]（顺序可能不同）
```

### 2. 成员检测

集合提供了高效的成员检测操作，判断一个元素是否在集合中。

```python
my_set = {1, 2, 3, 4, 5}
is_present = 3 in my_set
print(is_present)  # True

# 性能对比：集合比列表的成员检测更快
import time

large_list = list(range(100000))
large_set = set(large_list)

# 列表的成员检测
start_time = time.time()
result = 99999 in large_list
list_time = time.time() - start_time

# 集合的成员检测
start_time = time.time()
result = 99999 in large_set
set_time = time.time() - start_time

print(f"列表检测时间: {list_time:.6f}秒")
print(f"集合检测时间: {set_time:.6f}秒")
```

### 3. 集合运算

集合支持并集、交集、差集等运算，这对于数据处理和逻辑操作非常有用。

```python
# 找出两个列表中共同的元素
list1 = [1, 2, 3, 4, 5]
list2 = [3, 4, 5, 6, 7]
common_elements = set(list1) & set(list2)
print(common_elements)  # {3, 4, 5}

# 找出只在第一个列表中出现的元素
unique_to_list1 = set(list1) - set(list2)
print(unique_to_list1)  # {1, 2}

# 合并两个列表并去重
combined = set(list1) | set(list2)
print(combined)  # {1, 2, 3, 4, 5, 6, 7}
```

### 4. 数据分析和过滤

集合可以用于快速过滤数据，只保留符合特定条件的元素。

```python
# 过滤数据
data = {10, 20, 30, 40, 50, 60, 70}
filtered_data = {x for x in data if x > 30}
print(filtered_data)  # {40, 50, 60, 70}
```

### 5. 唯一性要求

当需要确保元素的唯一性时，集合是一个理想的选择。

```python
# 存储唯一的用户名
unique_usernames = {'user1', 'user2', 'user3'}

# 添加新用户名，自动去重
unique_usernames.add('user3')  # 不会重复添加
print(unique_usernames)  # {'user1', 'user2', 'user3'}
```

### 6. 数学运算

集合可以用于模拟数学中的集合运算，如排列组合等。

```python
# 数学集合运算示例
set_a = {1, 2, 3}
set_b = {3, 4, 5}

# 并集
union_set = set_a | set_b
print(f"并集: {union_set}")  # 并集: {1, 2, 3, 4, 5}

# 交集
intersection_set = set_a & set_b
print(f"交集: {intersection_set}")  # 交集: {3}

# 差集
difference_set = set_a - set_b
print(f"差集: {difference_set}")  # 差集: {1, 2}

# 对称差集
symmetric_difference_set = set_a ^ set_b
print(f"对称差集: {symmetric_difference_set}")  # 对称差集: {1, 2, 4, 5}
```

## 七、集合与其他数据类型的比较

### 1. 集合与列表的比较

| 特性 | 集合（Set） | 列表（List） |
| --- | --- | --- |
| **有序性** | 无序 | 有序 |
| **可重复性** | 元素唯一 | 元素可重复 |
| **索引访问** | 不支持 | 支持 |
| **添加/删除** | 添加/删除元素高效 | 在末尾添加/删除高效，中间插入/删除低效 |
| **成员检测** | O(1)时间复杂度，非常高效 | O(n)时间复杂度，较慢 |
| **内存使用** | 通常比列表占用更多内存 | 相对节省内存 |
| **适用场景** | 去重、成员检测、集合运算 | 需要顺序访问、允许重复元素 |

### 2. 集合与元组的比较

| 特性 | 集合（Set） | 元组（Tuple） |
| --- | --- | --- |
| **可变性** | 可变 | 不可变 |
| **有序性** | 无序 | 有序 |
| **可重复性** | 元素唯一 | 元素可重复 |
| **索引访问** | 不支持 | 支持 |
| **哈希性** | 不可哈希（不能作为字典的键） | 可哈希（可以作为字典的键） |
| **适用场景** | 去重、集合运算 | 固定数据、字典键 |

### 3. 集合与字典的比较

| 特性 | 集合（Set） | 字典（Dictionary） |
| --- | --- | --- |
| **存储内容** | 只存储键（key） | 存储键值对（key-value） |
| **有序性** | 无序（Python 3.7+字典有序） | Python 3.7+有序 |
| **可重复性** | 键唯一 | 键唯一 |
| **访问方式** | 通过成员运算符访问 | 通过键访问值 |
| **哈希性** | 不可哈希 | 不可哈希 |
| **适用场景** | 去重、集合运算 | 键值对存储、快速查找 |

### 4. 性能对比

```python
import time

# 创建测试数据
data = list(range(10000))
test_list = data * 10  # 100000个元素，有重复
test_set = set(test_list)
test_tuple = tuple(test_list)
test_dict = {x: None for x in test_list}

# 测试成员检测性能
def test_membership_performance():
    # 列表成员检测
    start_time = time.time()
    for _ in range(1000):
        9999 in test_list
    list_time = time.time() - start_time
    
    # 集合成员检测
    start_time = time.time()
    for _ in range(1000):
        9999 in test_set
    set_time = time.time() - start_time
    
    # 元组成员检测
    start_time = time.time()
    for _ in range(1000):
        9999 in test_tuple
    tuple_time = time.time() - start_time
    
    # 字典成员检测
    start_time = time.time()
    for _ in range(1000):
        9999 in test_dict
    dict_time = time.time() - start_time
    
    print(f"列表成员检测时间: {list_time:.6f}秒")
    print(f"集合成员检测时间: {set_time:.6f}秒")
    print(f"元组成员检测时间: {tuple_time:.6f}秒")
    print(f"字典成员检测时间: {dict_time:.6f}秒")

test_membership_performance()
```

## 八、集合的最佳实践

### 1. 何时使用集合

- **需要去重时**：当需要确保数据中没有重复元素时
- **频繁进行成员检测时**：当需要频繁检查元素是否存在时，集合的O(1)时间复杂度比列表的O(n)更高效
- **需要进行集合运算时**：当需要进行交集、并集、差集等数学运算时
- **数据顺序不重要时**：当数据的顺序不重要，只需要确保唯一性时

### 2. 何时避免使用集合

- **需要保持数据顺序时**：集合是无序的，不能保持元素的插入顺序
- **需要索引访问时**：集合不支持索引和切片操作
- **存储可变元素时**：集合中的元素必须是不可变类型
- **内存受限时**：集合通常比列表占用更多内存

### 3. 性能优化建议

- **使用集合进行成员检测**：对于大型数据集，使用集合进行成员检测比列表快得多
- **预分配集合大小**：如果知道集合的大致大小，可以使用集合推导式预先分配
- **使用适当的集合操作**：根据需要选择合适的集合操作方法，如使用`&`或`intersection()`进行交集运算
- **考虑使用frozenset**：当需要不可变集合时，使用frozenset而不是普通集合

### 4. 代码示例

```python
# 最佳实践示例

# 1. 使用集合去重
def remove_duplicates(items):
    """去除列表中的重复元素"""
    return list(set(items))

original_list = [1, 2, 2, 3, 4, 4, 5]
unique_list = remove_duplicates(original_list)
print(f"去重前: {original_list}")
print(f"去重后: {unique_list}")

# 2. 使用集合进行高效的成员检测
def find_common_elements(list1, list2):
    """找出两个列表中的共同元素"""
    set2 = set(list2)
    return [item for item in list1 if item in set2]

list1 = [1, 2, 3, 4, 5]
list2 = [3, 4, 5, 6, 7]
common = find_common_elements(list1, list2)
print(f"共同元素: {common}")

# 3. 使用集合进行数据分析
def analyze_data(data):
    """分析数据集"""
    data_set = set(data)
    
    # 基本统计
    print(f"数据总数: {len(data)}")
    print(f"唯一值数量: {len(data_set)}")
    print(f"最小值: {min(data_set)}")
    print(f"最大值: {max(data_set)}")
    
    # 数据过滤
    filtered = {x for x in data_set if x > 50}
    print(f"大于50的值: {filtered}")

sample_data = [10, 20, 30, 20, 40, 50, 60, 50, 70, 80]
analyze_data(sample_data)

# 4. 使用集合进行权限管理
class PermissionManager:
    """权限管理器"""
    def __init__(self):
        self.admin_users = {'admin', 'superuser'}
        self.normal_users = {'user1', 'user2', 'user3'}
        self.guest_users = {'guest1', 'guest2'}
    
    def is_admin(self, username):
        """检查是否为管理员"""
        return username in self.admin_users
    
    def is_valid_user(self, username):
        """检查是否为有效用户"""
        all_users = self.admin_users | self.normal_users | self.guest_users
        return username in all_users
    
    def get_user_permissions(self, username):
        """获取用户权限"""
        if username in self.admin_users:
            return "read, write, delete"
        elif username in self.normal_users:
            return "read, write"
        elif username in self.guest_users:
            return "read"
        else:
            return "no permissions"

# 使用权限管理器
pm = PermissionManager()
print(f"admin的权限: {pm.get_user_permissions('admin')}")
print(f"user1的权限: {pm.get_user_permissions('user1')}")
print(f"guest1的权限: {pm.get_user_permissions('guest1')}")
print(f"unknown的权限: {pm.get_user_permissions('unknown')}")
```

## 九、总结

Python集合是一种强大而灵活的数据结构，具有以下特点：

1. **核心特性**：无序性、唯一性、可变性（元素本身不可变）
2. **主要优势**：高效的成员检测、自动去重、支持数学集合运算
3. **适用场景**：去重、成员检测、集合运算、数据分析等
4. **性能特点**：成员检测时间复杂度为O(1)，比列表更高效
5. **局限性**：无序、不支持索引、元素必须是不可变类型

集合在Python编程中扮演着重要角色，特别是在需要处理唯一元素和进行集合运算的场景中。合理使用集合可以大大提高代码的效率和可读性。在实际开发中，应根据具体需求选择合适的数据结构，充分发挥集合的优势。
