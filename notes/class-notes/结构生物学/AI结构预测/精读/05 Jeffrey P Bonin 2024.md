# AlphaFold2 as a replacement for solution NMR structure determination of small proteins: Not so fast!

## 一句话结论

一个 22 kDa 量级、紧凑折叠的小蛋白 pro-IL-18，被 AlphaFold2 以**高置信度**预测成了错误的拓扑——AF2 给出的其实是「成熟细胞因子 IL-18 + 一条无序尾巴」，而非实验测得的「前体蛋白把前结构域嵌进 β-三叶草核心」；AlphaFold3 犯了完全相同的错误。

## 研究问题

论文的出发点是一个**方法学问题**：AF2 在 CASP14 与多项后续研究中已被反复验证精度接近实验，那么它能否**替代**溶液 NMR 的结构测定？

作者选择用一个具体案例来回答——并且明确声明这个案例**不属于任何已知的 AF2 局限类别**。这是全文最关键的一句自我定位：

> "we share a case where the incorrect structure predicted by AF2 **does not fall under any of these known limitations**"

## 方法与数据

- **实验结构**：作者此前报道的 pro-IL-18 溶液 NMR 结构（PDB 8URV），以及 pro-IL-18 与 caspase-1 / caspase-4 的冷冻电镜复合物结构（PDB 8SV1 等）。
- **对照对象**：
  - AF2 对 pro-IL-18 的预测；
  - 成熟 IL-18 的晶体结构（PDB 3WO2）；
  - AF3 对 pro-IL-18 的预测（论文写作期间刚发布，作者补充测试）。
- **评价指标**：主链重原子 RMSD（分区域计算）、pLDDT 置信度、Cα–Cα 距离。

## 关键图表解读

**Fig. 1 — 核心证据图。** 溶液 NMR 结构（pro-domain 绿色、成熟域橙色）与 AF2 预测结构（按 pLDDT 43–100 做黄-蓝渐变着色）叠合。整体主链重原子 RMSD **5.2 Å**，计算范围仅含成熟域的 β 链（45–49 β1、55–58 β\*、82–88 β4、97–103 β5、107–113 β6、115–121 β7、137–142 β9、148–153 β10、159–165 β11、170–176 β12、185–190 β13）。图中标出了 β1′、β3′、αAF、βAF 等 NMR 与 AF2 结构不同的元件。

**Fig. 2 — 强调「哪里一致、哪里不一致」。** C 端半段的 β4–β13 叠合良好，主链重原子 RMSD 仅 **2.0 Å**；而 N 端的 β1 与 β\* 的 RMSD 达 **13.3 Å**。若只用 β4–β13 对齐，其余部分的 RMSD 降到 **1.7 Å**。这张图的价值在于说明差异不是全局性的**噪声**，而是**局部但确定的拓扑分歧**。

**Fig. 3 — 揭示错误的来源。** 成熟 IL-18 的晶体结构（PDB 3WO2）与 AF2 对 pro-IL-18 的预测（**去掉 pro-domain**）叠合，主链重原子 RMSD 仅 **0.2 Å**——两者在有序残基上**几乎完全一致**。这张图直接点破：AF2 不是「预测不准」，而是**预测了一个错误的分子**。

**Fig. 4 — 功能论证。** 展示 AF2 预测、溶液 NMR（8URV）、pro-IL-18:caspase-1 冷冻电镜复合物（8SV1）三者。画出 I48（exosite 结合位点）与 L33（caspase 活性位点识别的四肽）之间 Cα–Cα 的距离。

**Fig. 5 — AF3 复核。** AF2（品红）与 AF3（青色）预测叠合，除 pro-domain 取向外**几乎无法区分**，RMSD 同样为 **0.2 Å**。AF3 预测时加入了 50 个 Na⁺ 与 Cl⁻ 离子，但离子不改变 pro-domain 之外的预测。

## 主要结果与关键数字

| 指标 | 数值 |
| --- | --- |
| 整体主链重原子 RMSD（仅成熟域 β 链，11 段） | **5.2 Å** |
| N 端 β1 与 β\* 的主链重原子 RMSD | **13.3 Å** |
| C 端 β4–β13 的主链重原子 RMSD | **2.0 Å**（仅用 β4–β13 对齐时全局降至 1.7 Å） |
| 成熟 IL-18（3WO2）vs AF2 预测 pro-IL-18（去 pro-domain） | **0.2 Å** |
| AF2 vs AF3 对 pro-IL-18 的预测 | **0.2 Å**（几乎完全相同） |
| pro-domain 区 pLDDT | **40 < pLDDT < 70**（低置信） |
| 成熟域 β 链 pLDDT | **pLDDT > 90**（高置信） |
| L33–I48 Cα–Cα 距离：pro-IL-18:caspase-1 复合物 | **19.1 Å** |
| 同上，pro-IL-18:caspase-4 复合物 | **19.6 Å** |
| 同上，NMR 结构 | **15.8 Å** |
| 同上，**AF2 预测结构** | **36.7 Å** |

**功能性推论（论文的核心论证）**：pro-IL-18 与 caspase 之间有两个相互作用面——caspase 活性位点识别 pro-IL-18 的四肽序列 33-LESD-36，以及被称为「exosite」的 I48 侧链与 caspase 中色氨酸残基的相互作用。**要让这两个面同时结合，四肽与 I48 必须处在合适的相对位置。** 若 pro-IL-18 真按 AF2 预测的构象折叠（距离 36.7 Å），两个相互作用面就无法同时形成，细胞因子将无法被 caspase 加工成熟。此外四肽在 NMR 结构中位于一段柔性环内（这种柔性可能是其可被活性位点接近的必要条件），而在 AF2 预测中它紧邻 β1，可能反而妨碍活性位点相互作用。作者进一步推测：无结构的 pro-domain 容易被**其他**细胞蛋白酶切割，从而绕过 caspase，导致 IL-18 成熟通路失调。

## 对照与消融

论文做了三组对照，构成本文的论证骨架：

1. **AF2 vs 溶液 NMR** — 揭示差异（5.2 Å / 13.3 Å vs 2.0 Å）。
2. **AF2 预测 vs 成熟 IL-18 晶体结构** — 证明 AF2 预测的是「成熟态 + 无序尾巴」（0.2 Å），从而定位错误性质。
3. **AF2 vs AF3 vs 两个冷冻电镜复合物** — 证明这不是模型代际问题，且从功能后果角度论证 AF2 的拓扑不可能工作。

引言还系统列举了**此前已知的 AF2 局限**（作者正是为了说明本案例不属于其中任何一类）：
- 人蛋白中约 **15%** 的内在无序区（IDR）被 AF2 自信地赋予结构（「假阳性」），且这些结构常是 IDR **结合靶标时**才采用的「条件折叠」构象；
- 对长环区预测不佳；
- 多构象蛋白只预测其中一个构象，无法反映构象多样性；
- 无法预测点突变诱导的结构变化；
- 某些膜蛋白场景表现吃力；
- 预测中不包含翻译后修饰；
- 只预测基态结构，不预测瞬时构象。

## 作者自述的局限

作者对自己结论的限定相当克制，三处都值得引用：

1. **明确声明这是个案**：结论是 "in certain cases, even ones involving small, globular proteins, where experimental structure determination still remains **essential**"——用的是「某些情况下」而非「普遍不适用」。
2. **主动指出可能的一般化机制**：论文说该发现「可能引发对其他具有类似翻译后加工的蛋白的预测准确性的担忧」，用的是 *may raise some concerns*，并给出机制解释——**PDB 中有大量成熟 IL-18 结构，却没有 pro-IL-18 结构**，训练分布里缺这一类。
3. **指出这是一类独特的算法挑战**：两个蛋白序列几乎完全相同（本文中 pro-domain 之后的序列完全一致），结构却差异巨大，这对「从序列预测结构」的算法构成独特挑战。

## 我的评价

**这篇为什么重要：它攻击的正是 pLDDT 高置信度最可信的那种情形。**

回顾 AlphaFold 的失败案例，多数集中在无序区、环区、多构象——这些恰好也是 pLDDT **低**的区域。因此「pLDDT 低 → 别信」已是一条可靠的操作规则，而这条规则也让高置信预测显得相对安全。

本文的贡献恰恰在于推翻这个安心：**错误发生在 pLDDT > 90 的 β 链区域，而低置信度只出现在真正正确地无序的那条尾巴上。** 置信度与正确性在这里完全解耦。

**最能解释这个案例的一点，是 Fig. 3 的 0.2 Å。** AF2 不是在自由发挥，而是在忠实地预测一个它认为合理的分子——只是那个分子是**错的化学实体**。训练语料里有大量成熟 IL-18 结构（于是模型很清楚 IL-18 长什么样），却没有任何 pro-IL-18 结构（于是模型对前结构域如何嵌进核心毫无信息）。模型把已知的「好答案」套用到了输入上。

**汇报时必须讲清的边界**（否则会过度解读）：
- 这是一篇 Communication 级的个案报告，**没有任何统计**。1 个反例不能推论 AlphaFold2 的错误率，谈不上「AF2 不可靠」。
- 论文自己的问题意识也不是「AF2 错了」，而是「**存在一类情况，实验测定依然必要**」。
- 它的正确用法是**给出失效类型的分类**，而不是给出失效率的估计。

**第二个值得追问的技术点**：Fig. 5 显示 AF3 犯了一模一样的错（0.2 Å），且加入 50 个 Na⁺/Cl⁻ 离子没有改变结果。这说明换更大更强的模型、加上离子环境，都不能自动修复训练分布缺失导致的错误——**模型规模不是这类失效的解药**。这一条对本专题 M3 模块（AF3 的能力边界）是一个具体注解。

**方法学上最值得学的一点**：作者不是只说「结构不对」，而是把差异翻译成了**功能后果**（L33–I48 距离 36.7 Å vs 复合物中的 19 Å），并借冷冻电镜复合物结构作为裁判。这让一个结构学观察变成了一个可检验的生化断言——是这类「反例论文」应有的写法。

## 术语

| 术语 | 含义 |
| --- | --- |
| pro-domain（前结构域） | 前体蛋白中被切除、成熟后不保留的那部分结构域 |
| β-三叶草折叠（β-trefoil） | 由两组三段 β 链组成的球状折叠，IL-18 成熟域采用此折叠 |
| tetradpeptide / exosite | 四肽 33-LESD-36（活性位点识别）与 exosite（I48 侧链相互作用面），是 pro-IL-18 与 caspase 的两处接触 |
| pLDDT | 逐残基置信度，>90 为高置信，40–70 为低置信 |
| RMSD95 | 95% 残基覆盖率下的 Cα RMSD，CASP 常用指标 |
| intrinsically disordered region (IDR) | 内在无序区，天然状态下不形成稳定三维结构的区域 |
| 翻译后加工（post-translational processing） | 蛋白质合成后被蛋白酶切割等修饰加工的过程 |
