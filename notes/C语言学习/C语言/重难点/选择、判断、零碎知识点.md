# 零碎知识点

1. gets()只能接受字符数组
2. int、double类型，必须加&
3. 多维数组在内存中是按行存储的。
4. 一维数组在内存中是按行存储的，不能通过数组名直接修改数组的大小。
5. 在 C 语言中，对于二维数组的部分初始化，未赋值的元素会被自动初始化为 0 ，所以该数组的初始化是合法的，且未赋值元素值为 0 。
6. *(arr[2])的首地址
7. 文件都有随机操作和顺序操作
8. 函数申明是，可以不申明变量名，但不能不声明类型
9. 在switch语句中可以不使用break语句
10. 这个主要是考察表达式  '0'<= c <= '9'，根据优先级和结合性，应该是 （'0'<= c） <= '9'，不管c是什么字符，都会输出YES
11. 函数定义默认为int类型
12. C语言有且只能有一个MAIN函数，从main函数开始，到main函数结束
13. 在C语言中，malloc函数返回的是一个void*类型的指针，需要进行类型转换才能使用。calloc函数分配的内存块会被自动初始化为零。realloc函数用于调整已分配内存的大小，如果新的大小小于原大小，多余的内存会被释放而不是保存。free函数用于释放内存，释放后的内存不能再被使用，否则会导致未定义行为。
14. 在C语言中，ptr是一个指向包含4个整数的数组的指针。因此，*(ptr+1)指向第二行，*(*(ptr+1)+2)访问第二行第三个元素，即arr[1][2]。同样，*(ptr[1]+2)和ptr[1][2]也是访问arr[1][2]的正确方式。
15. 函数指针在声明时需要指定其指向的函数的参数列表和返回类型，因此它可以指向特定类型和返回类型的函数。
16. 函数可以返回结构体类型
17. 函数可以嵌套使用但不能嵌套调用
18. 指针在 32 位系统占 4 字节，在 64 位系统占 8 字节，其他与无关
19. 采用“自顶向下、逐步求精”和模块化的方法进行结构化程序设计
20. 数组的应用只能逐个引用数组的元素，不能整个数组一起应用
21. C语言中结构类型变量在程序执行期间，所有成员一直驻留在内存中，按照成员先后顺序，根据自身的数据类型占用连续的存储单元，一起创建，一起释放
22. 字符串的比较不能用==只能用 strcmp 函数
23. STRCMPB 比较的是 ASCII 码，通常采用逐字符比较
24. 如`*p++`等价于`*(p++)`而非`(*p)++`！！！！！！！
25. 如++p->num 实际为 num+1
26. (++p)->num 为下一个 num

- `calloc()`自动初始化为0，`malloc()`不初始化

# 第一章

1. C 语言不提供输入输出语句，提供的是库函数
2. 为解决某一实际问题而设计的语句序列就是程序
3. 在程序设计中，把解决问题的方法和有限的步骤称为算法

# 第二章

1. C 语言的大小写是两个不同的字符（存储的 asii 码不同）因此要注意变量名的大小写。不能用保留字，数字、特殊符号开头命名变量
2. 数据是对客观事物的符号表示，是所有能被输入到计算机中，且能被计算机处理的符号（数字、字符等）的集合，是计算机操作对象的总称。
3. 整形数据在计算机中以补码的形式存储
4. 字符串常量和字符常量是不同的概念，不能混淆，“a”与'a'是两个不同的数据，字符串末尾会默认加上 \0
5. 当关系运算符用于比较两个字符时，比较的是字符的 ASCII 码

# 第七章

- struct 是结构体的关键字
- 结构体所占的字节是所有字节加起来
- 在定义结构体时不分配内存空间
- *的运算优先级低于.所以要写成（*）p.num
- 三种方式等价
- 共用体按照最长的字节数分配
- 枚举元素列表不能是数字
- enum weekday{sun,mon,tue,wed,thu,fri,sat}
- 枚举元素是符号常量，它们的值不能用赋值的方法得到
- 只能把枚举元素赋值给枚举变量，不能把枚举元素对应的整数值直接赋值给枚举变量
- typeof 不产生新的数据类型

```c
int CountWord(FILE *file) {
    int word_count = 0; // 用于记录单词数量
    int in_word = 0;    // 标记是否处于单词内
    int ch;             // 用于存储从文件中读取的字符

    while ((ch = fgetc(file)) != EOF) { // 循环读取文件中的字符
        if (isalpha(ch)) { // 如果字符是字母
            if (!in_word) { // 如果当前不在单词内
                in_word = 1; // 标记进入单词
                word_count++; // 单词计数加1
            }
        } else { // 如果字符不是字母
            in_word = 0; // 标记离开单词
        }
    }
    return word_count; // 返回单词总数
}
```

```c
#include <stdio.h>

int gcd(int a, int b) {
    while (b != 0) {
        int temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}

int main() {
    int T;
    scanf("%d", &T);
    for (int i = 0; i < T; i++) {
        int m, n;
        scanf("%d%d", &m, &n);
        printf("%d\n", gcd(m, n));
    }
    return 0;
}
```

#include <math.h>
#include <stdbool.h>

bool isPrime(int n) {
    if (n <= 1) return false;       // 1和负数不是素数
    for (int i = 2; i <= sqrt(n); i++) {
        if (n % i == 0) {
            return false;           // 能整除，不是素数
        }
    }
    return true;                   // 是素数
}
