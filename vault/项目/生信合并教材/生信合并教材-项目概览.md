# 生信合并教材

> 把 15 部原著与 5 个在线技术文档按知识点关联程度合并成一本书，讲解详细有图，不添加原著之外的知识。

## 目标与完成标准

- 按知识点关联程度重组章节，不做简单拼接：已组织为 8 个部分、43 章、1215 节。
- 讲解详细、有图有表：290 幅插图、311 张表格、498 个编号公式。
- 全部内容可溯源到原著：正文与图表标题均标注来源编号。
- 交付 PDF 与 HTML 可视化站点两种形态。

## 现状

| 产物 | 位置 | 状态 |
| --- | --- | --- |
| 章文件（Markdown 源） | `output/book/` 44 个 `.md` | 完成，453,821 汉字 |
| PDF | `output/生物信息学与数据科学_合并版.pdf` | 836 页，51.0 MB |
| 可视化站点 | `output/site/` | `npm run build` 产出 `dist/` |

站点能力：部分→章两级目录树、全文检索（1215 节索引）、hash 路由、KaTeX 公式、antd 图片预览、明暗主题。

## 构建入口

```bash
# PDF（约 4–5 分钟）
cd <项目根> && ./work/.venv/bin/python build_book.py

# 站点
cd output/site && npm run build
```

改章节内容只编辑 `output/book/NN_*.md`，两种成品都从它生成。

## 约定

- 章节编号：`# 第 N 章` / `## N.M` / `### N.M.K`；「关键概念 / 本节小结 / 公式与推导」为无编号辅助小节。
- 图注：图片链接 + 空行 + `**图 N-M 标题**`。
- 来源编号：[G][Z][M][P][PBM][PYB][PYDA][PANDAS][R4DS][RART][MAT][OIS][ISLR][MSMB][DL][DLLS][DCB][RLM][ILL][SCANPY]。
- `output/生物信息学与数据科学_合并版.md` 是 44 个章文件的完整拼接快照，批量改章文件前先备份它。
