# 第 4 课 · 酶的分离工程

>授课导师：藤原千花
>日期：2026-06-18

---

## 核心逻辑链

```
发酵液/细胞 → 预处理（破碎）→ 液固分离（离心）→ 粗分离（沉淀）→ 精纯化（层析）→ 成品（浓缩/干燥/结晶）
```

---

## 1. 细胞破碎

### 四大方法

| 方法 | 原理 | 代表技术 | 适用场景 |
|------|------|---------|---------|
| **机械法** | 剪切力/压缩力 | 高压匀浆、捣碎、研磨 | 工业大规模（主流） |
| **物理法** | 温度/压力/声波 | 反复冻融、压差、超声 | 实验室小规模 |
| **化学法** | 溶解细胞膜 | 有机溶剂、表面活性剂 | 特定场景 |
| **酶促法** | 酶解细胞壁 | 溶菌酶、纤维素酶 | 温和条件 |

### 保护措施

- **低温操作**（0～10℃）：防止酶热变性
- **控制破碎程度**：避免过度释放杂蛋白
- **加保护剂**：还原剂（抗坏血酸）、金属螯合剂（EDTA）
- **快速操作**：减少蛋白酶降解

>⚠️ **关键概念**：细胞破碎后，内源蛋白酶会释放出来降解目标酶。低温 + 适当低 pH 可抑制蛋白酶活性。

---

## 2. 液固分离

| 方法 | 截留颗粒 | 适用场景 |
|------|---------|---------|
| **过滤**（粗滤） | > 2 μm | 酵母、霉菌、大颗粒 |
| **微滤** | 0.05～2 μm | 细菌、细胞碎片 |
| **离心** | 各种 | 工业主流（碟片式/螺旋卸料） |

### 离心机类型

- **三足式**：间歇操作，手动卸料
- **管式高速**：> 10000 r/min，适合稀悬浮液
- **碟片式**：4000～7000 r/min，连续操作，乳浊液分离
- **螺旋卸料**：连续排渣
- **超速离心**：> 60000 r/min，蛋白质/细胞器分离

---

## 3. 沉淀法（粗分离）

### 3.1 盐析沉淀

**原理**：中性盐抢走蛋白质表面水分子 → 破坏水化层 → 疏水区域暴露 → 聚集沉淀

**盐析方程**：

$$
\lg S = \lg S_0 - K_s I
$$

| 参数 | 含义 | 特点 |
|------|------|------|
| $S$ | 当前溶解度 | — |
| $S_0$ | 纯水溶解度 | — |
| $I$ | 离子强度 | 盐浓度 |
| $K_s$ | 盐析系数 | 与蛋白结构、盐价数有关；**与温度、pH 无关** |
| $\beta = \lg S_0$ | 酶特征常数 | 与酶性质、温度、pH 有关；**与盐种类无关** |

>**核心规律**：$K_s$ 越大 → 溶解度下降越快 → 越容易沉淀

**分级盐析**：不同蛋白 $K_s$ 不同 → 在不同盐浓度下分段沉淀 → 实现分离

### 3.2 等电点沉淀

**原理**：pH = pI 时，蛋白质净电荷为零 → 溶解度最低 → 沉淀

**局限**：pI 时仍有水化层 → 沉淀不完全 → 需配合盐析或有机溶剂

### 3.3 有机溶剂沉淀

**原理**：降低水的介电常数 → 蛋白质间静电引力增大 → 聚集沉淀

**注意**：可能引起变性 → **必须低温操作**

## 4. 层析法（精纯化）

### 4.1 离子交换层析

| 交换剂类型 | 活性基团 | 结合对象 |
|-----------|---------|---------|
| **阳离子交换剂** | 酸性（—SO₃⁻） | 带**正电**蛋白 |
| **阴离子交换剂** | 碱性（—N⁺R₃） | 带**负电**蛋白 |

**选择逻辑**：

- pH > pI → 蛋白带负电 → 用**阴离子交换剂**
- pH < pI → 蛋白带正电 → 用**阳离子交换剂**

**洗脱**：盐浓度梯度 → 结合力弱的先下来，结合力强的后下来

### 4.2 凝胶过滤层析（分子筛）

**原理**：按分子大小分离

- **大分子**：进不了孔 → 走颗粒间隙 → 路程短 → **先出来**
- **小分子**：钻进孔里 → 绕远路 → **后出来**

**优点**：条件温和，不影响酶活性

### 4.3 亲和层析

**原理**：利用生物特异性亲和力（钥匙-锁）

| 配体类型 | 例子 |
|---------|------|
| 底物/抑制剂 | 酶特异性识别的分子 |
| 辅酶 | NAD⁺、ATP |
| 抗体 | 抗原-抗体亲和 |
| 金属离子 | Ni²⁺（His-tag 纯化） |
| 凝集素 | ConA（糖蛋白） |

**特点**：选择性最高，纯化倍数大，但成本高

## 5. 成品加工

| 步骤 | 方法 |
|------|------|
| **浓缩** | 超滤、真空蒸发、PEG 吸水 |
| **脱盐** | 透析、凝胶过滤 |
| **干燥** | 真空干燥、喷雾干燥、**冷冻干燥**（最温和） |
| **结晶** | 盐析结晶、有机溶剂结晶、等电点结晶 |

---

## 易错点

1. **盐析 ≠ 变性**：盐析可逆，变性不可逆
2. **$K_s$ 越大越容易沉淀**（不是越小）
3. **带负电蛋白 → 阴离子交换剂**（异性相吸）
4. **凝胶过滤：大分子先出，小分子后出**
5. **液固分离用离心/过滤，不是层析**
