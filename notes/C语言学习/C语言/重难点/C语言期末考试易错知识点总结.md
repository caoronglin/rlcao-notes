# C语言期末考试易错知识点总结

### 🤖 Assistant

以下是C语言期末考试中**易错且容易被忽视的知识点总结**，结合考试题型整理，建议重点复习：

---

### **一、选择题/判断题易错点**

1. **指针与数组的混淆**

- 数组名 `arr` 作为参数传递时，实际传递的是地址（等价于 `int*`），但 `sizeof(arr)` 在函数内会返回指针大小（4/8字节），而非数组总长度。

- 指针运算：`int* p; p++` 会跳过 `sizeof(int)` 字节，而非1字节。

2. **结构体内存对齐**

- 结构体成员的对齐方式可能因编译器而异（如4字节对齐），导致 `sizeof(结构体)` 不等于成员大小之和。

- 位域（bit-field）的使用：`unsigned int a : 2;` 只占2位，但可能因平台不同导致跨字节问题。

3. **宏定义的副作用**

- 宏替换是简单的文本替换，参数未加括号可能导致运算符优先级错误。  
  例：`#define MAX(a, b) a > b ? a : b`，调用 `MAX(x++, y++)` 会导致 `x` 和 `y` 被多次自增。

4. **全局变量与静态变量**

- 全局变量未显式初始化时默认为0，但局部变量未初始化则值不确定。

- `static` 修饰局部变量时，生命周期延长至整个程序运行，但作用域仍限于函数内。

5. **文件操作模式**

- `"r"`（只读，文件不存在报错）、`"w"`（清空写入，文件不存在则创建）、`"a"`（追加写入，文件不存在则创建）。

- `fopen` 返回 `NULL` 时需判断，否则后续操作会崩溃。

---

### **二、程序填空题易错点**

1. **循环条件与边界处理**

- `for` 循环中 `i` 的初始值、终止条件、步长易写反（如 `i <= n` 与 `i < n`）。

- 二维数组遍历时行、列顺序混淆（如 `arr[i][j]` vs `arr[j][i]`）。

2. **指针与数组下标**

- `* (arr + i)` 等价于 `arr[i]`，但 `arr + i` 的类型是 `int*`，不能直接赋值给 `int` 变量。

- 字符串处理中，`char s[10]; scanf("%s", s);` 会自动添加 `\0`，但 `scanf("%[^\n]", s);` 需手动处理换行符。

3. **函数参数传递**

- 值传递：函数内修改形参不影响实参；地址传递需通过指针修改实参值。

- 例：`void swap(int* a, int* b)` 需通过 `*a` 和 `*b` 交换值。

4. **动态内存分配**

- `malloc` 返回 `void*`，需强制类型转换（如 `int* p = (int*)malloc(n * sizeof(int));`）。

- `free(p)` 后需将指针置为 `NULL`，避免野指针。

---

### **三、编程题易错点**

1. **数组越界与字符串处理**

- 字符串复制 `strcpy(s1, s2)` 时，需确保 `s1` 有足够空间，否则引发缓冲区溢出。

- 使用 `strcat` 或 `sprintf` 时，注意目标数组的大小。

2. **递归函数**

- 递归终止条件不完整可能导致栈溢出（如阶乘函数未处理 `n=0` 的情况）。

- 递归深度过大时，建议改用迭代实现。

3. **结构体与共用体**

- 结构体嵌套时，成员访问需逐层展开（如 `struct A a; a.b.x`）。

- 共用体（`union`）所有成员共享同一块内存，修改一个成员会覆盖其他成员的值。

4. **文件读写**

- 读取文件时，需处理 `EOF`（文件结束符），避免死循环。

- 二进制文件读写需使用 `fread`/`fwrite`，注意参数顺序（如 `fread(buffer, size, count, fp)`）。

### **四、高频考点清单**

| 知识点 | 易错点 |
| --- | --- |
| 指针与数组 | 数组名作为参数传递时的类型差异、指针算术运算 |
| 结构体与共用体 | 内存对齐、位域、共用体成员覆盖 |
| 宏定义与预处理 | 宏参数未加括号、宏替换的副作用 |
| 动态内存 | `malloc`/`calloc` 的区别、`free` 后置空指针 |
| 文件操作 | 模式字符串误用、文件指针位置（`fseek`/`ftell`） |
| 字符串处理 | 缓冲区溢出、`strcat`/`strcpy` 的安全使用 |

### **复习建议**

1. **针对性练习**：多做历年真题中的易错题型（如指针、结构体、文件操作）。

2. **代码调试**：用 `printf` 或调试工具检查指针、数组下标、内存分配是否正确。

3. **记忆口诀**：

- "指针数组，数组指针，弄清顺序"

- "宏定义，参数括号，避免陷阱"

- "文件操作，模式选对，EOF 处理"
