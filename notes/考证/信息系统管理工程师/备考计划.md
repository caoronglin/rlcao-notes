## A 方案：冲 2026-10-24（37 天，高强度）

### 阶段一 · 过书（Day 1–15）

- 按 [[知识体系]] 的 ①→④ 板块顺序推进；**第 1、2 章速览即可**（不考案例），把时间喂给 3–16 章。
- 每章产出：一张思维导图（用 Obsidian 的 Mind Map 插件）+ 5 条自问自答。
- 达标线：合上书能说出每章"管什么、有哪些过程/角色/文档"。
- 配套：B 站第 2 版精讲（见 [[复习资料清单]]）按章节倍速过一遍，**只补看不懂的**。

### 阶段二 · 刷题 + 案例（Day 16–30）

- 每天：选择题 60–80 道（信管网题库），错题**当场记成笔记**，不攒。
- 隔天：1 道案例题**手写**，写完对照参考答案标出漏掉的术语与步骤。
- 重点刷：8.4 运维过程链、15.5 容灾、16.5 等保、10 章项目过程组、9.x 云服务交付。
- 建立"术语本"：ITIL（事件/问题/变更/配置/发布）、ITSS、SLA、RTO/RPO、等保 2.0 分级、DCMM、DAMA。

### 阶段三 · 模拟 + 收口（Day 31–37）

- 全真机考模拟 ≥ 2 次，**严格计时**，练界面、计算器、草稿纸。
- 时间分配：选择题 ≤ 60 分钟，案例留足 90 分钟以上。
- 考前 3 天：不再碰新题，只回顾错题本 + 背诵卡 + 术语本。

### 案例题答题模板（背下来）

| 题型 | 结构 |
|---|---|
| 故障排查 | 定位问题 → 分析日志 → 隔离环境 → 验证修复 → 复盘预防 |
| 方案设计 | 总（目标与依据标准）→ 分（分条列措施，每条挂术语）→ 总（评估与持续改进） |
| 流程设计 | 按标准框架起手（ITIL/ITSS 过程名）→ 结合场景落地角色与输入输出 → 补应急与改进 |

**得分要点**：写术语（ITIL / ITSS / 等保 2.0 / SLA / RTO / RPO / CMDB）、写指标、写责任角色；宁可多分点，不要写大段散文。
