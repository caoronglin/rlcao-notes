# Hello,world!

让我们照例先写一个Hello,world!

```c
#include <stdio.h> //这一步引进头文件
int main(){
	printf('Hello,world!'); //此处为C语言内置打印函数
  return 2022;//此处为函数运行完成后，返回的数据
}
```

利用gcc编译C语言源文件

```bash
gcc helloword.c
./a.out
```

这就是一个很简单的C语言函数，让我们来看一下运行效果（此为编译后的效果）
