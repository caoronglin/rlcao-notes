# 参看文档

{% emoji blobcat 0_0 %} 本站主体是**学习笔记**；这里收录的是
由 11 本教材/教程、1 篇方法学论文与 3 个站点文档融合而成的**教材正文**，
作为查证与回溯用的参看文档。原始版权归各自作者与出版社所有。

{% box 这本书是怎么来的 color:blue %}

它不是合订本：11 本书按**一条学习主线**重排为 6 编 19 个板块，
同一知识点只保留讲得最深的一个源作正文，其余进入各章末的「对照阅读」。
每章章首有编者导语与自动生成的「本板块导读」（列出该板块真实的图/案例/公式）。
{% endbox %}
