# 高频考点速记

>⚠️ **性质说明**：本页是**机构（希赛网）整理的应试速记**，不等于官方权重分布——第 2 版真题样本少，目前**没有任何权威分值统计**。用法：当日程表背，别当考纲。
>权威骨架以 [[知识体系]]（官方大纲原文）为准。

## 一、必背口诀（希赛提供）

| 口诀 | 展开 | 对应考点 |
|---|---|---|
| **花—开—云—消** | 规划(花) → 开发(开) → 运维(云) → 消亡(消) | 信息系统生命周期四阶段 |
| **划—分—即—实—验** | 总体规划 → 系统分析 → 系统设计 → 系统实施 → 系统验收 | 开发阶段细分 |
| **应用资源网，技产人才强，法规标准棒** | 信息技术应用、信息资源、信息网络、信息技术产业、信息化人才、政策法规与标准规范 | 国家信息化体系**六要素** |
| **功能靠用小护翼** | 功能性、可靠性、易用性*、效率、可维护性、可移植性 | 软件质量六大特性 |

\* 希赛原文写作"可用性"，但按 ISO 9126 质量特性与谐音（功能—靠—用—小—护—翼）对应，此处应为**易用性**。「可用性」属涉密/运维语境术语，与质量模型不同源——**这是一处需要以教程原文为准存疑的点**。

## 二、高频重点模块（希赛提炼）

### IT 服务管理（ITSM）

- 核心框架：**ITIL**；重点流程：**事件管理 / 问题管理 / 变更管理**
- 关联：服务级别管理（SLA）、服务台、CMDB（配置管理）
- 出题倾向：给运维场景 → 要求指出流程缺失或设计服务流程

### 项目管理工具

- **WBS（工作分解结构）**：把项目拆成可管理任务包
  - 例：系统集成 → 网络配置 / 服务器部署 / 安全加固

### 技术与前沿

- 数据库：**E-R 模型**、SQL 优化（JOIN、GROUP BY）
- 云服务：**IaaS / PaaS / SaaS 三层区别**
- 数字化转型：工业互联网平台架构四层——网络层（5G/NB-IoT）、平台层（数据中台）、数据层（时序数据库）、安全层（零信任架构）

## 三、高频失分点（希赛指出，按科目分）

**《基础知识》向**

- 子网划分计算 → 需熟练 **CIDR** 表示法
- Linux 命令混淆 → **chmod（改权限）vs chown（改所有者）**

**《应用技术》向**

- 故障排查**步骤缺失** → 必须走完"定位问题 → 分析日志 → 隔离环境 → 验证修复"
- SQL 语句写错 → JOIN / GROUP BY 语法

## 六、知乎速记条目（原文称 100 条，公开部分为 15 条）

>来源：[知乎《25上软考中级——100条知识点速记》](https://zhuanlan.zhihu.com/p/20114084633)（2025-01-24）。原文自述"涵盖全书 80% 重点"，实为节选。

1. 信息系统五个基本功能：**输入、存储、处理、输出、控制**
2. 信息系统生命周期：系统规划（可行性分析与项目开发计划）→ 系统分析（需求分析）→ 系统设计（概要/详细设计）→ 系统实施（编码、测试）→ 系统运行和维护
3. 信息系统开发原则：高层管理人员介入、用户参与开发、自顶向下规划、工程化
4. 数字化转型模型框架：成熟度等级、能力域、成熟度要求描述；涉及组织、技术、数据、资源、数字化运营、数字化生产、数字化服务
5. 工业互联网平台体系四层级：**以网络为基础、平台为中枢、数据为要素、安全为保障**
6. 计算机硬件：控制器、运算器、存储器、输入设备、输出设备；软件：系统软件、应用软件、中间件；网络按作用范围：个人局域网、局域网、城域网、广域网
7. 存储分类：内置存储 / 外挂存储（直连式 DAS、网络化存储）；网络化存储按传输协议分 NAS、SAN
8. **OSI 七层**（见下表）
9. 常见数据结构模型：层次模型、网状模型、关系模型（前两者合称格式化数据模型）
10. 信息安全三要素 CIA：保密性 Confidentiality / 完整性 Integrity / 可用性 Availability
11. 信息系统安全四层次：设备安全、数据安全、内容安全、行为安全
12. 物联网：三层架构（感知层、网络层、应用层）；本质特点（互连、识别与通信、智能化）；关键技术（传感器、传感网、应用系统架构）
13. 云计算特征：超大规模、高可扩展、虚拟化、高可靠、通用性、廉价、灵活定制；服务类型 IaaS/PaaS/SaaS
14. 大数据特征：海量、类型多样、价值密度低、处理速度快；处理技术：采集、存储、计算、展现与交互
15. 区块链特征：去中心化、多方维护、时序数据、智能合约、不可篡改、开放共识、安全可信；关键技术：分布式账本、加密算法、共识机制

### OSI 七层速查

| 层 | 名称 | 主要功能 | 主要设备及协议 |
|---|---|---|---|
| 7 | 应用层 | 实现具体的应用功能 | POP3、FTP、HTTP、Telnet、SMTP、DHCP、TFTP、SNMP、DNS |
| 6 | 表示层 | 数据格式与表达、加密、压缩 | JPEG、ASCII、GIF、DES、MPEG |
| 5 | 会话层 | 建立、管理和终止会话 | RPC、SQL、NFS |
| 4 | 传输层 | 确保数据可靠、顺序、无错地从 A 点传输到 B 点 | TCP、UDP、SPX |
| 3 | 网络层 | IP 与 MAC 地址翻译；分组传输和路由选择 | 三层交换机、路由器、ARP、RARP、IP、ICMP、IGMP |
| 2 | 数据链路层 | 控制网络层与物理层通信，传送以帧为单位的信息 | 网桥、交换机（多端口网桥）、网卡、IEEE802.3/2、HDLC、PPP、ATM |
| 1 | 物理层 | 物理连网媒介，二进制传输 | 中继器、集线器（多端口中继器） |

>⚠️ 注：第 7、8、12–15 条多为**旧版教材（第 1 版）体系**的概念（OSI、物联网三层、云计算特征等），第 2 版已将其压缩进第 2 章作概述。用作概念速记可以，**章节归属别照搬**。

## 七、勘误（做题时发现）

- [[练习题·基础知识]] 中，同一考点在不同来源写法不一：一版作"信息系统的**开放性**、脆弱性和健壮性"，另一版作"**开发性**"。对照解析（讲的是开放性的定义），**"开发性"应为"开放性"** —— 引用时以"开放性"为准。
