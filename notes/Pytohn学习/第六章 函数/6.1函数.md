# 6.1函数

### Python函数总结

#### 一、函数基础

**1. 定义与调用**

- 函数是组织好的、可重复使用的代码块，用于实现单一或相关联功能。
- 定义语法：

```python
def 函数名(参数列表):
    函数体
    [return 返回值]
```

- 调用：`函数名(实参列表)`

**2. 函数分类**

- **内置函数**：Python启动时自动加载，如`len()`、`print()`、`str()`。
- **标准库函数**：需`import`导入，如`math.sqrt()`、`time.sleep()`。
- **第三方库函数**：需安装并导入，如`numpy.array()`。
- **自定义函数**：用户自行定义。

**3. return语句**

- 用于返回函数执行结果，也可提前结束函数。
- 不写`return`默认返回`None`。
- 可返回任意类型：数字、字符串、列表、元组、字典、函数对象等。

---

#### 二、参数传递

**1. 参数种类**

- **位置参数**：按顺序传递，实参与形参一一对应。
- **关键字参数**：通过参数名指定，可无序传递。
- **默认参数**：形参带默认值，调用时可省略。
- **可变参数**：

- `*args`：接收任意数量的位置参数，以元组形式存储。
- `**kwargs`：接收任意数量的关键字参数，以字典形式存储。

- **强制关键字参数**：参数列表中`*`之后的参数必须用关键字方式传递。

**2. 参数传递机制**

- Python中一切皆对象，参数传递本质是“传对象引用”。
- **不可变对象**（如`int`、`str`、`tuple`）：函数内修改不会影响原对象。
- **可变对象**（如`list`、`dict`、`set`）：函数内修改会影响原对象。

---

#### 三、作用域与生命周期

**1. 作用域**

- **局部作用域**：函数内部，局部变量仅在函数内有效。
- **全局作用域**：模块顶层，全局变量在整个模块有效。
- **闭包作用域**：嵌套函数，外层函数的变量对内层函数可见。
- **内置作用域**：Python内置名称，如`len`、`range`。

**2. global与nonlocal**

- `global`：在函数内声明全局变量，可修改全局变量。

```python
x = 1
def f():
    global x
    x = 2
```

- `nonlocal`：在嵌套函数内修改外层（非全局）变量。

```python
def outer():
    x = 1
    def inner():
        nonlocal x
        x = 2
```

---

#### 四、匿名函数（lambda）

**1. 定义**

- 使用`lambda`关键字，用于创建简单、一次性函数。
- 语法：`lambda 参数: 表达式`
- 只能有一个表达式，返回值即为表达式的结果。

**2. 应用场景**

- 常用于`map()`、`filter()`、`sorted()`等函数式编程场景。
- 示例：

```python
list(map(lambda x: x*x, [1, 2, 3]))  # [1, 4, 9]
sorted([(1, 2), (3, 1)], key=lambda x: x[1])  # 按元组第二元素排序
```

---

#### 五、闭包（Closure）

**1. 定义**

- 闭包是指嵌套函数中，内层函数引用了外层函数的变量，并返回该内层函数。
- 闭包使得外层函数的变量可以持久保存在内存中。

**2. 用途**

- **读取函数内部变量**：通过闭包暴露内部变量。
- **变量持久化**：外层函数的变量不会因函数结束而销毁。
- **装饰器**：闭包是装饰器实现的基础。

**3. 注意事项**

- 闭包会增加内存消耗，可能引发内存泄漏。
- 闭包内无法直接修改外层不可变变量，需用`nonlocal`。
- 返回闭包时，不要引用循环变量或后续变化的变量。

**4. 判断闭包**

- 通过`__closure__`属性，返回`cell`对象元组，可查看引用的外部变量。

---

#### 六、装饰器（Decorator）

**1. 定义**

- 装饰器本质是高阶函数，用于在不修改原函数代码的情况下增加额外功能。
- 语法：使用`@装饰器名`置于函数定义前。

**2. 基本装饰器**

```python
def log(func):
    def wrapper(*args, **kwargs):
        print(f"call {func.__name__}()")
        return func(*args, **kwargs)
    return wrapper

@log
def now():
    print("2024-6-1")
```

**3. 带参数的装饰器**

- 需要三层嵌套，外层函数接收装饰器参数。

```python
def log(text):
    def decorator(func):
        def wrapper(*args, **kwargs):
            print(f"{text} {func.__name__}()")
            return func(*args, **kwargs)
        return wrapper
    return decorator

@log("execute")
def now():
    print("2024-6-1")
```

**4. functools.wraps**

- 用于保留原函数的元信息（如`__name__`、`__doc__`）。

```python
import functools
def log(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        print(f"call {func.__name__}()")
        return func(*args, **kwargs)
    return wrapper
```

#### 七、函数式编程

**1. 高阶函数**

- 接收函数作为参数，或返回函数的函数。
- 常见高阶函数：`map()`、`filter()`、`sorted()`、`reduce()`。

**2. map/reduce**

- `map(func, iterable)`：对每个元素应用`func`，返回迭代器。
- `reduce(func, iterable)`：递归计算，如`reduce(lambda x,y: x+y, [1,2,3])`结果为6。

**3. filter**

- `filter(func, iterable)`：筛选满足条件的元素，返回迭代器。

```python
list(filter(lambda x: x>0, [1, -1, 2]))  # [1, 2]
```

---

#### 八、递归函数

- 函数调用自身，需有终止条件，否则会栈溢出。
- 示例：阶乘

```python
def factorial(n):
    if n == 1:
        return 1
    return n * factorial(n-1)
```

---

#### 九、总结

- **函数**是Python的核心模块，用于封装代码、提高复用性。
- **参数**支持位置、关键字、默认、可变等多种传递方式。
- **作用域**决定变量可见性，`global`和`nonlocal`用于跨作用域修改变量。
- **lambda**用于简洁匿名函数，适合函数式编程。
- **闭包**和**装饰器**是Python高级特性，用于增强函数功能。
- **函数式编程**通过高阶函数、map/reduce/filter等实现代码简洁。

掌握函数，有助于编写模块化、可维护、高效的Python代码。
