### 2.1 选址详述

**朱德故里景区**位于四川省南充市仪陇县马鞍镇，是国家 AAAAA 级旅游景区，包括朱德同志故居纪念馆、朱德故居、朱德诞生地、朱德父母故居等多处红色教学点。景区总面积约 5 平方公里，展陈空间分层丰富：户外广场、纪念雕塑、序厅、生平展区、专题展区、互动学习区、纪念品区等，天然适合拆分为 10 个以上 VR 全景点位。

**交通**：从南充主城区驾车约 1.5–2 小时，从仪陇县城驾车约 30 分钟。

**拍摄可行性**：需提前致电场馆确认全景拍摄许可。公开户外区域（广场、景区入口）通常可拍；室内展区需馆方个案审批。建议携带学校介绍信、比赛通知和脚本说明。

## 六、VR 漫游统一制作模板

### 6.1 每场景必须包含

| 元素 | 具体要求 |
|---|---|
| 全景底图 | 1 张 ≥8000×4000 JPG/PNG，可加 1 张备份 |
| 普通照片 | 3 张：环境照 + 团队/人物照 + 细节照 |
| 语音讲解 | 1 段 60–90 秒 MP3，另备 30 秒短版 |
| 知识热点 | ≥1 个：解释人物/事件/地点/展品 |
| 思考热点 | ≥1 个：观众可回答的思政问题 |
| 前后跳转 | "上一场景""下一场景"标签 |
| 返回总览 | "返回总览"标签 |

### 6.2 跳转关系表

```
场景01 入口 ───→ 场景02 序厅 ───→ 场景03 早年 ───→ 场景04 革命
                                                                      │
场景10 复盘 ←── 场景09 研学 ←── 场景08 广场 ←── 场景07 故居 │
                                                                      │
                     场景06 艰苦 ←── 场景05 军队 ←─────────────────┘
```

每个场景均可"返回总览（场景列表）"。

### 6.3 讲解词统一规范

- 第一人称导览，语气亲切
- 每场景 60–90 秒（约 200–280 字）
- 开头："大家好，我们现在在【位置】"
- 中间：1–2 个核心知识点 + 思政连接
- 结尾：自然过渡 → 下一场景

### 6.4 素材命名规范

```
全景：  {编号}_{场景名}_全景_{时间戳}.jpg
环境：  {编号}_{场景名}_环境.jpg
人物：  {编号}_{场景名}_人物.jpg
细节：  {编号}_{场景名}_细节.jpg
讲解：  {编号}_{场景名}_讲解.mp3
```

示例：

```
01_景区入口_全景_20260721.jpg
01_景区入口_环境.jpg
01_景区入口_人物.jpg
01_景区入口_细节.jpg
01_景区入口_讲解.mp3
```
