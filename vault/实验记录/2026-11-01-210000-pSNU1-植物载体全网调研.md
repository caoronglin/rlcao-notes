# pSNU1 植物载体全网调研

## Goal

用户要求全网查找 pSNU1 这一植物载体的所有信息。目标是给出可引用的完整画像：来源、结构、抗性、启动子、MCS、衍生体、全部使用文献、序列可得性与获取途径。

## Findings

- **pSNU1 = Seoul National University 的 T-DNA 双元载体**，不是通用表达载体，而是专为农杆菌介导的植物病毒侵染性克隆（agroinfection）设计。命名 SNU 即首尔国立大学。
- **原始文献是 Park & Kim 2006, Plant Pathol J 22(4):386-390, DOI 10.5423/ppj.2006.22.4.386**。该文**未被 PubMed/Europe PMC 收录**，只在 KCI、Scopus、Semantic Scholar 可见——这是全网检索最容易漏掉的一篇，也是唯一记载载体构建细节的一篇。
- **骨架来自 pCAMBIA0390**（Cambia 双元载体）。T-DNA 拓扑：`LB → 2×CaMV35S → MCS(12 sites) → Rz(自剪切核酶) → NOSt → RB`。
- **MCS 12 个位点**：EcoRI, XbaI, StuI, NcoI, BamHI, KpnI, SacI, MluI, XhoI, SrfI, SmaI, SpeI。抗性为 **kanamycin**，农杆菌菌株 **GV2260**。
- **全部 10 篇使用文献均出自 Kim KH 实验室（首尔大学）**，覆盖 PVX / SMV / CMV / CGMMV / PepMoV / TVCV 六种病毒。核心衍生体：pSNU2（MCS 缩为 4 位点）、pSPVXp31/pSPVXp32、pSMV-G7H、pSMV-MCS、pSMV-Dual、pCGMMV-KW/KOM、pCMV-209R1/2/3、pP1/pP2/pP3、pSNU1::CMV-RNA1/2/3、pPepMoV。
- **序列可得性是本次最关键的现实结论**：pSNU1 本身在 NCBI Nucleote 检索为 0、Addgene 检索为 0，从未公开提交，也无商业供应。唯一公开的衍生体完整序列是 **pSMV-Dual → GenBank LY490841.1（17,320 bp）**，来自韩国专利 KR 1020170054154-A。
- **LY490841.1 本地结构解析结果（第一轮）**：1–~9,500 bp 为 SMV 基因组；~9,600–17,320 bp 为载体骨架；检出 1 个精确 LB 25 bp 重复（+ 链 16,425 位）、CaMV 35S as-1/TATA 核心（+ 链 17,228 位）、pUC/ColE1 型 ori + rop 区（− 链）。第一轮据「未检出 nptII」判定缺少选择标记——**这个结论是错的，见下**。
- **关键更正：pCAMBIA 家族的细菌抗性基因是 aadA，不是 nptII。** 改用 pCAMBIA-1391Z（AF234312）做 k-mer 映射后，aadA 在 LY490841 − 链 15,206–16,006 被 100% 检出。同步确认的 100% 一致元件还有：nos 3'UTR（9,876–10,128）、T-DNA RB（10,166–10,191）、pVS1 STA（11,232–12,234）、pVS1-REP ori（12,825–13,825）、bom（14,235–14,495）、pBR322 ori（14,635–14,915，−链）、T-DNA LB（16,425–16,450）。未检出：hptII（潮霉素抗性）、CaMV 3'UTR、第二个 35S 拷贝、完整 12 位点 MCS。
- **这个更正的方法论教训**：在骨架来源已知（pCAMBIA0390）的情况下，应该先用同家族参考序列做 k-mer 映射，而不是凭常见载体经验假设抗性基因是 nptII。先用错基因名做精确检索，会把「检不到」误判成「不存在」。
- **已知短板**：Tran et al. 2019（J Virol Methods 265:26-34）报告 pSNU1 中的 PepMoV 克隆在 *E. coli* DH10B 中不稳定，会自发重组（*E. coli* 序列插入 NIa-protease 区致侵染性下降），用植物内含子替换后才恢复。Park & Kim 2006 也指出 5' 端多 6 nt 的影响尚未排除。

## Reproduction

```bash
# 一手文献 PDF（扫描版，需 OCR）
curl -sL -o ppj.pdf https://www.ppjonline.org/upload/pdf/PPJ022-04-15.pdf
pdftoppm -r 300 -gray -png ppj.pdf pg && for f in pg-*.png; do tesseract "$f" "${f%.png}" -l eng; done

# 全文献库全文检索 pSNU1
curl -s "https://www.ebi.ac.uk/europepmc/webservices/rest/search?query=%22pSNU1%22&format=json&pageSize=25&resultType=core"

# 序列可得性核查
curl -s "https://eutils.ncbi.nlm.nih.gov/entrez/eutils/esearch.fcgi?db=nuccore&term=pSNU1&retmode=json"   # → count 0
curl -sL "https://www.addgene.org/search/?q=pSNU"                                                    # → "0 results"

# pSMV-Dual 序列（唯一公开衍生体）
curl -s "https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=nuccore&id=1371023957&rettype=fasta&retmode=text"
```

## Problems

- **Exa MCP 与 Bing MCP 的 session 均过期**，改走 cherry-tools web_search + NCBI E-utilities + Europe PMC REST 直连，反而更可控。
- **PPJ 的 2006/2008 年 PDF 是纯扫描图**（`pdftotext` 得 0 字），用 `pdftoppm` 转 300 dpi PNG 后 tesseract OCR 才取到全文；OCR 会把 `pSNU1` 误识为 `pSNUI`，需对照原图校正。
- **`pSNU` 无引号检索会被 Europe PMC 模糊匹配**成 "problematic social networking use" 等无关文献；必须用 `"pSNU1"` 精确短语。
- **首尔大学 s-space 学位论文有 JS challenge**，需先从落地 HTML 取 `js-challenge` cookie 再带 cookie 请求 PDF。

## Verification

- 载体结构与 MCS 位点：已对照 Park & Kim 2006 原书第 387 页正文 + Fig. 1，以及 Phan 2014 / Seo 2016 的 Fig. 1 图注文字三方交叉一致。
- 10 篇使用文献：Europe PMC `"pSNU1"` 全文检索返回 7 条 + 引用网络回溯（Crossref 12 篇被引、OpenCitations、Semantic Scholar）补 3 条，全部核对到 PMID/DOI。
- 序列缺失结论：NCBI Nucleotide（`pSNU1`/`pSNU`/`PSNU`）与 Addgene 均实检为 0，非推断。
- LY490841.1 结构判定：本地 k-mer 比对 + 双链 motif 扫描 + ORF 翻译，结论已区分「已检出」与「未检出」，未检出不等于不存在。

## Result

pSNU1 是首尔大学 Kim KH 实验室 2006 年自 pCAMBIA0390 改造的病毒侵染性克隆专用双元载体（LB–2×35S–MCS(12)–Rz–NOSt–RB，Kan^R，GV2260），支撑了该实验室 2006–2021 年六种植物的病毒侵染性克隆体系，并衍生出 VOX 载体。骨架序列从未公开，也无商业渠道；唯一公开衍生体为 GenBank LY490841.1（pSMV-Dual，17,320 bp），但该记录不含完整选择标记 cassette。
