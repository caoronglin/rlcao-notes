# 生信实验一 NCBI浏览与序列文件解读

## 实验目的与假设

- 了解 NCBI 上提供的数据库资源；熟悉 GenBank 序列文件；掌握 PubMed 搜索文献的方法。
- 假设：一个基因在不同数据库里的标识可以互相校对；一条 RefSeq mRNA 记录里的全部信息都能从特征表与序列本身独立推出并交叉验证。

## 样品与分组

无湿实验样品。研究对象为玉米 `ZmFIE1` 及其同源记录。

| 样品编号 | 处理/分组 | 重复 | 备注 |
| --- | --- | --- | --- |
| LOC542075 | 研究对象 | — | 玉米 FIE1，4 号染色体减链 |
| NM_001111711.1 / NP_001105181.1 | 本次分析的主记录 | — | RefSeq，人工校核，1787 nt / 461 aa |
| XM_023302232.2 / XP_023158000.1 | 预测模型对照 | — | 1738 nt / 430 aa，13 个编码外显子 |
| Q8VZY7 | UniProt 对照 | — | `FIE1_MAIZE`，Reviewed，461 aa |

## 方法与参数

- 方法/协议：[[vault/方法/生信分析/05_基因记录与序列文件解读|基因记录与序列文件解读流程]]
- 仪器与软件版本：NCBI E-utilities（2026-10-27 核对）；UniProt REST 2026_03；Ensembl Plants；PDBe API；Datasets v2alpha
- 关键参数、试剂批次：
  - 检索式 1：`FIE1[Gene Name] AND "Zea mays"[Organism]`（Gene 库）→ 1 条；`fie[Gene Name] AND "Zea mays"[Organism]` → 0 条
  - 序列取数：`efetch db=nuccore id=NM_001111711 rettype=gb`（GenBank 全记录）+ `efetch db=gene id=542075 rettype=gene_table`（基因-转录本-外显子对照）
  - 坐标核对：`esummary` 的 `genomicinfo`（0-based）、Datasets API 的 `genomic_range`（1-based）、`gene_table`（1-based）三路比对
  - 文献检索：`maize[Title/Abstract] AND PRC2[Title/Abstract]`；`("Zea mays"[MeSH Terms] OR maize[Title/Abstract]) AND (FIE[Title/Abstract] OR FIS-PRC2[Title/Abstract] OR "Polycomb group"[Title/Abstract]) AND 2020:2026[Date - Publication]`

## 结果与质控

- 11 个问题逐项给出答案与**证据来源**（GenBank 特征行 / `gene_table` / 序列实测 / UniProt 特征表）。
- 坐标用三套 API 交叉核对，统一到 1-based；长度关系 1787 = 1766 + 21 与 `ORIGIN` 末 21 个 A 相互印证。
- 8 个数据库介绍的中文字数全部 ≥50（实测 65–78 字）。
- 质控：所有登录号带版本号；`XM_023302232.2` 明确标注为模型预测并与人工校核记录区分；文献条目含 PMID 与 DOI 双标识。

## 分析与结论

> 区分观察到的结果、推测和仍需验证的解释。

- **观察**：`ZmFIE1` 在 4 号染色体减链 37,782,884–37,788,773，14 个外显子剪接 1766 nt，编码 461 aa 的 6×WD40 重复蛋白。
- **观察**：`FIE1` 与 `FIE2` 在禾谷类中分工不同——`FIE1` 母源印记、胚乳优先表达，`FIE2` 父源优势表达；`FIE1` 通过在 α-zein 基因簇与 `ZmMADS` 位点投放 H3K27me3 平衡灌浆与增殖。
- **推测**：`LOC` 号段只说明基因名未获批准，与"研究程度低"无关——该基因有 20 篇直接文献。
- **仍需验证**：`NM_001111711.1` 仍是 PROVISIONAL RefSeq，5′/3′ 端完整性需回溯 `AY061964.1` 原始文献；`XM_023302232.2` 与 NM 的剪接差异需按 GT-AG 边界核对是真实内含子变化还是注释模型差异。
