# 西北农林科技大学《概率论》期末复习“避坑”模拟卷

**适用专业：** 全校各专业
**难度系数：** ⭐⭐⭐⭐⭐ (高)

### 一、 选择与判断题 (概念陷阱区)

*本部分主要考察对定义的精确理解，很多直觉是错误的。*

1. **【判断】** 若 $P(A)=0$，则 $A$ 是不可能事件。（ ）
2. **【判断】** 若随机变量 $X$ 与 $Y$ 不相关（即 $\rho_{XY}=0$），则 $X$ 与 $Y$ 相互独立。（ ）
3. **【判断】** 若 $X, Y$ 均服从正态分布，则 $(X,Y)$ 服从二维正态分布。（ ）
4. **【判断】** 若 $f_X(x)$ 和 $f_Y(y)$ 分别是 $(X,Y)$ 的边缘概率密度，若 $f(x,y) \neq f_X(x)f_Y(y)$，则 $X$ 与 $Y$ 不独立。（ ）
5. **【选择】** 设 $A, B$ 为随机事件，且 $P(B|A)=1$，则下列结论正确的是（ ）。  
   A. $A \subset B$  
   B. $B \subset A$  
   C. $A - B = \emptyset$ (空集)  
   D. $P(A - B) = 0$
6. **【选择】** 设随机变量 $X$ 与 $Y$ 独立同分布，且 $P\{X=-1\} = P\{Y=-1\} = 1/2$， $P\{X=1\} = P\{Y=1\} = 1/2$，则下列各式成立的是（ ）。  
   A. $P\{X=Y\} = 1/2$  
   B. $P\{X=Y\} = 1$  
   C. $P\{X+Y=0\} = 1/4$  
   D. $P\{XY=1\} = 1/4$

### 二、 填空题 (计算易错区)

*本部分考察公式的熟练度，符号和系数最容易出错。*

1. 已知随机变量 $X$ 的分布函数为 $F(x)$，且 $P(X \le 1) = 0.15$，则 $P(X > 1) = \_\_\_\_\_\_$。若 $X$ 是连续型，则 $F(1) = \_\_\_\_\_\_$。
2. 已知 $X \sim N(1, 2^2)$， $Y \sim N(2, 3^2)$，且 $X, Y$ 相互独立，则 $Z = 2X - Y + 1 \sim \_\_\_\_\_\_$。
3. 设二维随机变量 $(X,Y)$ 在区域 $D: 0 < x < 1, 0 < y < x$ 上服从均匀分布，则 $(X,Y)$ 的概率密度 $f(x,y) = \_\_\_\_\_\_$。
4. 设 $X, Y$ 的方差分别为 1 和 4，相关系数为 -0.5，则根据切比雪夫不等式 $P\{|X+Y - E(X+Y)| \ge 6\} \le \_\_\_\_\_\_$。

### 三、 计算题 (综合应用与积分地狱区)

*这是拉开分数的关键，请注意步骤规范。*

#### 1. 贝叶斯公式与全概率 (阅读理解陷阱)

**题目来源：** 2023-06-09 A卷 / 2025-01-06 A卷 综合
**题目：**
某工厂有甲、乙、丙三台机器生产同一种零件，它们的产量分别占总产量的 25%, 35%, 40%。已知甲、乙、丙三台机器产品的次品率分别为 5%, 4%, 2%。
(1) 从产品中任取一件，求它是次品的概率。
(2) 如果取出的产品是次品，求它是由**甲机器**生产的概率。

#### 2. 随机变量函数的分布 (变换陷阱)

**题目来源：** 2020-2021-2 A卷 / 2024-2025-1 A卷 综合
**题目：**
设随机变量 $X$ 的概率密度为：

$f_X(x) = \begin{cases} e^{-x}, & x > 0 \\ 0, & x \le 0 \end{cases}$

(1) 求 $Y = e^{-X}$ 的概率密度函数 $f_Y(y)$。
(2) 求 $Z = X^2$ 的概率密度函数 $f_Z(z)$。
*(提示：注意变换后的定义域变化，以及单调性讨论)*

#### 3. 二维连续型随机变量 (积分限陷阱)

**题目来源：** 2021-2022-1 A卷 / 2019-2020-1 A卷
**题目：**
设二维随机变量 $(X,Y)$ 的概率密度为：

$f(x,y) = \begin{cases} 2e^{-(x+2y)}, & x>0, y>0 \\ 0, & \text{其他} \end{cases}$

(或者考三角形区域：$f(x,y)=kxy, 0<x<1, 0<y<x$)
**求：**
(1) 边缘概率密度 $f_X(x)$ 和 $f_Y(y)$。
(2) 判断 $X$ 与 $Y$ 是否独立。
(3) 求概率 $P\{X + 2Y \le 1\}$ (或者 $P\{Y < X\}$)。

#### 4. 离散型变量的独立性与协方差 (计算陷阱)

**题目来源：** 2022-2023-1 A卷
**题目：**
已知随机变量 $(X,Y)$ 的分布律如下表：

| X \ Y | -1 | 0 | 1 |
| --- | --- | --- | --- |
| **0** | 0.1 | 0.2 | 0 |
| **1** | 0.05 | 0.05 | 0.1 |
| **2** | 0.15 | 0 | 0.1 |
| **3** | 0.1 | 0.1 | 0.05 |

(1) 求 $X$ 和 $Y$ 的边缘分布律。
(2) 求在 $X=1$ 条件下 $Y$ 的条件分布律。
(3) 计算 $Cov(X,Y)$ 及相关系数 $\rho_{XY}$。

#### 5. 卷积公式与独立性 (难题)

**题目来源：** 模拟卷二 / 2021-2022-1 A卷
**题目：**
设 $X$ 和 $Y$ 相互独立，且 $X \sim U(0,1)$ (在0到1上的均匀分布)，$Y$ 服从参数为 1 的指数分布（即 $f_Y(y) = e^{-y}, y>0$）。
**求：** $Z = X + Y$ 的概率密度函数 $f_Z(z)$。
*(易错点提示：这是有限区间均匀分布与无限区间指数分布的卷积，必须严格分段积分，分为 *$z<0, 0<z<1, z>1$* 讨论)*

#### 6. 最大似然估计 (统计学必考)

**题目来源：** 2020-2021-2 概率与数理统计卷
**题目：**
设总体 $X$ 的概率密度为：

$f(x;\theta) = \begin{cases} \theta x^{\theta-1}, & 0 < x < 1 \\ 0, & \text{其他} \end{cases}$

其中 $\theta > 0$ 为未知参数。$x_1, x_2, \dots, x_n$ 是来自该总体的简单随机样本。
(1) 求 $\theta$ 的最大似然估计量 $\hat{\theta}$。
(2) (进阶) 判断 $\hat{\theta}$ 是否为无偏估计 (若未学数理统计可忽略此问)。

### 四、 答案解析与避坑指南 (简要版)

#### 第一部分：选择与判断

1. **×** (错)。**坑点：** 连续型随机变量取任意单点的概率为0，但该点可能发生。不可能事件是 $\emptyset$。
2. **×** (错)。**坑点：** 不相关 $\nRightarrow$ 独立（除非是二维正态分布）。独立 $\Rightarrow$ 不相关。
3. **×** (错)。**坑点：** 边缘正态不代表联合正态，必须强调 $(X,Y)$ 服从二维正态。
4. **√** (对)。**核心：** 独立的充要条件是联合等于边缘之积。
5. **D**。**坑点：** $P(B|A)=1 \Rightarrow P(AB)/P(A)=1 \Rightarrow P(AB)=P(A)$。这意味着 $A$ 发生的概率质量几乎全集中在 $B$ 中，也就是 $P(A-B)=0$，但不代表集合包含关系 $A \subset B$（可能差一个概率为0的集合）。
6. **A**。**计算：** $P(X=Y) = P(X=-1,Y=-1) + P(X=1,Y=1) = (1/2)(1/2) + (1/2)(1/2) = 1/2$。

#### 第二部分：填空

1. **0.85**； **0.15** (连续型 $P(X=1)=0$，所以 $P(X \le 1) = F(1)$)。
2. $N(1, 29)$。**坑点：** $E(Z) = 2(1)-2+1=1$；$D(Z) = 2^2 D(X) + (-1)^2 D(Y) = 4 \times 4 + 9 = 25$。注意方差系数要平方，且独立相加。
3. **2**。**坑点：** 三角形面积是 $1/2$，均匀分布密度是面积的倒数。
4. **1/9** (或类似)。利用 $D(X+Y) = D(X)+D(Y)+2\rho\sqrt{DX}\sqrt{DY}$ 算出总方差，再套切比雪夫公式。

#### 第三部分：计算题避坑

- **题3（二维积分）：**

- **避坑：** 求 $P(X+2Y \le 1)$ 时，积分区域 $D$ 是 $x>0, y>0, x+2y \le 1$ 围成的三角形。**画图！画图！画图！**
- **写法：** $\int_{0}^{1/2} dy \int_{0}^{1-2y} f(x,y) dx$。

- **题5（卷积）：**

- **避坑：** $f_Z(z) = \int_{-\infty}^{+\infty} f_X(x)f_Y(z-x) dx$。
- 由于 $f_X(x)$ 只在 $(0,1)$ 非零，所以积分范围限制在 $(0,1)$。
- 同时要求 $f_Y(z-x)$ 非零 $\Rightarrow z-x > 0 \Rightarrow x < z$。
- **分段：**

- 当 $0 < z < 1$ 时，积分限是 $0$ 到 $z$。
- 当 $z \ge 1$ 时，积分限是 $0$ 到 $1$（因为 $x$ 最多到1，且 $x<z$ 恒成立）。
- 这一步分段讨论是拿满分的关键。

- **题6（MLE）：**

- **步骤：** 1. 写似然函数 $L(\theta) = \prod f(x_i)$； 2. 取对数 $\ln L$； 3. 求导 $\frac{d \ln L}{d \theta} = 0$； 4. 解方程。
- **易错：** $\ln(\prod x_i^{\theta-1}) = (\theta-1)\sum \ln x_i$，很多人求导时把求和符号弄丢。
