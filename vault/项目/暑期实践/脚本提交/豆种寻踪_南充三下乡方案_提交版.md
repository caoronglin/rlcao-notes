# 豆种寻踪：川北丘陵区大豆调研暑期三下乡方案

团队：西北农林科技大学"豆种寻踪"实践队  
地点：四川省南充市  
建议时间：2026 年 7 月 20 日至7 月 26 日，共 7 天  
主线：南夏豆 25、豆玉带状复合种植、野生大豆线索核查  
红色实践点：南充市烈士陵园

## 一、选南充的理由

这次三下乡只写四川南充，不再保留其他省份备选。

南充是川北丘陵区的重要农业市，有南充市农业科学院，也有适合观察豆玉复合种植的县区。对我们来说，南充还有一个优点：调研点、住宿点和红色实践点相对集中。队伍能把时间用在访谈、田间观察和资料整理上，而不是一直坐车。

本方案不承诺发现野生大豆。所有相关内容统一写"线索核查"。如果没有核到确认记录，就如实写没有核到；如果只看到疑似生境，也只记录生境，不采集、不挖掘、不公开敏感坐标。

## 二、实践目标

1. 了解南夏豆 25 在南充周边的推广情况，重点听农技人员和种植户怎么说。
2. 记录豆玉带状复合种植的田间表现，包括行距、长势、管理难点和农户收益感受。
3. 在专家或农技人员指导下做野生大豆线索核查，只做访问和生境观察。
4. 形成一份 3000至5000 字调研报告，数据不够就少下结论。
5. 安排一次南充市烈士陵园红色社会实践，把"实事求是"落实到调研和写作里。

## 六、调研方法

### 1. 访谈

访谈对象包括农科院专家、农技人员、合作社负责人和种植户。每次访谈先征得同意再录音。对方不愿录音，就只做手写记录。

给专家的问题：

1. 南夏豆 25 的主要特点是什么？适合南充哪些地块？
2. 推广中最难的是品种、机械、技术，还是农户收益预期？
3. 南充目前豆玉复合种植主要在哪些区县推进？
4. 嘉陵江沿线是否有公开的野生大豆记录或疑似线索？能否推荐公开资料？

给农户的问题：

1. 今年种了多少亩大豆？品种叫什么？
2. 和单种玉米或单种大豆相比，复合种植麻烦在哪里？
3. 收购、补贴、病虫害、机械作业，哪个最影响积极性？
4. 如果明年继续种，最希望农技部门帮什么？

### 2. 田间观察

每块田至少记录这些内容：地点到乡镇级即可，日期，天气，作物长势，是否豆玉复合，行距或带宽，病虫草害情况，农户说法，照片编号。涉及野生大豆疑似生境时，不写精确坐标，不采样。

### 3. 资料核验

所有数字至少标注来源。来自访谈的写"据受访农户/农技人员介绍"；来自公告的写公告名称；现场看不清的展板、品种牌，拍照后回去放大核对。

## 七、红色实践安排

红色实践只去南充市烈士陵园。安排在 D6 下午，原因有三个：离顺庆区近，室外空间适合团队参观，和 VR 比赛素材采集能合并完成。

当天任务不复杂：参观纪念碑、浮雕、陈列馆允许区域、题字碑林和墓园外围；每名队员写三行现场记录；摄影组拍普通照片、云台视频和全景素材。无人机只有在陵园同意且空域允许时才飞。

这部分不写成"精神洗礼"式大段口号。报告里重点写我们看到了什么、哪些信息还要核实、这次参观怎样提醒我们做调研不能编数字。

## 十、风险控制

| 情况 | 处理 |
|---|---|
| 农科院专家临时没空 | 改为线上访谈，现场转去农技站或合作社 |
| 田块进不去 | 只在田埂或道路边观察，不踩踏作物 |
| 农户不愿受访 | 不追问，换对象；已问内容不公开姓名 |
| 暴雨 | 改室内访谈和资料整理，田间顺延 |
| 野生大豆线索不足 | 如实写"未核到确认记录" |
| 陵园不允许拍摄 | 完成参观和文字记录，VR 素材另约时间补拍 |
| 无人机不允许飞 | 取消飞行，改用云台和地面全景 |

## 十一、纪律要求

- 每天 18:00 前向指导教师报平安。
- 田间 2 人以上同行，不单独行动。
- 不采集野生植物，不公开敏感坐标。
- 访谈前说明身份和用途。
- 不把未经核实的数字写进结论。
- 红色场馆拍摄服从管理要求。

这份方案按真实出队来写。能做的事情写具体，不能确定的地方留核验口径，不为了显得完整去堆场馆和口号。
