# 8.1类

## 一、面向对象编程（OOP）核心思想

### 1. 类与对象

- **类（Class）**：对象的模板，定义属性和方法。
- **对象（Object/Instance）**：类的具体实例，拥有独立属性。

```python
class Student:
    def __init__(self, name, age):
        self.name = name  # 实例属性
        self.age = age

s1 = Student("Alice", 20)  # 创建对象
```

### 2. OOP三大特性

- **封装**：隐藏内部细节，暴露接口。
- **继承**：子类复用父类代码，可扩展。
- **多态**：不同对象对同一方法响应不同行为。

## 二、类的基本结构

### 1. 类的定义与实例化

```python
class Person:
    species = "Human"  # 类属性

    def __init__(self, name):  # 构造方法
        self.name = name  # 实例属性

    def greet(self):  # 实例方法
        print(f"Hello, I'm {self.name}.")

p = Person("Bob")
p.greet()  # Hello, I'm Bob.
```

### 2. 属性

- **类属性**：所有实例共享。
- **实例属性**：每个实例独立。
- **私有属性**：双下划线`__`开头，外部不可直接访问（实际为`_类名__属性`）。

```python
class Example:
    class_attr = "shared"

    def __init__(self, value):
        self.__private_attr = value  # 私有属性

e = Example(10)
print(e._Example__private_attr)  # 强制访问（不推荐）
```

### 3. 方法

- **实例方法**：第一个参数为`self`，操作实例数据。
- **类方法**：`@classmethod`装饰，第一个参数为`cls`，操作类数据。
- **静态方法**：`@staticmethod`装饰，无默认参数，与类无关的工具函数。

```python
class MyClass:
    def instance_method(self):
        return "instance method"

    @classmethod
    def class_method(cls):
        return "class method"

    @staticmethod
    def static_method():
        return "static method"
```

## 三、继承与多态

### 1. 继承

子类继承父类，可复用和扩展代码。

```python
class Animal:
    def speak(self):
        pass

class Dog(Animal):
    def speak(self):
        return "Woof!"

class Cat(Animal):
    def speak(self):
        return "Meow!"
```

### 2. 方法重写与super()

子类可重写父类方法，`super()`调用父类方法。

```python
class Parent:
    def show(self):
        print("Parent")

class Child(Parent):
    def show(self):
        super().show()  # 调用父类方法
        print("Child")

c = Child()
c.show()
```

### 3. 多重继承与MRO

Python支持多重继承，方法解析顺序（MRO）决定调用顺序。

```python
class A:
    def method(self):
        print("A")

class B(A):
    def method(self):
        print("B")

class C(A):
    def method(self):
        print("C")

class D(B, C):
    pass

d = D()
d.method()  # 输出 B（MRO: D->B->C->A）
print(D.mro())  # 查看MRO列表
```

### 4. 多态

不同对象调用相同方法，表现出不同行为。

```python
def animal_speak(animal):
    print(animal.speak())

animal_speak(Dog())  # Woof!
animal_speak(Cat())  # Meow!
```

## 四、高级特性

### 1. 特殊方法（魔术方法）

以双下划线`__`开头和结尾，用于实现对象的内置行为。

| 方法 | 说明 |
| --- | --- |
| `__init__` | 构造方法 |
| `__str__` | `print(obj)`时调用 |
| `__repr__` | `repr(obj)`时调用，调试用 |
| `__len__` | `len(obj)`时调用 |
| `__getitem__` | 索引访问`obj[key]` |
| `__call__` | 对象可调用`obj()` |

```python
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __str__(self):
        return f"Vector({self.x}, {self.y})"

    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)

v1 = Vector(1, 2)
v2 = Vector(3, 4)
print(v1 + v2)  # Vector(4, 6)
```

### 2. 属性访问控制

- `@property`：将方法转为属性，实现只读或计算属性。
- `属性名.setter`：控制属性赋值。

```python
class Student:
    def __init__(self):
        self.__score = 0

    @property
    def score(self):
        return self.__score

    @score.setter
    def score(self, value):
        if 0 <= value <= 100:
            self.__score = value

s = Student()
s.score = 85  # 通过setter赋值
print(s.score)  # 通过getter读取
```

### 3. 抽象类

使用`abc`模块定义抽象基类，强制子类实现方法。

```python
from abc import ABC, abstractmethod

class Shape(ABC):
    @abstractmethod
    def area(self):
        pass

class Circle(Shape):
    def __init__(self, radius):
        self.radius = radius

    def area(self):
        return 3.14 * self.radius ** 2

# s = Shape()  # 报错，不能实例化抽象类
c = Circle(5)
print(c.area())  # 78.5
```

### 4. **slots**

限制实例属性，节省内存。

```python
class Point:
    __slots__ = ('x', 'y')  # 只允许x和y属性

p = Point()
p.x = 1
p.y = 2
# p.z = 3  # 报错，不允许添加z属性
```

## 五、设计原则与最佳实践

### 1. 单一职责原则（SRP）

一个类只负责一项功能。

### 2. 开闭原则（OCP）

对扩展开放，对修改封闭。通过继承和组合实现。

### 3. 组合优于继承

优先使用组合（has-a）而非继承（is-a），减少耦合。

```python
# 组合示例
class Engine:
    def start(self):
        print("Engine start")

class Car:
    def __init__(self):
        self.engine = Engine()  # 组合

    def drive(self):
        self.engine.start()
```

### 4. 避免滥用继承

继承层次不宜过深，优先用组合或接口。

### 5. 合理使用私有属性

用`__`前缀保护内部数据，通过方法控制访问。

## 六、总结

Python类是面向对象编程的核心，通过类和对象实现代码的模块化、复用性和扩展性。核心要点包括：

1. **类与对象**：类是模板，对象是实例。
2. **三大特性**：封装、继承、多态。
3. **方法类型**：实例方法、类方法、静态方法。
4. **高级特性**：特殊方法、属性控制、抽象类、`__slots__`。
5. **设计原则**：单一职责、开闭原则、组合优于继承。

掌握这些知识点，能够编写结构清晰、易于维护的Python面向对象程序，是Python进阶开发的必备技能。
