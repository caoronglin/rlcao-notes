# 6.2命名空间和作用域

### ​

#### 一、命名空间（Namespace）

**1. 定义**

- 命名空间是从名称（变量名、函数名等）到对象的映射，就像字典，键是名称，值是对象。
- 作用：避免名称冲突，支持代码模块化和作用域管理。

**2. 分类**

- **内置命名空间（Built-in）**：Python启动时创建，包含内置函数和异常（如`abs`、`BaseException`等），解释器关闭时销毁。可通过`dir(__builtins__)`查看。
- **全局命名空间（Global）**：模块级别定义的名称，包括模块中变量、函数、类等。每个模块有独立的全局命名空间，随解释器终止销毁。
- **局部命名空间（Local）**：函数内部定义的名称，仅在函数调用时创建，函数返回时销毁。
- **闭包命名空间（Enclosing / Nonlocal）**：嵌套函数中，外层函数的命名空间对内层函数可见，用于闭包场景。

**3. 生命周期**

- 命名空间的生命周期与其作用域绑定，作用域结束则命名空间销毁（如函数返回）。
- 内置和全局命名空间生命周期与程序运行期相同。

---

#### 二、作用域（Scope）

**1. 定义**

- 作用域是程序中可以直接访问某个命名空间的代码区域。
- 作用域决定名称的“可见性”，即变量在哪些地方可被访问。

**2. 分类**

- **L（Local）**：最内层，函数内部。
- **E（Enclosing）**：外层非局部、非全局（闭包函数的外层函数）。
- **G（Global）**：模块最外层，全局变量。
- **B（Built-in）**：内置作用域。

**3. 查找规则：LEGB**
Python查找名称时按 Local → Enclosing → Global → Built-in 顺序进行，找不到则抛出`NameError`。

---

#### 三、全局变量与局部变量

- **全局变量**：在函数外定义，可在整个模块访问。
- **局部变量**：在函数内定义，仅函数内可访问。
- 优先级：局部变量优先于全局变量（同名时函数内优先使用局部变量）。

**示例**

```python
x = 10  # 全局变量

def my_function():
    x = 5  # 局部变量
    print(x)  # 输出 5

my_function()
print(x)  # 输出 10
```

---

#### 四、global 与 nonlocal 关键字

- **global**：在函数内声明使用全局变量，可修改全局变量。

```python
x = 1
def fun():
    global x
    x = 2
fun()
print(x)  # 输出 2
```

- **nonlocal**：在嵌套函数内修改外层（非全局）变量。

```python
def outer():
    x = 10
    def inner():
        nonlocal x
        x = 20
    inner()
    print(x)  # 输出 20
outer()
```

---

#### 五、作用域的创建规则

- Python中只有模块（module）、类（class）、函数（def/lambda）会引入新作用域。
- 其他代码块（如`if`、`for`、`try`等）不引入新作用域，内部定义的变量外部可访问。

**示例**

```python
if True:
    msg = "I am from Runoob"
print(msg)  # 可访问，输出 "I am from Runoob"

def test():
    msg_inner = "I am from Runoob"
print(msg_inner)  # 报错：NameError: name 'msg_inner' is not defined
```

---

#### 六、常见错误与注意事项

- **局部变量引用错误**：在函数内先引用后赋值局部变量，会报`UnboundLocalError`。

```python
a = 10
def test():
    # a = a + 1  # 报错，局部变量a未定义就引用
    global a
    a = a + 1  # 正确，声明使用全局变量
```

---

#### 七、总结

- **命名空间**是名称到对象的映射，**作用域**是名称可被访问的代码区域。
- 命名空间分为内置、全局、局部、闭包四种，作用域按LEGB规则查找。
- 使用`global`和`nonlocal`可跨作用域修改变量。
- 只有模块、类、函数引入新作用域，其他代码块不引入。

掌握命名空间和作用域，有助于编写结构清晰、无命名冲突的高质量代码。
