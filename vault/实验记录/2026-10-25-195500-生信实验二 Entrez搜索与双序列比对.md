# 生信实验二 Entrez搜索与双序列比对

> 2026-11-06 修订：研究分子保持玉米 `ZmFIE1`；任务 1.1 的人 EGF 检索是题目指定，不再把实验二整体换成 EGF。1.3 的 5 条并系同源用其它禾本科的 FIE2 补齐。

## 实验目的与假设

- 掌握 Entrez 检索、直系/并系同源判断、EBI 数据库浏览、Needle/Water 双序列比对。
- 假设：FIE1 与 FIE2 的差异主要在 N/C 端延伸；去掉末端后，WD40 核心的 identity 会明显升高。

## 结果与质控

- 核酸：Needle 56.3% / 28.5% gaps；Water 58.5% / 25.6% gaps。
- 蛋白直系：Needle 58.0% / 18.8% gaps；Water 72.3% / 0.3% gaps。
- 蛋白并系：Needle 62.7% / 17.8% gaps；Water 77.7% / 0 gaps。
- 核酸 EDNAFULL 与 EDNAMAT 逐项相同；蛋白 EBLOSUM62/45/80 的 identity、gaps 和比对路径相同，score 分别 1,475 / 1,791 / 2,343。
- 蛋白全局比对只有 4 段空位，最长 58 aa，落在 query 1–58、157、435–461；Water 保留 64–431，切掉 N/C 端延伸。
- ELink 复核：Gene 542075 产出 `NM_001111711.1` 与 `XM_023302232.2`，Gene 542076 产出 `NM_001111712.1`；`fie[Gene Name]` 在 nuccore 检索返回 0 条，基因名检索不能替代物种 + 标题限定。

## 分析与结论

- 观察：FIE1 与 OsFIE1 的核酸 identity 只有 56–59%，但蛋白 WD40 核心局部 identity 72.3%；差异集中在 N/C 端。
- 观察：并系 FIE2 的局部 identity 77.7%，高于远缘直系（拟南芥 59.0%）；identity 不能单独判定直系/并系。
- 推测：水稻/小麦 461–466 aa 的“FIE1-like”是 FIE2 支，需基因树复核。
- 待验证：Ensembl 1,815 nt 与 RefSeq 1,787 nt 的差异来自 5′UTR 还是可变剪接。
