# 4.2循环语句

## 一、循环语句的基本概念

循环是编程中最基本也是最重要的控制结构之一，它允许代码重复执行，直到满足特定的条件为止。Python提供了两种主要的循环结构：`for`循环和`while`循环。

### 1. for循环

`for`循环是Python中最常用的循环结构，用于遍历任何序列（如列表、元组、字符串）或其他可迭代对象。

#### 基本语法

```python
for iterating_var in sequence:
    statements(s)
```

#### 基本用法

```python
# 遍历字符串
for letter in 'Python':
    print("当前字母:", letter)

# 遍历列表
fruits = ['banana', 'apple', 'mango']
for fruit in fruits:
    print("当前水果:", fruit)
```

#### 通过序列索引迭代

```python
fruits = ['banana', 'apple', 'mango']
for index in range(len(fruits)):
    print('当前水果:', fruits[index])
```

#### 使用enumerate()获取索引和值

```python
# 更Pythonic的方式
for index, fruit in enumerate(fruits):
    print(f"索引 {index}: {fruit}")
```

### 2. while循环

`while`循环在条件为True时重复执行代码块，当条件变为False时停止。

#### 基本语法

```python
while condition:
    statements(s)
```

#### 基本用法

```python
count = 0
while count < 9:
    print("当前计数:", count)
    count = count + 1
print("结束!")
```

#### 无限循环

```python
# 无限循环示例（使用Ctrl+C中断）
var = 1
while var == 1:  # 该条件永远为true
    num = input("输入一个数字:")
    print("你输入了:", num)
```

## 二、循环控制语句

Python提供了三个循环控制语句：`break`、`continue`和`pass`，用于控制循环的执行流程。

### 1. break语句

`break`语句用于立即终止整个循环，跳出循环体。

#### 语法

```python
break
```

#### 用法示例

```python
# 在for循环中使用break
for letter in 'Python':
    if letter == 'h':
        break
    print("当前字母:", letter)

# 在while循环中使用break
var = 10
while var > 0:
    print("当前变量值:", var)
    var = var - 1
    if var == 5:
        break
```

### 2. continue语句

`continue`语句用于跳过当前循环的剩余语句，直接进入下一次循环。

#### 语法

```python
continue
```

#### 用法示例

```python
# 在for循环中使用continue
for letter in 'Python':
    if letter == 'h':
        continue
    print("当前字母:", letter)

# 在while循环中使用continue
var = 10
while var > 0:
    var = var - 1
    if var == 5:
        continue
    print("当前变量值:", var)
```

### 3. pass语句

`pass`是空语句，不做任何事情，一般用作占位符，保持程序结构的完整性。

#### 语法

```python
pass
```

#### 用法示例

```python
# 作为占位符
for letter in 'Python':
    if letter == 'h':
        pass  # TODO: 后续实现
    print("当前字母:", letter)

# 在空函数中使用
def empty_function():
    pass
```

## 三、循环的else语句

Python中的循环可以带有一个`else`子句，它在循环正常结束（即不是通过`break`跳出）时执行。

### 1. for...else语句

```python
# 寻找质数的例子
for num in range(10, 20):
    for i in range(2, num):
        if num % i == 0:
            print(f"{num} 等于 {i} * {num//i}")
            break
    else:
        print(f"{num} 是一个质数")
```

### 2. while...else语句

```python
count = 0
while count < 5:
    print(count, " 小于 5")
    count = count + 1
else:
    print(count, " 不小于 5")
```

## 四、循环的嵌套

Python允许在一个循环体内嵌套另一个循环，这称为循环的嵌套。

### 1. for循环嵌套

```python
# 打印乘法表
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{j} * {i} = {i * j}", end="\t")
    print()

# 打印三角形
for i in range(1, 6):
    for j in range(i):
        print("*", end=" ")
    print()
```

### 2. while循环嵌套

```python
# 简单的猜数字游戏
import random

target = random.randint(1, 100)
guess = 0
attempts = 0

while guess != target and attempts < 10:
    while True:
        try:
            guess = int(input("猜一个数字(1-100): "))
            break
        except ValueError:
            print("请输入有效的数字!")
    
    attempts += 1
    
    if guess < target:
        print("太小了!")
    elif guess > target:
        print("太大了!")
    else:
        print(f"恭喜你，用了{attempts}次猜对了!")
        break
else:
    print(f"游戏结束，正确答案是{target}")
```

### 3. 混合嵌套

```python
# for和while混合嵌套
names = ['Alice', 'Bob', 'Charlie']
for name in names:
    print(f"处理用户: {name}")
    attempts = 0
    while attempts < 3:
        print(f"尝试 {attempts + 1}")
        attempts += 1
    print()
```

## 五、列表推导式和生成器表达式

### 1. 列表推导式

> [!success]
> 列表推导式是Python中创建列表的简洁方式，它可以将for循环和if语句结合在一行代码中。

#### 基本语法

```python
[expression for item in iterable if condition]
```

#### 基本用法

```python
# 创建平方数列表
squares = [x**2 for x in range(10)]
print(squares)  # [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

# 带条件的列表推导式
even_squares = [x**2 for x in range(10) if x % 2 == 0]
print(even_squares)  # [0, 4, 16, 36, 64]

# 多重循环的列表推导式
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
flattened = [num for row in matrix for num in row]
print(flattened)  # [1, 2, 3, 4, 5, 6, 7, 8, 9]
```

> [!success]
> #### 性能特点
>
>   1. 列表推导式是**立即计算**的（Eager Loading），所有元素在创建时立即计算并存储在内存中
>   2. 适合需要多次迭代或需要随机访问的场景
>   3. 对于大数据集可能会消耗大量内存

### 2. 生成器表达式

生成器表达式与列表推导式类似，但它使用圆括号而不是方括号，返回的是一个生成器对象。

#### 基本语法

```python
(expression for item in iterable if condition)
```

#### 基本用法

```python
# 创建生成器表达式
squares_gen = (x**2 for x in range(10))
print(squares_gen)  # <generator object <genexpr> at 0x...>

# 使用生成器
for square in squares_gen:
    print(square)

# 带条件的生成器表达式
even_squares_gen = (x**2 for x in range(10) if x % 2 == 0)
print(list(even_squares_gen))  # [0, 4, 16, 36, 64]
```

> [!success]
> #### 性能特点
>
>   1. 生成器表达式是**惰性计算**的（Lazy Loading），元素只在需要时才生成
>   2. 创建时间几乎是常数时间，不受元素数量影响
>   3. 内存效率高，适合处理大数据集或无限序列
>   4. 只能迭代一次，不能重复使用或随机访问

### 3. 列表推导式与生成器表达式的选择

| 特性 | 列表推导式 | 生成器表达式 |
| --- | --- | --- |
| 语法 | 使用方括号 `[]` | 使用圆括号 `()` |
| 计算方式 | 立即计算（Eager） | 惰性计算（Lazy） |
| 内存使用 | 存储所有元素 | 按需生成元素 |
| 可重复使用 | 可以多次迭代 | 只能迭代一次 |
| 随机访问 | 支持索引访问 | 不支持索引访问 |
| 适用场景 | 需要多次迭代、小数据集 | 大数据集、无限序列 |

#### 选择建议

- **使用列表推导式**：当需要多次迭代、数据集较小、需要随机访问时
- **使用生成器表达式**：当处理大数据集、数据是无限的、只需要迭代一次时

## 六、循环的最佳实践

### 1. 使用函数修饰被迭代对象来优化循环

使用内置函数和itertools模块中的工具函数来修饰被迭代对象，可以使循环代码更加简洁高效。

#### 使用enumerate()获取索引

```python
# 不推荐的方式
index = 0
for name in names:
    print(index, name)
    index += 1

# 推荐的方式
for index, name in enumerate(names):
    print(index, name)
```

#### 使用itertools.product()扁平化嵌套循环

```python
from itertools import product

# 不推荐的嵌套循环
for num1 in num_list1:
    for num2 in num_list2:
        for num3 in num_list3:
            if num1 + num2 + num3 == 12:
                return num1, num2, num3

# 推荐的方式
for num1, num2, num3 in product(num_list1, num_list2, num_list3):
    if num1 + num2 + num3 == 12:
        return num1, num2, num3
```

#### 使用itertools.islice()实现隔行处理

```python
from itertools import islice

# 不推荐的方式
for i, line in enumerate(fp):
    if i % 2 == 0:
        yield line.strip()

# 推荐的方式
for line in islice(fp, 0, None, 2):
    yield line.strip()
```

#### 使用itertools.takewhile()替代break

```python
from itertools import takewhile

# 不推荐的方式
for user in users:
    if not is_qualified(user):
        break
    # 处理用户

# 推荐的方式
for user in takewhile(is_qualified, users):
    # 处理用户
```

### 2. 按职责拆解循环体内复杂代码块

循环体内容易堆积各种逻辑，应该使用生成器函数将不同职责的代码块解耦出来。

#### 问题示例

```python
def award_active_users_in_last_30days():
    days = 30
    for days_delta in range(days):
        dt = datetime.date.today() - datetime.timedelta(days=days_delta)
        if dt.weekday() not in (5, 6):  # 5: Saturday, 6: Sunday
            continue
        time_start = datetime.datetime(dt.year, dt.month, dt.day, 20, 0)
        time_end = datetime.datetime(dt.year, dt.month, dt.day, 23, 0)
        ts_start = time.mktime(time_start.timetuple())
        ts_end = time.mktime(time_end.timetuple())
        for record in LoginRecord.filter_by_range(ts_start, ts_end):
            send_awarding_points(record.user_id, 1000)
```

#### 改进方案

```python
def gen_weekend_ts_ranges(days_ago, hour_start, hour_end):
    """生成过去一段时间内周六日特定时间段范围，并以UNIX时间戳返回"""
    for days_delta in range(days_ago):
        dt = datetime.date.today() - datetime.timedelta(days=days_delta)
        if dt.weekday() not in (5, 6):  # 5: Saturday, 6: Sunday
            continue
        time_start = datetime.datetime(dt.year, dt.month, dt.day, hour_start, 0)
        time_end = datetime.datetime(dt.year, dt.month, dt.day, hour_end, 0)
        ts_start = time.mktime(time_start.timetuple())
        ts_end = time.mktime(time_end.timetuple())
        yield ts_start, ts_end

def award_active_users_in_last_30days_v2():
    """发送奖励积分"""
    for ts_start, ts_end in gen_weekend_ts_ranges(30, hour_start=20, hour_end=23):
        for record in LoginRecord.filter_by_range(ts_start, ts_end):
            send_awarding_points(record.user_id, 1000)

def notify_nonsleep_users_in_last_30days():
    """发送通知"""
    for ts_start, ts_end in gen_weekend_ts_ranges(30, hour_start=3, hour_end=6):
        for record in LoginRecord.filter_by_range(ts_start, ts_end):
            notify_user(record.user_id, 'You should sleep more')
```

### 3. 其他最佳实践

#### 避免在循环中修改被迭代的对象

```python
# 不推荐：在循环中修改列表
numbers = [1, 2, 3, 4, 5]
for num in numbers:
    if num % 2 == 0:
        numbers.remove(num)  # 这会导致问题

# 推荐：创建新列表
numbers = [1, 2, 3, 4, 5]
numbers = [num for num in numbers if num % 2 != 0]
```

#### 使用zip()同时迭代多个序列

```python
names = ['Alice', 'Bob', 'Charlie']
ages = [25, 30, 35]

# 不推荐的方式
for i in range(len(names)):
    print(f"{names[i]} is {ages[i]} years old")

# 推荐的方式
for name, age in zip(names, ages):
    print(f"{name} is {age} years old")
```

#### 使用reversed()反向迭代

```python
# 不推荐的方式
for i in range(len(seq)-1, -1, -1):
    print(seq[i])

# 推荐的方式
for item in reversed(seq):
    print(item)
```

#### 使用sorted()排序迭代

```python
# 不推荐的方式
for item in sorted(seq, key=lambda x: x[1]):
    print(item)

# 推荐的方式
for item in sorted(seq, key=lambda x: x[1]):
    print(item)
```

### 3. 算法实现

```python
# 查找算法
def linear_search(arr, target):
    for index, value in enumerate(arr):
        if value == target:
            return index
    return -1

# 排序算法（冒泡排序）
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
    return arr
```
