# 2.1数字类型

> 计算机是用来处理数字的机器但不止能够处理数字，还能处理其他数据

| 数据类型 | 说明 |
| --- | --- |
| 整数 | 可以精确处理非常大的整数 |
| 浮点数 | 浮点数运算都有误差。8-2.1≠5.9 |
| 复数 | 由实部和虚部两部分组成的数 |
| 字符串 | 以‘’和“”括起来的任意字符 |
| 布尔值 | 只有 True 和 False 两种类型，代表 1 和 0 |
| 空值 | 特殊值，用 None 表示 |

# 整数类型

任何仅包含数字的序列，int 是整数类型，整数类型可以存储很大的数，甚至超过 64 位，在处理超大整数的计算中不会出错

> [!success]
> 你可以单独使用数字 0，但不能把数字 0 放到数字的前面

```python
print(078)
#SyntaxError: leading zeros in decimal integer literals are not permitted; 
#use an 0o prefix for octal integers
```

在 Python 中默认使用十进制，当然你也可以使用别的进制

> [!tip]
>   1. 0b 或 0B 代表二进制
>   2. 0o 或 0O 代表八进制
>   3. 0x 或 0X 代表十六进制

```python
print("0b10")
#2
print("0o10")
#8
print("0x10")
#16
```

## 运算符

| 运算符 | 说明 | 示例 | 运算结果 |
| --- | --- | --- | --- |
| + | 加法 | 1+2 | 3 |
| - | 减法 | 1-2 | -1 |
| * | 乘法 | 1*2 | 2 |
| / | 浮点数除法 | 1/2 | 0.5 |
| // | 整除 | 1/2 | 0 |
| % | 取模 | 1%2 | 1 |
| ** | 幂 | 2**3 | 8 |

> [!note]
> 幂的优先级高于乘除，乘除的优先级高于加减

# 浮点数

浮点数表示实数，用 float 表示

> [!note]
> 表示方法：
>
>   1. 用数字表示 1.23 3.14
>   2. 用科学计数法表示：1.23e9 （科学计数法 e 后面不能为空，且必须是整数）

浮点数的运算结果也是浮点数
