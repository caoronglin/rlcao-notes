# 基因记录与序列文件解读：Gene / GenBank / PubMed 的可复用核对流程

> 整理范围：库内 [[notes/生信实验/01/生物信息学实验报告_1_曹荣麟-2024014209_1|生信实验一]] 实操沉淀。
> 适用场景：拿到一个基因（或一条 RefSeq 记录）后，把"它到底在哪、是什么、有多长、凭什么这么注解"一次性核死，并顺带找出配套文献。
> 配套流程见 [[vault/方法/生信分析/04_序列检索与双序列比对|序列检索与双序列比对]]（检索同源序列与双序列比对）。

---

## 目标

1. 建立同一个基因在 NCBI / UniProt / Ensembl 之间的一一对应关系，不靠名称猜。
2. 从 GenBank 记录本身（而不是从别人转述）独立推出全部序列特征，并与另一条官方路径对账。
3. 用可复现的检索式找到配套文献，并让文献真正补上证据链，而不只是列一堆标题。

## 输入数据

| 项 | 本次取值 | 说明 |
|---|---|---|
| 基因 | 玉米 `ZmFIE1` | NCBI Gene ID **542075**，符号 `LOC542075` |
| 主记录 | `NM_001111711.1` / `NP_001105181.1` | RefSeq mRNA 1787 nt / 蛋白 461 aa |
| 对照记录 | `XM_023302232.2` / `XP_023158000.1` | 模型预测，1738 nt / 430 aa |
| 蛋白对照 | UniProt `Q8VZY7` | `FIE1_MAIZE`，Reviewed，461 aa |
| 目标问题 | 11 项序列文件解读 + 3 篇文献 | 见报告任务三、任务四 |

## 步骤

### 1. 先把"身份"钉死：同一基因在不同库里的几套编号

| 标识体系 | 取值 | 怎么用 |
|---|---|---|
| 基因符号 | `LOC542075` | **`LOC` 号段 = 基因名尚未获批准**（`fie1` 只是别名），≠ 研究程度低 |
| NCBI Gene ID | 542075 | 跨库通用，主键 |
| RefSeq mRNA / 蛋白 | `NM_001111711.1` / `NP_001105181.1` | 人工校核（`NM_`/`NP_`）；**必须带版本号** |
| UniProt | `Q8VZY7`（Reviewed） | 蛋白注释权威源，看 `PE` 证据等级 |
| Ensembl Plants | `Zm00001eb173090`(+`_T001`/`_P001`) | 物种自有的基因模型编号 |
| InterPro / Pfam | `IPR051243` / `PF00400` | 蛋白家族的判据 |

```bash
E="email=your@email.com"

# 基因摘要：别名、染色体、组装
curl -s -G "https://eutils.ncbi.nlm.nih.gov/entrez/eutils/esummary.fcgi" \
  --data-urlencode "db=gene" --data-urlencode "id=542075" \
  --data-urlencode "retmode=json" --data-urlencode "$E"
# → otheraliases / genomicinfo{chraccver,chrstart,chrstop,exoncount}

# 基因-转录本-外显子对照表（坐标用 1-based，最可靠）
curl -s -G "https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi" \
  --data-urlencode "db=gene" --data-urlencode "id=542075" \
  --data-urlencode "rettype=gene_table" --data-urlencode "retmode=text" --data-urlencode "$E"
# → "Reference ... NC_050099.1 (minus strand) from: 37788773 to: 37782884"
# → 每个转录本的外显子表（基因组区间 / 转录本区间 / 编码区间 / 内含子长度）

# GenBank 全记录（特征表在这里）
curl -s -G "https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi" \
  --data-urlencode "db=nuccore" --data-urlencode "id=NM_001111711" \
  --data-urlencode "rettype=gb" --data-urlencode "retmode=text" --data-urlencode "$E"

# Datasets API（另一条独立路径，用来对账坐标）
curl -s "https://api.ncbi.nlm.nih.gov/datasets/v2alpha/gene/id/542075" -H "Accept: application/json"
# → reports[0].gene.annotations[0].genomic_locations[0].genomic_range{begin,end,orientation}
```

### 2. 11 项解读：每一项都要能指到"证据在哪一行"

| 问题 | 取数方式 |
|---|---|
| 登录号 / 总长 / 版本 | `LOCUS`、`ACCESSION`、`VERSION` 行 |
| 染色体位置 | `gene_table` 首行 + `esummary.genomicinfo` |
| 更新次数 | `VERSION` 的小数位（`.1` = 发布后未再改）；再看 `COMMENT` 是否 `PROVISIONAL REFSEQ` |
| 起止密码子 | `CDS` 特征行 + **直接读序列** `seq[start-1:start+2]` |
| 氨基酸数 | 蛋白记录 `LOCUS`；用 `(CDS长-3)/3` 对账 |
| CDS 区间 | `CDS` 特征行 |
| 外显子/内含子 | 数 `exon` 特征行；内含子数 = 外显子数 − 1；`gene_table` 的 "total annotated spliced exon length" 可对账 |
| 其他变体 | `elink dbfrom=gene db=nuccore` 看全部转录本；`esearch refseqgene[filter] AND <基因>[All Fields]` 查有无 NG_ |
| 多聚腺苷酸化信号 | 序列扫描 `AATAAA`/`ATTAAA`；**同时看记录里有没有 `polyA_signal` 特征行** |

### 3. PubMed：从"命中列表"到"证据链"

```bash
# 分层检索：基础 + 精筛
curl -s -G "https://eutils.ncbi.nlm.nih.gov/entrez/eutils/esearch.fcgi" \
  --data-urlencode "db=pubmed" \
  --data-urlencode 'term=(maize[Title/Abstract] OR "Zea mays"[Title/Abstract]) AND (FIE1[Title/Abstract] OR "Polycomb"[Title/Abstract]) AND (imprint*[Title/Abstract] OR endosperm[Title/Abstract])' \
  --data-urlencode "retmax=20" --data-urlencode "sort=date" --data-urlencode "retmode=json" --data-urlencode "$E"

# MeSH + 出版类型 + 年份区间（换一个检索式 = 换一个证据集）
curl -s -G "https://eutils.ncbi.nlm.nih.gov/entrez/eutils/esearch.fcgi" \
  --data-urlencode "db=pubmed" \
  --data-urlencode 'term=("Zea mays"[MeSH Terms] OR maize[Title/Abstract]) AND (FIE[Title/Abstract] OR FIS-PRC2[Title/Abstract] OR "Polycomb group"[Title/Abstract]) AND 2020:2026[Date - Publication]' \
  --data-urlencode "retmax=20" --data-urlencode "retmode=json" --data-urlencode "$E"

# 逐篇取摘要（判断它补的是哪一层证据）
curl -s -G "https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi" \
  --data-urlencode "db=pubmed" --data-urlencode "id=17437065,31127375,40269501" \
  --data-urlencode "rettype=abstract" --data-urlencode "retmode=text" --data-urlencode "$E"
```

| 文献 | 表达 | 甲基化 | 互作定位 | 表型 | 应用 |
|---|---|---|---|---|---|
| Hermon 2007（PMID 17437065） | ✓ | ✓ | | | |
| Ni 2019（PMID 31127375） | ✓ | | ✓ | | |
| Wang 2025（PMID 40269501） | | ✓ | ✓ | ✓ | |
| Shi 2025（PMID 40754619） | | | | ✓ | ✓ |

## 关键参数

| 参数 | 本次取值 | 依据 |
|---|---|---|
| 坐标基准 | **1-based 闭区间**，以 `gene_table` / Gene Viewer 为准 | `esummary` 给 0-based，直接抄会整体差 1 bp |
| 序列来源 | RefSeq `NM_`/`NP_`（人工校核） | `XM_`/`XP_` 是模型预测，会随注释更新而变 |
| 版本号 | 必记（`NM_001111711.1`） | 旧登录号会被 NCBI 回收复用 |
| 文献检索 | 关键词 + `[MeSH Terms]` + `[Date - Publication]` + `[pt]` | 换检索式即换证据集 |

**玉米 `ZmFIE1` 的实测结果**

| 项 | 值 |
|---|---|
| 基因位置 | 4 号染色体减链，`NC_050099.1` 上 37,782,884–37,788,773（1-based，跨度 5,890 bp），14 个外显子 |
| 参考组装 / 注释 | `Zm-B73-REFERENCE-NAM-5.0`（`GCF_902167145.1`），注释 `GCF_902167145.1-RS_2025_02` |
| mRNA | `NM_001111711.1`，1787 nt；14 个外显子剪接 **1766 nt** + 3′ 端 **21 nt poly(A) 尾**（1767–1787） |
| CDS | 169–1554（1386 nt）→ 461 aa；起始 `ATG` 169–171，终止 `TGA` 1552–1554 |
| 多聚腺苷酸化信号 | `AATAAA` 1288–1293（全序列唯一，无 `ATTAAA`），距 poly(A) 尾 474 nt；记录中**无** `polyA_signal` 特征行 |
| 其他变体 | `XM_023302232.2`（1738 nt，CDS 188–1480，13 个编码外显子）→ `XP_023158000.1` isoform X1（430 aa）；无 NG_ 记录 |
| UniProt | `Q8VZY7`（Reviewed，461 aa），6 个 WD40 重复：143–186、189–229、235–275、301–338、351–391、398–437 |

## 结果

- 11 项解读全部有据可查，且坐标经三套 API（`esummary` / Datasets / `gene_table`）换算后一致。
- 发现两条容易忽略的细节：**记录长度 ≠ 外显子之和**（差 21 nt 是 poly(A) 尾）；**`esummary` 坐标是 0-based**，与 Gene Viewer 差 1 bp。
- 3 篇核心文献 + 1 篇应用文献构成完整证据链：表达（2007）→ 互作定位（2019）→ 功能表型（2025）→ 应用（2025）。
- 结构信息靠 UniProt 的 WD40 重复注释与 InterPro 补齐；**PDBe 中没有玉米 FIE1 的实验结构**，只能靠同源外推。

## 踩坑记录

1. **坐标差 1 bp**：`esummary.genomicinfo` 给 0-based（37782883–37788772），Gene Viewer / `gene_table` / Datasets 给 1-based（37782884–37788773）。报告里必须写清基准。
2. **登录号会被回收复用**：`NP_005623` 现在是 calpain-15、`NM_003001` 现在是 SDHC。
3. **`LOC` 符号不是"没研究"**：`LOC542075` 只是基因名未获批准，别的库照样有 RefSeq、UniProt、Ensembl 和大量文献。
4. **`version` 字段会骗人**：`esummary` 的 `version` 常为空，取准确版本号要用 `efetch`（FASTA/GenBank 头里带版本）或 `accessionversion`。
5. **信号 ≠ 切割位点**：`AATAAA` 只是基序线索，记录里没有 `polyA_signal` 特征行时不能断言切割点。
6. **多外显子记录的长度要拆开算**：1787 = 1766（外显子）+ 21（poly(A) 尾），直接对账"记录长 = 外显子之和"必然对不上。
7. **文献要按证据层选**：只按关键词排序会拿到一堆同层面的文献；按「表达 / 甲基化 / 互作 / 表型 / 应用」分层，才能看清哪一层还没有文献。
8. **pandas 3.x 的 `pivot_table` 会返回列表值单元格**：`aggfunc='sum'/'max'` 在长表上会得到 `[1,1,0,0,0]` 这种列表列，ECharts 热力图会报 `could not convert string to float`。做矩阵要改用 `pd.crosstab` 或先把值写成标量。
