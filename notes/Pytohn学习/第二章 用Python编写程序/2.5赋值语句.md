# 2.5赋值语句

语句通常是一行一条语句；一行有多条语句用分号；隔开，如果太长可以用续航符 \ 跨行

# 赋值语句

变量=值的形式

```python
a=3
b=4
c=5
```

Python 支持序赋值

```python
x,y=3,4
print(x,y)
```

Python 支持多变量赋值

```python
a=b=c=5
b+=1
print(a,b,c)
```

> [!error]
> 注意：修个一个变量的值不影响其他变量

# if 语句

```plain
if 逻辑表达式：
  语句块1
else：
  语句块2
```

# for 语句

```plain
for variable in 列表：
  语句块
```

for 后面的变量先被赋值于列表的第一个值并执行下面的代码块

# 列表推导式

```plain
lst=[expression for item in 列表]
```

```python
newlist=[2*number for number in [1,2,3,4,5,6]]
```

列表推导也有 if 条件

```python
lst=[expression for item in 列表if condition]
lst=[num for num in list(range(1,8) if num %2 ==1]#生成奇数
```
