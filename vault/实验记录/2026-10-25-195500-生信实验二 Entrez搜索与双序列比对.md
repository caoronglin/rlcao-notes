# 生信实验二 Entrez搜索与双序列比对

## 实验目的与假设

- 熟练掌握 Entrez 搜索序列的方法；理解直系同源与并系同源；了解 EBI 数据与工具；用 NEEDLE 与 WATER 做双序列比对。
- 假设：选定一个分子后，可以用「物种 + 字段 + 过滤器」的组合把检索结果从"提到过它"收敛到"就是它"；并系同源拷贝之间即使共享结构域，序列一致性也应明显低于直系同源。

本实验不涉及湿实验样品，比较对象为公共数据库序列。

## 结果与质控

- 1.1 命中 62 条，其中真正编码 EGF 配体的 5 条；把 "human" 从关键词挪到 `[Organism]` 过滤后反而涨到 1475 条。
- 1.2 线粒体只编码 13 个蛋白，全部是 OXPHOS 链膜蛋白；与 `NC_012920.1` 的 13 CDS 互相印证。
- 1.3 直系同源 5 条（人/鼠/大鼠/犬/鸡 EGF，蛋白 1132–1245 aa）；并系同源 5 条（EGF/TGFA/AREG/EREG/HBEGF，蛋白 160–252 aa）。
- 任务三 8 组比对的一致性/相似性/空位率见方法笔记表格；DNAfull 与 DNAmat 结果完全一致（序列无简并碱基）。
- 质控：8 组结果由 EBI 在线与本地 EMBOSS 6.6.0 独立复算，两份输出的 Length / Identity / Similarity / Gaps / Score 逐项相同；空位统计与 EMBOSS 汇总行自洽（游程数 148/12/12，碱基数 2165/38/1081）。

## 分析与结论

> 区分观察到的结果、推测和仍需验证的解释。

- **观察**：核酸全局一致性 54.2%，局部 70.1%；并系同源蛋白全局 3.9%、空位 88.3%，局部 33.3%，且 99 列正好落在 UniProt 标注的成熟 EGF 样结构域（人 EGF 971–1023、TGFA 40–89）上。
- **观察**：直系同源对的相似性（77.7%）显著高于一致性（65.4%），并系同源对即使找到共同结构域也只有 33.3%。
- **推测**：3′UTR 的大段缺失更可能来自物种间 UTR 长度差异与注释版本差异，而非编码区的快速演化——但尚未对齐 EST/全长转录本证据，属待验证。
- **仍需验证**：NCBI BLAST「Global Align」与 EMBOSS 的数值对照未做成（长序列用 URL API 提交会超长，需改用网页表单）。
