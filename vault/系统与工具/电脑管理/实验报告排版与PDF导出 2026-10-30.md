# 实验报告排版与 PDF 导出（HTML + Chrome Headless）

## 用途

把 Markdown 实验报告排成固定页数（本次 5 页 A4）、带页眉页脚、三线表的 PDF。Markdown 负责内容，HTML 负责版式，两者同目录同名。

## 做法

1. 手写 HTML，用 `.page` 容器固定 `210mm × 297mm`，`page-break-after: always`，页脚用绝对定位写页码，保证页数完全可控。
2. `@page { size: A4; margin: 0 }`，用 `.page` 的内边距控制版心，避免浏览器默认页边距干扰。
3. 三线表：`thead th` 上 1.3pt、下 0.6pt，`tbody tr:last-child td` 下 1.3pt，其余不设边框。
4. 截图统一用 `object-fit: cover; object-position: top left` 压成等高缩略图，避免长截图撑页。
5. 导出：

```bash
google-chrome --headless=new --no-sandbox --disable-gpu \
  --no-pdf-header-footer \
  --print-to-pdf="报告.pdf" --virtual-time-budget=5000 \
  "file://$PWD/报告.html"
```

6. 校验：`pdfinfo` 看页数，`pdftoppm -png -r 90` 逐页看图，`pdftotext -f N -l N` 看每页末行是否被截断。

## 关键坑

- **内容溢出不会自动分页**：`.page` 设了 `overflow: hidden`，多出来的内容会被静默裁掉。必须逐页渲染检查，并核对每页最后一句是否完整。
- **页脚重叠**：内容区底部要留出 12mm 以上，否则正文会压到页脚线。页码用绝对定位，不占流。
- **Chrome 的 `--print-to-pdf` 不带页码**：想加页码只能自己在每页容器里写。
- **中文字体**：正文 `Noto Serif CJK SC`，标题与表头 `Noto Sans CJK SC`，本机已装。
- **图片路径**用相对路径时，`file://` 必须指向 HTML 所在目录，否则图不显示。
