# 生信实验课程知识结构

> 大纲笔记：Ctrl+Alt+M 用 XL Toolbox 打开导图，Markdown 是唯一内容源。导图可折叠缩放，点节点跳回原文。

## 核心问题

- 怎么让一次检索既准又可复现
  - 已有证据：关键词命中 62 条里只有 5 条是真 EGF；加 `refseq[filter]` 把 88 万降到 39 条
  - 尚待核实：3′UTR 大段缺失是 UTR 长度差异还是注释版本差异
- 怎么判断两个序列"有多像"
  - 已有证据：直系同源 65.4% / 相似性 77.7%；并系同源局部 33.3%
  - 尚待核实：BLAST Global Align 与 EMBOSS 的数值对照
- 怎么把一次实验变成能复用的资产
  - 已有证据：`vault/方法/生信分析/04_序列检索与双序列比对` 已沉淀 7 条踩坑
  - 已有证据：`vault/方法/生信分析/06_BLAST数据库搜索与参数选择` 沉淀 8 条踩坑，三次实验共 15 条
  - 尚待核实：三次实验的方法能否合并成同一套 SOP

## 思路与结构

- 选分子
  - 先看家族结构，再决定做哪个基因
    - 玉米 FIE 家族只有 FIE1/FIE2；5 条并系同源用其它禾本科的 FIE2 补齐
    - 水稻 466 aa、小麦 461 aa 的“FIE1-like”按序列归入 FIE2 支
  - 认准标识层级
    - 基因符号 ≠ Gene ID ≠ 序列登录号
      - 实验一：原稿把 `Zm00001eb318740` 当成 FIE1，实为另一基因
  - 记录版本号与标题
    - 登录号会被回收复用
      - `NP_005623` → calpain-15
      - `NM_003001` → SDHC
- 解读序列记录（实验一）
  - 坐标基准要写清
    - `esummary` 给 0-based，Gene Viewer / `gene_table` 给 1-based
      - 差 1 bp：37,782,884–37,788,773（1-based）
  - 记录长度 ≠ 外显子之和
    - 1787 = 1766（14 外显子）+ 21 nt poly(A) 尾
  - 信号 ≠ 切割位点
    - AATAAA 1288–1293，但记录里没有 polyA_signal 特征行
  - 文献要按证据层选
    - 表达 / 甲基化 / 互作 / 表型 / 应用
      - 单篇覆盖不了完整链条
- 检索
  - 字段限定符与过滤器
    - `[Organism]` `[Gene Name]` `[Title]` `[Accession]` `[SLEN]`
    - `refseq[filter]` `gb[filter]` `moltype` `biomol_mrna[prop]`
  - 布尔与精确短语
    - `"human epidermal growth factor"` ≠ 拆词
  - 用 Query Translation 自查
  - E-utilities 批量取数
    - esearch → esummary → efetch
    - elink 跨库：nuccore → protein → gene → pubmed
- EBI 资源
  - ENA：INSDC 核酸，EMBL 格式，与 GenBank 共用登录号
  - UniProtKB：行前缀式，Swiss-Prot 人工校核 / TrEMBL 自动注释
  - Ensembl：统一 ID 体系 + 基因组坐标
  - ArrayExpress → BioStudies：表达组学原始数据
  - PDBe：把 PDB 编号标到残基区间
  - 记录格式差异
    - ENA `AY061964` 与 NCBI `NM_001111711.1` 同为 1,787 bp、CDS 169–1554
      - 格式与交叉引用不同，序列相同
- 双序列比对
  - Needle 全局 vs Water 局部
    - 全局：两端整体同源才用
    - 局部：定位保守区段
  - 矩阵
    - `EDNAFULL` / `EDNAMAT` / `EBLOSUM62`
    - 简并碱基才需要 DNAmat
  - 三个指标怎么读
    - Identity / Similarity
    - Gaps 要按游程和区域拆
      - 628 个空位列 = 88 游程，最长 46 bp
      - CDS 空位率 15.7%，5′UTR 61.5%，3′UTR 50.6%
  - 局部比对找结构域
    - Water 保留 query 64–431，切掉 N 端 1–58 与 C 端 435–461 的延伸
- BLAST 数据库搜索（实验三）
  - 本地 BLAST+ 优于网页版
    - Debian 包解压即用，`LD_LIBRARY_PATH` 指向前置库
    - `-max_target_seqs 1000000`，否则命中数被默认值截断
  - 算法、参数、阈值三者不同
    - task 改变算法假设：megablast 长词连续 / dc-megablast 不连续词 / blastn 短词
    - 实测：blastn 335 / dc-megablast 313 / megablast 27
    - `blastn -word_size 28` 与 megablast 命中集合完全相同 → 差别在词长不在打分
  - 前 10 条几乎不随算法变
    - 头部由"有多像"决定，长尾才由"算法多敏感"决定
    - 只报前 10 条等于没比较，要报召回量 + 物种数 + 耗时
  - E 值是阈值不是灵敏度刻度
    - 1e-50 只剩 297 条；放宽到 1000 涨到 2,083 条，但 E<0.005 仍 313
  - 真正改变结果的是矩阵与 E 值
    - BLOSUM45 1,287、BLOSUM90 1,180，最高分 955→1,004
    - word 2 只多 8 条，word 6 掉到 809 条
  - 短 query 从矩阵买灵敏度，但组成校正会改排名
    - blastp-short 11,393 条，top1 是 Setaria FIE2 85.2%，玉米自身 100% 排第 2
    - `-comp_based_stats 0` 后自身回到第 1（88.0 bits，E=5.59e-21）
  - PSI-BLAST 不收敛是信号不是失败
    - 12 轮仍新增 2 条；第 2 轮起是蓝藻 WD40、RACK1、IFT172 等（11–19% identity）
    - PSSM 从 FIE1 漂移到 WD40 折叠本身
  - DELTA-BLAST 需要 CDD 库
    - `-db` 是搜索库，`-rpsdb` 才是 CDD；缺库时报 `Database memory map file error`
    - 3,162 条 / 570 物种；前 10 混入蓝藻（18.2%）与 Podospora（17.3%）WD40
  - 一致性低 ≠ 假阳性，但共享 WD40 的低分命中要逐条核对
    - 蓝藻 `Q8YRI1` 18.2% 排第 6，高于水稻 FIE1 60.9% 的第 8 → profile 权重问题
  - 核酸只认近亲，蛋白能认家族
    - TBLASTX 家族小库 280 条 vs BLASTN 22 条
    - BLASTX 前 10 条 9/10 同 blastp，代价是多一次翻译
