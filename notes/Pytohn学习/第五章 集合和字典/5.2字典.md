# 5.2字典

# Python字典总结

## 一、字典的定义和特点

### 1. 字典的定义

字典（Dictionary）是Python中的一种可变容器模型，且可存储任意类型对象。字典的每个键值（key:value）对用冒号（:）分割，每个键值对之间用逗号（,）分割，整个字典包括在花括号（{}）中。

```python
# 基本语法
d = {key1: value1, key2: value2}

# 示例
student = {'name': 'Alice', 'age': 20, 'gender': 'Female'}
```

### 2. 字典的特点

- **键值对结构**：字典由键（key）和值（value）组成，通过键来访问值
- **无序性**：在Python 3.6之前字典是无序的，3.7+版本中字典保持插入顺序
- **可变性**：字典是可变的，可以添加、修改或删除键值对
- **键的唯一性**：字典中的键必须是唯一的，如果重复则后面的值会覆盖前面的值
- **键的不可变性**：键必须是不可变类型，如字符串、数字或元组，不能是列表等可变类型
- **值的任意性**：值可以是任意数据类型，包括标准对象和用户定义对象

### 3. 字典的创建

```python
# 使用花括号创建字典
dict1 = {'name': 'Alice', 'age': 20, 'gender': 'Female'}

# 使用dict()函数创建字典
dict2 = dict(name='Bob', age=25, gender='Male')

# 从键值对列表创建字典
dict3 = dict([('name', 'Charlie'), ('age', 30), ('gender', 'Male')])

# 创建空字典
empty_dict = {}
empty_dict2 = dict()
```

## 二、字典的基本操作

### 1. 访问字典中的值

#### 使用方括号访问

```python
student = {'name': 'Alice', 'age': 20, 'gender': 'Female'}
print(student['name'])  # 输出: Alice
print(student['age'])   # 输出: 20

# 如果键不存在，会抛出KeyError
# print(student['score'])  # KeyError: 'score'
```

#### 使用get()方法访问

```python
student = {'name': 'Alice', 'age': 20, 'gender': 'Female'}

# 键存在时返回对应的值
print(student.get('name'))  # 输出: Alice

# 键不存在时返回None
print(student.get('score'))  # 输出: None

# 键不存在时返回指定的默认值
print(student.get('score', 0))  # 输出: 0
```

### 2. 修改字典

#### 添加或修改键值对

```python
student = {'name': 'Alice', 'age': 20, 'gender': 'Female'}

# 修改已有的键值对
student['age'] = 21
print(student)  # {'name': 'Alice', 'age': 21, 'gender': 'Female'}

# 添加新的键值对
student['score'] = 95
print(student)  # {'name': 'Alice', 'age': 21, 'gender': 'Female', 'score': 95}
```

#### 使用update()方法更新字典

```python
student = {'name': 'Alice', 'age': 20}

# 用另一个字典更新
student.update({'age': 21, 'gender': 'Female', 'score': 95})
print(student)  # {'name': 'Alice', 'age': 21, 'gender': 'Female', 'score': 95}

# 用关键字参数更新
student.update(name='Bob', age=25)
print(student)  # {'name': 'Bob', 'age': 25, 'gender': 'Female', 'score': 95}
```

#### 使用setdefault()方法

```python
student = {'name': 'Alice', 'age': 20}

# 键存在时，不修改值
student.setdefault('name', 'Bob')
print(student)  # {'name': 'Alice', 'age': 20}

# 键不存在时，添加键值对
student.setdefault('gender', 'Female')
print(student)  # {'name': 'Alice', 'age': 20, 'gender': 'Female'}
```

### 3. 删除字典元素

#### 使用del语句删除

```python
student = {'name': 'Alice', 'age': 20, 'gender': 'Female', 'score': 95}

# 删除指定的键值对
del student['score']
print(student)  # {'name': 'Alice', 'age': 20, 'gender': 'Female'}

# 删除整个字典
del student
# print(student)  # NameError: name 'student' is not defined
```

#### 使用pop()方法删除

```python
student = {'name': 'Alice', 'age': 20, 'gender': 'Female', 'score': 95}

# 删除指定的键值对并返回值
score = student.pop('score')
print(score)     # 输出: 95
print(student)   # {'name': 'Alice', 'age': 20, 'gender': 'Female'}

# 指定默认值，键不存在时返回默认值
grade = student.pop('grade', 'A')
print(grade)     # 输出: A
```

#### 使用popitem()方法删除

```python
student = {'name': 'Alice', 'age': 20, 'gender': 'Female'}

# 删除并返回最后一个键值对（Python 3.7+）
last_item = student.popitem()
print(last_item)  # ('gender', 'Female')
print(student)   # {'name': 'Alice', 'age': 20}
```

#### 使用clear()方法清空字典

```python
student = {'name': 'Alice', 'age': 20, 'gender': 'Female'}
student.clear()
print(student)  # {}
```

### 4. 字典的遍历

#### 遍历键

```python
student = {'name': 'Alice', 'age': 20, 'gender': 'Female'}

# 方法1：直接遍历字典
for key in student:
    print(key)

# 方法2：使用keys()方法
for key in student.keys():
    print(key)
```

#### 遍历值

```python
student = {'name': 'Alice', 'age': 20, 'gender': 'Female'}

# 使用values()方法
for value in student.values():
    print(value)
```

#### 遍历键值对

```python
student = {'name': 'Alice', 'age': 20, 'gender': 'Female'}

# 使用items()方法
for key, value in student.items():
    print(f"{key}: {value}")
```

#### 使用enumerate()遍历

```python
student = {'name': 'Alice', 'age': 20, 'gender': 'Female'}

for index, (key, value) in enumerate(student.items()):
    print(f"Index {index}: {key} = {value}")
```

## 三、字典的内置方法

### 1. 字典的常用方法

| 方法 | 描述 |
| --- | --- |
| `clear()` | 删除字典内所有元素 |
| `copy()` | 返回一个字典的浅复制 |
| `fromkeys(seq[, val])` | 创建一个新字典，以序列seq中元素做字典的键，val为字典所有键对应的初始值 |
| `get(key[, default])` | 返回指定键的值，如果值不在字典中返回default值 |
| `items()` | 以列表返回可遍历的(键, 值)元组数组 |
| `keys()` | 以列表返回一个字典所有的键 |
| `values()` | 以列表返回字典中的所有值 |
| `setdefault(key[, default])` | 和get()类似，但如果键不存在于字典中，将会添加键并将值设为default |
| `update(dict2)` | 把字典dict2的键/值对更新到dict里 |
| `pop(key[, default])` | 删除字典给定键key所对应的值，返回值为被删除的值。key值必须给出。否则，返回default值 |
| `popitem()` | 返回并删除字典中的最后一对键和值 |

### 2. 方法使用示例

```python
# 创建字典
student = {'name': 'Alice', 'age': 20, 'gender': 'Female'}

# copy()方法
student_copy = student.copy()
print(student_copy)  # {'name': 'Alice', 'age': 20, 'gender': 'Female'}

# fromkeys()方法
keys = ['name', 'age', 'gender']
default_dict = dict.fromkeys(keys, 'Unknown')
print(default_dict)  # {'name': 'Unknown', 'age': 'Unknown', 'gender': 'Unknown'}

# items()、keys()、values()方法
print(student.items())   # dict_items([('name', 'Alice'), ('age', 20), ('gender', 'Female')])
print(student.keys())     # dict_keys(['name', 'age', 'gender'])
print(student.values())   # dict_values(['Alice', 20, 'Female'])
```

## 四、字典推导式

字典推导式（Dictionary Comprehension）是一种简洁的创建字典的方式，类似于列表推导式。

### 1. 基本语法

```python
{key_expr: value_expr for item in iterable}
{key_expr: value_expr for item in iterable if condition}
```

### 2. 常见用法

#### 从一个可迭代对象创建字典

```python
# 创建数字及其平方的字典
squares = {x: x**2 for x in range(6)}
print(squares)  # {0: 0, 1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

# 创建字符及其ASCII码的字典
ascii_dict = {char: ord(char) for char in 'abcde'}
print(ascii_dict)  # {'a': 97, 'b': 98, 'c': 99, 'd': 100, 'e': 101}
```

#### 从两个可迭代对象创建字典

```python
# 使用zip()函数
names = ['Alice', 'Bob', 'Charlie']
ages = [20, 25, 30]
student_dict = {name: age for name, age in zip(names, ages)}
print(student_dict)  # {'Alice': 20, 'Bob': 25, 'Charlie': 30}
```

#### 带条件的字典推导式

```python
# 创建偶数及其平方的字典
even_squares = {x: x**2 for x in range(10) if x % 2 == 0}
print(even_squares)  # {0: 0, 2: 4, 4: 16, 6: 36, 8: 64}
```

#### 从现有字典创建新字典

```python
original_dict = {'Alice': 85, 'Bob': 92, 'Charlie': 78, 'David': 88}

# 创建成绩大于80的学生字典
excellent_students = {name: score for name, score in original_dict.items() if score > 80}
print(excellent_students)  # {'Alice': 85, 'Bob': 92, 'David': 88}

# 交换字典的键和值
swapped_dict = {score: name for name, score in original_dict.items()}
print(swapped_dict)  # {85: 'Alice', 92: 'Bob', 78: 'Charlie', 88: 'David'}
```

## 五、字典的应用场景

### 1. 数据存储和检索

字典是存储和检索数据的理想选择，特别是当需要通过键快速访问值时。

```python
# 学生信息存储
students = {
    '1001': {'name': 'Alice', 'age': 20, 'grade': 'A'},
    '1002': {'name': 'Bob', 'age': 21, 'grade': 'B'},
    '1003': {'name': 'Charlie', 'age': 22, 'grade': 'A'}
}

# 通过学号快速检索学生信息
student_id = '1002'
if student_id in students:
    print(f"学生姓名: {students[student_id]['name']}")
    print(f"学生年龄: {students[student_id]['age']}")
    print(f"学生成绩: {students[student_id]['grade']}")
```

### 2. 配置管理

字典常用于存储配置信息，如数据库连接参数、API密钥等。

```python
# 应用配置
config = {
    'database': {
```

### 3. 缓存和记忆化

字典可以用来实现缓存功能，避免重复计算，提高程序效率。

```python
# 斐波那契数列的记忆化实现
fib_cache = {}

def fibonacci(n):
    if n in fib_cache:
        return fib_cache[n]
    
    if n <= 1:
        result = n
    else:
        result = fibonacci(n-1) + fibonacci(n-2)
    
    fib_cache[n] = result
    return result

# 测试
print(fibonacci(10))  # 55
print(fibonacci(20))  # 6765
```

### 4. 统计和计数

字典非常适合用于统计元素的出现次数。

```python
# 统计文本中单词出现的次数
text = "Python is a popular programming language Python is easy to learn"
word_count = {}

for word in text.split():
    word = word.lower()
    if word in word_count:
        word_count[word] += 1
    else:
        word_count[word] = 1

# {'python': 2, 'is': 2, 'a': 1, 'popular': 1, 'programming': 1, 'language': 1, 'easy': 1, 'to': 1, 'learn': 1}
```

### 5. 数据转换和映射

字典可以用来建立映射关系，进行数据转换。

```python
# 数字到英文单词的映射
number_to_word = {
```

### 6. 状态机实现

字典可以用来实现状态机，管理不同状态之间的转换。

```python
traffic_light = {
```

### 7. 图和树的实现

字典可以用来实现图和树等数据结构。

```python
# 使用字典实现图
graph = {
    'A': ['B', 'C'],
    'B': ['A', 'D', 'E'],
    'C': ['A', 'F'],
    'D': ['B'],
    'E': ['B', 'F'],
    'F': ['C', 'E']
}

# 深度优先搜索
def dfs(graph, start, visited=None):
    if visited is None:
        visited = set()
    visited.add(start)
    print(start, end=' ')
    
    for next_node in graph[start]:
        if next_node not in visited:
            dfs(graph, next_node, visited)

# 测试
print("DFS遍历结果:")
dfs(graph, 'A')
```

## 六、字典与其他数据类型的比较

### 1. 字典与列表的比较

| 特性 | 字典（Dictionary） | 列表（List） |
| --- | --- | --- |
| **数据结构** | 键值对（key-value） | 线性序列 |
| **有序性** | Python 3.7+有序 | 有序 |
| **访问方式** | 通过键访问 | 通过索引访问 |
| **查找效率** | O(1)时间复杂度 | O(n)时间复杂度 |
| **元素唯一性** | 键必须唯一 | 元素可重复 |
| **可变性** | 可变 | 可变 |
| **内存占用** | 相对较高 | 相对较低 |
| **适用场景** | 需要快速查找、键值对存储 | 需要顺序访问、允许重复 |

### 2. 字典与元组的比较

| 特性 | 字典（Dictionary） | 元组（Tuple） |
| --- | --- | --- |
| **数据结构** | 键值对（key-value） | 线性序列 |
| **可变性** | 可变 | 不可变 |
| **有序性** | Python 3.7+有序 | 有序 |
| **访问方式** | 通过键访问 | 通过索引访问 |
| **元素类型** | 键不可变，值任意 | 任意类型 |
| **哈希性** | 不可哈希 | 可哈希 |
| **适用场景** | 需要修改的键值对数据 | 固定不变的数据 |

### 3. 字典与集合的比较

| 特性 | 字典（Dictionary） | 集合（Set） |
| --- | --- | --- |
| **数据结构** | 键值对（key-value） | 唯一元素集合 |
| **存储内容** | 存储键和值 | 只存储键（类似字典的键） |
| **有序性** | Python 3.7+有序 | 无序 |
| **访问方式** | 通过键访问值 | 通过成员运算符访问 |
| **元素唯一性** | 键必须唯一 | 所有元素必须唯一 |
| **可变性** | 可变 | 可变 |
| **适用场景** | 键值对映射、快速查找 | 去重、集合运算 |

### 4. 性能对比

```python
import time

# 创建测试数据
data_size = 100000
test_list = list(range(data_size))
test_dict = {i: f"value_{i}" for i in range(data_size)}
test_set = set(test_list)

# 测试查找性能
def test_lookup_performance():
    # 列表查找
    start_time = time.time()
    for _ in range(1000):
        data_size - 1 in test_list
    list_time = time.time() - start_time
    
    # 字典查找
    start_time = time.time()
    for _ in range(1000):
        data_size - 1 in test_dict
    dict_time = time.time() - start_time
    
    # 集合查找
    start_time = time.time()
    for _ in range(1000):
        data_size - 1 in test_set
    set_time = time.time() - start_time
    
    print(f"列表查找时间: {list_time:.6f}秒")
    print(f"字典查找时间: {dict_time:.6f}秒")
    print(f"集合查找时间: {set_time:.6f}秒")

test_lookup_performance()
```

## 七、字典的最佳实践

### 1. 何时使用字典

- **需要快速查找时**：字典的查找时间复杂度为O(1)，比列表的O(n)快得多
- **需要键值对存储时**：当数据具有明确的键值对应关系时
- **需要唯一键标识时**：当每个元素需要通过唯一标识符访问时
- **需要灵活的数据结构时**：字典可以存储不同类型的值

### 2. 何时避免使用字典

- **需要保持元素顺序时**：虽然Python 3.7+字典保持插入顺序，但如果顺序很重要，列表可能更合适
- **内存受限时**：字典通常比列表占用更多内存
- **只需要简单存储序列时**：如果不需要键值对结构，列表可能更简单

### 3. 性能优化建议

- **使用字典进行快速查找**：对于大型数据集，字典的查找性能远优于列表
- **合理选择键的类型**：使用不可变类型作为键，如字符串、数字或元组
- **避免过大的字典**：过大的字典会占用大量内存，考虑使用数据库或其他存储方案
- **使用字典推导式**：字典推导式比循环创建字典更简洁高效

### 4. 代码示例

```python
# 最佳实践示例

# 1. 使用字典进行配置管理
class ConfigManager:
    def __init__(self):
        self.config = {
            'database': {
                'host': 'localhost',
                'port': 3306,
                'username': 'root',
                'password': 'password'
            },
            'logging': {
                'level': 'INFO',
                'file': 'app.log'
            }
        }
    
    def get(self, section, key, default=None):
        """获取配置值"""
        if section in self.config and key in self.config[section]:
            return self.config[section][key]
        return default
    
    def set(self, section, key, value):
        """设置配置值"""
        if section not in self.config:
            self.config[section] = {}
        self.config[section][key] = value

# 使用配置管理器
config = ConfigManager()
db_host = config.get('database', 'host')
log_level = config.get('logging', 'level', 'DEBUG')

# 2. 使用字典实现缓存
class SimpleCache:
    def __init__(self, max_size=100):
        self.cache = {}
        self.max_size = max_size
    
    def get(self, key):
        """获取缓存值"""
        return self.cache.get(key)
    
    def set(self, key, value):
        """设置缓存值"""
        if len(self.cache) >= self.max_size:
            # 简单的LRU策略：删除第一个元素
            first_key = next(iter(self.cache))
            del self.cache[first_key]
        self.cache[key] = value
    
    def clear(self):
        """清空缓存"""
        self.cache.clear()

# 使用缓存
cache = SimpleCache()
cache.set('user_1001', {'name': 'Alice', 'age': 20})
user_data = cache.get('user_1001')

# 3. 使用字典进行数据统计
def count_words(text):
    """统计文本中单词出现的频率"""
    word_count = {}
    
    # 预处理文本
    for char in '.,!?;:"':
        text = text.replace(char, ' ')
    
    # 统计单词
    for word in text.lower().split():
        if word:
            word_count[word] = word_count.get(word, 0) + 1
    
    return word_count

# 测试单词统计
text = "Python is a popular programming language. Python is easy to learn and use."
word_freq = count_words(text)
print("单词频率统计:")
for word, count in sorted(word_freq.items(), key=lambda x: x[1], reverse=True):
    print(f"{word}: {count}")

# 4. 使用字典实现状态管理
class TrafficLight:
    def __init__(self):
        self.states = {
            'red': {'next': 'green', 'duration': 30},
            'green': {'next': 'yellow', 'duration': 25},
            'yellow': {'next': 'red', 'duration': 5}
        }
        self.current_state = 'red'
        self.timer = 0
    
    def update(self):
        """更新交通灯状态"""
        self.timer += 1
        if self.timer >= self.states[self.current_state]['duration']:
            self.current_state = self.states[self.current_state]['next']
            self.timer = 0
            return True
        return False
    
    def get_state(self):
        """获取当前状态"""
        return self.current_state

# 模拟交通灯
traffic_light = TrafficLight()
for i in range(70):
    if traffic_light.update():
        print(f"时间 {i}: 交通灯变为 {traffic_light.get_state()}")
```
