# Improved protein structure prediction using potentials from deep learning.

**Andrew W Senior et al.** · *Nature* · 2020 · DOI [10.1038/s41586-019-1923-7](https://doi.org/10.1038/s41586-019-1923-7)

**摘要要点**（来自 dataset.json 条目 abstract）：神经网络可被训练来准确预测残基对之间的距离，距离比接触预测传递更多结构信息；据此构造平均力势（potential of mean force），该势能可用简单梯度下降优化生成结构，无需复杂采样。系统名为 AlphaFold，在 CASP13 盲评中，43 个自由建模（FM）结构域中有 24 个达到高精度结构（TM-score ≥ 0.7），第二名方法仅 14/43。

## 一句话结论

AlphaFold 用深度残差卷积网络从多序列比对特征直接预测所有残基对 Cβ 距离的概率分布（distogram），把负对数似然组装成蛋白质特异的平均力势，再用 L-BFGS 梯度下降直接优化主链扭转角（φ, ψ）生成结构——完全绕开传统的片段装配与模拟退火采样；在 CASP13 中 FM 类 z-score 达 52.8，远超第二名（36.6），43 个 FM 结构域中 24 个 TM-score ≥ 0.7。

## 研究问题

- 蛋白质结构预测：从氨基酸序列确定三维形状，结构大体决定功能，但实验测定困难、耗时。
- 传统自由建模主流方法是片段装配（fragment assembly）+ 模拟退火：反复修改局部片段、保留降低统计势能的改动，需要数千次移动且要重复多次才能覆盖低势能结构（论文将之描述为昂贵）。
- 近年的进步来自共变（covariation）信息：MSA 中相关突变可推断接触残基对（接触定义：两残基 Cβ 原子距离在 8 Å 以内）；但接触预测只有二元信息。
- 本文的核心假设：距离预测比接触预测携带更多结构信息、提供更丰富的训练信号；若能把预测的距离分布变成可微的"蛋白质特异势能"，是否就能用简单的梯度下降直接"折出"结构，而不需要复杂采样？

## 方法与数据

**训练数据**
- 结构来自 PDB，用 CATH 35% 序列相似度聚类代表提取非冗余结构域，共 31 247 个结构域；按 29 427 / 1 820 分为训练集与测试集，同一同源超家族（CATH H-level）的所有结构域放在同一划分。
- CASP11、CASP12 中 FM 结构域的 CATH 超家族从训练集中剔除。
- 从测试集每个同源超家族取一个结构域，构成 377 结构域子集（正文结果主要基于该子集）。论文自注：该子集的精度高于 CASP13 测试结构域。

**输入特征**
- 用 HHblits 在 Uniclust30 中搜索比对同源序列得到 MSA；PSI-BLAST 提供额外 profile 特征。
- 共变特征：拟合一个正则化伪似然（pseudolikelihood）训练的 Potts 模型（类似 CCMPred），把其原始参数（484 维）与 Frobenius 范数（1 维）同时作为每个残基对 (i,j) 的输入。
- 序列长度级（1D）特征：HHblits 比对数（标量）；one-hot 氨基酸类型（21 维）；PSI-BLAST profile（21 维）；HHblits profile（22 维）、非空位 profile（21 维）、HHblits bias、HMM profile（30 维）；Potts 模型 bias（22 维）；删除概率（1 维）；残基索引（用 5 个最低有效位加一个标量编码）。
- 序列长度平方级（2D）特征：Potts 模型参数（484 维，用 Nesterov 动量 0.99 的梯度下降迭代 500 次拟合，无序列重加权）、Frobenius 范数（1 维）、空位矩阵（1 维）。此外显式提供 MSA 的空位与删除特征。
- 数据增强：为让网络适应浅 MSA，训练前从 HHblits MSA 中随机取一半序列再计算特征；每个结构域存 10 份这样的采样。

**网络结构**
- 二维空洞卷积残差网络（2D dilated convolutional residual network），全程二维，220 个残差块；每块含 3 个 batchnorm 层、2 个 1×1 投影层、1 个 3×3 空洞卷积、ELU 非线性；各层空洞率循环 1、2、4、8。末层用位置特异的 bias（按残基偏移，上限 32，以及 bin 编号索引）。
- 输入为 64×64 残基区域；距离目标量化到 2–22 Å、64 个等宽 bin；预测残基对 Cβ 原子距离（甘氨酸用 Cα）。损失为交叉熵，SGD 训练。
- 超参数：7×4 个 256 通道块 + 48×4 个 128 通道块；同步 SGD；每批 8 个 GPU worker 各 4 个 crop；dropout keep 概率 0.85；ELU；学习率 0.06，在 150 000、200 000、250 000、350 000 步各衰减 50%；辅助损失权重（二级结构 0.005、可及表面积 0.001）在 100 000 步后除以 10；训练约 5 天、600 000 步。
- 用 27 个 CASP11 FM 结构域早停做交叉验证，再用 27 个 CASP12 FM 结构域选模型。
- 数据增强与防过拟合：64×64 crop（含非对角 crop）、每次使用时随机化 crop 偏移（单个蛋白可产生数千训练样本）、按真实分辨率比例给原子坐标加噪声、MSA 子采样、dropout。
- 推理时用不同偏移的多次平铺并对中心区加权平均，再用 4 个独立训练（超参数略有不同）的模型集成平均。
- 辅助输出头：对倒数第二层 2D 激活做 mean/max pooling，预测 DSSP 8 类二级结构（Q3 准确率 84%，论文称与当时最优相当）与相对可及表面积（ASA）；1D 池化激活还预测每个残基的 Ramachandran 边缘分布 P(φᵢ, ψᵢ | S, MSA(S))，量化到 10°（1296 bin）。CASP13 实际中 distogram 用"只预测 distogram+SS+ASA"的网络，扭转角用第二个同时预测扭转角的类似网络。

**势能构造**
- Vdistance：对预测距离分布的负对数概率拟合样条，对所有残基对求和（L² 项）；减去一个参考分布（reference distribution）——由去掉序列/MSA 输入特征的小型同构网络在相同结构集上训练得到，仅以 δαβ（是否甘氨酸，决定 Cα/Cβ）和蛋白长度条件化。样条只拟合到 18 Å（交叉验证确定），之后做常数外推；CASP13 中样条拟合前 64 bin 中的 51 bin。
- Vtorsion：对每个残基的预测边缘分布拟合单峰 von Mises 分布，取负对数似然求和（论文承认这会牺牲多峰分布的建模保真度）。
- 防空间碰撞：加入 Rosetta 的 Vscore2_smooth（含 van der Waals 项）。
- Vtotal(φ, ψ) = Vdistance(G(φ, ψ)) + Vtorsion(φ, ψ) + Vscore2_smooth(G(φ, ψ))，三项各有乘性权重，但等权重效果最佳。

**结构实现（梯度下降折叠）**
- 用理想主链几何的可微模型 x = G(φ, ψ) 参数化结构；从预测扭转角分布采样初始化；用 L-BFGS 最小化 Vtotal。
- 优化依赖初值，故多次重启：维护 20 个最低势能结构组成的池，池满后 90% 轨迹从池中结构加 30° 主链扭转角噪声初始化，其余 10% 仍从预测扭转分布采样（"noisy restarts"）；CASP13 中每条链做 5000 次优化，计算按 (50+L)/2 个并行 worker 分摊（L 为链长）。

**全链折叠（不切结构域）**
- 传统上把长链切成结构域分别折叠，而"仅从序列做结构域切分本身就难且易错"，故本文折叠整条链。用滑动窗口（64、128、256，偏移为 64 的倍数）分别构建子序列 MSA，每个 MSA 产生一个对应主对角方块的 distogram，按各 MSA 序列数加权平均成全链 distogram。例外：T0999（1589 残基）基于 HHpred 同源匹配做了人工结构域切分。

**精度指标**
- 结构级：TM-score、GDT_TS、RMSD（需与实验结构做几何对齐）。
- 无需对齐的 lDDT：衡量候选结构中满足 |Dᵢⱼ − dᵢⱼ| < t 的原生距离（<15 Å、序列间隔 ≥ r）比例，容差 t ∈ {0.5, 1, 2, 4} Å 平均。
- 新指标 distogram lDDT（DLDDT）：用 distogram 概率直接计算与 lDDT 同形式的值。本文取 r = 12（近程距离短、易预测且不决定整体折叠拓扑），用 Cβ 距离计算 lDDT 与 DLDDT。

## 主要结果与关键数字

- **CASP13 总体成绩**：AlphaFold 与 97 个组同场，每个组对 84 条（结构保密的）序列各提交最多 5 个预测，评估者分为 104 个结构域。按评估者求和 capped z-score 排名：FM 类 best-of-5 得分 52.8，最近竞争者（322 组）36.6；FM+FM/TBM 合计 68.3 vs 48.2。TBM 类（只用自由建模技术、不用模板）：top-1 排第 4，best-of-5 排第 1（评估者 0-capped z-score 公式）。
- **里程碑数字**：43 个 FM 结构域中 24 个 TM-score ≥ 0.7，第二名仅 14 个。
- **接触精度（Fig. 1c / 正文 Table 1c）**，最可能的 L / L/2 / L/5 个长程接触：FM（31 个结构域）AF 45.5 / 58.0 / 70.1 vs 498 组 42.9 / 55.1 / 67.3 vs 032 组 39.8 / 51.7 / 61.6；FM/TBM（12 个）59.1 / 74.2 / 85.3 vs 53.0 / 64.5 / 81.0 vs 48.9 / 64.2 / 79.6；TBM（61 个）68.3 / 82.4 / 90.6 vs 65.5 / 80.3 / 90.5 vs 61.9 / 76.4 / 87.1。
- **距离预测质量**：预测众数与真值相关性好（Fig. 3e）；分布标准差低时预测更准（Fig. 3f）——网络在建模自身的不确定性。
- **势能消融（测试集 n = 377，Fig. 8c）**：Full+relax TM-score 0.649 / GDT_TS 65.8 / lDDT 54.2 / RMSD 5.94 Å；Full 0.642 / 65.0 / 53.9 / 5.91；无参考分布校正 0.632 / 64.3 / 50.0 / 6.64；无 score2_smooth 0.641 / 64.8 / 53.7 / 5.93；无扭转项 0.637 / 64.3 / 53.6 / 6.04；无距离势能 0.266 / 29.1 / 19.1 / 14.88。bin 下采样：48/64 → 0.643，24/32 → 0.643，12/16 → 0.644，6/8 → 0.641，3/4 → 0.620；最后一行"两箱势能"（模仿接触预测：只分 <8 Å 与 8–14 Å 概率质量，14 Å 外常数外推）2/3 → 0.576 / 58.2 / 49.3 / 8.38。
- **优化策略**：noisy restarts 平均 TM-score 0.641 vs 纯采样初始化 0.636；Rosetta 弛豫（Talaris2014 + 样条拟合的参考校正距离势能组合）额外 +0.007。
- **相关性**：TM-score 与 DLDDT₁₂ 的 Pearson r：CASP13 0.81、测试集 0.72；lDDT 与 DLDDT₁₂：0.92 / 0.90；DLDDT₁₂ 与长度归一化 N_eff：0.634（N_eff 定义为 62% 序列同一性去冗余后的 MSA 序列数除以目标残基数）。
- **二级结构辅助头**：DSSP 8 类、Q3 = 84%。
- **生物相关性**：在 CATH 结构搜索中更准确识别折叠（Fig. 11）；5 个异源二聚体目标中 4/5 界面 RMSD <5 Å（Fig. 12）；T1011 口袋预测 78.0 vs 68.7 GDT_TS（Fig. 13）；两个 TBM-hard 结构域 T0981-D5（72.8 GDT_TS）与 T0957s1-D2（88.0 GDT_TS）top-1 比其他任何组高 12 个 GDT_TS；分子置换（Molecular Replacement）：Read 等人报道 AlphaFold 原始坐标（无 B 因子）的似然增益（LLG）略优于其他所有组。
- **网络可解释性（积分梯度，Integrated Gradients）**：归因图稀疏且高度结构化，紧密反映预测几何；4 个接触对（1、2、3、5）的最高归因输入对都在相关二级结构内部或之间；非接触对 (4) 的最高归因是几何上位于 I、J 之间的残基；大部分高归因输入对自身就是接触对。论文解读：网络在利用中间预测发现重要相互作用，并从相关残基传递信息以细化最终预测。

## 对照与消融

- **与历史方法对照**：片段装配 + 模拟退火（Rosetta、FRAGFOLD、QUARK 等）依赖统计势能与随机采样，需要数千次移动与多次重复；本文用可微势能 + 梯度下降替代。QUARK 用过模板距离剖面约束，EPAD 用无共变特征的神经网络距离预测做排序——本文是把距离预测变成可优化的折叠势能本身。
- **与 CASP13 其他组对照**：z-score 52.8 vs 36.6（FM）、68.3 vs 48.2（FM+FM/TBM）；接触预测对 498（RaptorX-Contact）与 032（TripletRes）全面领先（Fig. 1c）；Fig. 10b 单次梯度下降 58.4/71.6/76.3/70.4 vs 单次片段装配 54.3/69.9/74.5/68.0——梯度下降系统在各类别都优于片段装配（含早期目标"回填"对照）。
- **势能组分消融**（见上节 Fig. 8c）：距离势能是主导项（去掉后 TM-score 从 0.642 跌到 0.266）；参考分布校正、范德华项、扭转项均为小增益（各约 0.00–0.01），但都有贡献；Rosetta 弛豫 +0.007。
- **距离分辨率消融**：bin 数从 64 连续减半，直到 6–8 bin 仍几乎不损失精度（0.641–0.644），3–4 bin 开始下降（0.620），压缩成接触式两箱势能降到 0.576——证明"距离信息多于接触信息"的量化价值。
- **采样策略对照**：noisy restarts 优于持续从预测扭转分布采样（0.641 vs 0.636）。
- **自身系统演化**：CASP13 前半程（T0975 之前）用模拟退火 + 片段装配系统（40 bin 距离分布），T0975 起切换为 64-bin distogram + 梯度下降（3 次独立运行）与 1 个片段装配系统（5 次独立运行）混合，5 个提交从 8 个结构中选；top-1 取梯度下降的最低势能结构。

## 作者自述的局限

- "自由建模预测很少能达到实验结构的精度"；FM 精度仍落后于 TBM，"对困难结构的详细理解仍不能依赖它"。
- 优化依赖初值（"The optimised structure is dependent on the initial conditions"），因此需要大量重启（CASP13 每链 5000 次）与并行计算，长链优化更久。
- 距离势能只拟合到 18 Å、最后一个 bin 积压了 22 Å 以外的所有概率质量，远距离本身更难预测准确。
- 扭转项把可能多峰的边缘分布拟合成单峰 von Mises 分布，"以牺牲多峰分布建模保真度为代价"来统一概率质量。
- 势能三项的尺度无法保证等价，加权参数需交叉验证确定（实际等权重最好）。
- 深层网络输入归因（解释性）问题是"困难、欠定、仍在研究中的课题"，积分梯度只是其中一种方法。
- 结构域切分本身"难且易错"，全链折叠靠滑动窗口 MSA 加权平均近似处理；超长目标（如 T0999，1589 残基）仍需基于 HHpred 的人工切分。
- 测试集子集（377 结构域）的精度高于 CASP13 测试结构域——论文明确承认该数据集上的数字偏乐观。

## 我的评价

- 这篇论文的方法学故事非常干净：把"结构预测"改写为"可微势能上的确定性优化"，用距离分布的负对数似然作为势能、用可微几何模型 G(φ,ψ) 连接扭转角与坐标、用 L-BFGS 求解。相比片段装配的随机采样范式，梯度下降路线在计算路径上简洁得多，且文中消融清楚表明距离势能占绝对主导（0.642 → 0.266）。
- 值得注意的是其"克制"：梯度下降只找到局部最优，作者用 5000 次重启 + noisy restarts 来弥补全局性缺失，0.641 vs 0.636 的提升幅度很小却要额外维护结构池——说明全局搜索能力仍是短板，只是被"多跑几次"掩盖了。这一点与后来 AlphaFold2 用端到端推理 + 结构模块回收（recycling）的方向形成有趣的对比，但本文未涉及后续工作，这里仅就论文自身指出其全局优化依赖算力堆砌。
- distogram lDDT 作为"无需折叠即可评估折叠结果"的代理指标很有工程价值：它让消融与模型选择可以绕开昂贵的结构实现步骤，文中 TM-score 与 DLDDT₁₂ 的 r 值（0.72–0.81）支撑了这一用法。
- 可疑之处：测试集（377）上报告的平均 TM-score（0.642）显著高于 CASP13 实际表现，论文自己承认测试集精度偏高，但对"CASP13 精度偏低是浅 MSA 还是评估口径导致"没有分解；读者引用平均数字时应格外小心。
- 训练集划分按 CATH 超家族同分，且剔除 CASP11/12 的 FM 超家族，这是防止"结构记忆泄漏"的严谨做法，值得肯定；但 64×64 crop 训练导致的长程接触（>64 残基）依赖非对角 crop 的间接建模，文中只是引用他人结论（Jones & Kandathil，接触预测只需有限上下文窗口）做支撑，缺少对"更长程相互作用是否被系统性低估"的检验。
- 图注与正文编号不一致（正文称 Table 1c、Table 10b，图注中是 Fig. 1c、Fig. 10b 面板），是作者版本未最终排版的痕迹，引用时需注意。

## 可复现要点

- **代码**：论文承诺发表后公开 distogram 与扭转角预测的源代码、网络权重与 CASP13 目标的输入数据；框架为 TensorFlow + DeepMind Sonnet；Rosetta 需授权使用。
- **数据版本**：PDB 2018-03-15；CATH 2018-03-16；Uniclust30 2017-10；PSI-BLAST nr（2017-12-15）；另将公开训练/测试划分（CATH 结构域代码）。
- **工具版本**：HHblits 3.0-beta.3（3 轮迭代，E-value 1e-3）；PSI-BLAST 2.6.0（3 轮迭代，E-value 1e-3）；Rosetta v3.5；BioPython v1.65；TM-align 20160521；SST 网页服务器（2019 年 3 月）；PyMol 可视化。
- **关键训练设置**：220 块 2D 空洞残差网络；7×4×256 通道 + 48×4×128 通道；空洞率 1/2/4/8 循环；64 bin（2–22 Å）；batch = 8 GPU worker × 4 crop；dropout 0.85；ELU；LR 0.06，150k/200k/250k/350k 步减半；辅助损失 SS 0.005、ASA 0.001（100k 步后 ×0.1）；约 5 天 600k 步；4 模型集成；Potts 参数 500 次 Nesterov（动量 0.99）梯度下降拟合、不重加权；训练集每个结构域 10 份半 MSA 采样。
- **折叠流程**：从预测扭转分布采样初始化 → L-BFGS 最小化 Vtotal → 20 结构池 → 90% 从池内 + 30° 噪声重启 / 10% 从扭转分布采样 → CASP13 每链 5000 次、并行 (50+L)/2；CASP13 提交排序势能 VTalaris2014 + 0.2·Vdistance；样条拟合前 51/64 bin、18 Å 外常数外推。
- **指标口径**：lDDT/DLDDT 取 r = 12、容差 0.5/1/2/4 Å、原生距离 <15 Å，用 Cβ 距离；接触由 distogram 8 Å 以下概率质量求和得到。

## 术语

- distogram（距离直方图矩阵）：对所有残基对距离分布的预测集合，由 64×64 区域预测平均拼接而成。
- potential of mean force（平均力势）：本文指由预测距离分布负对数似然构造的、描述蛋白形状的势能函数。
- TM-score（模板建模分数）：0–1，衡量预测与原生结构整体（主链）形状匹配程度。
- GDT_TS（Global Distance Test Total Score）：CASP 常用全局相似度指标。
- lDDT（Local Distance Difference Test，局部距离差异检验）：无需对齐的局部结构相似度。
- DLDDT（distogram lDDT）：用 distogram 概率直接计算的 lDDT 形式指标。
- N_eff（有效序列数）：62% 序列同一性去冗余后的 MSA 序列数（本文再除以目标长度做归一化），表征共变信息量。
- MSA（Multiple Sequence Alignment，多序列比对）。
- CASP（Critical Assessment of Protein Structure Prediction，蛋白质结构预测关键评估）：两年一度的盲评。
- FM / TBM / FM-TBM：自由建模 / 模板建模 / 中间类别。
- Cβ：β 碳原子；甘氨酸无 Cβ 时用 Cα。
- Potts model（玻茨模型）：本文指伪似然训练的成对共变模型（类似 CCMPred）。
- von Mises distribution（冯·米塞斯分布）：圆上单峰概率分布，用于拟合扭转角预测。
- L-BFGS（Limited-memory Broyden–Fletcher–Goldfarb–Shanno）：有限内存拟牛顿优化算法。
- dilated convolution（空洞卷积）：增大感受野的卷积方式，空洞率 1/2/4/8 循环。
- residual block（残差块）与旁路连接：允许极深网络训练的结构。
- ELU（Exponential Linear Unit）：指数线性单元激活函数。
- HHblits：基于 HMM-HMM 比对的迭代序列搜索工具；PSI-BLAST：位点特异迭代 BLAST。
- Uniclust30：聚类的蛋白序列数据库；CATH：按类别/架构/拓扑/同源性分类的结构数据库（文中用其 35% 聚类代表与 S40 子集）。
- Rosetta：蛋白建模软件套件（本文用其 Vscore2_smooth、Talaris2014 势能与弛豫协议）。
- DSSP：二级结构指派算法；Q3：三态二级结构预测准确率。
- ASA（Accessible Surface Area，可及表面积）。
- Ramachandran distribution：主链扭转角 (φ, ψ) 分布。
- Integrated Gradients（积分梯度）：深度学习输入归因方法。
- molecular replacement（分子置换）：晶体学中用已知结构模型求解相位的方法；LLG（log-likelihood gain，似然增益）为其评价指标。
- noisy restarts（带噪重启）：从低势能结构池加扭转角噪声重新初始化的优化策略。
- back-fill（回填）：对切换系统之前的目标用新系统补算一遍作对照。
