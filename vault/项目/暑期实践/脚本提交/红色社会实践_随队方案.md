# 红色社会实践随队方案：南充市烈士陵园

关联项目：豆种寻踪·南充三下乡  
实践地点：南充市烈士陵园  
建议时间：三下乡第 6 天下午，必要时第 7 天上午补拍  
队伍：西北农林科技大学"豆种寻踪"实践队

## 一、这次只去一个场馆

红色社会实践不再写多馆路线。南充能去的红色场馆不少，但对我们这支队伍来说，时间和交通成本必须算清楚。三下乡的主任务还是大豆调研，不能为了红色材料把田间工作挤掉。

本次随队红色实践只选择南充市烈士陵园。它在顺庆区西山风景区内，离住宿点、南充市农业科学院和嘉陵江沿线核查点都比较近。上午做完访谈或生境观察，下午过去参观和拍摄，时间上最稳，也最可能拿到完整素材。

## 二、实践目标

1. 完成一次正式的红色场馆参观，不把它当"顺路打卡"。
2. 给三下乡总结报告补充一段真实的思政实践内容。
3. 为红色全景 VR 比赛拍摄南充市烈士陵园的外景、全景、云台视频和许可记录。
4. 让队员把田间调研和烈士陵园参观联系起来：做农业调研也要讲真实、讲纪律、讲责任。

## 三、行程安排

| 时间 | 安排 | 负责人 |
|---|---|---|
| 出发前 3至5 天 | 电话确认开放时间、团队参观、拍照、全景拍摄、无人机申请流程 | 队长 |
| 当天 13:30 | 从顺庆区住宿点或调研点出发 | 后勤联络 |
| 14:00 | 到陵园门口，先向工作人员报备，不直接开拍 | 队长 |
| 14:10至14:40 | 集体参观大门、牌坊、纪念碑，做简短默哀 | 全队 |
| 14:40至15:30 | 参观陈列馆允许区域，记录展板信息 | 资料记录 |
| 15:30至16:20 | 拍摄全景、云台转场、普通照片；如获批，拍无人机外景 | 摄影组 |
| 16:20至16:50 | 题字碑林、墓园外围参观，队员写一句现场感受 | 宣传组 |
| 17:00 | 离园前再次确认是否需要素材审核 | 队长 |
| 晚上 | 备份照片和视频，整理实践日志 | 全队 |

如果下午遇到暴雨或场馆临时活动，改为只参观不拍摄，第二天上午补拍外景。社会实践可以完成，比赛素材另行补。

## 四、现场怎么做

### 1. 进门先报备

队伍到场后先找工作人员说明身份和用途。不要一进门就支三脚架、飞无人机、打开全景相机。介绍信、学生证、团队名单和比赛通知打印一份，手机里也存电子版。

### 2. 参观要慢一点

纪念碑前不抢合影，不大声讨论脚本。陈列馆里先看展板，再记关键词。遇到不确定的数字，比如烈士人数、展室分期、建成时间，先记"待核"，不当场编。

### 3. 拍摄分两条线

一条线是社会实践素材：队员参观、记录、微团课、合影。另一条线是比赛素材：全景、云台、无人机、录音。两条线可以同一天完成，但文件要分开存。

## 五、设备使用

| 设备 | 用途 | 现场要求 |
|---|---|---|
| 无人机 | 拍陵园外景和西山环境 | 必须获批；不越过人群和墓园低空飞行 |
| 云台 | 拍入园、纪念碑前、浮雕墙、题字碑林慢走镜头 | 队员走路放慢，别边拍边聊天 |
| 360 全景相机 | 拍比赛主场景 | 先确认是否能架三脚架 |
| 手机/微单 | 拍实践照片、展板细节 | 不拍禁拍区域，不拍游客正脸 |
| 录音笔 | 录现场环境声和队员讲解 | 讲话前先试音 |
| 手机空间扫描 | 试扫纪念碑前或题字碑林 | 只做补充，失败不影响主任务 |

## 六、微团课安排

主题：把调研数据写实，把红色参观也写实。

地点：纪念碑前或离人流较少的空地，具体听从工作人员安排。  
时长：10 分钟，不拉长。

流程：

1. 队长说明为什么选择南充市烈士陵园，而不是跑多个场馆。
2. 调研主笔分享一个田间访谈中印象最深的细节，比如农户对品种、天气或收成的担心。
3. 摄影同学说明今天哪些地方能拍、哪些地方不能拍，为什么要遵守。
4. 每名队员写一句话，晚上原样放进实践日志，不统一改成口号。

## 七、队员现场记录卡

每个人只写三行，越具体越好。

```
我今天在陵园看到的一个细节：
我不确定、需要回去核实的一点：
这件事和我们做大豆调研的关系：
```

示例写法：

```
我今天在陵园看到的一个细节：纪念碑前比我想的安静，大家走到那里声音会自然变小。
我不确定、需要回去核实的一点：墓园安放烈士的具体人数，不同资料说法不完全一样。
这件事和我们做大豆调研的关系：不能为了让文章好看就把没核实的数字写死。
```

## 九、电话联系话术

老师您好，我们是西北农林科技大学"豆种寻踪"暑期社会实践队，7 月下旬会在南充做农业调研。我们想安排半天到南充市烈士陵园开展红色社会实践，也想为大学生红色全景资源展示比赛拍一些公开区域的全景照片和视频。请问团队参观、普通拍照、全景相机拍摄是否需要提前预约？如果涉及无人机，我们会单独提交飞行说明，未经允许绝不起飞。

如果对方说不能拍，就回复：明白，我们以参观学习为主，拍摄完全服从管理要求。请问哪些区域可以记录文字笔记，哪些区域不能拍照？我们会提前提醒队员。

## 十、注意事项

- 不写"已获得许可"，除非有电话记录或书面回复。
- 不在墓园区域摆拍、跳拍、搞花絮。
- 不把无人机飞行写成必然完成，只写"获批后拍摄"。
- 不用 AI 生成烈士形象或历史场景。
- 当天素材当天备份，文件名按"陵园_日期_类型_序号"保存。

这份方案就是为实际出队准备的。能做的写清楚，做不了的留备选，不把话说满。
