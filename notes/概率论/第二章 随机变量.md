# 第二章 随机变量

### **知识点总结**

#### 1. **条件概率**

条件概率是指在已知事件B发生的条件下，事件A发生的概率。它的计算公式为：$P(A|B) = \frac{P(A \cap B)}{P(B)}$​

- **例子**：如果一个人投篮的成功率是80%，而已知他今天的投篮成功率下降至60%，那么求他今天投篮成功的概率可以通过条件概率公式求得。

#### 2. **贝叶斯公式**

贝叶斯公式是根据新观测数据更新已有概率的公式。它的公式为：$P(A|B) = \frac{P(B|A)P(A)}{P(B)}$​

- **例子**：如果一个病人做了一个检测，结果为阳性，且已知该病的检测精度和该病在人群中的发病率，可以通过贝叶斯公式来计算病人在阳性结果下患病的实际概率。

#### 3. **全概率公式**

全概率公式用于计算某一事件的总概率。它将复杂的事件分解为多个互斥事件，然后求和。例如，事件B可以分解为多个事件( A_1, A_2, ..., A_n )的联合事件，公式为：$P(B) = \sum_{i=1}^{n} P(A_i) \cdot P(B|A_i)$​

- **例子**：一个人在不同交通工具上迟到的概率，可以通过全概率公式计算出其总的迟到概率。

#### 4. **伯努利试验与二项分布**

伯努利试验指的是每次实验只有两种可能的结果（成功或失败）。如果进行( n )次独立的伯努利试验，可以使用二项分布来描述成功次数的概率：$P(X = k) = \binom{n}{k} pk (1-p){n-k}$​

- **例子**：如果一个篮球运动员罚球命中率是90%，则可以通过二项分布计算出他在5次罚球中命中4次的概率。

#### 5. **泊松分布**

泊松分布通常用于描述某个事件在单位时间内发生的次数，尤其是当事件发生的概率很小且试验次数很大时。例如，车祸发生的次数、客户到达服务窗口的次数等。

- **公式**：当事件发生的平均频率为( \lambda )时，泊松分布的概率为：  
  [  
  P(X = k) = \frac{\lambda<sup>k e</sup>{-\lambda}}{k!}  
  ]
- **例子**：一个餐厅每小时大约接待30个顾客，求1小时内接待25个顾客的概率。

#### 6. **随机变量的函数与分布**

如果随机变量( X )的分布已知，并且我们通过一个函数( g(X) )定义了新的随机变量( Y )，那么可以通过分布函数法或公式法来推导( Y )的分布。

- **例子**：如果随机变量( X )服从正态分布，( Y = 2X + 3 )，那么( Y )的分布可以通过变换求得。

#### 7. **多维随机向量与分布**

多维随机向量是由多个随机变量组成的向量。在二维的情况下，描述的是两个随机变量( X )和( Y )的联合分布，计算它们的边际分布和条件分布时，需要用到联合概率密度函数。

- **例子**：研究一组数据，既包含身高也包含体重，可以通过联合分布函数来描述。

### **积分上下限的确定**

在处理概率密度函数和分布函数时，经常需要使用积分来计算概率。如何确定积分的上下限，通常取决于以下几个方面：

1. **对于离散型随机变量**，我们使用求和而非积分，计算概率时考虑每个取值的概率。
2. **对于连续型随机变量**，积分的上下限通常是变量的取值范围。例如，对于正态分布，如果我们想计算( X )在区间([a, b])内的概率，则积分的上下限是( a )和( b )，并且使用概率密度函数进行积分：$P(a \leq X \leq b) = \int_a^b f(x) , dx$  
   如果不指定区间，常见的上下限是( -\infty )到( +\infty )，比如标准正态分布的概率就是在整个实数范围内积分。
3. **应用实例**：如果已知( X )服从均匀分布( U(a, b) )，并且要计算( X )在区间([c, d])内的概率，则积分的上下限是( c )和( d )，即：$P(c \leq X \leq d) = \int_c^d \frac{1}{b - a} , dx$  
   对于其他分布，选择上下限时要注意分布函数的定义域。
