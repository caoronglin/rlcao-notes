# 3.1序列的访问及运算符

# 什么是序列

容器是存放数据的东西，数据容器是现代程序设计的重要基础设施，一个容器里可以放很多数据，随着数据增多，容器会自己逐渐变大。容器的大小只受计算机本身限制

序列是一大类数据容器的统称

> [!note]
>   1. 每个数据被分配一个序号
>   2. 可以通过序号访问数据
>   3. 序号从 0 开始编写
>
> Python 包含 6 种内置序列，列表、元祖、字符串、Unicode 字符串、buffer 对象和 range 对象

# 通用序列操作

可以进行某些特定操作，索引、分片、元祖（不可变）、加、乘，以及检查是否属于这个序列。

| 操作 | 描述 |
| --- | --- |
| x1+x2 | 合成新序列 |
| x*n | 序列 x 重复 n 次生成新序列 |
| x[i] | 引用下标为 i 的数据 |
| x[i:j] | 切片，包含 i 的数据不包含 j 的数据，相当于在 i,j 前砍一刀 |
| x[i:j:k] | i 到 j-1 的数据，步长为 2 |
| len(x) | 计算序列长度 |
| max(x) | 序列最大值 |
| min(x) | 序列最小值 |
| v in x | 检查 v 是否在序列 x 中 |
| v not in x | 检查 v 是否不在序列 x 中 |

## 访问单个数据

通过列表名称+[] 及索引

```python
a=[1,2,3,4,5]
print(a[1])
#2
```

当下标是负数时，表示从列表的最后向前数

```python
a=[1,2,3,4,5]
print(a[-1],a[-2])
#5,4
```

## 访问一部分数据

使用切片可以访问序列中的一部分数据

```python
a=[1,2,3,4,5]
b=a[1:3]
print(b)
#[2,3]
```

> [!note]
> 切片蓄序列相当于生成新的序列，切片序列的改变不影响原序列的内容
