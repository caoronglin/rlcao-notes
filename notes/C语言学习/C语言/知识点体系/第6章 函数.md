## 6.1 模块化程序设计的思想

### 模块化设计特点

- **函数式语言**：C程序必须有一个`main`主函数，执行从`main`开始，在`main`结束
- **模块化思想**：将大程序按功能分割成小模块
- **特点**：

- 各模块相对独立、功能单一
- 控制程序设计复杂性
- 提高软件可靠性和可维护性

- **开发方法**：自上向下、逐步分解、分而治之

### 函数分类

| 分类角度 | 类型 | 说明 |
| --- | --- | --- |
| 用户角度 | 标准函数（库函数） | 系统提供，需包含头文件 |
| <br> | 用户自定义函数 | 用户编写 |
| 函数形式 | 无参函数 | 如 `void printstar()` |
| <br> | 有参函数 | 如 `int max(int x, int y)` |

**库函数使用注意**：

1. 函数功能
2. 参数数目、顺序、类型及含义
3. 返回值类型及含义
4. 需包含的头文件

## 6.2 函数的定义和调用

### 函数定义格式

```c
返回值类型 函数名(参数列表) {
    // 函数体
}
```

- **返回值类型**：缺省为`int`，无返回值写`void`
- **函数名**：合法标识符
- **参数列表**：形参声明，无参可写`void`或空括号

**示例**：

```c
// 有参函数
int max(int x, int y) {
    return x > y ? x : y;
}

// 无参函数
void printstar() {
    printf("**********\n");
}
```

### 返回值处理

- **返回语句**：`return 表达式;` 或 `return (表达式);`
- 函数中可有多个`return`
- 无`return`时，遇`}`自动返回
- 返回值类型与函数类型不一致时，**自动转换为函数类型**

**类型转换示例**：

```c
int main() {
    int max(float, float); // 函数声明
    float a=3.5, b=4.2;
    int c = max(a, b);     // 返回值float自动转int
    printf("%d", c);       // 输出4
}

int max(float x, float y) {
    float z = x > y ? x : y;
    return z; // 返回float值，但函数定义为int
}
```

### 函数调用与声明

**调用形式**：`函数名(实参表);`

**调用方式**：

- **函数语句**：`printstar();`
- **函数表达式**：`m = max(a,b) * 2;`
- **函数参数**：`printf("%d", max(a,b));`

**函数声明**：

```c
返回值类型 函数名(参数类型列表); 
```

**声明规则**：

- 位置：函数内或函数外（数据说明部分）
- **可省略情况**：

- 被调函数定义在主调函数之前
- 返回值为`int`或`char`

**示例**：

```c
#include <stdio.h>
int mypow(int px, int pn); // 声明幂函数

int main() {
    int x=2, n=3;
    int y = mypow(x, n);   // 调用函数
    printf("%d^%d=%d", x, n, y);
    return 0;
}

int mypow(int px, int pn) { // 函数定义
    int result = 1;
    for(int i=1; i<=pn; i++)
        result *= px;
    return result;
}
```

## 6.3 函数参数及其数据传递方式

### 形参与实参

| 特性 | 形式参数 | 实际参数 |
| --- | --- | --- |
| **定义** | 函数定义时括号中的变量名 | 函数调用时括号中的表达式 |
| **内存** | 调用时分配，结束时释放 | 已分配内存 |
| **要求** | 必须指定类型 | 必须有确定值 |

### 参数传递方式

#### 1. 值传递（单向）

- 特点：形参是实参的副本，修改形参不影响实参
- 适用场景：基本数据类型变量

```c
void swap(int x, int y) { 
    int temp = x;
    x = y; 
    y = temp; // 不影响实参
}
```

#### 2. 地址传递（双向）

- 特点：传递变量地址，形参和实参指向同一内存
- 适用场景：需修改实参值或传递大数据时

```c
void swap(int *x, int *y) {
    int temp = *x;
    *x = *y;
    *y = temp; // 修改实参值
}
```

### 数组参数传递

#### 一维数组

```c
// 三种等效写法
float average(int stu[10], int n);
float average(int stu[], int n);
float average(int *stu, int n);
```

#### 二维数组

```c
// 列数必须指定
int max_value(int array[][5], int rows); 
int max_value(int (*array)[5], int rows);
```

#### 字符数组

```c
void copy_str(char from[], char to[]);
void copy_str(char *from, char *to);
```

### 函数指针参数

```c
void calculate(int a, int b, int (*func)(int, int)) {
    printf("Result: %d", func(a, b));
}
```

### main函数参数

```c
int main(int argc, char *argv[]) {
    // argc: 命令行参数个数
    // argv: 参数字符串指针数组
}
```

**示例**：

```c
#include <stdio.h>
#include <stdlib.h>
int main(int argc, char *argv[]) {
    int sum = 0;
    for(int i=1; i<argc; i++)  // 跳过程序名
        sum += atoi(argv[i]);  // 字符串转整数
    printf("Sum: %d", sum);
    return 0;
}
```

**运行**：

```bash
$ ./sum 10 20 30
Sum: 60
```

## 6.4 通过函数返回值传递数据

### 返回指针的函数

```c
类型 *函数名(参数列表) {
    // 函数体
    return 指针;
}
```

**示例**：

```c
int *pmax(int *pa, int *pb) {
    return (*pa >= *pb) ? pa : pb;
}

int main() {
    int a=10, b=20;
    int *p = pmax(&a, &b);
    printf("Max: %d", *p); // 输出20
    return 0;
}
```

## 6.5 变量的作用域和生存周期

### 作用域

| 变量类型 | 定义位置 | 作用范围 |
| --- | --- | --- |
| 局部变量 | 函数内部 | 本函数内 |
| 全局变量 | 函数外部 | 定义位置到文件结束 |

**扩展全局变量作用域**：

```c
extern int global_var; // 在使用前声明
```

### 存储类型

| 存储类型 | 关键字 | 生命周期 | 初始化 | 默认值 |
| --- | --- | --- | --- | --- |
| 自动变量 | `auto` | 函数执行期间 | 每次调用重新初始化 | 随机值 |
| 寄存器变量 | `register` | 函数执行期间 | 同auto | 随机值 |
| 静态局部 | `static` | 程序整个运行期 | 只初始化一次 | 0 |
| 外部变量 | `extern` | 程序整个运行期 | 定义时初始化 | 0 |

**静态局部变量示例**：

```c
void counter() {
    static int count = 0; // 只初始化一次
    count++;
    printf("Count: %d\n", count);
}
// 调用3次输出：1, 2, 3
```

### 全局变量使用注意

- 尽量少用全局变量
- 若与局部变量同名，局部变量优先
- 静态全局变量（`static`修饰）限定文件内使用

## 6.6 函数的嵌套调用和递归调用

### 嵌套调用

函数A → 调用函数B → 调用函数C

```c
int factorial(int n) {   // 计算阶乘
    if(n == 0) return 1;
    return n * factorial(n-1);
}

int sum_factorial(int n) { // 计算阶乘和
    int sum = 0;
    for(int i=1; i<=n; i++)
        sum += factorial(i); // 嵌套调用
    return sum;
}
```

### 递归调用

**递归条件**：

1. 递归结束条件（递归出口）
2. 递归表达式（递归体）
3. 问题规模向终止条件递减

**递归示例**：

```c
// 阶乘计算
int fact(int n) {
    if(n <= 1) return 1;      // 递归出口
    return n * fact(n-1);     // 递归体
}

// 斐波那契数列
int fib(int n) {
    if(n < 2) return n;       // 递归出口
    return fib(n-1) + fib(n-2); // 递归体
}

// 字符串逆序输出
void reverse(char *str) {
    if(*str) {
        reverse(str+1);      // 递归调用
        putchar(*str);       // 逆序输出
    }
}
```

**递归注意事项**：

- 递归层次过深可能导致栈溢出
- 递归代码简洁但效率可能较低
- 重要应用：树结构遍历、分治算法等

### 递归经典案例

```c
// 汉诺塔问题
void hanoi(int n, char A, char B, char C) {
    if(n == 1) {
        printf("Move disk 1 from %c to %c\n", A, C);
    } else {
        hanoi(n-1, A, C, B);
        printf("Move disk %d from %c to %c\n", n, A, C);
        hanoi(n-1, B, A, C);
    }
}
```
