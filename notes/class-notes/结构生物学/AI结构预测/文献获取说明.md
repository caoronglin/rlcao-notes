## 获取途径（按优先级）

1. **学校图书馆订阅** — 西北农林科技大学图书馆的 Nature / Science / Elsevier / Wiley 数据库代理
2. **馆际互借 / 文献传递** — 对没有订阅的期刊，用 DOI 提交申请
3. **作者邮件索取** — Nature 系论文附 SharedIt 链接或通讯作者邮箱，多数会回复
4. **Unpaywall 网页版** — <https://unpaywall.org> 输入 DOI 可查看该文的全部开放版本
5. **bioRxiv 预印本** — 用浏览器直接访问 `biorxiv.org`，脚本被反爬拦截但人工可下

## 重跑方式

```bash
cd <项目目录>
env no_proxy='*' python3 work/download_pdfs.py '<输出目录>'          # 第一轮：Unpaywall + Europe PMC
env no_proxy='*' python3 work/download_pdfs_pass2.py '<输出目录>' '<报告路径>'   # 第二轮：渲染端点重试 + 出版商通道
```

> `no_proxy='*'` 是必需的：本机默认走本地代理，代理隧道不稳时会整片超时；直连反而更快更稳。
