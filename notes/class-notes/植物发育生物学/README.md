## 关键结论速查

**论文主张**：分生组织发育含两个耦合的过程——模式形成（细胞如何获得位置信息与命运）与形态发生（组织如何获得三维形状）。当前最大缺口在两者的接口：力学量既是模式的读出，也是模式的输入。

**四条实质修订**（2026-10-06）：

1. **CSLD5**（*Nat Commun* 2025, 16:7229）首次在**茎端分生组织本体**上测得壁刚度。但只能填"半边"——壁软化与该突变体同时造成的细胞周期阻滞未被解耦，跨层方向全自最外层出发。缺口因此被精确化为"缺**可解耦的因果链下半段**"。
2. **ERECTA–CLV3**（*Development* 2024, 151:dev202870）带来两条纠错：ERF 家族**不含 BAM**；该模型是手工拟合的定性模型而非定量模型。其"主动排除力学"的自述，正好为本文把力学显式纳入提供靶子。
3. **大麦 CLAVATA**（*Nat Commun* 2025, 16:3937）给出作物尺度的"什么时候停"：野生型大麦小穗轴开一朵即止，小麦可达 12 朵——"单花即止"是受体信号主动设定的性状。
4. **空间组学**两篇经全文检索确认**均无力学数据**，故论证改为用数据立论：快速生长窗口 P11–P15 恰是**转录静默**窗口。

**四处已修正的硬错误**：`[13]` 作者姓氏 `Hu` → **Hua**（PDF 首页为准，Crossref 字段有误）；壁截面积归属说反；微管"受压时不稳定" → **低张力下不稳定**且是**聚合**；CZ/PZ/RM 三分区补引。

**表述精确化**（2026-10-23，`SPEC.md` §1.4–§1.5）：Long 等的 32.2%/3.3% 原被误归属为"分生组织区标记"，实为 **VRT2** 在发育中穗轴 vs 颖/外稃；大麦"转录静默"由定性改为定量（P11–P15 **0 个 DEG**，P5 转换点 303 个）；细胞分裂素机制补为"经抑制肽酶 DA1 稳定 WUS 蛋白"；Dao 的增产靶点主张补回主语。同时按 humanizer 清单清掉行内加粗小标题、范式转折浮夸语、无主语被动归属等机器写作痕迹。顺带修掉 `build_tex.py` 会把参考文献生成 `size[J][J]` 的缺陷。

**23 篇全量回溯一手 PDF**（§1.5）：firecrawl 工具面本机不可用，改用本地 23 篇 PDF 逐条核。21 篇逐字吻合；另发现 §4.2 把双域受体假说的反证引到了 `[Cosgrove]`，实际出自 Coen & Cosgrove 2023 *Science* 物理页 5（Cosgrove 2024 综述全文无此反驳，其唯一的 "two domains" 指 expansin）；§5.2 原写大麦 CLV 通路"而非经由 WUS"，而该文从未检测大麦 WUS——已改为"WUS 未被检测，是否作用于 WUS 尚无数据"。

## 构建流水线

正文改动请落在 `work/paper_body_draft.md`（用 `[Cui]` 这类符号引用键），再依次：

```bash
python3 scripts/renumber_refs.py    # 草稿 → paper/paper.md，按出现顺序重编号
python3 scripts/build_tex.py        # paper.md → paper/paper.tex（含图表块）
xelatex paper.tex                   # 需先恢复 TeX Live
```

直接改 `paper/paper.md` 会在下次重编号时被覆盖。表格里的 `\cite` 由 `build_tex.py` 按第一作者姓氏反查解析，正文重编号后不会失效。
