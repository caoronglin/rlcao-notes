## 一、Python 依赖：系统 python3 没有 pandas/matplotlib

系统 `python3`（3.14）不带 pandas、matplotlib、openpyxl。**不要往系统环境里装**，用 `uv` 临时环境：

```bash
uv run --with "pandas>=3.0.1,<4.0.0" --with "numpy>=2.4.3,<3.0.0" \
       --with "openpyxl>=3.1.5,<4.0.0" --with "xlrd>=2.0.1,<3.0.0" \
       python3 <脚本.py>
```

带 `--with matplotlib` 同理；`uv` 有缓存，二次运行是毫秒级。

**注意**：`uv run` 会重建临时环境，**当前 shell 里的 `python3` 指向不会因此改变**；反之 `source conda.sh` 会改变 `python3` 指向，跨命令会串（本机 `/media/rlcao/Data/software` 曾经掉线导致 mamba 环境丢失，环境路径要现用现查）。

## 二、EMBOSS：本地装一份做交叉验证

```bash
mamba create -y -n emboss_env -c conda-forge -c bioconda emboss
export EMBOSS_DATA=<env>/share/EMBOSS/data
export PATH=<env>/bin:$PATH
needle -asequence a.fa -bsequence b.fa -datafile EDNAFULL \
       -gapopen 10.0 -gapextend 0.5 -aformat3 clustal -outfile stdout -auto
```

| 坑 | 现象 | 处理 |
|---|---|---|
| 矩阵名 | `-datafile DNAfull` 报 `Unable to read matrix 'DNAfull'` | 本地文件叫 `EDNAFULL`/`EDNAMAT`/`EBLOSUM62`；EBI 网页标签才是 DNAfull |
| 矩阵目录 | 找不到矩阵 | 必须设 `EMBOSS_DATA=<env>/share/EMBOSS/data` |
| 输出为空 | 文件 0 字节 | 必须加 `-outfile stdout`（或 `-outfile x.txt`） |
| `-stype` | `Unknown qualifier -stype` | 本地 needle/water 没有这个限定符，靠序列自动判别；只有 EBI REST 需要显式传 `stype=dna` |

## 三、EBI 在线 EMBOSS：主站会限流

- `https://www.ebi.ac.uk/Tools/services/rest/<tool>/run` 对某些 IP 返回
  `You have been temporarily blocked from submitting new sequence analysis jobs`（JDispatcher 公平使用策略）。
- **可用替代**：`https://wwwdev.ebi.ac.uk/Tools/services/rest/...`（同一套 Job Dispatcher 的开发镜像）。
- 开发镜像的 SLURM 后端偶发 503，任务会一直 `QUEUED`，需要重试提交。

**REST 接口的三个细节**（与网页表单不同）：

1. 矩阵填 **EMBOSS 内部名**（`EDNAFULL`/`EDNAMAT`/`EBLOSUM62`），填 `DNAfull` 报 `Value for "matrix" is not valid`。
2. `status/<jobid>` 返回**纯文本**（`QUEUED`/`RUNNING`/`FINISHED`），不是 JSON；`jobid` 要 `.strip()`。
3. `resulttypes/<jobid>` 返回 **XML**（`<identifier>`），其中输出标识符是 `out` 而不是 `outfile`。

**交叉验证**：本地 EMBOSS 6.6.0 与 EBI 在线 EMBOSS 6.6.0 同版本同默认值，8 组比对的 Length / Identity / Similarity / Gaps / Score 逐项一致（可作为报告里的"同源两路计算互证"证据）。

## 四、NCBI E-utilities

- `email` 参数必填，缺失会被限流。
- 长序列用 GET 提交会 `414 Request-URI Too Long`，BLAST URL API 同理。
- `esummary` 的 `version` 字段常为空，取准确版本号要用 `efetch`（FASTA 头里带 `NM_001963.6`）或 `accessionversion`。
- 登录号会被回收复用（`NP_005623` → calpain-15；`NM_003001` → SDHC），**必须同时记 version 与 title**。

## 五、md → PDF：pandoc + Chrome（无 LaTeX）

本机没有 LaTeX，但有 `google-chrome-stable`。链路：`pandoc` → 独立 HTML → Chrome headless 打印 PDF。

```bash
uv run --with pypandoc-binary python3 mkpdf.py     # pypandoc 自带 pandoc 3.9 二进制
google-chrome-stable --headless --disable-gpu --no-sandbox \
  --no-pdf-header-footer --allow-file-access-from-files \
  --print-to-pdf=out.pdf --virtual-time-budget=20000 file:///abs/path.html
```

**两个必须踩过才知道的坑**：

1. **pandoc 自带 CSS 会把正文压成 36em 宽**（`body { max-width: 36em; padding: 50px }`）。不覆盖的话，正文只有约 11 cm 宽，页数虚高、字号被迫调小。注入自己的 `<style>` 时要显式写
   `body { max-width: none; margin: 0; padding: 0; }`。
2. **CSS 注入位置**：pandoc 的默认 `<style>` 在 `</head>` 之前，自定义 CSS 要追加在 `</head>` 之前才能覆盖它。

**A4 排版基线**（5 页正文 + 3 张图 + 5 张表的实测配置）：

```css
@page { size: A4; margin: 10mm 12mm 9mm 12mm; }
body { font-size: 8.9pt; line-height: 1.30; max-width: none; margin: 0; padding: 0; }
table { font-size: 7.2pt; page-break-inside: avoid; }
img { max-width: 42%; page-break-inside: avoid; }
pre code { font-size: 7.0pt; }
```

正文 8.6–8.9 pt 是"5 页硬约束 + 表格多"下的折中；题干要求"不要为了页数把字体调得太小"，所以更该砍文字和图幅，而不是压到 7 pt 以下。

## 七、Obsidian 侧

- 插件数据文件（`*.duowei`）在 Obsidian **未运行时**可直接改 JSON；开着的时候改会被内存版本覆盖。
