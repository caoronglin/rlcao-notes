# 笔记工作流使用指南

## 每天怎么用

1. 打开 [[Home|个人工作台]]，先写“今日日记”的今日三件事。
2. 新实验点“新建实验”，记录样品、参数、原始数据位置与观察；关联项目填完整笔记链接。
3. 课题或任务点“新建项目”，明确完成标准和下一步；在项目总览表中维护状态、截止日期。
4. 下班前点“每日总结”，补充完成情况、问题和明日计划。

首页按“今日计划”“进行中项目与实验”“历史与待整理清单”分组：只有今天日记里的计划，以及明确标为 `进行中` 的项目/实验清单直接展开。日记中“明日计划”不提前计入今天；旧清单折叠保留，勾选仍写回原笔记，不会自动判断项目是否完成。项目状态为 `待整理` 或未填写时，请在项目管理中按实际情况维护。

首页下方按学习、科研、收集管理分组提供入口；上方统计卡片也可以直接进入对应总览。

## 大纲笔记与导图

- 新建大纲后，以标题和缩进列表写作。
- **Ctrl+Alt+M**：用自研插件 XL Toolbox 打开当前笔记的导图，Markdown 仍是唯一内容源。
- 导图右侧工具栏：重新生成、全部展开、折到 2 层、适应窗口、缩放、导出 SVG/PNG。
- 点节点跳到原文对应行；带 `+N` 的圆点可折叠子树。长文本按卡片宽度换行，最多 6 行后省略。
- **Ctrl+Alt+S**：直接导出当前笔记的导图 SVG（写到笔记同目录，同名文件自动加序号）。
- Canvas 适合自由布局、连线和混合附件，与自动生成的大纲导图互补。

## 多维表格与项目管理

- [[vault/工作台/项目管理]]、[[vault/工作台/实验管理]]、[[vault/工作台/文献管理]]使用内置 Bases：每行是笔记，属性直接存回 Markdown。
- [[vault/工作台/独立工作表.duowei|独立工作表]]用于不需要每行成为笔记的数据；已配置表格、状态看板、附件画廊。
- 独立表字段为标题、状态、完成、日期、关联笔记、附件、数值、备注。可从空表开始添加真实数据。
- Duowei 自动备份间隔 10 分钟，保留 12 份，同目录带“自动备份”字样的文件不要当成正式表编辑；备份与当前库在同一设备上，不等于异地备份。

## 附件与云文档

- [[vault/工作台/附件浏览]]按文件汇总本地附件。
- PDF、图片可直接预览；HTML 用内置网页查看器或系统浏览器打开；Office 文件走系统关联软件。
- “添加云文档”会要求标题和真实链接，生成原始链接、iframe 和本地摘记区。
- 金山/飞书是否允许 iframe，取决于该文档的分享权限、平台策略和当前登录状态。拒绝嵌入时，用原始链接在内置网页查看器或系统浏览器打开。
- 当前没有用户提供的金山/飞书链接，因此没有宣称已验证私人文档的登录和内嵌效果，也没有修改任何分享权限。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+Alt+N | 打开 QuickAdd 工作流选择器 |
| Ctrl+Alt+M | 当前笔记生成导图（XL Toolbox） |
| Ctrl+Alt+S | 导出当前笔记导图 SVG |
| Ctrl+Alt+Z | 从 Zotero 导入/更新文献笔记 |
| Ctrl+Alt+C | 插入文献引用 |
| Ctrl+Alt+Q | 收集闪念到收件箱 |

## 目录约定

- `vault/大纲笔记`：大纲与知识梳理。
- `vault/实验记录`：按实验日期记录实际过程。
- `vault/项目`：具体项目与资料索引，BSA 和 maize-ltr 资料已归入这里。
- `vault/日记`：每日记录与总结，原路径保留。
- `vault/文献笔记`：Zotero 导入笔记，原路径保留。
- `vault/方法`：实验方法、生信分析、甲基化流程。
- `vault/系统与工具`：电脑与服务器配置资料。
- `vault/工作台`：总览视图、独立表、云文档入口和本指南。
- `muban`：模板；`panel`：工作台组件；`assets`：附件。
- `notes`、`wiki`、`_posts`保持为三个独立项目，未合并或搬动。
