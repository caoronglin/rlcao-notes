# 1.2Python语言简介

# Python运算符优先级和结合性详细总结

## 运算符优先级和结合性表格

| 优先级 | 运算符 | 描述 | 结合性 |
| --- | --- | --- | --- |
| 1 | `(expressions...)`, `[expressions...]`, `{key: value...}`, `{expressions...}` | 圆括号、列表、字典、集合表达式 | 从左到右 |
| 2 | `x[index]`, `x[index:index]`, `x(arguments...)`, `x.attribute` | 下标、切片、调用、属性引用 | 从左到右 |
| 3 | `await x` | 等待表达式 | 无 |
| 4 | `**` | 幂运算 | 从右到左 |
| 5 | `+x`, `-x`, `~x` | 正号、负号、按位取反 | 无 |
| 6 | `*`, `@`, `/`, `//`, `%` | 乘、矩阵乘、除、整除、取模 | 从左到右 |
| 7 | `+`, `-` | 加、减 | 从左到右 |
| 8 | `<<`, `>>` | 左移、右移 | 从左到右 |
| 9 | `&` | 按位与 | 从左到右 |
| 10 | `^` | 按位异或 | 从左到右 |
| 11 | ` | ` | 按位或 |
| 12 | `in`, `not in`, `is`, `is not`, `<`, `<=`, `>`, `>=`, `!=`, `==` | 成员测试、身份测试、比较 | 从左到右 |
| 13 | `not x` | 逻辑非 | 无 |
| 14 | `and` | 逻辑与 | 从左到右 |
| 15 | `or` | 逻辑或 | 从左到右 |
| 16 | `if-else` | 条件表达式（三元运算符） | 从右到左 |
| 17 | `lambda` | Lambda表达式 | 无 |
| 18 | `:=` | 海象运算符（赋值表达式） | 从右到左 |

## 详细说明

### 优先级说明

- **数字越小，优先级越高**：优先级1的运算符最先执行，优先级18的运算符最后执行
- **相同优先级的运算符**：按照结合性规则执行

### 结合性说明

- **从左到右**：运算符从左向右计算，如 `a + b + c` 等价于 `(a + b) + c`
- **从右到左**：运算符从右向左计算，如 `a ** b ** c` 等价于 `a ** (b ** c)`
- **无**：运算符不支持组合，如 `-a` 不能写为 `- -a`（但实际可写为 `-(-a)`）

## 各优先级运算符详解

### 优先级1：括号和容器表达式

```python
# 圆括号
result = (2 + 3) * 4  # 20，不是14

# 列表
my_list = [1, 2, 3, 4]

# 字典
my_dict = {'name': 'Alice', 'age': 25}

# 集合
my_set = {1, 2, 3, 4}
```

### 优先级2：下标、切片、调用和属性引用

```python
# 下标
my_list = [1, 2, 3]
print(my_list[0])  # 1

# 切片
my_list = [1, 2, 3, 4, 5]
print(my_list[1:4])  # [2, 3, 4]

# 调用
def greet(name):
    return f"Hello, {name}!"

print(greet("Alice"))  # Hello, Alice!

# 属性引用
class Person:
    def __init__(self, name):
        self.name = name

p = Person("Alice")
print(p.name)  # Alice
```

### 优先级3：await表达式

```python
async def my_coroutine():
    return "Hello"

async def main():
    result = await my_coroutine()
    print(result)  # Hello
```

### 优先级4：幂运算

```python
# 幂运算是从右到左结合
print(2 ** 3 ** 2)  # 512，等价于 2 ** (3 ** 2)
print((2 ** 3) ** 2)  # 64
```

### 优先级5：一元运算符

```python
# 正号、负号、按位取反
x = 5
print(+x)  # 5
print(-x)  # -5
print(~x)  # -6（按位取反）
```

### 优先级6：乘法类运算符

```python
# 乘、矩阵乘、除、整除、取模
a, b = 10, 3
print(a * b)    # 30（乘法）
print(a @ b)    # 矩阵乘法（需要numpy等库）
print(a / b)    # 3.333...（除法）
print(a // b)   # 3（整除）
print(a % b)    # 1（取模）
```

### 优先级7：加减法

```python
# 加法、减法
a, b = 10, 3
print(a + b)  # 13
print(a - b)  # 7
```

### 优先级8：位移运算符

```python
# 左移、右移
a = 10  # 二进制：1010
print(a << 2)  # 40（二进制：101000）
print(a >> 1)  # 5（二进制：101）
```

### 优先级9-11：位运算符

```python
a, b = 5, 3  # 二进制：101, 011

# 按位与
print(a & b)  # 1（二进制：001）

# 按位异或
print(a ^ b)  # 6（二进制：110）

# 按位或
print(a | b)  # 7（二进制：111）
```

### 优先级12：比较和成员运算符

```python
# 比较运算符
a, b = 5, 3
print(a > b)   # True
print(a < b)   # False
print(a == b)  # False
print(a != b)  # True

# 成员测试
my_list = [1, 2, 3]
print(2 in my_list)      # True
print(4 not in my_list)  # True

# 身份测试
x = [1, 2, 3]
y = x
z = [1, 2, 3]
print(x is y)      # True（同一对象）
print(x is z)      # False（不同对象，但值相同）
print(x is not z)  # True
```

### 优先级13-15：逻辑运算符

```python
a, b, c = True, False, True

# 逻辑非
print(not a)  # False

# 逻辑与
print(a and b)  # False

# 逻辑或
print(a or b)  # True

# 短路求值
print(a or (1/0))  # True（不会执行1/0）
print(b and (1/0))  # 报错（会执行1/0）
```

### 优先级16：条件表达式

```python
# 三元运算符
x = 10
y = 20
result = "x is greater" if x > y else "y is greater"
print(result)  # "y is greater"

# 结合性从右到左
result = "A" if True else "B" if False else "C"
# 等价于 "A" if True else ("B" if False else "C")
print(result)  # "A"
```

### 优先级17：Lambda表达式

```python
# Lambda表达式
square = lambda x: x ** 2
print(square(5))  # 25

# 与其他运算符结合
functions = [lambda x: x + 1, lambda x: x * 2]
print(functions[0](5))  # 6
print(functions[1](5))  # 10
```

### 优先级18：海象运算符

```python
# 海象运算符（Python 3.8+）
if (n := len("hello")) > 3:
    print(f"Length is {n}")  # Length is 5

# 在列表推导式中使用
numbers = [1, 2, 3, 4, 5]
squares = [sq for x in numbers if (sq := x ** 2) > 4]
print(squares)  # [9, 16, 25]
```

## 实际应用示例

### 复杂表达式分析

```python
# 示例1：混合运算
result = 2 + 3 * 4 ** 2 // 5 - 1
# 计算步骤：
# 1. 4 ** 2 = 16（幂运算，优先级4）
# 2. 3 * 16 = 48（乘法，优先级6）
# 3. 48 // 5 = 9（整除，优先级6）
# 4. 2 + 9 = 11（加法，优先级7）
# 5. 11 - 1 = 10（减法，优先级7）
print(result)  # 10

# 示例2：逻辑和比较混合
result = 5 > 3 and 2 < 4 or not 1 == 1
# 计算步骤：
# 1. 5 > 3 = True（比较，优先级12）
# 2. 2 < 4 = True（比较，优先级12）
# 3. 1 == 1 = True（比较，优先级12）
# 4. not True = False（逻辑非，优先级13）
# 5. True and True = True（逻辑与，优先级14）
# 6. True or False = True（逻辑或，优先级15）
print(result)  # True
```

## 最佳实践和注意事项

### 1. 使用括号明确优先级

```python
# 不推荐：依赖默认优先级
result = 2 + 3 * 4  # 可能产生歧义

# 推荐：使用括号明确意图
result = 2 + (3 * 4)  # 清晰表达计算顺序
```

### 2. 链式比较的特殊处理

```python
# Python支持链式比较，数学上更直观
x = 5
print(1 < x < 10)  # True，等价于 1 < x and x < 10
print(1 < x < 3)   # False
```

### 3. 短路求值的利用

```python
# 利用短路求值提高效率
def expensive_function():
    print("Expensive function called")
    return True

# 如果第一个条件为False，不会调用expensive_function
result = False and expensive_function()  # 不会打印

# 如果第一个条件为True，会调用expensive_function
result = True and expensive_function()   # 会打印
```

### 4. 位运算符的特殊用途

```python
# 位运算符的实用技巧
# 快速判断奇偶
x = 5
print(x & 1)  # 1（奇数），0（偶数）

# 快速交换两个数（不使用临时变量）
a, b = 5, 3
a ^= b
b ^= a
a ^= b
print(a, b)  # 3, 5
```

### 5. 海象运算符的使用场景

```python
# 避免重复计算
import math
# 传统方式
radius = 5
circumference = 2 * math.pi * radius
if circumference > 10:
    print(f"Circumference is {circumference}")

# 使用海象运算符
if (circumference := 2 * math.pi * 5) > 10:
    print(f"Circumference is {circumference}")
```

## 常见错误和陷阱

### 1. 运算符优先级误解

```python
# 常见错误：误认为and优先级高于or
result = True or False and False
# 实际计算：True or (False and False) = True
# 误认为：(True or False) and False = False
print(result)  # True
```

### 2. 混淆is和==

```python
# is比较对象身份，==比较对象值
a = [1, 2, 3]
b = [1, 2, 3]
c = a

print(a == b)  # True（值相同）
print(a is b)  # False（不同对象）
print(a is c)  # True（同一对象）
```

### 3. 整数除法的陷阱

```python
# Python 3中/总是返回浮点数
print(5 / 2)   # 2.5
print(5 // 2)  # 2（整除）
```

### 4. 负数的取模运算

```python
# 负数取模的结果可能出乎意料
print(10 % 3)   # 1
print(-10 % 3)  # 2（因为 -10 = -4*3 + 2）
print(10 % -3)  # -2（因为 10 = -4*-3 + (-2)）
```
