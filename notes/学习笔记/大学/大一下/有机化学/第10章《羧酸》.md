### **§10-1 羧酸**

#### **1. 分类与命名**

- **分类**：

- 脂肪羧酸（饱和、不饱和）
- 芳香羧酸（如苯甲酸）
- 二元羧酸（如草酸、琥珀酸）

- **命名**：

- 系统命名：选含羧基的最长碳链为主链（如`3-甲基丁酸`）。
- 俗名：草酸（乙二酸）、琥珀酸（丁二酸）、巴豆酸（反-2-丁烯酸）。

#### **2. 结构与性质**

- **p-π共轭**：羧基中C=O与-OH形成共轭体系，使O-H极性增强→酸性增强。
- **氢键作用**：羧酸易形成二聚体（沸点高于同分子量醇）。

#### **3. 化学性质**

| **反应类型** | **条件/试剂** | **产物/应用** |
| --- | --- | --- |
| **酸性** | NaOH/NaHCO₃ | 羧酸盐（**酸性强弱**：HCl > RCOOH > H₂CO₃ > ArOH） |
| **取代反应** | <br> | <br> |
| - 酰氯生成 | SOCl₂, PCl₅ | RCOCl（高活性酰化试剂） |
| - 酯化反应 | ROH/H⁺（酸催化） | RCOOR'（1°/2°醇：氧氢断键；3°醇：碳氧断键） |
| - 酸酐生成 | 脱水剂(P₂O₅) | (RCO)₂O |
| - 酰胺生成 | NH₃ | RCONH₂ |
| **脱羧反应** | <br> | <br> |
| - α-吸电子基羧酸 | 加热 | 脱CO₂（如Cl₃CCOOH → CHCl₃） |
| - β-酮酸 | 室温 | 酮 + CO₂（如乙酰乙酸 → 丙酮） |
| - 二元酸脱羧 | 加热 | C₂-C₃：脱羧；C₄-C₅：脱水成酐；C₆-C₇：脱羧脱水 |
| **α-H卤代** | X₂/P（Hell-Volhard-Zelinsky） | α-卤代羧酸（如CH₃CH₂COOH → BrCH₂CH₂COOH） |
| **还原反应** | LiAlH₄ | 伯醇（甲酸、草酸可被弱还原剂还原） |

> **酸性影响因素**：
>
>   - 吸电子基（-Cl, -NO₂）→ 酸性↑（如Cl₃CCOOH pKa=0.65）
>   - 供电子基（-CH₃）→ 酸性↓（如(CH₃)₃CCOOH pKa=5.03）
>   - 吸电子基距离羧基越近，酸性越强（如ClCH₂COOH > ClCH₂CH₂COOH）

### **§10-2 羧酸衍生物**

#### **1. 命名与结构**

| **类型** | **命名规则** | **例子** |
| --- | --- | --- |
| **酰卤** | 某酰卤 | 乙酰氯、苯甲酰氯 |
| **酸酐** | 某酸酐 | 乙酸酐、邻苯二甲酸酐 |
| **酯** | 某酸某酯 | 乙酸乙酯、阿司匹林（乙酰水杨酸酯） |
| **酰胺** | 某酰胺；N-取代基某酰胺 | 乙酰胺、N,N-二甲基甲酰胺（DMF） |
| **酰亚胺** | 某酰亚胺 | 邻苯二甲酰亚胺 |

- **反应活性顺序**：酰氯 > 酸酐 > 酯 > 酰胺（受p-π共轭和-I效应影响）。

#### **2. 化学性质**

| **反应类型** | **通式** | **应用** |
| --- | --- | --- |
| **水解** | RCOZ + H₂O → RCOOH + HZ | 酰氯室温水解；酯/酰胺需加热 |
| **醇解** | RCOZ + R'OH → RCOOR' + HZ | 酯交换（合成新酯） |
| **氨解** | RCOZ + NH₃ → RCONH₂ + HZ | 合成酰胺 |

**特殊性质**：  

- **酰胺**：

- 中性（p-π共轭降低N碱性）；酰亚胺显弱酸性。
- **Hofmann降解**：RCONH₂ + Br₂/NaOH → RNH₂（少1个C的伯胺）。

- **酯**：

- **Claisen缩合**：2分子酯在碱作用下生成β-酮酸酯（如乙酰乙酸乙酯）。

#### **3. 乙酰乙酸乙酯（AAE）**

- **互变异构**：酮式（92.5%）⇌ 烯醇式（7.5%）。

- 烯醇式验证：FeCl₃显紫色、Br₂/CCl₄褪色。

- **合成应用**：

- **酮式分解**：稀OH⁻ → 取代丙酮（RCOCH₂R'）。
- **酸式分解**：浓OH⁻ → 取代乙酸（RCH₂COOH）。

#### **4. 丙二酸二乙酯（DEM）**

- **合成应用**：

- 水解脱羧 → 取代乙酸（RCH₂COOH）。
- 例：合成环戊基乙酸。

### **§10-3 取代酸**

#### **1. 羟基酸**

- **命名**：乳酸（2-羟基丙酸）、水杨酸（邻羟基苯甲酸）、柠檬酸（3-羧基-3-羟基戊二酸）。
- **性质**：

| **脱水方式** | **条件** | **产物** |
| --- | --- | --- |
| **α-羟基酸** | 加热 | 交酯（环状二酯） |
| **β-羟基酸** | 加热 | α,β-不饱和酸（如巴豆酸） |
| **γ/δ-羟基酸** | 室温/加热 | 内酯（五/六元环） |

- **氧化**：α-羟基酸 → α-酮酸（如乳酸 → 丙酮酸）。
- **酚酸脱羧**：邻/对羟基苯甲酸加热脱羧成酚。

#### **2. 羰基酸**

- **命名**：丙酮酸（2-氧代丙酸）、乙酰乙酸（3-氧代丁酸）。
- **性质**：

- **氧化**：α-酮酸 → 少1个C的羧酸（如丙酮酸 → 乙酸 + CO₂）。
- **脱羧**：β-酮酸 → 酮 + CO₂（如乙酰乙酸 → 丙酮）。

### **综合鉴别方法**

| **试剂** | **阳性反应对象** | **现象** |
| --- | --- | --- |
| **NaHCO₃** | 羧酸（pKa < 10） | 气泡（CO₂） |
| **FeCl₃** | 烯醇式结构（如AAE）、酚酸 | 紫色（水杨酸显紫红色） |
| **2,4-DNPH** | 醛酮、α-酮酸 | 黄色沉淀 |
| **Tollen试剂** | 甲酸、醛类 | 银镜 |
| **Br₂/H₂O** | 烯醇式（AAE）、不饱和酸 | 褪色 |

---

### **典型合成应用**

1. **延长碳链**：

- **丙二酸二乙酯** → 取代乙酸（RCH₂COOH）。
- **乙酰乙酸乙酯** → 取代丙酮（RCOCH₃）。

2. **减少碳链**：

- **Hofmann降解**：RCONH₂ → RNH₂（少1个C）。
- **脱羧反应**：二元酸（如草酸）加热脱CO₂。
