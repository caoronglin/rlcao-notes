# 7.1文件

## 以下是对Python文件操作的全面总结，涵盖文件打开、读写、关闭、上下文管理、常见模式、二进制文件、文件指针、目录操作、异常处理等核心知识点，便于快速掌握和实际应用。

---

## 一、文件基础

### 1. 文件操作流程

Python文件操作一般遵循三个步骤：

1. **打开文件**：使用`open()`函数，获得文件对象。
2. **操作文件**：通过文件对象进行读写。
3. **关闭文件**：使用`close()`方法，释放资源。

> 推荐使用`with`语句自动管理文件关闭，避免忘记或异常导致资源泄漏。

---

## 二、打开文件（open函数）

### 1. 基本语法

```python
open(file, mode='r', buffering=-1, encoding=None, errors=None, newline=None, closefd=True, opener=None)
```

- `file`：文件路径（相对或绝对）。
- `mode`：打开模式（见下表）。
- `encoding`：文本模式下指定编码（如`'utf-8'`）。

### 2. 常见打开模式

| 模式 | 说明 |
| --- | --- |
| `'r'` | 只读（默认） |
| `'w'` | 写入（会覆盖已有文件） |
| `'a'` | 追加（在文件末尾写入） |
| `'rb'` | 二进制只读 |
| `'wb'` | 二进制写入 |
| `'ab'` | 二进制追加 |
| `'r+'` | 读写（文件必须存在） |
| `'w+'` | 读写（会覆盖已有文件） |
| `'a+'` | 读写（追加模式） |

### 3. 示例

```python
# 只读模式打开
with open('example.txt', 'r', encoding='utf-8') as f:
    content = f.read()
```

## 三、文件读写

### 1. 写入（write）

```python
with open('example.txt', 'w', encoding='utf-8') as f:
    f.write("Hello, Python!")
```

- `'w'`模式会覆盖原有内容，`'a'`模式则追加。

### 2. 读取

#### （1）read()：读取全部内容

```python
with open('example.txt', 'r') as f:
    content = f.read()  # 读取整个文件
```

#### （2）readline()：逐行读取

```python
with open('example.txt', 'r') as f:
    line = f.readline()  # 每次读取一行
    while line:
        print(line.strip())
        line = f.readline()
```

#### （3）readlines()：读取所有行到列表

```python
with open('example.txt', 'r') as f:
    lines = f.readlines()  # 返回列表，每行一个元素
```

### 3. 二进制文件读写

```python
# 二进制写入
with open('example.bin', 'wb') as f:
    f.write(b'\x00\x01\x02')

# 二进制读取
with open('example.bin', 'rb') as f:
    data = f.read()
```

## 四、上下文管理（with语句）

`with`语句可以自动管理文件的打开和关闭，即使发生异常也能正确关闭文件。

```python
with open('example.txt', 'r') as f:
    for line in f:
        print(line.strip())
# 文件自动关闭
```

## 五、文件指针

文件对象内部维护一个指针，指示当前读写位置。

- `tell()`：返回当前指针位置。
- `seek(offset, whence)`：移动指针。

- `whence=0`（默认）：从文件开头。
- `whence=1`：从当前位置。
- `whence=2`：从文件末尾。

```python
with open('example.txt', 'r') as f:
    print(f.tell())  # 初始位置0
    f.seek(5)        # 移动到第5字节
    print(f.read())  # 从第5字节开始读取
```

## 六、目录与文件管理（os模块）

### 1. 常用os模块函数

```python
import os

# 获取当前工作目录
os.getcwd()

# 列出目录内容
os.listdir('path')

# 创建目录
os.mkdir('dir')          # 单级目录
os.makedirs('dir/sub')   # 多级目录

# 删除文件/目录
os.remove('file.txt')    # 删除文件
os.rmdir('dir')          # 删除空目录
os.removedirs('dir/sub') # 删除多级空目录

# 重命名文件/目录
os.rename('old.txt', 'new.txt')

# 切换工作目录
os.chdir('path')
```

### 2. os.path模块

```python
import os.path

# 拼接路径
os.path.join('dir', 'file.txt')

# 获取绝对路径
os.path.abspath('file.txt')

# 判断是否存在
os.path.exists('file.txt')

# 判断是否为文件/目录
os.path.isfile('file.txt')
os.path.isdir('dir')

# 分离路径和文件名
os.path.split('/path/to/file.txt')  # ('/path/to', 'file.txt')
```

## 七、异常处理

文件操作可能遇到异常（如文件不存在、权限不足），建议使用`try...except`捕获。

```python
try:
    with open('nonexistent.txt', 'r') as f:
        content = f.read()
except FileNotFoundError:
    print("文件不存在！")
except PermissionError:
    print("没有权限！")
except Exception as e:
    print(f"发生错误: {e}")
```

## 八、常见文件格式读写示例

### 1. CSV文件

```python
import csv

# 写入
with open('data.csv', 'w', newline='') as f:
    writer = csv.writer(f)
    writer.writerow(['Name', 'Age'])
    writer.writerow(['Alice', 25])

# 读取
with open('data.csv', 'r') as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)
```

### 2. JSON文件

```python
import json

# 写入
data = {'name': 'Alice', 'age': 25}
with open('data.json', 'w') as f:
    json.dump(data, f)

# 读取
with open('data.json', 'r') as f:
    data = json.load(f)
    print(data)
```

## 九、最佳实践

1. **使用**`with`**语句**：自动管理资源，避免忘记关闭文件。
2. **明确文件模式**：根据需求选择`'r'`、`'w'`、`'a'`等模式。
3. **处理异常**：捕获并处理可能出现的文件异常。
4. **路径处理**：使用`os.path.join`拼接路径，增强跨平台兼容性。
5. **大文件逐行处理**：使用`readline()`或直接迭代文件对象，避免内存问题。
6. **二进制模式处理非文本文件**：如图片、视频等。
