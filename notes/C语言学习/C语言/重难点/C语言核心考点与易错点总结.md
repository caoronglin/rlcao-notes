# C语言核心考点与易错点总结

## [第4章 数组](about:blank)

### 易错点

1. **数组越界访问**：C语言不检查下标越界（如`int a[5]; a[5]=10;`）
2. **二维数组初始化**：

```c
int a[2][3] = {{5,6},{7,8}};  // 正确：{{5,6,0},{7,8,0}}
int b[2][3] = {5,6,7,8};     // 正确：{{5,6,7},{8,0,0}}
```

3. **字符数组 vs 字符串**：

- `char s1[] = {'a','b'};` // 无结束符
- `char s2[] = "ab";`      // 自动补'\0'

### 重难点

1. **排序算法**：

- 冒泡排序：双重循环相邻比较（`for(j=0;j<n-i-1;j++)`）
- 选择排序：每轮选最小元素交换

2. **二分查找**：**必须是有序数组**，时间复杂度O(log₂n)

```c
while(low<=high){
  mid=(low+high)/2;
  if(x==a[mid]) return mid;
  else if(x<a[mid]) high=mid-1;
  else low=mid+1;
}
```

### 关键函数

| 函数 | 作用 | 注意点 |
| --- | --- | --- |
| `strlen(s)` | 字符串长度 | 不包含'\0' |
| `strcpy(d,s)` | 字符串复制 | d需足够空间 |
| `strcmp(s1,s2)` | 字符串比较 | 返回0表示相等 |
| `strcat(d,s)` | 字符串拼接 | d需足够空间 |

## 第5章 指针

### 易错点

1. **野指针**：未初始化的指针直接使用（`int *p; *p=10;`）
2. **指针类型匹配**：

```c
int a; float *p=&a; // 错误！类型不匹配
```

3. **指针运算**：`p+1`实际移动**数据类型字节数**

### 重难点

1. **指针与数组关系**：

- `a[i]` ⇔ `*(a+i)`
- 二维数组：`int a[3][4]`中：

- `a+1` → 移动一行(16字节)
- `a[0]+1` → 移动一列(4字节)

2. **多级指针**：

- `int **p;` → 指向指针的指针
- `char *str[] = {"A","B"};` → 指针数组

### 关键概念

```c
int *p[5];   // 指针数组（5个int指针）
int (*p)[5]; // 数组指针（指向含5元素的数组）
```

## 第6章 函数

### 易错点

1. **参数传递方式**：

- 值传递：形参修改不影响实参（普通变量）
- 地址传递：可修改实参（数组/指针）

2. **递归出口缺失**：导致栈溢出

```c
// 必须有递归终止条件！
int fact(int n){
  if(n<=1) return 1; // 出口
  else return n*fact(n-1);
}
```

### 重难点

1. **变量作用域**：

- 局部变量：函数内有效
- 静态变量`static`：生存期延长至程序结束
- 全局变量：所有函数共享（慎用！）

2. **命令行参数**：

```c
int main(int argc, char *argv[]){
  // argc: 参数个数
  // argv[0]: 程序名
}
```

### 关键用法

```c
// 函数指针：实现回调机制
int (*pfun)(int,int);
pfun = max; // 指向max函数
c = pfun(a,b); // 等价于c=max(a,b)
```

## 第8章 文件

### 易错点

1. **文件打开模式混淆**：

- `"r"`：文件必须存在
- `"w"`：清空原内容
- `"a"`：追加写入

2. **文件关闭遗漏**：导致数据丢失或资源泄漏

```c
FILE *fp = fopen("a.txt","r");
// ...操作...
fclose(fp); // 必须关闭！
```

### 重难点

1. **文件定位函数**：

```c
fseek(fp, offset, SEEK_SET); // 文件头偏移
rewind(fp);                  // 重置到文件头
ftell(fp);                   // 获取当前位置
```

2. **二进制文件操作**：

```c
while(fread(&data,sizeof(data),1,fp)==1){
  // 成功读取一个数据块
}
```

- 读写用`fread/fwrite`
- **不能用**`feof()`**判断结束**（用返回值判断）

### 核心函数

| 函数 | 作用 |
| --- | --- |
| `fopen("f","mode")` | 打开文件 |
| `fprintf(fp,"%d",i)` | 格式化写入 |
| `fscanf(fp,"%d",&i)` | 格式化读取 |
| `fgetc(fp)` | 读取字符 |
| `fputs(s,fp)` | 写入字符串 |
| `feof(fp)` | **仅文本文件**结束判断 |

> **最易忽视**：文件路径转义
> `fopen("C:\\data.txt","r")` ← 必须用双反斜杠或单正斜杠
