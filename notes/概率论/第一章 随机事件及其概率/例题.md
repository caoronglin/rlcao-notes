# 例题

### 1. **事件的概率计算**

**题目：**
抛一枚均匀的骰子，求出现偶数点数的概率。

**解答：**
样本空间为 ( S = { 1, 2, 3, 4, 5, 6 } )。
偶数点数的样本为 ( { 2, 4, 6 } )。
所以，出现偶数点数的概率为：$P(\text{偶数}) = \frac{3}{6} = 0.5$​

### 2. **条件概率**

**题目：**
某个盒子中有7个白球和3个黑球，随机抽取两个球，若已知第一次抽到的是白球，求第二次抽到白球的概率。

**解答：**
第一次抽到白球后，盒中剩余的球为6个白球和3个黑球。
第二次抽到白球的条件概率为：$P(\text{第二次白球}|\text{第一次白球}) = \frac{6}{9} = \frac{2}{3}$​

### 3. **全概率公式**

**题目：**
某人有50%的概率选择乘火车，30%的概率选择乘飞机，20%的概率选择乘汽车。已知乘火车时，迟到的概率是0.3，乘飞机时，迟到的概率是0.1，乘汽车时，迟到的概率是0.2。求该人迟到的总概率。

**解答：**
设 ( A_1 ) 表示选择火车，( A_2 ) 表示选择飞机，( A_3 ) 表示选择汽车，( B ) 表示迟到。
根据全概率公式：$P(B) = P(A_1) \cdot P(B|A_1) + P(A_2) \cdot P(B|A_2) + P(A_3) \cdot P(B|A_3)$
代入数据：$P(B) = 0.5 \cdot 0.3 + 0.3 \cdot 0.1 + 0.2 \cdot 0.2 = 0.15 + 0.03 + 0.04 = 0.22$
所以，该人迟到的总概率为 0.22。

### 4. **贝叶斯公式**

**题目：**
某地区患癌症的人占0.005，患癌症的人对某种检测的阳性反应率为0.95，正常人对该检测的阳性反应率为0.04。现抽查一个人，检测结果为阳性，问此人是癌症患者的概率。

**解答：**
设 ( A ) 表示“此人患癌症”，( B ) 表示“检测结果阳性”。
我们要求的是 ( P(A|B) )，即在检测结果为阳性的情况下，此人患癌症的概率。根据贝叶斯公式：
[
P(A|B) = \frac{P(A) \cdot P(B|A)}{P(B)}
]
首先计算 ( P(B) )（总的阳性概率）：
[
P(B) = P(A) \cdot P(B|A) + P(A<sup>c) \cdot P(B|A</sup>c)
]
代入数据：
[
P(B) = 0.005 \cdot 0.95 + 0.995 \cdot 0.04 = 0.00475 + 0.0398 = 0.04455
]
然后计算 ( P(A|B) )：
[
P(A|B) = \frac{0.005 \cdot 0.95}{0.04455} \approx 0.107
]
所以，此人是癌症患者的概率约为 0.107。

### 5. **二项分布与伯努利试验**

**题目：**
某工厂生产的零件中，2%的零件是次品。现从中随机抽取10件，求其中恰好有1件是次品的概率。

**解答：**
这是一个典型的二项分布问题，设 ( X ) 为抽到次品的数量，( X \sim \text{Binomial}(n = 10, p = 0.02) )。要求的是恰好有1件次品的概率，即 ( P(X = 1) )。
根据二项分布公式：
[
P(X = k) = \binom{n}{k} p<sup>k (1 - p)</sup>{n-k}
]
代入数据：
[
P(X = 1) = \binom{10}{1} (0.02)<sup>1 (0.98)</sup>9 = 10 \cdot 0.02 \cdot (0.98)^9 \approx 10 \cdot 0.02 \cdot 0.834 = 0.1668
]
所以，恰好有1件次品的概率约为 0.1668。

### 6. **互斥事件与联合概率**

**题目：**
在一次掷骰子的实验中，求“掷出偶数点数”与“掷出大于4点”的事件的联合概率。

**解答：**
首先明确事件：

- 事件A：“掷出偶数点数”，即样本空间中的偶数点为 {2, 4, 6}。
- 事件B：“掷出大于4点”，即样本空间中的大于4点为 {5, 6}。

事件A和B的交集是：

- ( A \cap B = { 6 } )，即掷出偶数点数且大于4点的唯一结果是6。

因此，联合概率为：
[
P(A \cap B) = \frac{1}{6}
]
因为总共有6个可能的结果，所以联合概率为 ( \frac{1}{6} )。
