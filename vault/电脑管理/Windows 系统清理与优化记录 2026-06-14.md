
## 6. 遗留问题

- `mstsc.exe` 在 WinSxS 组件库中但未部署到 System32（Insider 预览版 Bug）
- 需管理员权限才能修复：`dism /online /enable-feature /featurename:Remote-Desktop-Services /all`
- 或安装 Microsoft Remote Desktop Client：`winget install "Microsoft.RemoteDesktopClient"`
