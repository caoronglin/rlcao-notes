### 1.1 细胞生物学的定义

**细胞生物学（Cell Biology）**：利用现代技术和手段从**细胞整体水平、亚细胞水平、分子水平**三个层次研究细胞生命活动及其基本规律的科学。

>🏷️ **考点**：三个研究层次——细胞水平、亚细胞水平、分子水平

**细胞生物学的三大根本问题**：

1. **基因组如何指导细胞活动**？——基因表达调控与蛋白质组
2. **细胞如何从环境中获取能量和物质**？——代谢与物质运输
3. **一个受精卵如何发育成复杂多细胞个体**？——增殖/分化/形态发生

**与农林业的关系**：作物抗逆(细胞信号/膜系统)、家畜育种(干细胞/克隆)、植物病虫害(细胞识别/免疫)、农产品加工(细胞壁酶解/发酵)

### 1.5 细胞体积守恒定律

个体机的大小与**细胞的大小无关**，而与**细胞的数目成正比**。一定细胞类型其体积是恒定的。

>🏷️ **考点**：细胞体积恒定的原因——受表面积/体积比、核质比等限制

### 1.6 细胞生物学的三大根本问题

细胞生物学围绕三个核心命题展开：

1. **细胞的起源与进化**：第一个细胞如何诞生？原核细胞如何演化为真核细胞？内共生学说（线粒体←好氧细菌，叶绿体←蓝细菌）提供了关键解释。
2. **细胞的结构与功能关系**：各种细胞器如何进行区室化分工？膜的流动性与不对称性如何调控物质交换与信号传递？细胞骨架如何维持形态与驱动运动？
3. **细胞的增殖、分化与死亡**：细胞周期如何精确调控？同一基因组如何产生200多种不同细胞类型？衰老与死亡的分子开关是什么？

### 1.7 细胞生物学与农林业的关系 ⭐⭐

细胞生物学是农林业科技创新的基础：

- **作物遗传改良**：原生质体融合（体细胞杂交）打破物种生殖隔离，已应用于马铃薯、油菜等作物的抗病育种；单倍体培养加速纯系选育；体细胞无性系变异筛选耐盐/抗旱突变体。
- **转基因技术**：农杆菌介导的T-DNA转化（Ti质粒）基于细胞生物学对基因转移机制的理解；基因枪法将外源DNA导入植物细胞；CRISPR-Cas9基因组编辑实现精准性状改良。
- **植物组织培养与快繁**：细胞全能性原理的应用——兰花、草莓、马铃薯脱毒苗的工厂化生产；人工种子（体细胞胚包埋）技术；种质资源超低温保存（液氮冻存茎尖分生组织）。
- **林木发育调控**：形成层干细胞维持与木材形成机制→速生优质林木分子设计；体细胞胚胎发生（针叶树如云杉、松树大规模繁殖）。
- **病虫害防治**：以细胞信号转导为靶标的新型杀菌剂（如靶向真菌MAPK通路）；RNAi技术沉默害虫关键基因；昆虫细胞系用于杆状病毒生物农药生产。
- **动物科学应用**：体细胞核移植（克隆牛/羊）→优良品种快速扩繁；精原干细胞冷冻保存→濒危动物遗传资源保护；乳腺生物反应器（转基因动物乳腺表达药用蛋白，如抗凝血酶III）。

### 2.2 分辨率公式 ⭐⭐⭐

>**R = 0.61λ / NA**（NA = n·sinα/2）

- R：最小分辨距离（越小越好）
- λ：照明光波长
- NA：镜口率

>🏷️ **考点**：分辨率与波长成**正比**，与镜口率成**反比**

### 2.3 各类显微镜用途

| 显微镜类型 | 用途 |
|-----------|------|
| 普通光镜 | 观察显微结构 |
| 相差显微镜 | 观察**活细胞**微细结构 |
| 荧光显微镜 | 荧光标记分子定位 |
| 暗视野显微镜 | 观察未染色活体 |
| 偏振光显微镜 | 观察纺锤丝、染色体等纤维结构 |
| 透射电镜(TEM) | 观察细胞**内部**超微结构 |
| 扫描电镜(SEM) | 观察细胞**表面**三维形态 |
| 共焦激光扫描显微镜 | 观察三维结构（内质网、细胞骨架） |

### 2.4 细胞培养

- **原代培养**：直接从机体取材进行的首次培养
- **传代培养**：原代细胞增殖到一定密度后进行的再培养
- **细胞系**：HeLa细胞系、3T3细胞系、CHO细胞系
- **接触抑制**：细胞贴壁生长成单层，达到一定密度后相互接触时生长增殖受抑制

### 2.5 细胞组分分离

| 方法 | 原理 |
|------|------|
| **差速离心** | 不同组分沉降速度不同，逐步提高离心力分离 |
| **密度梯度离心** | 在密度梯度介质中，组分沉降到与自身密度相等的位置 |

沉降系数单位：**S（Svedberg）**

### 2.6 其他重要技术

- **放射自显影**：追踪活细胞中蛋白质合成与分泌过程（用³H标记氨基酸）
- **原位杂交**：用核苷酸探针对DNA分子上特定基因进行定位
- **单克隆抗体**：小鼠骨髓瘤细胞与B细胞融合→杂交瘤细胞→单克隆抗体
- **流式细胞术**：快速测定细胞DNA含量、RNA含量、蛋白质含量、细胞体积

### 2.7 现代分子细胞生物学前沿技术 ⭐⭐⭐

#### FRAP（荧光漂白恢复技术）

- **原理**：用高能量激光瞬时漂白细胞膜选定区域的荧光标记分子→观察荧光恢复速率。
- **应用**：① 定量测量**膜脂侧向扩散系数**（验证液态镶嵌模型流动性的经典实验）；② 测量膜蛋白在脂双层中的运动速率；③ 评估蛋白质在细胞不同区域的交换动力学。
- **关键参数**：移动分数（mobile fraction）= 恢复荧光/漂白前荧光，反映可自由移动分子的比例。

#### FRET（荧光共振能量转移）

- **原理**：当供体荧光团发射光谱与受体荧光团激发光谱重叠且距离<10nm时，激发供体后能量非辐射转移至受体→受体发光。
- **应用**：① **蛋白质相互作用**——CFP标记蛋白A + YFP标记蛋白B → FRET信号=两者直接结合；② 实时监测胞内Ca²⁺、cAMP等第二信使浓度变化的生物传感器；③ GPCR与G蛋白相互作用检测。

#### 酵母双杂交（Yeast Two-Hybrid）

- **原理**：将转录因子GAL4分为DNA结合域（BD）和转录激活域（AD）；BD融合"诱饵蛋白X"、AD融合"猎物蛋白Y"；若X与Y相互作用→BD和AD靠近→报告基因（lacZ/HIS3等）转录激活。
- **应用**：① 全基因组蛋白质相互作用网络图谱构建；② 鉴定新蛋白质的相互作用伙伴（筛选cDNA文库）；③ 药物靶标发现——找到与疾病蛋白相互作用的关键节点蛋白。

#### CRISPR-Cas9基因组编辑

- **原理**：sgRNA引导Cas9核酸酶到靶序列（需PAM序列NGG）→Cas9切割DNA双链→细胞通过NHEJ（插入/缺失→基因敲除）或HDR（提供修复模板→精确编辑/敲入）修复。
- **在细胞生物学中的应用**：
  - **基因敲除（KO）**：快速建立特定基因敲除的细胞系，研究基因功能。
  - **条件性敲除**：Cre-loxP + CRISPR结合，实现组织/时间特异性基因敲除。
  - **全基因组筛选**：sgRNA文库→大规模筛选与表型（增殖/耐药/凋亡等）相关的基因。
  - **荧光标记内源基因**：将GFP/RFP敲入到目的基因C端→内源水平示踪蛋白定位。
  - **疾病模型**：构建携带特定突变的细胞系→研究致病机制和药物筛选。
- **重要改进**：dCas9（核酸酶失活）融合转录激活/抑制域→CRISPRa/CRISPRi（基因表达调控而不改变基因组序列）；碱基编辑器（Base Editor，C→T或A→G单碱基转换）；Prime Editor（搜索-替换式精准编辑，无需DSB）。

### 3.1 细胞质膜结构模型

**液态镶嵌模型（Fluid Mosaic Model）**——目前公认的模型：

```
       细胞外侧
    ↗  糖链  ↖      糖蛋白    糖脂
   ════════════════════════════════
     ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○   ← 磷脂亲水头部
     │ │ │ │ │ │ │ │ │ │ │ │ │
     │ │ │ │ │ │ │ │ │ │ │ │ │   ← 磷脂疏水尾部
     ════════════════════════════════
       细胞内侧         整合蛋白    外周蛋白
```

>🖼️ **配图**：见教材**图3-1 细胞质膜的液态镶嵌模型**

**核心要点**：

- 脂质双分子层构成膜的基本骨架
- 蛋白质以不同方式镶嵌或附着在脂双层中
- 膜具有**流动性**和**不对称性**

### 3.2 膜脂 ⭐⭐⭐

| 种类 | 特点 |
|------|------|
| **磷脂** | 含量最多，两性分子（亲水头+疏水尾） |
| **胆固醇** | 调节膜流动性，在生理温度下降低流动性 |
| **糖脂** | 含糖基，分布于质膜外侧 |

>🖼️ **配图**：`./images/cellbio/fig-3-2.png` — 见教材 **图3-2 膜脂分子结构**（磷脂酰胆碱PC、磷脂酰丝氨酸PS、磷脂酰乙醇胺PE、鞘磷脂SM、胆固醇的分子结构式）

>🏷️ **考点**：磷脂为两性分子——疏水的极性头和亲水的脂肪酸链（注意：教材中描述为"疏水极性头"和"亲水脂肪酸链"可能有误，标准描述应为亲水极性头+疏水脂肪酸尾）

### 3.3 膜蛋白

| 类型 | 结合方式 | 特点 |
|------|---------|------|
| **整合蛋白（内在蛋白）** | 嵌入脂双层内部 | 需去垢剂才能分离 |
| **外周蛋白（外在蛋白）** | 附着在膜表面 | 通过离子键等弱键结合，易分离 |
| **脂锚定蛋白** | 通过共价键与脂分子结合 | — |

### 3.4 膜的流动性 ⭐⭐⭐

膜脂的运动方式：

- ① **侧向扩散**（最常见）
- ② 旋转运动
- ③ 摆动
- ④ **翻转运动**（最罕见，需翻转酶催化）

影响流动性的因素：

- 脂肪酸链越**短**、不饱和度越**高** → 流动性↑
- 胆固醇：生理温度下降低流动性；低温下防止膜固化

### 3.5 膜的不对称性

- 脂质分布不对称（鞘磷脂、磷脂酰胆碱在外侧；磷脂酰丝氨酸、磷脂酰乙醇胺在内侧）
- 蛋白质分布不对称
- 糖类全部在**外侧**

### 3.6 脂筏（Lipid Raft）⭐⭐

>🖼️ **配图**：`./images/cellbio/fig-3-3.png` — 见教材 **图3-3 脂筏模型**（富含鞘磷脂和胆固醇的微区域，作为信号分子和膜蛋白的组织平台）

**脂筏**是质膜上富含**鞘磷脂+胆固醇**的微区域（~10-200nm），比周围膜更厚、更有序，呈液态有序相（Lo相），漂浮在液态无序相（Ld相）的"海洋"中。

- **分子特征**：鞘磷脂含长饱和脂肪酸链+胆固醇填充间隙→紧密堆积→抵抗去垢剂提取（DRM, detergent-resistant membrane）。
- **功能**：① **信号转导平台**——富集GPCR、G蛋白、Src家族激酶等信号分子→提高信号效率和特异性；② **膜泡运输**——参与胞吞（caveolae：由caveolin蛋白稳定的特殊脂筏内陷）和顶端分选；③ **病毒入侵**——HIV、流感病毒等利用脂筏进入宿主细胞。
- **Caveolae（细胞膜小凹/膜窖）**：脂筏的特殊形态——caveolin-1/2/3蛋白形成发夹结构嵌入膜内小叶→质膜形成烧瓶状内陷（~50-100nm），在血管内皮细胞、脂肪细胞中特别丰富。

### 3.7 膜脂流动性实验证据：FRAP恢复 ⭐⭐⭐

**FRAP实验验证膜流动性**：

1. 用荧光标记物（如NBD-PC，荧光标记的磷脂酰胆碱类似物）标记细胞质膜。
2. 选择一小区域用高能量激光瞬时漂白（荧光团被不可逆破坏→黑斑）。
3. 随时间观察黑斑的荧光恢复：周围的未漂白荧光分子通过**侧向扩散**进入漂白区→荧光恢复。
4. **实验结果**：膜脂恢复速率极快（D ≈ 10⁻⁸ cm²/s），恢复比例>90%→证明膜脂可自由侧向扩散，直接验证液态镶嵌模型。
5. **补充发现**：约30-50%膜蛋白也显示快速恢复→膜蛋白也可侧向扩散（部分受细胞骨架锚定限制）。

### 3.8 脂质体制备及其应用 ⭐⭐

**脂质体（liposome）**是人工制备的封闭脂双层囊泡：

- **制备方法**：
  - **超声法**：磷脂悬浮液超声处理→形成小单室脂质体（SUV, 25-50nm）。
  - **挤压法**：反复挤压通过聚碳酸酯膜（孔径100-400nm）→尺寸均一的大单室脂质体（LUV）。
  - **反向蒸发法**：磷脂溶于有机溶剂+水相→超声乳化→蒸去有机溶剂→形成大单室脂质体，包封效率高。
- **应用**：
  - **药物递送**：脂质体包裹化疗药物（如Doxil®—脂质体阿霉素）→减少毒副作用+延长循环时间+EPR效应（增强渗透滞留效应）被动靶向肿瘤；PEG化脂质体（隐形脂质体）逃避RES系统清除。
  - **基因治疗**：阳离子脂质体结合DNA/RNA→促进细胞摄取和内涵体逃逸。
  - **膜蛋白研究**：将纯化的膜蛋白重建入脂质体→研究其功能和调控（如离子通道电生理记录）。
  - **mRNA疫苗**：COVID-19 mRNA疫苗的脂质纳米颗粒（LNP）核心为可电离阳离子脂质形成的脂双层结构。

### 3.9 细胞被（糖萼）

细胞膜上糖蛋白和糖脂外伸的**糖链**构成，功能：

- 保护细胞
- 细胞识别
- 细胞黏着

### 5.6 泛素-蛋白酶体系统（UPS）⭐⭐⭐

**泛素-蛋白酶体系统**是真核细胞内最主要的**选择性蛋白质降解途径**，负责降解异常/错误折叠蛋白和短寿命调控蛋白（80-90%胞内蛋白降解），高度特异且耗能（ATP）。

**泛素化级联反应（E1→E2→E3）**：

| 酶 | 特点 | 功能 |
|----|------|------|
| **E1（泛素激活酶）** | 1-2种，高度保守 | ATP驱动→Ub C端与E1半胱氨酸形成硫酯键→"充电" |
| **E2（泛素结合酶）** | ~40种，UBC家族 | E1→E2转硫酯反应→携带活化Ub→决定链类型(Lys48=降解/Lys63=信号) |
| **E3（泛素连接酶）** | ~600-1000种！决定底物特异性 | 同时结合E2-Ub和底物蛋白→催化Ub转移至底物Lys残基→形成异肽键 |

**26S蛋白酶体结构与功能**：

- **20S核心颗粒（CP）**：4个环（α₇β₇β₇α₇），β亚基含苏氨酸蛋白酶活性（β1=类caspase、β2=类trypsin、β5=类chymotrypsin），将底物切成3-22氨基酸短肽。
- **19S调节颗粒（RP）（帽）**：含Ub受体（Rpn10/Rpn13）+去泛素化酶（Rpn11/Uch37）+AAA+ATP酶环（Rpt1-6）→识别K48多聚Ub链→去折叠底物→易位入20S→降解；Ub回收。
- **组装顺序**：20S + 19S（一侧或两侧）→ 26S全酶。

**UPS的生物学功能**：

- ① 蛋白质质量控制：清除错误折叠蛋白（内质网来源的通过ERAD途径）。
- ② 细胞周期调控：APC/C（Cdh1/Cdc20）和SCF泛素化Cyclin/securin等→精确调控周期进程。
- ③ 信号转导：IκB磷酸化后被SCF^β-TrCP泛素化→降解→NF-κB释放入核。
- ④ 转录调控：p53与MDM2（E3）形成负反馈→MDM2泛素化p53→低水平维持。
- ⑤ 凋亡调控：IAP蛋白（cIAP1/2）作为E3泛素化caspase和促凋亡蛋白。

### 5.7 ERAD（内质网相关蛋白降解）⭐⭐

**定义**：内质网腔内错误折叠/未组装蛋白被识别→逆向易位（ dislocation）至胞质→泛素化→26S蛋白酶体降解。

**ERAD通路关键步骤**：

1. **识别**：分子伴侣（Bip/CNX/CRT）+凝集素（EDEM/Osl-9/XTP3-B识别Man修剪状态）+PDI识别错误折叠蛋白。
2. **逆向易位（ dislocation/retrotranslocation）**：错误折叠蛋白经**Sec61通道**（或Derlin/VIMP/p97复合体）从ER腔逆向转运至胞质——需p97/VCP（AAA+ATP酶）提供拉力。
3. **泛素化标记**：胞质侧E3连接酶（Hrd1/Doa10/gp78等）在底物Lys残基上合成K48多聚Ub链。
4. **蛋白酶体降解**：26S蛋白酶体识别Ub链→去折叠→降解。

**ERAD与疾病**：

- **α1-抗胰蛋白酶缺乏症**：Z突变体聚合滞留在ER→ERAD过载→ER应激→UPR→肝细胞凋亡→肝纤维化/肺气肿。
- **囊性纤维化（CF）**：CFTR-ΔF508突变→错误折叠→被ERAD完全降解→无法到达质膜→Cl⁻转运障碍→囊性纤维化（CFTR增强剂如Ivacaftor可部分挽救）。

>🏷️ **ERAD vs 自噬**：ERAD降解单个错误折叠蛋白；自噬降解整个细胞器或大的蛋白聚集体。

## 第六章 蛋白质分选与膜泡运输

### 6.1 蛋白质分选概述 ⭐⭐⭐

**定义**：蛋白质在内部信号指导下，从细胞质定向转运至各种目标细胞器或细胞表面的过程。

**基本事实**：

- 真核细胞高度区室化，每个细胞器有独特蛋白质组成
- 约**50%的蛋白质需跨膜转运**（30%为膜蛋白，20%为可溶性蛋白）
- 绝大多数蛋白质由核基因编码、在细胞质中合成
- 无任何信号序列的蛋白默认驻留在细胞质基质中

**两条主要途径**：

| 类型 | 定义 | 适用蛋白 |
|------|------|------|
| **共翻译转运** | 合成过程中边合成边转运 | 分泌蛋白、ER蛋白、溶酶体蛋白、质膜整合蛋白 |
| **翻译后转运** | 胞质中完全合成后再转运 | 细胞核、线粒体、叶绿体、过氧化物酶体蛋白 |

**四种基本转运机制**：

| 机制 | 描述 | 应用 |
|------|------|------|
| **门控通道运输** | 通过核孔复合体，折叠/组装形式 | 核蛋白入核/出核 |
| **跨膜运输** | 依赖信号肽，通过膜上易位子，未折叠+分子伴侣 | ER、线粒体、叶绿体、过氧化物酶体 |
| **膜泡运输** | 膜泡出芽→转运→融合，蛋白和脂质方向不变 | ER↔高尔基↔质膜/溶酶体 |
| **胞质蛋白转运** | 与细胞骨架密切相关 | — |

### 6.2 信号假说 ⭐⭐⭐

- **提出**：Blobel & Sabatini 1971年；Blobel因设计体外翻译-转运系统验证该假说获**1999年诺贝尔奖**
- **核心**：① 分泌蛋白N端信号肽将核糖体引导到ER膜；② 多肽通过ER膜上水性通道进入ER腔

>🖼️ **配图**：`./images/cellbio/fig-6-1.png` — 见教材 **图6-1 信号假说示意图**（核糖体在胞质中起始翻译→信号肽露出→SRP识别结合→SRP-核糖体停靠ER膜SRP受体→翻译继续→新生肽链经Sec61通道进入ER腔）

**信号肽特征**：

| 特征 | 说明 |
|------|------|
| **位置** | 蛋白质N端 |
| **长度** | 16~26个氨基酸残基 |
| **三部分结构** | ① N端碱性区(Arg/Lys) + ② 疏水核心区(6~15aa) + ③ C端极性区(信号肽酶切割位点) |
| **命运** | 完成分选后被信号肽酶切除 |

### 6.3 共翻译转运核心分子机器

**SRP（信号识别颗粒）**：

- 组成：**6种蛋白质 + 1条7S RNA**（约300bp）
- P54蛋白（GTP酶含Met残基）→识别信号肽疏水核心
- P9/P14复合体→结合核糖体大亚基，阻断翻译延伸（翻译暂停）

>🖼️ **配图**：`./images/cellbio/fig-6-2.png` — 见教材 **图6-2 SRP结构**（SRP由6个蛋白亚基+7S RNA组成，P54负责识别信号肽，RNA提供结构骨架）

**SRP受体（停泊蛋白DP）**：ER膜整合蛋白，α亚基+GTP酶

**易位子（Sec61复合体）**：3~4个Sec61复合物构成，Sec61α(10次跨膜)为核心通道

>🖼️ **配图**：`./images/cellbio/fig-6-4.png` — 见教材 **图6-4 共翻译转运过程**（SRP循环：信号肽识别→翻译暂停→SRP-SRP受体停靠→GTP水解→SRP释放循环→核糖体-Sec61对接→新生肽链穿膜→信号肽切除→蛋白质折叠）

**共翻译转运七步**：

```
① 核糖体翻译出信号肽 → ② SRP识别信号肽+结合核糖体大亚基→翻译暂停
→ ③ SRP-核糖体复合物→ER膜→与SRP受体结合(GTP增强)
→ ④ 核糖体与Sec61结合→GTP水解→SRP解离循环
→ ⑤ 肽链恢复延伸→信号肽引导以袢环穿过易位子→信号肽被切除
→ ⑥ 肽链全部进入ER腔→⑦ 折叠成熟(Bip等分子伴侣辅助)
```

### 6.4 内质网膜整合蛋白的拓扑学 ⭐⭐

**四种拓扑类型**：

| 类型 | N端 | C端 | 跨膜次数 | 举例 |
|------|-----|-----|:---:|------|
| **I型** | ER腔/胞外 | 胞质侧 | 单次 | LDL受体 |
| **II型** | 胞质侧 | ER腔/胞外 | 单次 | 高尔基半乳糖转移酶 |
| **III型** | ER腔 | 胞质侧 | 单次 | 细胞色素P450 |
| **IV型** | 不定 | 不定 | 多次 | GPCR、GLUT1 |

**正电荷在内规则**：带正电荷氨基酸一侧朝向胞质侧

关键序列：起始转移序列(信号肽)、内在停止转移锚定序列(STA)、内在信号锚定序列(SA)

### 6.6 翻译后转运 ⭐⭐

**线粒体输入**：前体蛋白+胞质Hsc70(维持未折叠)→Tom20/22识别导肽→Tom40外膜通道+Tim23/17内膜通道→基质Hsc70(ATP驱动拉入)→导肽切除→折叠

**叶绿体输入**：Toc/Tic复合体，需ATP和GTP(无质子动力势)，分四条类囊体途径(SRP依赖/pH依赖Tat/ATP依赖Sec/直接插入)

**过氧化物酶体输入**：Pex5受体识别PTS1→Pex14膜受体→Pex12/10/2复合物→ATP水解→受体循环；PTS1信号不被切除

**核孔复合体转运**：以完全折叠形式；入核需NLS+Importin，出核需NES+Exportin；Ran-GTP/GDP浓度梯度（核内Ran-GTP高）提供方向性

### 7.2 电子传递链(呼吸链) ⭐⭐⭐

>🖼️ **配图**：`./images/cellbio/fig-7-2.png` — 见教材 **图7-2 呼吸链复合体**（线粒体内膜上四大复合体I-IV的排列、电子传递顺序、CoQ和Cyt c的电子载体角色、各复合体的H⁺泵出位置）

**四大复合体**：

| 复合体 | 名称 | 功能 | 泵H⁺数/e⁻对 |
|:---:|------|------|:---:|
| **I** | NADH-辅酶Q氧化还原酶 | NADH→CoQ | **4** |
| **II** | 琥珀酸-辅酶Q氧化还原酶 | FADH₂→CoQ | **0**(不泵H⁺) |
| **III** | 辅酶Q-细胞色素c氧化还原酶 | CoQ→Cyt c | **4** |
| **IV** | 细胞色素c氧化酶 | Cyt c→O₂→H₂O | **2** |

**电子传递顺序**：

```
NADH → I → CoQ(泛醌) → III → Cyt c → IV → O₂ → H₂O
                     ↑
FADH₂ → II → CoQ ──┘
```

**关键载体**：CoQ(脂溶性醌，膜内自由扩散)、Cyt c(水溶性血红素蛋白，膜间隙侧)

### 7.3 化学渗透假说(Mitchell 1961) ⭐⭐⭐

获**1978年诺贝尔化学奖**：电子传递释放能量将H⁺从基质泵至膜间隙→形成**质子动力势(ΔP)**→H⁺经ATP合酶返回时驱动ATP合成。

>🖼️ **配图**：`./images/cellbio/fig-7-3.png` — 见教材 **图7-3 化学渗透假说模型**（电子传递链泵H⁺→内膜两侧形成质子梯度→H⁺经ATP合酶回流→驱动ATP合成，解偶联剂DNP携带H⁺泄漏产热）

**ΔP = ΔΨ − (2.3RT/F)ΔpH ≈ 220mV**（ΔΨ约-160mV外正内负，ΔpH约1.4单位）

⚠️ 关键前提：内膜必须完整，质子不能自由透过

### 7.4 ATP合酶(F₀F₁) ⭐⭐⭐

>🖼️ **配图**：`./images/cellbio/fig-7-4.png` — 见教材 **图7-4 ATP合酶结构**（F₁头部α₃β₃γδε亚基排列+F₀基部ab₂c₁₂质子通道；三个β亚基L→T→O构象变化；γ亚基旋转驱动ATP合成；每圈合成3个ATP的旋转催化模型）

| 部分 | 组成 | 功能 |
|------|------|------|
| **F₁头部**(基质侧) | α₃β₃γδε | 催化ATP合成，**催化位点在β亚基** |
| **F₀基部**(嵌入内膜) | ab₂c₁₂ | 形成质子通道 |

**结合变化机制/旋转催化**(Boyer 1979)：3个β亚基分别处于L(结合ADP+Pi)→T(催化ATP)→O(释放ATP)三种构象；γ亚基旋转驱动周期性变化；每10个H⁺通过Fo→c环转一圈→合成3个ATP。

### 7.8 光合作用光反应 ⭐⭐⭐

**三大步骤**：

| 步骤 | 内容 | 能量转化 |
|------|------|----------|
| 原初反应 | 光能吸收、传递与转换 | 光能→电能 |
| 光合电子传递+磷酸化 | H₂O→NADP⁺，耦联合成ATP/NADPH | 电能→活跃化学能 |
| 碳同化(暗反应) | 利用ATP/NADPH固定CO₂ | 活跃化学能→稳定化学能 |

**光系统对比**：

| 项目 | **PSII** | **PSI** |
|------|----------|----------|
| **反应中心色素** | **P680** | **P700** |
| **位置** | 基粒片层(垛叠区) | 基质片层和基粒边缘 |
| **功能** | H₂O光解(放O₂+H⁺) | 激发电子→Fd→NADP⁺ |
| **特殊结构** | 含放氧复合体(OEC)锰簇Mn₄CaO₅ | — |

**"Z"字形电子传递链（非循环式）**：

```
H₂O → PSII(P680) → PQ → Cyt b₆f → PC(质体蓝素) → PSI(P700) → Fd(铁氧还蛋白) → FNR → NADP⁺ → NADPH
```

>🖼️ **配图**：`./images/cellbio/fig-7-6.png` — 见教材 **图7-6 Z字形光合电子传递**（PSII→PQ→Cyt b₆f→PC→PSI→Fd→FNR→NADP⁺的完整电子传递路径；氧化还原电位变化呈"Z"形；水的光解放氧位置；跨膜H⁺泵出位点）
每对电子泵入类囊体腔约6H⁺(PSII处2+2 + Cyt b₆f处4)→驱动ATP合酶

**循环式光合磷酸化**：电子经PSI→Fd→Cyt b₆f→PC→回P700；只产ATP不产NADPH不放O₂

**光合磷酸化 vs 氧化磷酸化**：

| 项目 | 光合磷酸化 | 氧化磷酸化 |
|------|-----------|-----------|
| 场所 | 叶绿体类囊体膜 | 线粒体内膜 |
| 能量来源 | 光能 | 有机物化学能 |
| 电子来源 | H₂O光解 | NADH/FADH₂ |
| 最终受体 | NADP⁺ | O₂ |
| H⁺泵入方向 | 基质→类囊体腔 | 基质→膜间隙 |

### 7.9 半自主性 ⭐⭐⭐

线粒体和叶绿体有自身DNA（双链环状）和蛋白质合成体系，但大部分蛋白由核基因编码。

**自主性证据**：

- DNA为环状(类似细菌)；核糖体70S(对氯霉素敏感/对放线菌酮不敏感)
- 起始aa为N-甲酰甲硫氨酸(同原核)；RNA聚合酶可被利福平抑制
- **人mtDNA编码**：2种rRNA(12S/16S)、22种tRNA、13种多肽(7个NADH脱氢酶亚基+1个Cyt b+3个COX+2个F₀亚基)

**核质反向信号**：细胞器向核发送信号调控核基因表达（如线粒体功能异常→水稻细胞质雄性不育CMS）

### 7.10 内共生起源学说 ⭐⭐⭐

**核心**：线粒体←好氧细菌，叶绿体←蓝细菌，被原始真核细胞吞噬后共生。

**八大证据**：①环状DNA ②70S核糖体 ③N-甲酰甲硫氨酸起始 ④对氯霉素敏感 ⑤利福平抑制RNA聚合酶 ⑥双层膜 ⑦分裂方式增殖 ⑧基因密度高含操纵子

>🖼️ **配图**：`./images/cellbio/fig-7-7.png` — 见教材 **图7-7 内共生起源证据**（原始真核细胞先后吞噬好氧细菌和蓝细菌→分别演化为线粒体和叶绿体；双层膜的由来；分子进化的证据链图示）

**对比总结**：

| 项目 | 线粒体 | 叶绿体 |
|------|--------|--------|
| 分布 | 几乎所有真核细胞 | 仅植物和藻类 |
| 能量来源 | 有机物 | 光能 |
| 核心功能 | 氧化磷酸化 | 光合磷酸化 |
| 内膜特化 | 嵴 | 类囊体 |
| 电子传递链 | 呼吸链I-IV | PSII→Cyt b₆f→PSI |
| 最终受体 | O₂→H₂O | NADP⁺→NADPH |
| 内共生起源 | 好氧细菌 | 蓝细菌 |

### 8.5 细胞骨架药物汇总 ⭐⭐⭐

**微丝靶向药物**：

| 药物 | 来源 | 作用机制 | 效应 | 应用 |
|------|------|----------|------|------|
| **细胞松弛素(Cytochalasin)** | 真菌代谢产物 | 结合F-actin倒刺端→阻止G-actin添加 | 抑制微丝聚合→破坏应力纤维/伪足/胞质分裂 | 研究工具，抑制胞质分裂产生双核细胞 |
| **鬼笔环肽(Phalloidin)** | 毒蘑菇Amanita phalloides | 结合F-actin侧面→稳定纤维，抑制解聚 | F-actin过度稳定→细胞骨架僵化 | **荧光标记鬼笔环肽**(如Alexa-Phalloidin)是研究微丝的标准染料 |
| **Latrunculin** | 海绵 | 结合G-actin→阻止其加入纤维 | 微丝解聚，效果类似cytochalasin但更特异 | 细胞迁移/内吞研究 |
| **Jasplakinolide** | 海绵 | 稳定F-actin+促进成核 | 类似phalloidin，但细胞通透性好 | 活细胞微丝稳定化研究 |

**微管靶向药物**：

| 药物 | 来源 | 作用机制 | 效应 | 临床应用 |
|------|------|----------|------|----------|
| **秋水仙素(Colchicine)** | 秋水仙(植物) | 结合游离β-微管蛋白→阻止其添加到微管末端 | 微管解聚→纺锤体破坏→中期阻滞→多倍体 | 急性痛风(抑制中性粒细胞微管); 多倍体育种(无籽西瓜) |
| **长春碱(Vinblastine)** | 长春花(植物) | 结合微管蛋白→促进形成无功能副晶体 | 微管解聚→M期阻滞 | 霍奇金淋巴瘤、睾丸癌化疗 |
| **长春新碱(Vincristine)** | 长春花 | 同vinblastine类似但结合位点不同 | 微管解聚 | ALL(急性淋巴细胞白血病)、神经母细胞瘤(神经毒性较大) |
| **紫杉醇(Paclitaxel/Taxol)** | 太平洋紫杉(红豆杉) | **结合微管内表面→稳定微管**，抑制解聚(即使无GTP) | 微管过度稳定→动态受阻→纺锤体功能异常→M期阻滞→凋亡 | **卵巢癌、乳腺癌、非小细胞肺癌**一线化疗药; 支架涂层(药物洗脱支架防再狭窄) |
| **Nocodazole** | 合成 | 结合β-微管蛋白→阻止聚合 | 快速可逆的微管解聚(洗去后恢复) | 同步化细胞于M期(研究工具) |
| **多西紫杉醇(Docetaxel)** | 半合成(紫杉醇衍生物) | 同紫杉醇，亲和力更强 | 微管稳定 | 乳腺癌、前列腺癌、胃癌 |

>🏷️ **考点**：紫杉醇=稳定微管（"冻住"），秋水仙素/长春碱=解聚微管（"融化"）；两者相反机制但最终都破坏纺锤体正常功能→M期阻滞→细胞凋亡。

**临床耐药机制**：

- **P-糖蛋白(P-gp/MDR1)多药耐药**：ABC转运蛋白外排药物→胞内药物浓度降低（紫杉醇、长春碱均可被排出）。
- **β-微管蛋白同种型转换**：肿瘤细胞上调βIII-tubulin（对紫杉醇低亲和力）→紫杉醇耐药。
- **微管蛋白突变**：结合位点氨基酸突变→药物无法有效结合。

### 9.4 染色质组装层次 ⭐⭐⭐

| 层次 | 结构 | 直径 | 压缩比(累积) |
|------|------|:---:|:---:|
| ① DNA双螺旋 | 双链DNA | 2nm | — |
| ② 核小体链 | DNA+H2A/H2B/H3/H4八聚体（"串珠"） | 11nm | ~7× |
| ③ 30nm纤维 | H1参与下核小体螺旋排列成螺线管(solenoid) | 30nm | ~42× |
| ④ 环状结构域 | 30nm纤维锚定在染色体骨架形成~50-100kb环 | 300nm | ~750× |

### 9.5 常染色质与异染色质 ⭐⭐⭐

| 类型 | 染色深度 | 压缩程度 | 转录活性 | 复制时间 |

| **常染色质(Euchromatin)** | 浅 | 较松散 | 活跃转录 | S期早期 |
| **异染色质(Heterochromatin)** | 深 | 高度压缩 | 转录不活跃/沉默 | S期晚期 |

## 第十章 核糖体

### 10.1 核糖体结构 ⭐⭐⭐

核糖体由**rRNA + 核糖体蛋白**构成，是蛋白质合成的分子机器。

| 项目 | 原核(70S) | 真核(80S) |
|------|-----------|-----------|
| **全核糖体** | 70S | 80S |
| **大亚基** | 50S (23S+5S rRNA + 31种蛋白) | 60S (28S+5.8S+5S rRNA + 49种蛋白) |
| **小亚基** | 30S (16S rRNA + 21种蛋白) | 40S (18S rRNA + 33种蛋白) |

>🖼️ **配图**：`./images/cellbio/fig-10-1.png` — 见教材 **图10-1 原核与真核核糖体对比**（70S vs 80S核糖体的大小亚基组成、rRNA种类、蛋白质数量及三维结构对比）

**rRNA功能**：不仅作为结构骨架，还具有**催化活性**——肽酰转移酶活性由大亚基23S/28S rRNA承担（核酶ribozyme，催化肽键形成）。

### 10.2 核糖体功能位点 ⭐⭐⭐

| 位点 | 全称 | 所处亚基 | 功能 |
|------|------|----------|------|
| **A位** | 氨酰位(Aminoacyl site) | 大小亚基交界 | 接纳新氨基酰tRNA |
| **P位** | 肽酰位(Peptidyl site) | 大小亚基交界 | 携带新生肽链 |
| **E位** | 出口位(Exit site) | 主要在大亚基 | 脱酰tRNA离开 |
| **mRNA结合位点** | — | 小亚基 | 结合mRNA，识别起始密码子 |
| **GTP酶相关位点** | — | 大亚基 | 翻译因子结合(GTP水解) |

### 10.3 多核糖体 ⭐⭐

多个核糖体同时翻译同一条mRNA，形成**多核糖体(polysome/polyribosome)**，极大提高翻译效率。

- 原核：可**边转录边翻译**（无核膜分隔，转录-翻译耦联）
- 真核：mRNA加工成熟后输出到胞质再翻译（转录和翻译时空分离）

### 10.4 蛋白质合成过程详述 ⭐⭐⭐

>🖼️ **配图**：`./images/cellbio/fig-10-2.png` — 见教材 **图10-2 蛋白质合成过程**（起始→延伸→终止三阶段：小亚基结合mRNA→起始tRNA识别→大亚基加入→A位接纳氨基酰tRNA→肽键形成→转位→终止密码子识别→释放因子结合→肽链释放→大小亚基解离的循环过程）

**（一）起始阶段**：

| 步骤 | 原核 | 真核 |
|------|------|------|
| 小亚基-mRNA结合 | SD序列(Shine-Dalgarno)与16S rRNA配对 | 5'帽子识别，Kozak序列扫描 |
| 起始tRNA | fMet-tRNAᶠᴹᵉᵗ | Met-tRNAᵢᴹᵉᵗ |
| 起始因子 | IF1/IF2/IF3 | eIF1~eIF6（种类繁多） |
| 大亚基加入 | GTP水解驱动 | GTP水解驱动 |

**（二）延伸阶段（每轮三步）**：

```
① 氨基酰tRNA进入A位（需EF-Tu/eEF1α·GTP，校正机制保真度~10⁻³⁻⁴）
② 肽键形成（P位肽链→A位氨基酰tRNA，由rRNA催化，不需额外能量）
③ 转位（EF-G/eEF2·GTP驱动，A位→P位→E位）
```

**（三）终止阶段**：

- 终止密码子(UAA/UAG/UGA)→A位
- **I类释放因子**识别：原核RF1(UAA/UAG)+RF2(UAA/UGA)；真核eRF1(全部三个)
- **II类释放因子**(RF3/eRF3·GTP)促进I类因子释放
- 肽链水解释放→核糖体大小亚基解离→循环

### 10.5 核糖体的组装与定位 ⭐⭐

**组装场所**：

- 真核：rRNA基因(rDNA)在**核仁**中转录→rRNA加工修饰→与核糖体蛋白组装→大小亚基分别经核孔输出
- 原核：在胞质中完成

**定位**：

- **游离核糖体**：合成胞质蛋白、核蛋白、线粒体/叶绿体/过氧化物酶体蛋白
- **附着核糖体（粗面内质网）**：合成分泌蛋白、质膜蛋白、溶酶体蛋白、ER/高尔基驻留蛋白

### 10.6 以核糖体为靶标的抗生素 ⭐⭐

| 抗生素 | 靶点 | 作用机制 |
|--------|------|----------|
| **四环素** | 30S小亚基A位 | 阻断氨基酰tRNA进入 |
| **链霉素** | 30S小亚基 | 引起读码错误+阻断起始 |
| **氯霉素** | 50S大亚基(23S rRNA) | 抑制肽酰转移酶活性 |
| **红霉素** | 50S大亚基 | 阻断肽链出口通道 |
| **嘌呤霉素** | A位 | 氨基酰tRNA类似物，引起肽链提前释放 |
| **放线菌酮** | 60S大亚基(真核) | 抑制真核肽酰转移酶 |

>⚠️ **重要区分**：氯霉素抑制**原核**70S核糖体（线粒体/叶绿体也敏感）→ 线粒体/叶绿体70S与原核相似之证据；放线菌酮抑制**真核**80S核糖体但对原核无效

### 10.7 核酶(Ribozyme)概念 ⭐⭐

核酶是具有催化活性的RNA分子。核糖体大亚基rRNA(23S/28S)催化肽键形成是核酶的经典例证，这一发现（Cech & Altman，**1989年诺贝尔化学奖**）证实RNA既可携带遗传信息又可作催化剂，支持"RNA世界"假说。

- 翻译终止密码子三个：**UAA、UAG、UGA**

## 第十一章 细胞信号转导

### 11.1 细胞通讯的类型 ⭐⭐⭐

| 类型 | 特点 | 举例 |
|------|------|------|
| **内分泌** | 激素经血液远距离传送 | 胰岛素、甲状腺素、肾上腺素 |
| **旁分泌** | 局部信号作用于邻近细胞 | 神经递质、生长因子、NO |
| **自分泌** | 信号作用于自身 | 癌细胞自泌生长因子、T细胞IL-2 |
| **突触传递** | 化学突触 | 乙酰胆碱、多巴胺 |
| **膜接触依赖** | 膜结合信号分子 | Delta-Notch、Ephrin-Eph |

### 11.2 信号分子与受体 ⭐⭐⭐

- **亲脂性信号分子**（甾体激素、甲状腺激素、视黄酸、NO）：可穿越质膜 → **胞内受体**（核受体超家族，作为配体依赖转录因子，含DNA结合域+配体结合域+转录激活域）
- **亲水性信号分子**（肽类激素、生长因子、神经递质）：不能穿越质膜 → **细胞表面受体**（三大类）

### 11.3 细胞表面受体三大类 ⭐⭐⭐

| 受体类型 | 结构特征 | 代表 | 信号转换方式 |
|----------|----------|------|-------------|
| **G蛋白偶联受体(GPCR)** | 7次跨膜α螺旋，最大受体家族(>800成员) | β肾上腺素受体、视紫红质、嗅觉受体 | 配体→GPCR→G蛋白激活→效应酶→第二信使 |

>🖼️ **配图**：`./images/cellbio/fig-11-1.png` — 见教材 **图11-1 GPCR结构（7次跨膜）**（N端胞外→7个α螺旋跨膜(TM1-TM7)→C端胞内；配体结合口袋位于跨膜螺旋内部；胞内环与G蛋白相互作用；GRK磷酸化位点和β-arrestin结合位点）
| **酶联受体** | 单次跨膜，胞内段具酶活性或结合酶 | 受体酪氨酸激酶(RTK)、TGF-β受体(Set/Thr激酶) | 配体→二聚化→激活胞内酶→磷酸化级联 |
| **离子通道偶联受体** | 配体门控离子通道 | 烟碱型乙酰胆碱受体(nAChR)、GABA受体 | 配体→通道开放→离子流→膜电位变化 |

### 11.4 GPCR介导的信号通路 ⭐⭐⭐

#### 11.4.1 G蛋白三大家族

| Gα家族 | 效应蛋白 | 第二信使 | 代表受体 |
|--------|----------|----------|----------|
| **Gαs** | 激活腺苷酸环化酶(AC) | cAMP↑ | β肾上腺素受体、胰高血糖素受体 |
| **Gαi** | 抑制AC | cAMP↓ | α₂肾上腺素受体 |
| **Gαq** | 激活PLCβ | IP₃↑ + DAG↑ + Ca²⁺↑ | α₁肾上腺素受体、血管紧张素II受体 |

#### 11.4.2 cAMP-PKA通路（Gαs）

>🖼️ **配图**：`./images/cellbio/fig-11-2.png` — 见教材 **图11-2 cAMP-PKA通路**（配体→GPCR→Gαs→AC→cAMP↑→PKA激活→磷酸化CREB→CRE转录；信号终止：PDE降解cAMP、GRK/β-arrestin介导受体脱敏）

```
配体结合GPCR → GPCR构象变化(充当GEF)
  → Gαs·GDP → Gαs·GTP（Gα与Gβγ解离）
  → Gαs·GTP激活腺苷酸环化酶(AC，跨膜12次) → ATP→cAMP↑
  → cAMP结合PKA调节亚基(R₂) → R₂C₂解离 → 催化亚基(C)释放激活
  → C亚基磷酸化靶蛋白包括：
     · 胞质：糖原磷酸化酶激酶(糖原分解)、激素敏感脂酶(脂肪分解)
     · 入核：磷酸化转录因子CREB(Ser133) → CBP/p300共激活 → CRE元件转录
```

**PKA结构**：R₂C₂四聚体；每个R亚基结合2个cAMP后释放2个C亚基。

**信号终止**：cAMP被**磷酸二酯酶(PDE)**降解为5'-AMP；Gαs内在GTP酶活性(GAP辅助)→Gαs-GDP重聚Gβγ；受体被GRK磷酸化→β-arrestin结合→内吞脱敏。

#### 11.4.3 PI-PLC-Ca²⁺双信使通路（Gαq）

>🖼️ **配图**：`./images/cellbio/fig-11-3.png` — 见教材 **图11-3 PI-PLC通路**（GPCR→Gαq→PLCβ→PIP₂水解→IP₃扩散至ER→Ca²⁺释放+DAG留膜激活PKC；Ca²⁺/CaM→CaMKII等下游信号的级联）

```
配体 → GPCR → Gαq·GTP激活PLCβ
  → PLCβ水解PIP₂(磷脂酰肌醇-4,5-二磷酸)
  → ① IP₃(水溶性)扩散至ER膜 → 结合IP₃受体(Ca²⁺通道)→ ER Ca²⁺释放→ [Ca²⁺]i↑
       → Ca²⁺结合CaM(钙调蛋白)→ Ca²⁺/CaM激活CaMKII等 → 磷酸化靶蛋白
       → 或直接激活PKC
  → ② DAG(脂溶性，留膜上) + Ca²⁺ → 激活PKC(蛋白激酶C)
       → PKC磷酸化多种靶蛋白( Raf→MAPK通路激活、MARCKS、离子通道等)
```

**Ca²⁺双功能**：既是第二信使(胞内浓度从~100nM→1μM)，又参与信号终止(Ca²⁺泵回ER/泵出胞外)。

### 11.5 RTK-Ras-MAPK通路 ⭐⭐⭐

>🖼️ **配图**：`./images/cellbio/fig-11-4.png` — 见教材 **图11-4 RTK-Ras-MAPK通路**（生长因子→RTK二聚化→交叉自磷酸化→Grb2-SOS→Ras-GTP→Raf→MEK→ERK级联→ERK入核磷酸化转录因子→促进增殖基因表达；Ras突变(G12V)持续激活致癌）

```
生长因子(EGF/PDGF/胰岛素)结合 → RTK二聚化
  → 胞内激酶域交叉自磷酸化(Tyr残基)
  → 接头蛋白Grb2：SH2结构域→结合pTyr，SH3结构域→结合SOS(脯氨酸富集区)
  → SOS(Ras-GEF)接近质膜 → 催化Ras·GDP→Ras·GTP
  → Ras·GTP激活Raf(MAPKKK) → Raf磷酸化MEK(MAPKK) → MEK磷酸化ERK(MAPK)
  → ERK入核 → 磷酸化转录因子(Ets/Elk-1 + SRF→c-Fos表达；c-Jun→AP-1)
  → 促进细胞增殖相关基因表达(Cyclin D等)
```

**Ras核心地位**：约**30%人类肿瘤**中Ras突变(如G12V)导致GTP酶活性丧失→Ras持续激活→持续增殖信号。

**信号终止**：受体被PTP(酪氨酸磷酸酶)去磷酸化；Ras·GTP被GAP促进水解→Ras·GDP；受体经泛素化(Cbl)→内吞降解。

### 11.6 其他重要信号通路 ⭐⭐⭐

>🖼️ **配图**：`./images/cellbio/fig-11-5.png` — 见教材 **图11-5 信号级联放大示意图**（一个信号分子→激活多个G蛋白→每个激活的AC产生大量cAMP→每个PKA磷酸化多个靶蛋白→信号被逐级放大可达10⁶~10⁸倍；各信号通路的交汇节点与串扰crosstalk）

#### 11.6.1 JAK-STAT通路

细胞因子(IL/IFN/EPO/生长激素)结合受体→受体二聚化→结合**JAK**(Janus kinase，酪氨酸激酶)→JAK交叉自磷酸化→磷酸化受体Tyr→招募**STAT**(SH2结合pTyr)→STAT被JAK磷酸化→STAT二聚化→入核→结合GAS元件→转录靶基因。**直接通路**(无第二信使)，从受体到核仅需3步。

#### 11.6.2 TGF-β-Smad通路

TGF-β→**RII受体**(Set/Thr激酶)组成性活化→招募并磷酸化**RI受体**→RI磷酸化**R-Smad**(Smad2/3)→R-Smad与**Smad4**(co-Smad)结合→入核→协同其他转录因子调控EMT/增殖抑制/细胞外基质基因。

#### 11.6.3 Wnt/β-catenin通路

**无Wnt时**：降解复合物(Axin+APC+GSK-3β+CK1)→GSK-3β磷酸化β-catenin→β-TrCP泛素化→蛋白酶体降解→胞质β-catenin低水平。

**Wnt结合Frizzled/LRP**：→招募Dishevelled(Dvl)→降解复合物解聚→GSK-3β失活→β-catenin累积→入核→与**TCF/LEF**转录因子结合→激活增殖基因(Myc/Cyclin D)。

>⚠️ **APC突变**：家族性腺瘤性息肉病(FAP)和>80%散发性结直肠癌→β-catenin持续激活。

#### 11.6.4 Notch通路

Notch受体合成后在高尔基被**Furin切割(S1)**→形成异二聚体至细胞表面。配体Delta/Jagged结合→**ADAM金属蛋白酶切割(S2)**→**γ-分泌酶切割(S3，跨膜内)**→释放**NICD**(Notch胞内域)→入核+CSL转录因子+共激活物MAML→激活靶基因(Hes/Hey)。**侧向抑制**：Notch高→抑制邻近细胞分化。

#### 11.6.5 NF-κB通路

静息态：NF-κB(p50/p65)被**IκB**(抑制蛋白)扣押在胞质。TNF-α/IL-1/LPS→**IKK**(IκB激酶)激活→磷酸化IκB→泛素化降解→**NF-κB释放入核**→结合κB元件→炎症因子/抗凋亡/增殖基因表达。广泛参与免疫、炎症、肿瘤。

### 11.7 第二信使总表 ⭐⭐⭐

| 第二信使 | 产生途径 | 降解/清除 | 主要作用 |
|----------|----------|-----------|----------|
| **cAMP** | AC催化ATP→cAMP | PDE→5'-AMP | 激活PKA、CNG离子通道 |
| **cGMP** | GC(鸟苷酸环化酶)催化GTP→cGMP | PDE→5'-GMP | 激活PKG、光感受器暗适应 |
| **IP₃** | PLC水解PIP₂ | 磷酸酶逐步去磷酸→IP₂→IP→I | 开放ER IP₃受体Ca²⁺通道 |
| **DAG** | PLC水解PIP₂ | DAG激酶→PA；DAG脂酶 | 激活PKC |
| **Ca²⁺** | IP₃/电压门控/配体门控通道 | Ca²⁺-ATP酶泵回ER/胞外 | 激活CaM/CaMK/PKC等 |
| **NO** | NOS(一氧化氮合酶)催化Arg→NO | 自发氧化为NO₂⁻/NO₃⁻ | 激活sGC→cGMP↑(血管舒张) |
| **PIP₃** | PI3K磷酸化PIP₂ | PTEN(磷酸酶)→PIP₂ | 招募PH域蛋白(Akt/PDK1) |

### 11.8 信号级联放大效应 ⭐⭐

肾上腺素促糖原分解级联：**1分子**肾上腺素→1个GPCR→多个Gαs→多个AC→**10² cAMP**→多个PKA→多个磷酸化酶激酶→多个糖原磷酸化酶→**10⁷个**葡萄糖-1-磷酸。总放大约**10⁷倍**。

### 11.9 信号转导的整合与调控 ⭐⭐⭐

**五大特征**：

| 特征 | 说明 | 例证 |
|------|------|------|
| **特异性** | 不同细胞对同一信号不同反应 | ACh→骨骼肌收缩/心肌舒张/唾液腺分泌 |
| **放大** | 酶级联逐级放大 | 肾上腺素→10⁷倍放大 |
| **网络化** | 多条通路交叉对话(crosstalk) | Ca²⁺信号影响cAMP通路 |
| **反馈调控** | 正反馈强化/负反馈抑制 | PKC磷酸化受体→脱敏(负反馈) |
| **整合** | 多信号输入综合决定输出 | 增殖决策需生长信号+营养+锚定 |

**受体脱敏五种机制**：

1. **受体磷酸化**：GRK(GRK2)磷酸化激活GPCR→β-arrestin结合→G蛋白解耦
2. **受体内吞**：β-arrestin招募网格蛋白/AP2→网格蛋白包被小窝→内吞
3. **受体下调**：持续刺激→受体泛素化→溶酶体降解(数量减少)
4. **第二信使降解**：PDE降解cAMP/cGMP
5. **抑制蛋白**：IκB扣押NF-κB、Smad7抑制TGF-β通路

### 11.10 四类信号通路综合对比 ⭐⭐⭐

| 类型 | 受体 | 信号传递 | 速度 | 可逆性 |
|------|------|----------|:---:|:---:|
| **GPCR通路** | 7次跨膜+G蛋白 | 第二信使扩散+激酶级联 | 秒～分 | 可逆(脱敏/磷酸酶) |
| **RTK通路** | 单次跨膜+激酶域 | 磷酸化级联+小G蛋白 | 分～时 | 可逆(磷酸酶/GAP) |
| **核受体通路** | 胞内受体 | 配体结合→构象变化→直接入核结合DNA | 时 | 可逆(配体解离) |
| **Notch/蛋白水解** | 含切割位点 | **不可逆蛋白水解**→ICN入核 | 时 | **不可逆**(受体被切割降解) |

>⚠️ Notch通路独特性：信号传递依赖受体本身的**不可逆蛋白水解**，每个Notch分子只能传递一次信号。

### 12.3 有丝分裂全过程 ⭐⭐⭐

>🖼️ **配图**：`./images/cellbio/fig-12-2.png` — 见教材 **图12-2 有丝分裂过程**（前期→前中期→中期→后期→末期→胞质分裂各阶段的典型细胞形态和染色体行为变化；纺锤体微管的三类：星体微管+极微管+动粒微管；收缩环的形成与缢裂）

#### 前期(Prophase)

- **凝缩蛋白(condensin)**加载→染色质凝集成染色体(每条含2条姐妹染色单体)
- **黏连蛋白(cohesin)**沿染色单体臂分布，维持姐妹染色单体配对
- 中心体分离移向两极(驱动蛋白Eg5推动)→星体微管+极微管+动粒微管形成
- 核仁开始解体

#### 前中期(Prometaphase)

- 核膜破裂(NEBD)→纺锤体微管进入核区
- **搜索-捕获模型**：动粒微管从两极随机延伸→遇到染色体动粒→被捕获稳定
- **动粒(Kinetochore)KMN复合物**：CENP-A(着丝粒特异性H3变体)+Ndc80复合体(微管结合)+Mis12复合体
- 未连接动粒发出**等待信号**(Mad2/BubR1抑制Cdc20→APC/C不活化)

>🖼️ **配图**：`./images/cellbio/fig-12-4.png` — 见教材 **图12-4 纺锤体与动粒连接**（着丝粒-动粒-微管的分子连接：CENP-A→CCAN→KMN(Ndc80/Mis12/Knl1)→微管；星体微管/极微管/动粒微管三类微管的分布；两极纺锤体的对称结构；马达蛋白在纺锤体组装中的作用）

#### 中期(Metaphase)

- 染色体排列在赤道板，**牵拉力**(动粒微管缩短)与**外推力**(极微管滑动+kinesin推动)平衡
- 所有动粒被微管连接→Mad2/Bub解除→APC/C可活化
- **核型分析最常用于此期**：染色体最凝缩，形态最清晰

#### 后期(Anaphase)

- **APC/C-Cdc20**泛素化securin→**separase**(分离酶)释放
- Separase切割cohesin(黏连蛋白Scc1亚基)→姐妹染色单体分离
- **后期A**：动粒微管去极化缩短→染色体拉向两极(Kinesin-13/MCAK催化)
- **后期B**：极微管滑动(由Kinesin-5推动)+星体微管拉力→两极进一步远离

#### 末期(Telophase)+胞质分裂

- Cdk1失活(Cyclin B降解)→磷酸酶去磷酸化底物
- 核膜从ER重新形成→核孔复合体组装→染色体去凝集→核仁重现
- **胞质分裂**：赤道板处**收缩环**(actin + myosin II)形成→**分裂沟**加深→形成**中体**(中心纺锤体残余)→最终切断
- 中体位置决定分裂平面(受星体微管信号调控)

### 12.4 减数分裂 ⭐⭐⭐

>🖼️ **配图**：`./images/cellbio/fig-12-3.png` — 见教材 **图12-3 减数分裂过程**（减数分裂I：前期I五亚期→中期I二价体排列→后期I同源染色体分离→末期I；减数分裂II：类似有丝分裂→姐妹染色单体分离→形成四个遗传独特的单倍体细胞；交叉chiasma的形成与遗传重组的关系）

#### 12.4.1 减数分裂I（减数分裂，2n→n）

**前期I（最关键，五亚期）**：

| 亚期 | 关键事件 |
|------|----------|
| **细线期** | 染色质凝集；**SPO11**产生DNA双链断裂(DSB)，启动同源重组 |
| **偶线期** | 同源染色体配对(**联会**synapsis)；**联会复合体(SC)**形成：横向纤维连接侧向元件 |
| **粗线期** | 联会完成→DSB修复：**Dmc1/Rad51**介导链侵入→形成**dHJ**(双霍利迪连接体)→交叉/非交叉产物；交换产生**交叉(chiasma)** |
| **双线期** | SC解体，同源染色体开始分开，交叉点端化(向末端移动)，交叉仍维持连接 |
| **终变期** | 染色体进一步凝缩，交叉端化至末端，**二价体**(四分体)最清晰 |

**中期I**：二价体排列赤道板，姐妹动粒朝向同一极(单方向附着)

**后期I**：同源染色体分离(1n,2c)，交叉消失；**着丝粒区cohesin被Shugoshin保护不被切割**→姐妹染色单体保持连接

**末期I+胞质分裂I**

#### 12.4.2 减数分裂II（均等分裂，类似有丝分裂）

- **无DNA复制**直接在末期I后进入
- 姐妹染色单体动粒朝向相反两极(双方向附着，与有丝分裂相同)
- 着丝粒区cohesin被降解(Shugoshin被去除)→姐妹染色单体分离→(1n,1c)

#### 12.4.3 减数分裂关键分子

| 分子 | 功能 |
|------|------|
| **SPO11** | 产生程序性DSB，启动重组 |
| **Dmc1**(减数分裂特化)+**Rad51**(通用) | 链侵入，同源重组核心酶 |
| **SC(联会复合体)** | 横向纤维(Zip1)+侧向元件(Cohesin核心)+中央元件 |
| **Rec8**(cohesin减数分裂特化亚基) | 替代Scc1，沿染色单体臂分布，维持姐妹单体配对 |
| **Shugoshin** | 保护着丝粒区Rec8-cohesin，防止减I时被切割 |

#### 12.4.4 减数分裂错误 ⭐⭐

| 错误类型 | 机制 | 后果 |
|----------|------|------|
| **非整倍体** | 染色体不分离(减I—同源染色体；减II—姐妹单体) | 单体/三体 |
| **21三体(唐氏综合征)** | **母源减I不分离**最常见(>90%卵子来源，随母龄↑) | 47,XX/XY,+21 |
| **18三体/13三体** | 减数分裂不分离 | 爱德华兹/帕陶综合征 |
| **性染色体非整倍体** | X不分离 | Turner(XO)/Klinefelter(XXY) |

### 12.5 细胞周期同步化方法 ⭐⭐

| 方法 | 原理 | 收集时期 |
|------|------|:---:|

**发现史完整时间线**：

| 年份 | 科学家 | 发现 |
|------|--------|------|
| 1971 | **Masui & Markert** | 爪蟾卵中发现MPF活性——注射成熟卵胞质→驱动未成熟卵母细胞G₂→M |

### 13.3 DNA复制执照因子系统 ⭐⭐⭐

**后随链DNA复制严格控制"一次且仅一次"复制**：

```
G₁期：ORC(起始识别复合体)结合复制起始点
  → 招募Cdc6(AAA+ATP酶)+Cdt1
  → 装载MCM2-7解旋酶(执照因子)→前复制复合体(pre-RC)
  → 获得"执照"(license)——允许启动一次复制
S期：CDK2/Cyclin E+DDK磷酸化MCM→激活解旋酶→复制叉启动
  → CDK同时磷酸化Cdc6(降解)+Cdt1(抑制)
  → 抑制Geminin蛋白结合Cdt1→阻止再装载MCM
  → 防止在同一周期内再复制
G₂/M期：高CDK活性持续抑制pre-RC组装
```

>⚠️ **意义**：确保每个复制起始点在一个细胞周期中仅被使用一次→维持基因组倍性稳定

### 13.5 p53调控网络 ⭐⭐⭐

**p53("基因组卫士")调控环路**：

>🖼️ **配图**：`./images/cellbio/fig-13-4.png` — 见教材 **图13-4 p53信号通路**（DNA损伤→ATM/ATR→Chk1/Chk2→磷酸化p53→p53稳定性增加→四聚体转录因子→激活p21(G₁/S阻滞)+GADD45(DNA修复)+14-3-3σ(G₂/M阻滞)+Bax/PUMA(凋亡)+PTEN(PI3K/Akt抑制)；MDM2负反馈环：MDM2泛素化p53→降解；ARF→抑制MDM2→稳定p53）

```
正常细胞：p53低水平——MDM2(E3泛素连接酶)结合p53→泛素化→蛋白酶体降解→负反馈
DNA损伤：ATM/ATR激酶→磷酸化Chk1/Chk2
  → ① 磷酸化p53 Ser15/20→减弱MDM2结合→p53稳定累积
  → ② 磷酸化MDM2→MDM2自降解→p53进一步稳定
  → p53四聚体作为转录因子→激活靶基因：
```

| 靶基因 | 功能 | 结果 |
|--------|------|------|
| **p21** | CDK抑制(CDK2/1) | **细胞周期阻滞**(G₁/S或G₂/M) |
| **GADD45** | DNA修复+周期阻滞 | DNA修复 |
| **14-3-3σ** | 扣押Cyclin B/CDK1于胞质 | G₂/M阻滞 |
| **Bax** | 促凋亡效应者 | **凋亡**(严重损伤) |
| **PUMA** | BH3-only→激活Bax/Bak | **凋亡**(严重损伤) |
| **PTEN** | 抑制PI3K/Akt促存活通路 | 抑制增殖/促进凋亡 |

>⚠️ **p53突变**：>50%人类肿瘤中p53失活——多数为**错义突变**在DNA结合域，突变蛋白不仅失活还能抑制残余野生型p53(dominant-negative)

### 13.6 Rb(视网膜母细胞瘤蛋白) ⭐⭐⭐

- **低磷酸化Rb**(G₀/G₁早期)：结合E2F→HDAC招募→抑制S期基因转录→周期阻滞
- **磷酸化Rb**(G₁晚期→M)：Cyclin D/CDK4/6启动→Cyclin E/CDK2完成→Rb过度磷酸化→释放E2F→自由E2F+DP→激活S期基因(Cyclin E/A, DNA聚合酶, PCNA等)
- **Knudson二次打击**：视网膜母细胞瘤需Rb基因双等位基因失活(遗传性—一次生殖系突变+一次体细胞突变；散发—两次体细胞突变)

### 13.6b pRb-E2F通路详解 ⭐⭐⭐

**pRb-E2F是G₁/S转换的核心开关**：

1. **G₀/G₁早期（低CDK活性）**：
   - pRb**低磷酸化**→结合E2F1-3转录因子（与DP1/2形成异二聚体）→招募**HDAC**(组蛋白去乙酰化酶)+**SWI/SNF**染色质重塑复合物+**Suv39H1**(H3K9甲基化酶)→局部染色质压缩→**沉默S期基因**（Cyclin E/A、CDK2、DNA聚合酶α、PCNA、MCM等）。

2. **G₁中期→晚期（CDK逐步激活）**：
   - **Cyclin D/CDK4/6**（生长因子信号→Ras→MAPK→Cyclin D表达）→**磷酸化pRb C端**(Ser780/795等，低磷酸化)→pRb部分失活→少量E2F释放→**Cyclin E转录开始**。
   - **Cyclin E/CDK2**→**过度磷酸化pRb**(更多位点)→pRb完全失活→E2F大量释放→**正反馈**：E2F进一步激活Cyclin E和CDK2自身表达→形成"全或无"开关→不可逆通过**限制点R**。

3. **S/G₂/M期（pRb持续失活）**：
   - Cyclin A/CDK2和Cyclin B/CDK1维持pRb磷酸化→直至M期末Cdh1激活→磷酸酶(PP1)去磷酸化pRb→恢复低磷酸化→进入G₁。

4. **pRb通路的癌变意义**：
   - pRb功能丧失=限制点失效→不受控进入S期（视网膜母细胞瘤、骨肉瘤、小细胞肺癌）。
   - **HPV E7**→结合并降解pRb→pRb失活（宫颈癌发生的分子机制之一）。
   - **p16^INK4a缺失/甲基化**→无法抑制CDK4/6→pRb持续磷酸化失活（多种肿瘤）。

### 13.6c 肿瘤异质性与肿瘤微环境 ⭐⭐⭐

**肿瘤异质性(Tumor Heterogeneity)**：

| 类型 | 描述 | 机制 | 临床影响 |
|------|------|------|----------|
| **肿瘤间异质性** | 不同患者同一类型肿瘤的差异 | 种系遗传背景+环境暴露+随机体细胞突变 | 需个体化/精准治疗 |
| **肿瘤内异质性** | 同一肿瘤内不同区域/克隆的差异 | 基因组不稳定性+CSC分化层级+微环境差异+克隆进化 | 单一活检可能遗漏关键突变 |
| **时间异质性** | 同一肿瘤在治疗过程中的演变 | 治疗选择压力→耐药克隆扩增→获得性耐药 | 需动态监测ctDNA/CTC |

**克隆进化模型**：肿瘤由单一祖先细胞（founder clone）不断积累突变→分支进化(branched evolution)→多个亚克隆共存→Darwinian选择（治疗→敏感克隆死亡→耐药克隆优势生长）。

**肿瘤微环境(TME)**：

| TME组分 | 细胞类型 | 促肿瘤作用 |
|---------|----------|-----------|
| **癌症相关成纤维细胞(CAF)** | 成纤维细胞活化(α-SMA⁺) | 分泌生长因子(HGF/EGF/TGF-β)+MMP重塑ECM→促侵袭 |
| **肿瘤相关巨噬细胞(TAM)** | M2型极化 | 分泌VEGF/MMP/IL-10→促血管生成+免疫抑制 |
| **髓源性抑制细胞(MDSC)** | 未成熟髓系细胞 | 抑制CD8⁺T细胞和NK细胞功能→免疫逃逸 |
| **调节性T细胞(Treg)** | CD4⁺Foxp3⁺ | 抑制抗肿瘤免疫应答 |
| **肿瘤血管** | 内皮细胞+周细胞 | 结构异常(迂曲渗漏)→缺氧微环境→促EMT+耐药 |
| **ECM重塑** | 胶原/纤连蛋白交联+HA积累 | 基质硬度↑→整合素信号→YAP/TAZ入核→促增殖+EMT |

**治疗意义**：靶向TME（抗血管生成如贝伐珠单抗、免疫检查点抑制如PD-1/CTLA-4抗体、CAF靶向、ECM降解酶递送）可与直接抗肿瘤药物协同。

### 13.7 APC/C(后期促进复合体/周期体) ⭐⭐⭐

APC/C为E3泛素连接酶，有两个关键适配蛋白：

| 适配蛋白 | 活跃时期 | 底物 | 功能 |
|----------|----------|------|------|
| **Cdc20** | 中期→后期 | Securin(→separase释放→cohesin切割→分离)、Cyclin B | 驱动后期起始 |
| **Cdh1** | 后期→G₁早期 | Cyclin A/B、Cdc20、Aurora A/B、Plk1等 | 维持M期退出后低CDK状态，允许pre-RC组装 |

**M期纺锤体检验点**：未连接动粒→Mad2/BubR1复合体→**抑制Cdc20**→APC/C不活化→等待信号

### 13.8 癌细胞基本特征 ⭐⭐⭐

1. **无限增殖**：端粒酶激活(85-90%)或ALT延长端粒；永生化
2. **接触抑制丧失**：多层堆积生长，不受密度调控
3. **锚定依赖性丧失**：软琼脂中可形成集落(体外转化标志)
4. **基因组不稳定**：突变率高、染色体异常(非整倍体/易位/扩增)
5. **抗凋亡**：Bcl-2过表达/p53突变/PI3K-Akt通路激活
6. **侵袭与转移**(见13.10)
7. **血管生成**：分泌VEGF、bFGF→诱导血管新生(肿瘤>1-2mm³需血管)
8. **代谢重编程**(见13.9)

### 13.9 Warburg效应(有氧糖酵解) ⭐⭐

**定义**：癌细胞即使在有氧条件下也优先进行糖酵解产生乳酸（而非氧化磷酸化），由**Otto Warburg**1924年发现。

- 正常细胞：有氧→氧化磷酸化(~36ATP/葡萄糖)；缺氧→糖酵解→乳酸(2ATP/葡萄糖)
- 癌细胞：有氧也大量糖酵解→乳酸

**意义**：糖酵解速率快→产生更多生物合成前体(戊糖磷酸途径→核苷酸；3-PG→丝氨酸；丙酮酸→丙氨酸)+乳酸酸化微环境促侵袭/抑免疫。临床应用：**PET-CT**(FDG-PET，¹⁸F-FDG标记葡萄糖→肿瘤高摄取显像)。

### 13.10 EMT(上皮-间充质转化)与转移级联 ⭐⭐⭐

**EMT**：上皮细胞→失去极性+E-Cadherin下调→获得间充质特征(N-Cadherin/Vimentin↑)→侵袭+迁移。

**转移级联**：

```
原发肿瘤 → 局部侵袭(EMT+MMP降解ECM)
  → 血管内渗(intravasation)→循环肿瘤细胞(CTC)
  → 血管外渗(extravasation)→转移灶形成(需适应新微环境)
  → 微小转移→临床可检测转移(MET：间充质→上皮恢复)
```

>⚠️ **转移是肿瘤致死首要原因**(>90%肿瘤死亡归因于转移)

### 13.11 癌基因与抑癌基因 ⭐⭐⭐

| 类型 | 代表 | 功能 | 突变方式 | 遗传模式 |
|------|------|------|----------|----------|
| **癌基因(oncogene)** | Ras, Myc, Src, HER2/Neu | 促进增殖 | 显性、**功能获得**(GOF) | 体细胞突变 |
| **抑癌基因(tumor suppressor)** | p53, Rb, APC, PTEN, BRCA1/2 | 抑制增殖/促凋亡/维持基因组稳定 | 隐性、**功能丧失**(LOF，二次打击) | 生殖系+体细胞 |

**癌基因激活三大机制**：

| 机制 | 举例 | 分子细节 |
|------|------|----------|
| **点突变** | **Ras G12V** | Gly12→Val→GTP酶活性丧失→Ras-GTP持续("卡在ON")→~30%人类肿瘤 |
| **基因扩增** | **Myc**(N-Myc/L-Myc) | 神经母细胞瘤中N-Myc扩增>100拷贝→双微体(DM)或HSR；乳腺癌HER2/Neu扩增 |
| **染色体易位** | **Bcr-Abl(费城染色体)** | t(9;22)→Bcr-Abl融合→组成性激活酪氨酸激酶→CML(慢性髓性白血病)；**伊马替尼(Gleevec)精准靶向治疗** |

**抑癌基因失活机制**：点突变(无义/错义)、缺失(LOH杂合性丢失)、启动子甲基化(表观遗传沉默)、病毒蛋白(HPV E6→p53降解；E7→Rb失活)

### 13.12 肿瘤干细胞假说

肿瘤中仅少数细胞(肿瘤干细胞CSC，<1%)具有无限增殖和致瘤能力，是常规放化疗后复发的根源（CSC处于静止/低增殖状态→对DNA损伤/抗有丝分裂剂耐受）。

## 第十四章 细胞分化与干细胞

### 14.1 细胞分化概念 ⭐⭐⭐

- **定义**：由同一受精卵产生的同源细胞，在形态结构功能上产生**稳定性差异**的过程
- **实质**：**基因的选择性表达**（基因组不变、表达谱改变）

>🖼️ **配图**：`./images/cellbio/fig-14-1.png` — 见教材 **图14-1 细胞分化层次示意图**（从受精卵→多能干细胞→多潜能祖细胞→终末分化细胞的层次递进关系；各层次对应的潜能范围；造血系统分化谱系作为经典范例）

- **管家基因**(housekeeping gene)：所有细胞都表达（组蛋白、核糖体蛋白、细胞骨架、糖酵解酶等）
- **奢侈基因**(luxury gene)：特定细胞特异性表达（血红蛋白→红细胞、胰岛素→胰岛β细胞、抗体→B细胞、角蛋白→表皮细胞）

### 14.2 组合调控(Combinatorial Control) ⭐⭐⭐

**核心概念**：少数转录因子的**特定组合**决定细胞命运，而非单一主控基因。

- MyoD基因是成肌决定基因的经典：将**MyoD导入成纤维细胞**→成纤维细胞转化为骨骼肌细胞
- 肌肉特异性基因表达需：MyoD + MEF2 + 其他辅助因子组合
- 同一转录因子在不同组合中可决定不同命运（如Oct4在ES细胞中维持多能性，但在不同组合中可诱导不同分化方向）

### 14.3 基因组等价性 ⭐⭐⭐

**概念**：个体所有体细胞含有与受精卵相同的基因组（T细胞受体重排和抗体VDJ重组除外）。

| 实验 | 年份 | 结论 |
|------|------|------|
| **Gurdon爪蟾核移植** | 1962 | 蝌蚪肠上皮细胞核→去核卵→蝌蚪→成蛙；证明终末分化细胞核保留全能性；**2012年诺贝尔奖** |
| **Dolly克隆羊** | 1997 | 乳腺上皮细胞核→去核卵(S期同步)→代孕母羊→Dolly；首例哺乳动物体细胞克隆 |
| **iPS细胞** | 2006 | Yamanaka四因子→成纤维细胞→多能干细胞，无需卵母细胞 |

### 14.4 胚胎诱导(Embryonic Induction) ⭐⭐⭐

**Spemann & Mangold 1924年组织者实验**（获**1935年诺贝尔奖**）：

- 将蝾螈早期原肠胚**背唇**(dorsal lip)移植到另一胚胎腹侧
- 结果：形成**第二个体轴**（次级胚胎），包括神经管、体节等
- 证明背唇具有"组织者(organizer)"活性—可诱导周围组织命运转变
- 分子基础：组织者分泌BMP抑制剂(Noggin/Chordin/Follistatin)→阻断BMP→默认命运为神经外胚层

**胚胎诱导级联**：初级诱导(脊索→神经管)→次级诱导(神经管→晶状体)→三级诱导(晶状体→角膜)

### 14.5 形态发生素梯度 ⭐⭐

| 模式系统 | 形态发生素 | 来源 | 调控 |
|----------|-----------|------|------|
| **果蝇前后轴** | **Bicoid**(转录因子) | 前极mRNA局部翻译→从前向后扩散→梯度分布 | 浓度依赖性激活不同靶基因(如hb高浓度→前部，kni低浓度→后部) |
| **果蝇背腹轴** | **Dorsal**(NF-κB同源) | 腹侧核定位→向背侧递减 | Toll通路激活→Dorsal入核梯度 |
| **脊椎动物肢芽** | **Shh**(Sonic Hedgehog) | 肢芽后部ZPA区 | 沿前后轴浓度梯度决定指(趾)类型 |
| **脊椎动物神经管** | **Shh**(腹侧化)+**BMP**(背侧化) | 脊索/底板(Shh)；表皮/顶板(BMP) | 双重梯度决定神经元亚型 |

### 14.6 细胞记忆的分子基础 ⭐⭐

分化状态的稳定维持依赖**表观遗传记忆**：

| 机制 | 维持方式 | 关键酶 |
|------|----------|--------|
| **DNA甲基化** | 复制后**DNMT1**(维持甲基化酶)识别半甲基化CpG→将新链对应位点甲基化 | DNMT1/DNMT3 |
| **组蛋白修饰** | **PcG**(Polycomb)蛋白维持基因沉默(H3K27me3)；**TrxG**(Trithorax)蛋白维持基因激活(H3K4me3) | PRC2(EZH2)/PRC1；MLL |
| **正反馈自调控** | 关键转录因子激活自身表达 | MyoD、Pax6 |
| **染色质重塑** | SWI/SNF复合体维持开放/关闭状态 | BRG1/BRM |

### 14.7 细胞分化的全能性 ⭐⭐⭐

| 分化程度 | 潜能 | 实例 |
|----------|------|------|
| **全能性(totipotency)** | 发育为完整个体+胚外组织 | 受精卵、8细胞期分裂球 |
| **多能性(pluripotency)** | 三胚层所有细胞类型 | 内细胞团(ICM)、ES细胞、iPS细胞 |
| **多潜能性(multipotency)** | 特定谱系内多种细胞 | 造血干细胞、神经干细胞、间充质干细胞 |
| **单能性(unipotency)** | 只能分化为一种细胞 | 表皮干细胞、精原干细胞 |
| **终末分化** | 不可再分化 | 神经元、心肌细胞、红细胞(无核) |

### 14.8 干细胞 ⭐⭐⭐

#### 14.8.1 干细胞分类

>🖼️ **配图**：`./images/cellbio/fig-14-3.png` — 见教材 **图14-3 干细胞分化谱系**（造血干细胞→髓系祖细胞+淋巴系祖细胞→各类血细胞的分化树状图；间充质干细胞→成骨/软骨/脂肪的分化方向；神经干细胞→神经元/星形胶质细胞/少突胶质细胞）

| 类型 | 来源 | 分化潜能 | 特点 |
|------|------|----------|------|
| **胚胎干细胞(ESC)** | 囊胚内细胞团(ICM) | 多能性 | 可无限增殖+多向分化；涉及伦理争议(破坏胚胎)；表达Oct4/Nanog/Sox2 |
| **成体干细胞** | 各组织(骨髓/皮肤/肠隐窝/脑室下区等) | 多潜能 | 维持组织稳态和损伤修复；含量低(~0.1-1%)；niche微环境调控 |
| **iPS细胞** | 体细胞重编程获得 | 多能性 | 2006 Yamanaka→2012诺奖；**无伦理问题**；患者特异性疾病模型 |

#### 14.8.2 iPS细胞详细

>🖼️ **配图**：`./images/cellbio/fig-14-2.png` — 见教材 **图14-2 iPS重编程**（Yamanaka四因子(Oct4/Sox2/Klf4/c-Myc)通过反转录病毒载体导入体细胞→逐步重编程过程：体细胞标志↓→早期重编程标志↑→多能性标志Oct4/Nanog激活→内源多能性网络建立→外源因子沉默→获得iPS；技术迭代：整合型→非整合型→化学重编程CiPS）

**Yamanaka四因子**(2006)：**Oct4 + Sox2 + Klf4 + c-Myc**(OSKM)，反转录病毒载体导入小鼠成纤维细胞→iPS。

**Thomson四因子**(2007)：**Oct4 + Sox2 + Nanog + Lin28**（人源，避开c-Myc致癌风险）。

**技术迭代**：

| 方法 | 优点 | 缺点 |
|------|------|------|
| 反转录病毒/慢病毒 | 高效 | **基因组整合**→致癌风险 |
| 腺病毒/仙台病毒 | 不整合 | 效率低 |
| 质粒/episomal | 不整合 | 超低效率 |
| mRNA/蛋白质 | 零整合风险 | 需多次转染 |
| **化学重编程(CiPS)** | 小分子化合物，无遗传操作 | 目前效率尚低 |

**效率与安全**：OSKM效率~0.01-0.1%；c-Myc致癌→四因子中可省略(效率降至~0.001%)或替代为L-Myc/Glis1

### 14.9 影响细胞分化的因素 ⭐⭐

1. **细胞质不均一性**：卵母细胞中mRNA/蛋白质/miRNA分布不均→分裂后子细胞胞质不同→命运差异
2. **细胞间相互作用**：胚胎诱导(如脊索→诱导外胚层→神经管)、侧向抑制(Delta-Notch)
3. **位置信息-形态发生素**：浓度梯度提供位置信息
4. **激素调节**：甲状腺素→蝌蚪变态；蜕皮激素→昆虫蜕皮
5. **细胞记忆**：表观遗传维持分化状态

### 14.10 转分化(Transdifferentiation) ⭐⭐

**定义**：一种分化细胞**直接**转变为另一种分化细胞，不经过多能干细胞中间阶段。

- 实例：成纤维细胞→神经元(过表达Brn2/Ascl1/Myt1l)；胰腺外分泌细胞→胰岛β细胞(过表达Pdx1/Ngn3/MafA)
- 与iPS区别：转分化不经过多能状态，更直接但谱系受限

## 第十五章 细胞衰老与细胞程序性死亡

### 15.1 细胞衰老 ⭐⭐⭐

**Hayflick界限**(1961)：正常成纤维细胞体外培养约**50代**后停止分裂→进入复制性衰老。

**复制性衰老根本原因**：**端粒缩短**。每次分裂端粒缩短50-100bp（末端复制问题：后随链RNA引物去除后5'端无法补齐）。当端粒过短→暴露染色体末端→DNA损伤信号→ATM/ATR→p53/p21→细胞周期不可逆阻滞→衰老。

### 15.2 端粒结构详解 ⭐⭐⭐

- **端粒DNA**：重复序列**(TTAGGG)n**（人），长度5-15kb；3'悬突(overhang)侵入双链区形成**T-loop**+**D-loop**，保护染色体末端不被识别为DSB

>🖼️ **配图**：`./images/cellbio/fig-15-1.png` — 见教材 **图15-1 端粒结构（T-loop）**（端粒DNA 3'悬突侵入双链端粒重复区→形成T-loop和D-loop结构；Shelterin六蛋白复合体(TRF1/TRF2/POT1/TIN2/TPP1/RAP1)在T-loop上的分布；端粒酶(hTERT+hTR)识别3'端并添加TTAGGG重复）

- **Shelterin复合体（六聚体）**：

| 组分 | 功能 |
|------|------|
| **TRF1** | 双链端粒DNA结合，负调控端粒长度 |
| **TRF2** | 双链端粒DNA结合，**维持T-loop结构**，抑制ATM信号→**阻止NHEJ末端融合** |
| **POT1** | 结合3'悬突单链DNA，抑制ATR信号和C-stretch降解 |
| **TIN2** | 桥接TRF1+TRF2，招募TPP1 |
| **TPP1** | 连接TIN2和POT1；招募端粒酶 |
| **RAP1** | 结合TRF2，辅助功能 |

**TRF2缺失→T-loop解体→染色体末端暴露→ATM→DNA损伤修复→NHEJ融合→双着丝粒染色体→断裂-融合-桥循环→基因组灾难**

### 15.3 端粒酶 ⭐⭐⭐

- **组成**：**hTERT**(催化亚基，逆转录酶) + **hTR**(RNA模板，含AAUCCC互补序列) + dyskerin等辅助蛋白
- **机制**：以hTR为模板逆转录合成TTAGGG重复添加到3'端→端粒延长→端粒酶脱落→后随链补齐(C-strand由常规DNA聚合酶合成)
- **表达分布**：胚胎/生殖细胞/成体干细胞(高)→体细胞(无/极低)→增殖活跃的祖细胞(低，随年龄下降)
- **肿瘤中**：**85-90%癌细胞**重新激活端粒酶→维持端粒长度→无限增殖；5-10%用**ALT**(替代端粒延长机制，以同源重组方式延长)
- **临床**：端粒酶抑制剂(如Imetelstat)在临床试验中

### 15.4 复制性衰老(RS) Vs 应激诱导早衰(SIPS) ⭐⭐

| 项目 | 复制性衰老(RS) | 应激诱导早衰(SIPS) |
|------|---------------|-------------------|
| **诱因** | 端粒缩短→DNA损伤信号 | 氧化应激/癌基因激活(Ras)/DNA损伤/染色质紊乱 |
| **端粒依赖** | **是** | **否**(端粒未缩短即停滞) |
| **时间** | 需数十次分裂 | 数天内 |
| **p53/p21** | 激活(ATM/ATR) | 激活(DNA损伤途径) |
| **p16/Rb** | 低/中 | **高**(主要贡献者) |
| **生物学意义** | 肿瘤天然屏障(增殖极限) | 防止受损/癌前细胞扩增 |

### 15.5 衰老标志物完整表 ⭐⭐⭐

| 标志物 | 类型 | 说明 |
|--------|------|------|
| **SA-β-gal** | 酶活性 | 溶酶体β-半乳糖苷酶在pH6.0活性(衰老最常用标志) |
| **p16ᴵᴺᴷ⁴ᵃ** | CDK抑制 | 抑制CDK4/6，衰老中显著上调 |
| **p21** | CDK抑制 | p53靶基因，DNA损伤/端粒缩短后表达 |
| **γH2AX foci** | DNA损伤 | 持续DNA损伤灶(telomere dysfunction-induced foci, TIF) |
| **SASP** | 分泌表型 | IL-6/IL-8/MMPs/TGF-β等分泌 |
| **SAHF** | 染色质 | 衰老相关异染色质灶(H3K9me3+HP1+MacroH2A)，沉默促增殖基因 |
| **Lamin B1** | 核纤层 | **表达下降/丢失**(衰老新标志) |
| **端粒长度** | DNA | 缩短至临界长度 |

### 15.6 SASP(衰老相关分泌表型) ⭐⭐

衰老细胞分泌多种因子：**IL-6/IL-8/GROα**(炎症因子)、**MMP-1/3**(基质金属蛋白酶，破坏ECM)、**TGF-β**(旁分泌衰老)、**VEGF**(血管生成)、**GM-CSF**等。

**双重效应**：

- **短期有益**：吸引免疫细胞清除衰老细胞+损伤修复+限制纤维化
- **长期有害(inflammaging)**：慢性低度炎症→组织微环境恶化→促进邻近细胞衰老+肿瘤发生+退行性病变

### 15.7 细胞凋亡外源通路(死亡受体) ⭐⭐⭐

>🖼️ **配图**：`./images/cellbio/fig-15-2.png` — 见教材 **图15-2 凋亡外源通路**（FasL/Fas→FADD→Procaspase-8→DISC→Caspase-8自激活→切割效应Caspase-3/7→凋亡执行；II型细胞中Caspase-8切割Bid→tBid→线粒体放大通路）

```
FasL(三聚体)结合Fas(死亡受体，三聚化)
  → 胞内死亡域(DD)招募FADD(接头蛋白，含DD+DED)
  → FADD通过DED招募Procaspase-8 → 形成DISC(死亡诱导信号复合物)
  → Caspase-8自切割激活 → 切割激活效应Caspase-3/7
  → Caspase-3切割：
      · ICAD→释放CAD→降解DNA(核小体间切割→180bp梯状条带)
      · PARP(聚ADP-核糖聚合酶，DNA修复酶)→PARP失活→DNA不被修复
      · 核纤层蛋白(Lamin)→核膜解体，染色质凝缩
      · 细胞骨架蛋白→细胞皱缩、出泡→凋亡小体
```

>⚠️ **II型细胞需线粒体放大**：Caspase-8切割Bid→tBid(BH3-only)→激活Bax/Bak→Cyt c释放→增强Caspase-3激活（如肝细胞）

### 15.8 细胞凋亡内源通路(线粒体/BCL-2调控) ⭐⭐⭐

>🖼️ **配图**：`./images/cellbio/fig-15-3.png` — 见教材 **图15-3 凋亡内源通路**（DNA损伤/缺氧→BH3-only激活→Bax/Bak寡聚化→MOMP→Cyt c+Smac释放→Cyt c/Apaf-1/dATP→凋亡体→Caspase-9→Caspase-3；Smac拮抗XIAP解除Caspase抑制；Bcl-2/Bcl-xL阻止MOMP→抗凋亡）

```
DNA损伤/缺氧/生长因子撤除/内质网应激
  → BH3-only蛋白(Bim/Bid/Puma/Noxa)感知应激信号
  → BH3-only激活Bax/Bak → Bax/Bak寡聚化→嵌入线粒体外膜
  → MOMP(线粒体外膜通透化) → 释放：
      ① Cyt c(细胞色素c) → 结合Apaf-1 + dATP → Apoptosome凋亡体(七聚体轮状)
        → 招募Procaspase-9→Caspase-9自激活→激活Caspase-3
      ② Smac/DIABLO → 拮抗IAP(XIAP) → 解除对Caspase-3/9的抑制
      ③ AIF(凋亡诱导因子)/EndoG → 转位到核→Caspase非依赖DNA降解
```

### 15.9 Bcl-2家族完整分类 ⭐⭐⭐

| 类别 | 成员 | 功能 |
|------|------|------|
| **抗凋亡(多BH域)** | **Bcl-2, Bcl-xL, Bcl-w, Mcl-1, A1/Bfl-1** | 结合并抑制Bax/Bak；常过表达于肿瘤 |
| **促凋亡效应者(多BH域)** | **Bax, Bak** | 寡聚化→线粒体外膜孔→MOMP→Cyt c释放 |
| **BH3-only(感受器)** | **Bid**(Caspase-8切割激活，连接内外通路), **Bim**(细胞骨架/微管扰动), **Puma**(p53靶基因), **Noxa**(p53靶基因), **Bad**(生长因子撤除→去磷酸化激活) | 激活/抑制Bax/Bak或中和抗凋亡成员 |

**调控逻辑**：最终命运取决于抗凋亡 vs 促凋亡成员相对比例（"变阻器模型"）

### 15.10 IAP-Smac拮抗系统 ⭐⭐

| 组分 | 功能 |
|------|------|
| **XIAP** | 含BIR2(结合Caspase-3活性位点)+BIR3(结合Caspase-9)→直接抑制Caspase活性 |
| **cIAP1/2** | E3泛素连接酶→泛素化Caspase和促凋亡蛋白→降解 |

### 15.11 四种细胞死亡方式详细对比 ⭐⭐⭐

>🖼️ **配图**：`./images/cellbio/fig-15-4.png` — 见教材 **图15-4 凋亡vs坏死形态对比**（凋亡：细胞皱缩→膜出泡→凋亡小体形成→被吞噬，膜完整无炎症；坏死：细胞肿胀→膜破裂→内容物泄漏→炎症反应；焦亡：肿胀+质膜孔(GSDMD)→IL-1β/IL-18释放→强烈炎症；自噬性死亡：大量自噬体/溶酶体积累）

| 特征 | **凋亡(Apoptosis)** | **坏死(Necrosis)** | **自噬性死亡** | **焦亡(Pyroptosis)** |
|------|-------------------|-------------------|--------------|---------------------|
| **触发** | 发育/损伤/免疫 | 严重创伤/缺血/毒素 | 营养缺乏/应激 | 病原体/炎症小体 |
| **形态** | 细胞皱缩/膜出泡/凋亡小体/染色质凝集 | 肿胀/膜破裂/内容物泄漏 | 大量自噬体/溶酶体 | 肿胀+质膜孔形成 |
| **DNA降解** | 核小体间切割(180bp梯状) | 随机降解(涂片状) | 非必需降解 | 核凝缩+Caspase-1切割 |
| **ATP需求** | 需ATP(主动) | 不耗能(被动) | 需ATP | 需ATP |
| **炎症** | **无**(膜完整) | **有**(内容物泄漏→DAMPs) | 无 | **强**(释放IL-1β/IL-18) |
| **关键分子** | Caspase-3/8/9 | RIP1/RIP3/MLKL(程序性坏死) | Atg5/Atg7/LC3-II | **Caspase-1/4/5/11 + GSDMD** |
| **可调控性** | 高度调控 | 被动(除程序性坏死外) | 高度调控 | 高度调控 |

**程序性坏死(Necroptosis)**：TNF→RIP1→RIP3→磷酸化**MLKL**→MLKL转位质膜→穿孔→坏死样死亡（Caspase-8抑制时发生，凋亡备选方案）

**焦亡**：炎症小体(NLRP3/NLRC4/AIM2)→Caspase-1→切割**GSDMD**→N端片段在质膜上成孔(内径~18nm)→细胞肿胀破裂+释放IL-1β/IL-18→强烈炎症

### 15.11b 自噬（Autophagy）详细机制 ⭐⭐⭐

**自噬**是细胞通过溶酶体降解自身组分（蛋白质聚集体、受损细胞器、病原体等）的高度保守分解代谢过程，是细胞在应激条件下的重要生存机制。

**自噬的三种类型**：

| 类型 | 底物递送方式 | 降解底物 |
|------|-------------|----------|
| **巨自噬(Macroautophagy)** | 形成双层膜自噬体→与溶酶体融合 | 胞质蛋白、线粒体(线粒体自噬)、ER(ER-phagy) |
| **微自噬(Microautophagy)** | 溶酶体膜直接内陷包裹 | 少量胞质 |
| **分子伴侣介导的自噬(CMA)** | Hsc70识别KFERQ基序→LAMP-2A受体转运 | 含KFERQ基序的特异蛋白 |

**巨自噬核心通路（mTOR-ULK1-Atg5-Atg12-LC3）**：

```
营养充足：mTORC1活化 → 磷酸化ULK1(Ser757) + Atg13 → 抑制自噬起始
营养缺乏：mTORC1失活 → ULK1去磷酸化自激活 → 磷酸化Atg13+FIP200+Atg101
  → ULK1复合体定位至ER/线粒体接触位点(omegasome)
  → 招募PI3K复合体III(Vps34/Vps15/Beclin1/Atg14L) → 产生PI3P
  → PI3P招募WIPI2 → 进一步招募Atg12-Atg5-Atg16L复合体
  → Atg7(E1)+Atg10(E2)→Atg12共价连接Atg5→Atg12-Atg5-Atg16L复合体
  → 该复合体催化LC3-I + PE → LC3-II（脂化，锚定于自噬体膜）
  → LC3-II介导自噬体膜延伸+闭合+识别货物(p62/SQSTM1受体结合泛素化底物)
  → 自噬体与溶酶体融合→自噬溶酶体→内容物被酸性水解酶降解
```

**自噬的生物学功能**：

- ① **营养缺乏时的氨基酸/脂肪酸回收**：降解产物重新用于合成代谢。
- ② **细胞器质量控制**：线粒体自噬(mitophagy)——PINK1/Parkin通路→受损线粒体外膜积累PINK1→招募Parkin(E3)→泛素化线粒体外膜蛋白→p62识别→LC3-II包裹→降解（Parkin突变→早发帕金森病）。
- ③ **清除蛋白聚集体**：p62/SQSTM1同时结合泛素链和LC3→将泛素化蛋白聚集体靶向自噬体（p62突变→Paget骨病）。
- ④ **抗感染**：异源自噬(xenophagy)——包裹胞内病原体(如结核分枝杆菌、沙门氏菌)→递送至溶酶体灭活。
- ⑤ **发育与分化**：果蝇变态、哺乳动物着床前胚胎发育依赖自噬。

**自噬与疾病**：

- **自噬不足**→蛋白聚集→神经退行性疾病(AD/PD/HD)；受损线粒体积累→ROS↑→基因组不稳定→肿瘤易感。
- **自噬过度**→过度自噬性细胞死亡（如缺血再灌注损伤）。
- **肿瘤中自噬的双重角色**：早期→自噬抑制肿瘤（清除受损线粒体/减少ROS/防止基因组不稳定）；晚期→自噬支持肿瘤（提供营养/促进耐药/维持CSC干性）。

### 15.11c 铁死亡（Ferroptosis）⭐⭐⭐

**定义**：铁依赖的、脂质过氧化驱动的非凋亡性调节性细胞死亡，2012年由Brent Stockwell命名，是近年来细胞死亡研究的热点。

**核心机制**：

```
Fe²⁺(游离铁/不稳定铁池) + H₂O₂ → Fenton反应 → •OH(羟自由基)
  → 多不饱和脂肪酸(PUFA)磷脂(PUFA-PL，含花生四烯酸/肾上腺酸) → 脂质过氧化(ACSL4+LPCAT3→合成PUFA-PL；LOX脂氧合酶催化)
  → 脂质过氧化物积累(PL-OOH) → 膜完整性破坏 → 铁死亡
```

**铁死亡调控的核心通路（System Xc⁻-GSH-GPX4轴）**：

| 组分 | 功能 | 抑制效应 |
|------|------|----------|
| **System Xc⁻** (SLC7A11+SLC3A2) | 胞外cystine交换胞内glutamate(1:1) | **Erastin**抑制→cystine摄取↓→GSH合成↓ |
| **GSH(谷胱甘肽)** | GPX4的辅助底物 | BSO(丁硫氨酸亚砜胺)抑制GSH合成酶→GSH↓ |
| **GPX4(谷胱甘肽过氧化物酶4)** | 将PL-OOH还原为PL-OH→解毒脂质过氧化物 | **RSL3**直接抑制GPX4活性→脂质过氧化物积累 |
| **FSP1(铁死亡抑制蛋白1)/CoQ₁₀** | 独立于GPX4的平行抑制通路→还原脂质自由基 | FSP1抑制剂+iFSP1→与GPX4抑制协同 |

**铁死亡的特征**：

- **形态**：线粒体缩小+膜密度增加+嵴减少/消失（区别于凋亡/坏死/自噬）。
- **生化**：铁依赖+脂质过氧化物积累+GSH耗竭+GPX4失活；无Caspase激活；非MLKL/RIPK3依赖。
- **诱导剂**：Erastin(System Xc⁻抑制)、RSL3(GPX4抑制)、FIN56(GPX4降解)、FINO₂(铁氧化→脂质过氧化)。

**铁死亡的生物学与疾病意义**：

- ① **肿瘤治疗**：耐药肿瘤细胞（尤其间充质型/去分化型）对铁死亡高度敏感；联合诱导铁死亡可克服多种耐药（化疗耐药/靶向耐药/免疫治疗耐药）。
- ② **神经退行性疾病**：GPX4缺失→神经元铁死亡→海马神经元丢失；铁螯合剂或自由基清除剂具有神经保护潜力。
- ③ **缺血再灌注损伤**：再灌注时大量ROS+游离铁→铁死亡（ferrostatin-1可减轻IRI）。
- ④ **铁死亡与免疫**：CD8⁺T细胞释放IFNγ→下调肿瘤细胞SLC7A11/SLC3A2→促进肿瘤铁死亡→增强免疫治疗效果。

### 15.12 凋亡与疾病 ⭐⭐⭐

| 方向 | 机制 | 疾病 |
|------|------|------|
| **凋亡不足** | Bcl-2过表达[t(14;18)→Bcl-2在IgH增强子旁→过表达] | **滤泡性淋巴瘤**、CLL |
| | p53突变(>50%肿瘤中)→无法诱导凋亡 | 多种**恶性肿瘤** |
| | cIAP过表达 | 多种实体瘤 |
| **凋亡过度** | Aβ→p53/Bax↑→神经元凋亡 | **阿尔茨海默病(AD)** |
| | α-synuclein→线粒体功能障碍→凋亡 | **帕金森病(PD)** |
| | gp120→CD4⁺T细胞凋亡 | **AIDS**(免疫缺陷) |
| | 缺血再灌注→大量自由基+Ca²⁺超载→凋亡+坏死 | **心肌梗死/脑卒中** |

### 16.1 细胞连接 ⭐⭐⭐

>🖼️ **配图**：`./images/cellbio/fig-16-1.png` — 见教材 **图16-1 四种细胞连接**（紧密连接Occludin/Claudin封闭细胞间隙→黏着带Cadherin/Catenin连接肌动蛋白→桥粒Desmoglein/Desmocollin连接中间纤维→间隙连接Connexin连接子形成1.5nm通道→半桥粒整合素α6β4连接基膜；各连接在上皮细胞中的极性分布：顶端→基底依次排列）

| 连接类型 | 跨膜蛋白 | 连接细胞骨架 | 主要功能 |
|----------|----------|-------------|----------|
| **紧密连接** | Occludin, Claudin | 肌动蛋白 | 封闭细胞间隙，维持上皮极性 |
| **黏着带** | Cadherin(E-Cad) | 肌动蛋白(actin) | 机械连接，发育中的形态发生 |
| **桥粒** | Desmoglein, Desmocollin | 中间纤维 | 强韧机械连接(心/皮肤) |
| **间隙连接** | Connexin(6个=连接子) | — | 胞通讯，分子<1kD通过 |
| **半桥粒** | 整合素α6β4 | 中间纤维 | 连接上皮基底膜 |

### 16.2 细胞黏着分子(CAM)四大类 ⭐⭐

| 家族 | Ca²⁺依赖 | 结合方式 | 代表分子 | 功能 |
|------|:---:|------|------|------|
| **钙黏蛋白** | 是 | 同嗜性结合 | E-Cadherin(上皮)、N-Cadherin(神经) | 细胞间黏着 |
| **整合素** | 是(Mg²⁺) | 异嗜性(与ECM RGD序列) | α5β1(纤连蛋白受体) | 细胞-ECM黏着，信号传导 |
| **Ig超家族** | 否 | 同嗜或异嗜 | N-CAM, ICAM, VCAM | 免疫/发育/神经 |
| **选择素** | 是 | 异嗜性(识别糖基) | L-Selectin(白细胞)、P-Selectin | 炎症白细胞滚动 |

### 16.3 细胞外基质(ECM) ⭐⭐⭐

>🖼️ **配图**：`./images/cellbio/fig-16-2.png` — 见教材 **图16-2 细胞外基质组分**（胶原三螺旋结构+纤连蛋白二聚体RGD序列+蛋白聚糖核心蛋白GAG链+弹性蛋白交联网络+层粘连蛋白十字形结构+基膜IV型胶原网状结构；整合素介导细胞与ECM的黏着及由外向内/由内向外的双向信号传导）

| 组分 | 结构特点 | 功能 |
|------|----------|------|
| **胶原(Collagen)** | 3α链三螺旋(Gly-X-Y)n，X多为Pro,Y多为Hyp | **抗张力**，体内最丰富蛋白(~25%) |
| **纤连蛋白(FN)** | 二聚体，含RGD序列 | 桥联细胞(integrin)与ECM(胶原等) |
| **弹性蛋白** | 富含Gly+Pro，共价交联 | **弹性回缩**(大动脉/肺/皮肤) |
| **蛋白聚糖** | 核心蛋白+GAG链(硫酸软骨素/硫酸角质素等) | 抗压缩、信号分子储存与释放 |
| **层粘连蛋白** | 十字形αβγ三链 | 基膜主要成分 |

### 16.4 基膜

- **位置**：上皮/内皮/肌肉/脂肪细胞与结缔组织交界处
- **主要成分**：层粘连蛋白+IV型胶原+巢蛋白(Nidogen)+串珠素(Perlecan)
- **功能**：支撑+过滤+屏障(阻止肿瘤转移需首先突破基膜)
