## 一句话结论

把 RoseTTAFold 微调成一个扩散模型的**去噪网络**，RFdiffusion 就能从纯随机噪声出发**生成骨架**——在 25 个功能基序支架化基准问题中解出 **23 个**（Hallucination 15 个、RFjoint Inpainting 19 个），并把从头结合蛋白设计的实验成功率提高了**约两个数量级**。

## 研究问题

论文的出发点是一个观察：**扩散模型（DDPM）在图像与语言生成上已取得巨大成功，但在蛋白质上的应用此前很有限**。作者分析原因很可能在于——**蛋白主链几何与序列-结构关系的复杂性**。

作者列出 DDPM 适合蛋白质设计的三条性质：

1. **输出高度多样**——它被训练去「去噪」被高斯噪声污染的数据，学会随机地逆转这一污染过程，就能生成与训练数据相似但多样的输出；
2. **可在迭代生成的每一步被条件引导**到特定设计目标（通过提供条件信息）；
3. **几乎所有蛋白质设计应用都必须显式建模三维结构**——而**旋转等变的 DDPM** 可以用与全局参考系无关的表示来做。

作者的战略判断是：**应该借用结构预测方法中隐含的、对蛋白结构的深刻理解**。RoseTTAFold 恰好具备全部三条：生成高精度结构、以具有旋转等变性的刚性框架表示残基、其架构支持在残基 / 残基间距离与取向 / 三维坐标三个层面上加条件。

**与此前工作的关键差异**：RFjoint Inpainting 用 RF 在**一步内**围绕输入功能基序补全骨架。它能以原子精度支架化多种基序，但在**极简的位点描述**下失败（因为没有足够约束整体折叠），且因为是**确定性**的，对同一问题只能产出有限的多样性。RFdiffusion 的两个针对性改进是：

- **起点是随机噪声** → 每条去噪轨迹给出一个不同解；
- **结构通过多步去噪迭代渐进生成** → 几乎不需要任何起始结构信息。

## 方法与数据

**框架表示与加噪**

- 每个残基用 **Cα 坐标 + N–Cα–C 刚性取向**组成一个框架（frame）；
- 训练输入来自 PDB 采样结构，加噪**最多 200 步**；
- **平移**：对 Cα 坐标加 3D 高斯噪声；
- **取向**：在旋转矩阵流形上做**布朗运动**。

**损失函数（这是本文最容易被忽视、但最关键的技术决策）**

用**均方误差（m.s.e.）**，即框架预测与真实蛋白结构之间的 m.s.e.（**不做对齐**），在所有残基上平均。

作者明确对比了 RF 结构预测训练所用的 **FAPE**（frame aligned point error，框架对齐点误差）：

> 关键差异在于——**与 FAPE 不同，m.s.e. 损失对全局参考系不是不变的**，因此它**促成了相邻时间步之间全局坐标系的连续性**。

**推理流程**

初始化随机残基框架 → RFdiffusion 给出一次去噪预测 → 每个残基框架朝该预测方向迈步并加入噪声，作为下一步输入 → 加入噪声的性质与步长经过选择，使去噪过程匹配加噪过程的分布。

RFdiffusion 起初试图匹配与纯随机框架相容的**全部可能蛋白结构**，所以早期去噪结果**看起来不像蛋白**；随步数推进，可能性空间收窄，预测逐渐变得像蛋白（Fig.1c 展示了 300 残基链的完整轨迹）。

**序列设计**：用 **ProteinMPNN** 回填序列，通常每个设计采样 **8 条序列**。（作者也考虑过在 RFdiffusion 内同时设计结构与序列，但鉴于「扩散结构 + ProteinMPNN」的性能已足够好，未深入探索。）

**两项关键的训练策略**

1. **自条件（self-conditioning）**——模型可对**前一时间步的预测**做条件。这一设计的灵感来自 **AF2 中「循环（recycling）」的成功**，后者也是本文所用 RF 模型的核心。
2. **从预训练 RF 权重微调**。

**本文的「in silico 成功」判据（全文统一使用）**

用 AF2 结构预测网络验证，一个输出被视为成功需同时满足：

1. **高置信**——平均 pAE **< 5**；
2. **整体**上与设计结构的主链 RMSD **< 2 Å**；
3. 在**任何被支架化的功能位点**上主链 RMSD **< 1 Å**。

作者强调：这个判据已被发现与**实验成功相关**，且**比其他地方使用的基于模板建模（TM-score）的指标严格得多**。

## 关键图表解读

**Fig.1a — RF → RFdiffusion 的改造。** 上panel：扩散模型被训练去恢复被污染（加噪）的蛋白结构，并通过从随机噪声 X_T 迭代去噪生成新结构来逆转污染过程。中间panel左侧：**RF 结构预测网络**，主要输入是**序列**，额外结构信息以模板和初始坐标形式提供，预测最终三维坐标 X̂₀。中间panel右侧：**RFdiffusion**，主要输入变成**扩散后的残基框架（坐标与取向）**，同样预测最终 X̂₀。下panel：RFdiffusion 还接收自身上一步的预测作为**模板输入（self-conditioning）**。每个时间步 t（典型 **200 步**）中，RFdiffusion 接收上一步的 X̂₀^(t+1) 与 X_t，预测更新的 X̂₀^t；下一步坐标输入由一次**含噪插值**生成。

**Fig.1b — 适用范围的广度。** RFdiffusion 可以：无输入直接生成（顶行）；或按自上而下分别对**对称性规格 / 结合靶标 / 功能基序或对称功能基序**做条件。每种情况下都把随机噪声加上条件信息输入，迭代精修直到产生最终蛋白结构。

**Fig.1c — 300 残基链的无条件设计轨迹。** 逐步展示模型输入 X_t 与对应的 X̂₀ 预测。**高时间步（高 t）时 X̂₀ 与蛋白几乎不像**，随过程逐步精修为真实蛋白结构。

**Fig.2 — 单体生成（a–g）**

- **2a**：不同长度（300、600 残基）的无条件下游单体的 AF2 预测，r.m.s.d.（AF2 vs 设计）自左至右为 **0.90、0.98、1.15、1.67** Å。
- **2b**：RFdiffusion 的无条件设计是**新的、不存在于训练集中**（以与 PDB 的最高 TM-score 量化）；**与已知结构的偏离随长度增加而增大**。
- **2c**：无条件样本被 AF2 紧密复现，**上限约 400 个氨基酸**。
- **2d**：RFdiffusion 在无条件单体生成上**显著优于 Hallucination（with RF）**——双比例 z 检验，每条件 **n = 400** 个设计，**z = 9.5，P = 1.6 × 10⁻²¹**。Hallucination 虽能成功生成长度达 100 氨基酸的设计，但**超出该长度后 in silico 成功率迅速恶化**。
- **2e**：消融实验。**预训练（去掉：从未训练的 RF 起步）、RFdiffusion 微调、自条件、m.s.e. 损失（换成 FAPE 训练）**中的任何一项缺失都会**显著降低** RFdiffusion 的性能。
- **2f**：两个表达为可溶单体的 300 氨基酸蛋白案例，设计高度热稳定。
- **2g**：RFdiffusion 可以**对折叠信息做条件**。以此前设计的 TIM barrel（PDB **6WVS**）的二级结构与 block adjacency 为条件生成 TIM barrel，设计与 6WVS 的圆二色光谱谱图非常相似且高度热稳定。

- **4a**：**25 个**基准支架化问题的对比（收集自六篇近期文献）。in silico 成功定义为 AF2 vs 设计模型 r.m.s.d. < 2 Å、AF2 vs 天然功能基序 r.m.s.d. < 1 Å、AF2 pAE < 5。**每个问题生成 100 个设计**，此前未在该基准集上做过优化（Hallucination 需要一些）。**各方法在同一问题上的成功率是正相关的**，RFdiffusion 在所有方法都表现不佳的困难问题上仍会吃力。
- **4b**：四个 RFdiffusion 显著优于现有方法的案例。指标为「AF2 vs 设计 / vs 天然基序（Å），AF2 pAE」：5TRV long **1.17/0.57，4.73**；6E6R long **0.89/0.27，4.56**；7MRX long **0.84/0.82，4.32**；5TPN **0.59/0.49，3.77**。

- **4f**：经**微调**后，RFdiffusion 可支架化酶活性位点。氧化还原酶 EC1（PDB **1A4I**）案例：AF2 vs 设计主链 RMSD **0.88 Å**，AF2 vs 设计基序主链 **0.53 Å**，基序全原子 **1.05 Å**，pAE **4.47**。
- **4g**：EC1–5 活性位点的 in silico 成功率（判据比 4a 更严：基序主链 < 1 Å、主链与侧链原子 < 1.5 Å）。

- **5a**：设计 C3 对称三聚体，刚性持有三个 AHB2（ACE2 模拟物）拷贝，恰好匹配 SARS-CoV-2 刺突蛋白三聚体上的三个 ACE2 结合位点。输入为三个 AHB2 拷贝 + C3 噪声（中）；输出为 C3 对称寡聚体。AF2 预测以 **0.6 Å**（不对称单元）与 **2.9 Å**（C3 组装体）复现 AHB2 结构。

- **5d**：其他表征的 Ni²⁺ 结合蛋白 NiB2.15、NiB1.12、NiB1.20。图注注明：**ITC 图中每个点代表单次测量**。

**Fig.6 — 从头设计蛋白-结合蛋白（a–h）**

- **6b**：对五个靶标（Influenza A H1 HA、IL-7Rα、InsR、PD-L1、TrkA）设计的结合蛋白，**五个靶标全部**找到 BLI 响应 ≥ 阳性对照 50% 的命中。对 IL-7Rα、InsR、PD-L1、TrkA，**RFdiffusion 的成功率比原始设计活动高约两个数量级**。作者把这归因拆解为：**一个数量级来自 RFdiffusion 本身，第二个数量级来自用 AF2 过滤**（若此前活动也使用 AF2 过滤的估计成功率：HA **0%**；IL-7Rα **2.2%**；InsR **5.5%**；PD-L1 **3.7%**；TrkA **1.5%**）。

- **6g**：复合物的冷冻电镜结构与设计模型高度吻合，**r.m.s.d. 仅 0.63 Å**（界面侧链相互作用与 PDB 中最接近的结构**非常不同**）。
- **6h**：HA_20 结合蛋白单独的实验结构与设计模型叠合，**偏差仅 0.6 Å**。

## 主要结果与关键数字

### 一、无条件单体生成

| 指标 | 数值 |
| --- | --- |
| 设计长度 | 最多 **600** 残基 |
| AF2 紧密复现的上限 | 约 **400** 个氨基酸 |
| 实验表征 | **300 氨基酸设计中的 6 个**、**200 氨基酸设计中的 3 个**；CD 谱与设计的混合 α-β 拓扑一致，且**极度热稳定** |
| vs Hallucination（with RF） | z = **9.5**，P = **1.6 × 10⁻²¹**（n = 400/条件） |
| 速度 | 100 残基蛋白在 NVIDIA RTX A4000 GPU 上最快 **11 秒**；RF Hallucination 需约 **8.5 分钟** |
| 讨论中的总结 | **测试的无条件设计中约一半可溶表达** |

### 二、折叠条件化

| 折叠 | in silico 成功率 | 实验 |
| --- | --- | --- |
| TIM barrel | **42.5%** | 11 个设计，**至少 8 个**可溶、热稳定、CD 与设计一致 |
| NTF2 fold | **54.1%** | — |

### 三、对称寡聚体

| 指标 | 数值 |
| --- | --- |
| 送实验表征的设计数 | **608** |
| SEC 寡聚状态与设计一致（95% 置信区间内） | **至少 87 个** |
| 同上（99% 置信区间内） | **126 个** |
| D2 / D3 / D4 分子量符合预期 | **38 / 7 / 3** 个 |
| 二十面体送检 | **48** 个，其中 HE0902 形成均匀颗粒 |
| HE0902 直径 | **15 nm** |

**与 TIM barrel 的对照（本文最有启发性的设计观察）**：TIM barrel 是自然界中最丰富的折叠之一（8 链 8 螺旋）。RFdiffusion 生成的循环寡聚体超越了它——**HE0626** 是 C6 α-β 桶，含 **18 链 18 螺旋**；**HE0675** 是 C8 八聚体，内环 **16 条链**、外环 **16 条螺旋**，局部重复模式与 TIM barrel 非常相似（**螺旋:链 = 1:1**）。作者由此对比：**自然进化广泛探索了经典八链/八螺旋 TIM barrel 的结构变体，而 RFdiffusion 更容易探索桶曲率的全局改变**，从而发现螺旋与链数多得多的 TIM barrel 样结构。（**HE0600** 也是 α-β 桶，但每条螺旋配两条链，共 **24 链 12 螺旋**，因此局部模式与 TIM barrel 不同。）

### 四、功能基序支架化基准（25 题）

| 方法 | 解出题数 |
| --- | --- |
| **RFdiffusion** | **23 / 25** |
| RFjoint Inpainting | 19 / 25 |
| Hallucination | 15 / 25 |

- 在 RFdiffusion 解出的 23 题中，**有 19 题**的成功设计比例高于另外两种方法；
- RFdiffusion 的优异表现**不需要超参数调优或外部势**——而 Hallucination 可能需要针对具体问题优化；
- 在 **23 题中的 17 题**，**不在反向扩散轨迹中加噪**反而给出更高的 in silico 成功率；
- 支架化能力**与该基序是否出现在训练集中无关**。

### 六、酶活性位点

- **需要微调**才能获得 in silico 成功；
- EC1（PDB 1A4I）案例：AF2 vs 设计主链 RMSD **0.88 Å**，vs 基序主链 **0.53 Å**，基序全原子 **1.05 Å**，pAE **4.47**；
- **RFdiffusion 目前不能显式建模结合的小分子**——底物只能用**外部势**在活性位点周围引导生成「口袋」来隐式建模。演示案例：**retroaldolase 活性位点三联体**，隐式建模反应底物。

- 毒株：A/USA:Iowa/1943 H1N1；

## 对照与消融

论文的对照密度很高，且都是「有针对性的」而非泛泛的比较：

1. **方法学消融（Fig.2e）**——去掉四项中任一项都显著降低性能：**预训练**、**RFdiffusion 微调**、**自条件**、**m.s.e. 损失**。特别值得注意：从**从未训练的权重**起步、训练同等时长，效果远不如从预训练 RF 微调。

2. **与 Hallucination（with RF）的统计检验（Fig.2d）**——不是「看起来更好」，而是**双比例 z 检验，n = 400/条件，z = 9.5，P = 1.6 × 10⁻²¹**。而且作者指出 Hallucination 在**超过 100 氨基酸**后成功率迅速恶化——这正对上 RFdiffusion 的长链优势。

3. **外部基准 vs 自建基准（Fig.4a）**——**25 个问题全部收集自六篇已发表文献**，作者明确说「此前未在该基准集上做过优化（Hallucination 需要一些）」。这是防止「在自己的题上刷分」的关键设计。

4. **方法归因的诚实拆分（Fig.6b）**——作者没有把两个数量级的提升全部归给自己的方法，而是明确拆成**一个数量级来自 RFdiffusion、另一个来自 AF2 过滤**，并给出「若此前活动也用 AF2 过滤」的估计值（HA 0%、IL-7Rα 2.2%、InsR 5.5%、PD-L1 3.7%、TrkA 1.5%）。这是本文中最值得学习的一处自我约束。

5. **点突变阴性对照**——Ni²⁺ 设计中 **H52A 突变在 17/17** 案例中消除或显著降低结合；HA_20 的功能性也通过冷冻电镜位姿得到独立验证。

6. **结构验证的金标准**——HA_20 结合物 **0.63 Å** 的冷冻电镜结构与设计模型比对，这是全文中最硬的验证。

## 作者自述的局限

作者在正文中明确交代的：

1. **不能显式建模小分子**——「RFdiffusion 目前无法显式建模结合的小分子」；酶活性位点的底物只能用外部势**隐式**建模。
2. **酶活性位点需要微调**——作者明确括注「in silico success required fine tuning」。
3. **序列与结构未联合生成**——「鉴于扩散结构 + ProteinMPNN 的性能已足够好，未深入探索在 RFdiffusion 内同时设计结构与序列」。
4. **成功率的上限来源**——**测试的无条件设计中约一半可溶表达**（不是全部）；608 个对称设计中 SEC 确认寡聚态的只有 87–126 个。
5. **结合位点的适用范围**——作者明确限定：**「至少对这里所针对的非极性位点」**，并指出「仍需进一步研究来评估在**更极性的靶位点**以及**没有天然结合伙伴的位点**上的成功率」。
6. **特异性尚未全面表征**——竞争 BLI 显示 6/6 竞争结合，但作者明确说「**仍需进一步工作以充分表征全蛋白质组范围特异性**」。

## 我的评价

**这篇的核心贡献，是把「结构预测」与「结构设计」在架构层面统一了起来。**

RF 结构预测网络与扩散模型的一个去噪步，在数学形式上是同一件事：都是「把带噪坐标变换为预测的 X̂₀」。差别只在输入（序列 vs 扩散框架）与损失（框架对齐 vs 不对齐）。**一个简单的损失函数选择——从 FAPE 换成不做全局对齐的 m.s.e.——就打开了生成能力**，因为只有后者要求相邻时间步之间保持全局坐标系的连续性。这是我在本专题中见到的最漂亮的「方法论杠杆」之一。

**第二个值得讲的是作者对先前工作的诚实拆解。** Fig.4a 的 25 题基准全部来自他人论文、且作者声明未做针对性优化；Fig.6b 更把两个数量级的提升拆成「一个来自 RFdiffusion、一个来自 AF2 过滤」，并给出反事实估计值。这种写法让提升幅度更可信而非更响亮。

**第三个是「TIM barrel 对照」这个设计观察所承载的方法论启示。** 自然进化在经典 TIM barrel 的**局部变体**上走了 30 多亿年，而 RFdiffusion 能**直接把全局桶曲率改掉**——HE0626（18 链 18 螺旋）、HE0675（内 16 链外 16 螺旋）都是自然界几乎不可能出现的结构。这提示：**扩散模型与自然进化探索的是构象空间中不同的子集**，前者更像「跳出局部最优」的工具。

**汇报时必须讲清的边界（这篇容易被过度宣传）**：

- **「23/25」是 in silico 判据**，而这个判据虽然比 TM-score 严格得多、且已被证明与实验成功相关，但**它不是实验成功**。实验成功的数字要看小节：不对称寡聚体 608 个设计中 SEC 确认的只有 87 个（95% CI）；结合蛋白 19%；Ni²⁺ 36 个测 ITC 中 18 个结合。
- **无条件单体「约一半可溶」**——不要讲成「都能表达」。
- **不能建模小分子**，这对药物设计是硬约束；酶设计目前只能靠外部势隐式建模底物。
- **结合位点限非极性**这一限定是作者自己加的，引用时不能丢。

**最可靠的单个证据是 HA_20 的冷冻电镜结果**：0.63 Å（复合物）、0.6 Å（单独）、2.9 Å 密度图、界面侧链与 PDB 最近结构「非常不同」。这是「从头设计的结合蛋白达到原子级精度」这句话唯一的实证锚点，汇报时应把它作为核心，而不是用 19% 这个数字来代表成果——19% 说明的是效率，不是精度。

**与本模块其他篇的衔接**：ProteinMPNN 解决「给定骨架生成序列」，RFdiffusion 解决「生成骨架」，本文的酶活性位点与 Ni²⁺ 结合案例显示两者配合可以覆盖**功能**层面。而 Bennett 2026 的抗体设计把这两者合起来做表位定向设计。三篇构成从骨架到功能到应用的完整链条。

## 可复现要点

**模型与训练**
- 基础架构：RoseTTAFold 的更新版本（**注意：本文用的是更新版 RF，不是最初发表的三轨 RF**）
- 训练数据：PDB 采样结构；加噪**最多 200 步**；平移用 3D 高斯噪声、取向用旋转矩阵流形上的布朗运动
- 损失：**m.s.e.（不做对齐）**；关键在于**对全局参考系不不变**，以维持时间步间的坐标系连续性
- 从**预训练 RF 权重**微调（消融显示远优于从零训练）
- 自条件：模型接收自身上一步的预测作为模板输入（灵感来自 AF2 的 recycling）

**推理**
- 随机残基框架起步，典型 **200 步**反向扩散
- 每个设计采样 **8 条 ProteinMPNN 序列**
- 计算优化：推理时取更大的步长、提前截断轨迹（因为 RF 在每个时间步都预测最终结构）——100 残基蛋白最快 **11 秒**（NVIDIA RTX A4000）

**条件化类型**
- 对称性规格（点群 n 链 + 单体链长）
- 结合靶标 + **界面热点残基**（需在蛋白复合物上微调）
- 功能基序（以 3D 坐标输入，含序列与侧链）
- 折叠信息（二级结构 + block adjacency）
- 外部势（链内与链间接触势、底物口袋引导）

**验证**
- in silico：AF2 单序列预测；成功 = 平均 pAE < 5 + 全局主链 RMSD < 2 Å + 被支架化位点主链 RMSD < 1 Å
- 实验：SEC / SEC-MALS（寡聚态）、负染电镜（nsEM）、冷冻电镜、ITC（金属结合）、BLI（结合亲和力）、CD 谱与熔解曲线（热稳定性）

**重要参照结构**
- PDB **6WVS**（此前设计的 TIM barrel，用于折叠条件化）
- PDB **1A4I**（氧化还原酶 EC1，用于酶活性位点支架化）
- PDB **6BRP**、**6BRO**（C8 对称设计的最近 TM-align 参照）
- 复合物冷冻电镜：流感 HA 毒株 **A/USA:Iowa/1943 H1N1**

**计算规模**：608 个对称寡聚体设计送实验；每靶标 95 个结合蛋白设计送实验；44 个 Ni²⁺ 设计表达。
