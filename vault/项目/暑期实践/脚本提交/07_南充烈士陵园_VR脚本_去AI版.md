# 南充市烈士陵园 VR 全景脚本（无人机+云台+全景版）

作品暂名：西山英烈：南充市烈士陵园全景导览  
主体场馆：南充市烈士陵园  
拍摄方式：无人机获批后拍外景，云台拍地面动线，360 全景做主场景，手机空间扫描只做补充演示  
文字口径：能核实的写清楚，不能核实的写"待现场核对"

## 一、开拍前提醒

这版脚本按真实拍摄写，不按宣传片写。

1. 到场先找工作人员报备，确认哪些地方能拍，哪些地方不能拍。
2. 无人机只有在陵园同意、空域允许、现场安全的情况下起飞。
3. 陈列馆室内如果不允许全景拍摄，就改拍外景，热点里放经审核的文字资料。
4. 讲解词由队员真人录音。不要用太端正的播音腔，像给同学讲清楚即可。
5. 烈士人数、展室名称、建成时间等信息以现场展板和管理方确认为准。

## 三、场景脚本

### 01 西山入口到陵园方向

拍摄：如果无人机获批，从西山入口附近缓慢升高，拍 6至8 秒外景；如果不能飞，就用云台从路边标识和上行道路开始拍。

热点：

| 热点 | 内容 |
|---|---|
| 地图 | 标出顺庆区、西山风景区、陵园大致位置 |
| 说明 | 本片只拍南充市烈士陵园，不做多馆拼接 |
| 跳转 | 下一站：陵园大门 |

讲解词：

>我们现在在南充西山这边。今天只拍一个地方，南充市烈士陵园。前面几版方案写过很多馆，后来发现不现实，跑来跑去，素材也容易散。所以这次把时间留给一个场馆。能拍的拍扎实，不能拍的先记下来，回去核实。

### 02 陵园大门和牌坊

拍摄：360 全景放在大门内外都能看清的位置。云台从牌坊外慢慢推进，走路速度比平时慢一点。

热点：

| 热点 | 内容 |
|---|---|
| 场馆简介 | 南充市烈士陵园位于顺庆区西山风景区内 |
| 参观提醒 | 纪念场所内不喧哗，不在墓园区域摆拍 |
| 跳转 | 下一站：纪念碑 |

讲解词：

>到门口以后，声音会自然小一点。这里不是普通景点。我们先从大门进去，再到纪念碑、浮雕、陈列馆和墓园。拍摄时我们会避开游客正脸，也不会拍管理方不允许拍的地方。这个说明放在第一站，是为了让观看的人知道：全景不是想拍什么就拍什么。

### 03 烈士纪念碑前

拍摄：主全景放在纪念碑正前方。无人机如获批，可做一段高位俯看主轴线的视频。手机空间扫描可在碑前空地试扫一次，做成 20 秒演示热点。

热点：

| 热点 | 内容 |
|---|---|
| 纪念碑 | 介绍纪念碑位置和纪念功能，具体碑文现场核对 |
| 默哀提示 | 点击后出现"请停留 10 秒"提示 |
| 空间演示 | 手机空间扫描演示，若失败则删除 |
| 跳转 | 下一站：浮雕墙 |

讲解词：

>这一站放在前面。我们站的位置是纪念碑前，后面要看的展室、浮雕、碑林和墓园，最后都会回到这里。公开资料里提到陵园安放着多位烈士英灵，但具体数字我们到现场以后按展板和管理方说法核实，不在脚本里先写死。全景里我们会留一个十秒停顿，不放音乐，只让画面安静一下。

### 04 革命史浮雕墙

拍摄：云台沿浮雕横向慢移，至少拍两遍。全景放在能看见浮雕整体的位置。细节照片拍人物、队伍、文字，但不挡住参观通道。

热点：

| 热点 | 内容 |
|---|---|
| 浮雕细节 | 截取 3至4 个局部，配简短说明 |
| 时间线 | 北伐、红军、抗战、解放战争等分期，以现场展陈为准 |
| 拍摄花絮 | 云台横移 8 秒短视频 |
| 跳转 | 下一站：陈列馆入口 |

讲解词：

>浮雕墙不能一眼扫完。我们拍的时候会从左到右慢慢走，遇到文字和人物多的地方停一下。讲解也不把每个画面都硬解释，只挑看得清、能核实的内容说。看不明白的地方，先记下来，回去问老师或查陵园资料。

### 05 陈列馆入口

拍摄：如果室内允许拍摄，入口作为进馆前的全景；如果室内不允许，入口就是室内部分的替代讲解点。

热点：

| 热点 | 内容 |
|---|---|
| 展馆分区 | 展室数量和主题待现场核对 |
| 禁拍说明 | 标明哪些画面因管理要求不展示 |
| 跳转 | 下一站：红军时期展区或外部讲解点 |

讲解词：

>进陈列馆之前，我们先把规矩讲清楚。如果馆内能拍，我们就按展线走；如果不能拍，后面几个点位会用馆外全景加文字热点的方式呈现。红色场馆不是为了比赛给我们开方便门，能不能拍，要听现场管理要求。

### 06 红军时期展区或外部讲解点

拍摄：室内允许时拍展区全景；不允许时，在陈列馆外找安静位置拍全景，热点展示人物卡片。

热点：

| 热点 | 内容 |
|---|---|
| 人物卡片 | 任伟章等南充相关烈士，生卒年和事迹现场核对 |
| 地图 | 川陕苏区与南充周边关系，做手绘简图 |
| 跳转 | 下一站：抗战时期展区或外部讲解点 |

讲解词：

>这一段我们准备讲红军时期。人物资料不能凭印象写，尤其是生卒年、职务、牺牲地点这些细节，错一个就很不严肃。我们会先拍展板和笔记，晚上再整理成热点。全景里只放核实过的信息。

### 07 抗战时期展区或外部讲解点

拍摄：同上。若室内可拍，注意避开玻璃反光；若不可拍，用陈列馆外景和数据卡片替代。

热点：

| 热点 | 内容 |
|---|---|
| 数据卡片 | 南充抗战相关数据，以现场展陈为准 |
| 细节照片 | 展板局部或公开资料图，需获许可 |
| 跳转 | 下一站：解放战争/建设时期展区 |

讲解词：

>抗战这一部分很容易写成大词，但现场更打动人的往往是数字和名字。我们不会提前编一段很满的解说。到现场看展板，能核到什么就讲什么。讲不完没关系，讲错才是问题。

### 08 解放战争/建设时期展区或外部讲解点

拍摄：主全景加思考题热点。讲解词保持短，不做煽情结尾。

热点：

| 热点 | 内容 |
|---|---|
| 史实卡片 | 解放战争和社会主义建设时期相关展陈，现场核对 |
| 思考题 | "和平年代还会不会有牺牲？" |
| 跳转 | 下一站：题字碑林 |

讲解词：

>走到这一段，时间离我们更近。我们想放一个问题：和平年代是不是就没有牺牲了？答案其实不用急着说。观众可以先看展陈，再去下一站题字碑林。很多时候，场馆本身比讲解词更能说明问题。

### 09 题字碑林

拍摄：云台慢走，镜头不要贴太近。全景放在能看见碑林排列的位置。手机空间扫描可试扫一小段碑林空间，但不强求。

热点：

| 热点 | 内容 |
|---|---|
| 题字说明 | 具体题字人和内容以现场碑文为准 |
| 观看礼仪 | 不攀爬、不触摸、不把碑当合影背景 |
| 空间演示 | 手机空间扫描演示，若现场条件允许 |
| 跳转 | 下一站：墓园入口或外围 |

讲解词：

>题字碑林这一站适合慢一点。我们不把它拍成背景墙，也不让队员站成一排挡住碑文。镜头从一侧走过去，能看清多少是多少。碑文里的名字和内容，后期再逐条核对。

### 10 烈士墓园入口或外围

拍摄：只拍入口或外围公共区域。不要低空扫墓碑，不做队员摆拍。云台镜头走到入口前停住即可。

热点：

| 热点 | 内容 |
|---|---|
| 祭扫礼仪 | 保持安静，不喧哗，不摆拍 |
| 队员短句 | 每人一句真实感受，保留口语，不统一改口号 |
| 返回总览 | 回到场景 02 或总地图 |

讲解词：

>最后一站我们放在墓园入口或外围。这里不需要说太多。队员每个人写一句话，原样放进热点里。有人可能只写"我刚才不太敢说话"，这也可以。真实一点，比写一串漂亮词更好。

## 五、素材清单

| 类型 | 数量 | 说明 |
|---|---|---|
| 全景照片 | 10 张以上 | JPG/PNG，优先 8000×4000 |
| 普通照片 | 每点 3 张左右 | 环境、细节、队员工作照 |
| 云台视频 | 6至8 段 | 入园、浮雕、碑林、收尾必须有 |
| 无人机视频 | 3至5 段 | 获批后拍，不获批则删除该项 |
| MP3 讲解 | 10 段 | 真人录音，60 秒左右 |
| 手机空间扫描演示 | 0至3 段 | 只作补充热点 |
| 许可记录 | 1 份 | 电话、现场确认或书面材料 |

## 六、后期原则

1. 不用 AI 生成烈士形象。
2. 不用"宏大叙事"替代现场信息。
3. 热点文字每条控制在 80 字以内。
4. 普通照片要有来源和拍摄时间。
5. 史实由指导教师和陵园资料共同核对。

这版脚本的目标是能拍、能改、能提交。无人机和云台都保留，但任何设备都不能压过场馆本身。
