# 7.3pandas

以下是对Pandas库的详细总结，涵盖核心数据结构、数据读写、数据选择与过滤、数据清洗、数据合并、分组聚合、时间序列、可视化等核心模块，便于快速掌握和实战查阅。

---

## 一、Pandas简介

### 1. 什么是Pandas？

Pandas是Python的开源数据分析库，基于NumPy构建，提供高性能、易用的数据结构和数据分析工具，特别适合处理表格型、异质型数据。

### 2. 核心数据结构

- **Series**：一维带标签数组，类似字典或带索引的列表。
- **DataFrame**：二维表格型数据结构，带行索引和列索引，类似Excel或SQL表。

---

## 二、数据结构详解

### 1. Series

#### （1）创建

```python
import pandas as pd

# 列表创建，默认索引
s = pd.Series([1, 3, 5, 7])

# 自定义索引
s = pd.Series([1, 3, 5, 7], index=['a', 'b', 'c', 'd'])

# 字典创建（键为索引）
s = pd.Series({'a': 1, 'b': 3})

# 标量创建（重复值）
s = pd.Series(5, index=['a', 'b', 'c'])
```

#### （2）属性

- `s.values`：返回NumPy数组。
- `s.index`：返回索引。
- `s.dtype`：返回数据类型。

#### （3）访问

- `s['a']`：用标签访问。
- `s[0]`：用位置访问。
- `s.loc['a']`：显式索引访问。
- `s.iloc[0]`：隐式索引访问。

#### （4）切片

- `s.loc['a':'c']`：标签切片（闭区间）。
- `s.iloc[0:3]`：位置切片（左闭右开）。

---

### 2. DataFrame

#### （1）创建

```python
# 字典创建（键为列名）
df = pd.DataFrame({'A': [1, 2], 'B': [3, 4]})

# Series字典创建
df = pd.DataFrame({'A': pd.Series([1, 2]), 'B': pd.Series([3, 4])})

# 二维NumPy数组创建
df = pd.DataFrame(np.random.rand(3, 2), columns=['A', 'B'])

# 字典列表创建
df = pd.DataFrame([{'A': 1, 'B': 2}, {'A': 3, 'B': 4}])
```

#### （2）属性

- `df.values`：返回NumPy数组。
- `df.index`：行索引。
- `df.columns`：列索引。
- `df.shape`：形状（行数、列数）。
- `df.dtypes`：每列数据类型。

#### （3）访问

- **列**：`df['A']`或`df.A`。
- **行**：`df.loc['row']`或`df.iloc[0]`。
- **元素**：`df.loc['row', 'col']`或`df.iloc[0, 0]`。

## 三、数据读写

### 1. CSV

```python

df = pd.read_csv('file.csv')

df.to_csv('output.csv', index=False)
```

### 2. Excel

```python

```

### 3. JSON

```python
# 读取
df = pd.read_json('file.json')

# 写入

```

### 4. SQL


## 四、数据选择与过滤

### 1. 选择列

```python
df['A']          # 单列
df[['A', 'B']]   # 多列
```

### 2. 选择行

```python
df.loc['row']    # 按标签
df.iloc[0]       # 按位置
```

### 3. 条件过滤

```python
df[df['A'] > 2]              # 单条件
df[(df['A'] > 2) & (df['B'] < 5)]  # 多条件
```

### 4. isin、query

```python
df[df['A'].isin([1, 3])]     # isin
df.query('A > 2 & B < 5')    # query
```

## 五、数据清洗

### 1. 缺失值处理

```python
df.isnull()          # 检测缺失值
df.notnull()        # 检测非缺失值
df.dropna()         # 删除缺失值
df.fillna(0)        # 填充缺失值
```

### 2. 重复值处理

```python
df.duplicated()     # 检测重复
df.drop_duplicates() # 删除重复
```

### 3. 数据类型转换

```python
df['A'] = df['A'].astype('float')
```

### 4. 替换值

```python
df.replace(1, -1)  # 替换
```

## 六、数据合并

### 1. concat

```python
pd.concat([df1, df2], axis=0)  # 纵向拼接
pd.concat([df1, df2], axis=1)  # 横向拼接
```

### 2. merge

```python
pd.merge(df1, df2, on='key')           # 内连接
pd.merge(df1, df2, on='key', how='left')  # 左连接
```

### 3. join

```python
df1.join(df2, on='key')  # 按索引连接
```

## 七、分组与聚合

### 1. groupby

```python
grouped = df.groupby('A')
grouped.mean()          # 分组均值
grouped.sum()           # 分组求和
```

### 2. agg

```python
df.groupby('A').agg({'B': 'mean', 'C': 'sum'})
```

### 3. transform

```python
df['B_mean'] = df.groupby('A')['B'].transform('mean')
```

### 4. 数据透视表

```python
pd.pivot_table(df, values='B', index='A', columns='C', aggfunc='mean')
```

## 八、时间序列

### 1. 生成时间范围

```python
df['date'] = pd.to_datetime(df['date'])
```

```python

```

## 十、最佳实践

1. **使用**`with`**或上下文管理器**：确保文件正确关闭。
2. **避免链式索引**：用`.loc`或`.iloc`代替`df['A'][0]`。
3. **处理大数据时**：使用`chunksize`分块读取。
4. **时间索引**：对时间序列数据设置时间索引，便于重采样和窗口操作。
5. **内存优化**：使用`astype`转换数据类型，减少内存占用。
